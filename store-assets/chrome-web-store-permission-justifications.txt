치즈 스패너 1.3.9 — Chrome 웹 스토어 개인 정보 보호 관행

alarms 권한 요청 이유
사용자가 등록한 치지직 채널의 방송 시작 여부를 약 1분마다 확인하고, 사용자가 선택한 방송 시작 알림 및 자동 탭 열기 기능을 제공하기 위해 사용합니다. 해당 기능이 꺼져 있거나 활성화된 대상 채널이 없으면 주기적인 확인을 중단합니다.

notifications 권한 요청 이유
사용자가 알림을 켠 치지직 채널이 방송을 시작하면 채널명과 방송 제목을 데스크톱 알림으로 표시하기 위해 사용합니다. 선택 권한으로 선언되어 있으며, 사용자가 데스크톱 알림 기능을 켤 때 승인을 요청합니다. 알림을 누르면 해당 치지직 방송으로 이동합니다.
