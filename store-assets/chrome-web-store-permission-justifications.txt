치즈 스패너 1.4.6 — Chrome 웹 스토어 개인 정보 보호 관행

단일 목적
치즈 스패너는 치지직(chzzk.naver.com) 시청과 콘텐츠 탐색 경험 개선이라는 단일 목적의 확장 프로그램입니다. 광고 차단, 자동 화질, 재생 조작, 라이브·채팅 멀티뷰와 미리보기, 채팅·댓글 보기, 팔로잉 관리, 다시보기 검색, 방송 목록 필터, 방송 시간 표시와 시청 기록 등 치지직 이용 보조 기능을 제공합니다. 설정값은 Chrome 동기화 저장소에, 시청 기록은 이 기기의 로컬 저장소에 보관하며, 개발자 서버로 전송하지 않습니다.

storage 사용 근거
확장 프로그램의 설정과 기능 상태를 저장하기 위해 storage 권한을 사용합니다. 자동 화질, 스킵 시간, 검색 범위, 필터 설정, 기능별 켜짐·꺼짐, 고정 채널 목록과 팔로잉 폴더(폴더 이름·채널 ID·접기 상태)는 Chrome 동기화 저장소에 보관합니다. 라이브 시청 기록, 채널별 시청 시간 집계에 필요한 데이터, 팔로잉 라이브 제목 이력, 채널별 멀티뷰 딜레이, 채팅·사이드바 크기와 채팅 멀티뷰 구성 등은 이 기기의 로컬 저장소에 보관합니다. 저장된 데이터는 설정 유지와 시청 편의 기능 제공에 사용하며, 개발자 서버로 전송하지 않습니다.

scripting 사용 근거
동영상 광고 차단 설정에 따라 치지직 페이지에서 실행할 스크립트를 등록하거나 해제하기 위해 scripting 권한을 사용합니다. 또한 팔로잉 라이브 제목 이력을 켠 경우 약 1분마다, 시청 기록 페이지에서 후원 내역 갱신을 누른 경우 그때, 이미 열려 있는 치지직 탭에서 확장 패키지에 포함된 함수를 실행해 사용자의 기존 로그인 상태로 팔로잉 라이브 목록이나 로그인 계정을 확인합니다. 실행 대상은 시크릿 창이 아닌 치지직(chzzk.naver.com) 탭의 최상위 화면으로 제한합니다. 확장 패키지에 포함된 코드만 실행하고 원격 코드를 내려받아 실행하지 않으며, 로그인 쿠키·토큰을 읽거나 저장하지 않고 조회 결과를 개발자 서버로 전송하지 않습니다.

alarms 사용 근거
사용자가 등록한 치지직 채널의 방송 시작 여부를 약 1분마다 확인해 방송 시작 알림과 자동 탭 열기를 제공하고, 팔로잉 라이브 제목 이력 기능이 팔로우한 라이브 채널의 방송 제목을 약 1분마다 한 번에 확인해 이 기기에 기록하기 위해 사용합니다. 각 기능을 끄거나 방송 시작 알림 대상이 없으면 해당 주기 확인을 중단합니다.

notifications 사용 근거
사용자가 알림을 켠 치지직 채널이 방송을 시작하면 채널명과 방송 제목을 데스크톱 알림으로 표시하기 위해 사용합니다. 선택 권한으로 선언되어 있으며, 사용자가 데스크톱 알림 기능을 켤 때 승인을 요청합니다. 알림을 누르면 해당 치지직 방송으로 이동합니다.

호스트 권한 사용 근거
치지직(chzzk.naver.com) 접근 권한은 광고 차단, 자동 화질, 재생 조작, 라이브·채팅 멀티뷰, 채팅·댓글 보기, 팔로잉 고정·폴더, 방송 목록 검색·필터, 시청 기록 등 치지직 페이지 내 시청·탐색 보조 기능을 제공하기 위해 사용합니다.

api.chzzk.naver.com 및 apis.naver.com 접근 권한은 방송·채널 정보, 팔로우한 라이브 목록과 방송 제목, 라이브 멀티뷰·미리보기 재생 정보, 다시보기 정보, 댓글·답글과 검색 결과, 카테고리 정보, 방송 시간 통계를 조회하고 통나무 보상 자동 수령을 처리하기 위해 사용합니다. 열린 치지직 탭이 없으면 팔로우한 라이브 목록은 확장 백그라운드에서 조회합니다.

pstatic.net 하위 도메인 접근 권한은 라이브 멀티뷰 또는 라이브 호버 미리보기를 켤 때 요청하는 선택 권한입니다. 해당 기능의 영상 재생에 필요한 HLS 재생목록과 영상·오디오 세그먼트 등 미디어 데이터를 불러오는 데 사용합니다. 이 호스트에서 실행 코드를 내려받아 실행하지 않습니다.
