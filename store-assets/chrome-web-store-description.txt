이전 이름: Better Chzzk

치즈 스패너는 치지직(CHZZK) 시청과 탐색을 더 편하게 만들어 주는 비공식 Chrome 확장 프로그램입니다. 최대 6개 방송을 함께 보는 라이브 멀티뷰부터 자동 화질과 재생 조작, 채팅 모아보기, 팔로잉 관리, 다시보기 검색과 시청 기록까지 필요한 기능을 한곳에 모았습니다. 대부분의 기능을 설정에서 개별로 켜고 끌 수 있습니다.

[광고 차단 — 실험적]
• 라이브·다시보기의 방송 시작 전 광고, 중간 광고와 배너 광고 차단을 지원합니다. 확인된 광고 연결과 스케줄 처리를 보강했으며, 아직 실험적인 기능이라 불완전할 수 있습니다.
• 설정 → 플레이어 → 치지직 광고에서 동영상 광고 차단과 배너 광고 숨기기를 각각 켜고 끌 수 있습니다. 동영상 광고 차단은 기본 켜짐, 배너 광고 숨기기는 기본 꺼짐이며, 기존에 저장된 설정값은 유지됩니다. 동영상 광고 차단을 켜고 저장한 뒤에는 치지직 탭을 새로고침해 주세요.

[라이브 멀티뷰]
• 메인 포함 최대 6개 라이브 방송을 한 화면에서 함께 볼 수 있습니다. 라이브 URL을 입력하거나 사이드바의 팔로잉 채널을 영상 영역으로 끌어 추가합니다.
• 방송 추가에서 방송인 닉네임으로 검색하고, 팔로워순 상위 5개 결과 중 방송 중인 채널을 눌러 추가할 수 있습니다.
• 설정 → 플레이어 → 멀티뷰에서 기능을 켜고 영상 재생 권한을 허용한 뒤 저장해 주세요. 라이브 플레이어 하단의 넓은 화면 버튼 왼쪽 격자 버튼으로 멀티뷰를 켜고 끕니다.
• 영상을 드래그해 위치를 바꾸고, 모서리와 구분선으로 크기를 조절합니다. Alt+드래그로 박스 안 영상 위치도 조절할 수 있습니다.
• 보조 영상을 메인 영상 중앙에 놓으면 메인 방송과 채팅·방송 정보가 함께 바뀝니다.
• 각 화면의 재생·음소거·볼륨을 따로 조절합니다. 보조 영상 우클릭으로 음소거를 전환하고, 스피커나 볼륨 슬라이더 위에서 휠로 소리를 조절할 수 있습니다.
• 채널별 싱크를 0.1초 단위로 조절해 영상과 소리를 함께 맞춥니다. 조절한 딜레이는 다음 방송에도 불러오며, 빨리 감기로 라이브 위치에 복귀할 수 있습니다.
• 저장된 딜레이를 읽지 못하면 해당 보조 화면의 재생 재시도 버튼으로 다시 불러올 수 있습니다.
• 채팅창 상단의 멀티뷰 설정에서 방송 추가·제거, 기본 배치, 보조 방송 정렬과 싱크를 관리합니다. 자유 배치를 켜면 플레이어 밖의 사이드바·채팅 위까지 창을 옮기고 크기를 조절하며 겹칠 수 있습니다. 방송 링크를 끌어오면 보조 화면 기본 크기의 안내가 포인터를 따라 움직이며, 원하는 위치에 놓아 추가할 수 있습니다. 끄면 분할 배치로 돌아갑니다. 같은 탭에서 새로고침해도 선택·배치·소리 설정을 이어서 사용합니다.

[플레이어와 시청 편의]
• LIVE 배지 숨김, 방송 시작 시간 표시와 오프라인 방송 자동 새로고침을 지원합니다.
• 플레이어의 클립·PIP 버튼을 각각 숨길 수 있습니다. 기본값은 꺼짐이며, 이미 실행 중인 PIP는 종료하지 않습니다.
• 영상의 톱니바퀴 설정 메뉴에서 스트림 정보 열기를 선택하면 해상도, 비트레이트, 남은 재생 버퍼와 FPS를 확인할 수 있습니다. 하드웨어 가속 표시는 WebGL 렌더러 기준의 추정값입니다.
• 자동 화질 복구: 설정한 목표 화질(1080p·720p·480p)을 우선 적용하고, 없으면 가능한 하위 화질을 선택합니다.
• 화질 고정 강화: 지원되는 라이브 플레이어에서 프로그램 미설치로 취소되던 1080p·720p 선택을 유지합니다. 첫 재생이 시작된 뒤 목표 화질을 적용하고, 직접 일시정지한 상태는 유지합니다. 기존 그리드 우회 방식은 재생 정보를 변경하므로 네이버 이용약관의 서비스·소프트웨어 수정·변형 제한에 저촉될 소지가 있어, 배포와 지원을 계속하기 어렵다고 판단해 1.3.7에서 지원을 종료했습니다. 현재 화질 고정 기능은 설치된 그리드 프로그램의 사용을 차단하지 않습니다.
• 시청 방해 팝업 제거: 시청에 방해되는 팝업을 제거합니다.
• 다시보기·타임머신 앞뒤 스킵, 스킵 시간 조절, 일시정지 중 실시간 복귀 방지, 라이브 끝 지점으로 이동을 지원합니다.
• Space 또는 영상 화면의 마우스 왼쪽 버튼을 길게 누르는 동안 2배속을 적용하며, 두 조작을 옵션 하나로 켜고 끕니다. [ / ] 키로 0.25~4배속 범위에서 0.25배씩 조절하고 \ 키로 1배속을 복원합니다. 감소·증가 키를 길게 누르면 연속 조절합니다. 세 배속 키는 C 자막 키 등 기본 조작과 겹치지 않는 지원 키로 변경할 수 있습니다.
• 단축키 기본값 복원 버튼으로 배속 감소·증가·1배속 복원 키만 초기화하고, 옵션 저장으로 적용할 수 있습니다.
• Space·M·F·T 키가 반응하지 않을 때 사용할 수 있는 기본 단축키 복구 옵션을 제공합니다. 기본값은 꺼짐이며 채팅·검색 입력 중에는 개입하지 않습니다.
• 볼륨 휠 조절, 볼륨 표시와 오디오 컴프레서를 제공합니다.
• 영상 위에서 휠을 굴리면 커서 위치를 중심으로 최대 5배까지 확대하고, 드래그로 이동할 수 있습니다. 확대 박스의 슬라이더로 1%씩 세밀하게 조절할 수 있으며, 확대 버튼을 켠 동안만 적용하거나 영상 위에서 항상 적용하도록 설정할 수 있습니다.
• 컴프레서 전용 볼륨바로 압축 후 출력 크기를 조절합니다. 컴프레서의 켜짐·꺼짐과 출력 볼륨은 탭별로 기억하며, 같은 탭의 새로고침·이동 후 유지하고 탭 종료·브라우저 재시작 시 초기화합니다.
• 다시보기 장면의 실제 방송 시각과 타임머신의 실시간 대비 지연 시간을 표시합니다.

[채팅과 다시보기 댓글]
• 채팅 상단의 주간 후원·통나무 파워 랭킹을 숨기는 옵션을 제공합니다. 기본값은 꺼짐입니다.
• 채널 채팅 링크를 제공합니다.
• 방송자·채팅 운영자 모아보기: 사용자별 필터, 미확인 채팅 개수, 맨 아래로 이동, 여러 채팅 선택·복사를 지원합니다. 패널에서 실제로 화면에 보인 채팅만 확인 처리합니다.
• 모아보기를 켜면 일반 채팅창의 방송자·운영자 메시지도 닉네임 색상의 옅은 배경과 얇은 테두리로 강조합니다. 라이트·다크 모드에 맞춰 농도를 조절하고 본문색과 채팅 줄 크기를 유지합니다.
• 라이브·다시보기 채팅의 실제 서버 작성 시각을 표시하고, 환영·필터링 안내 메시지를 숨길 수 있습니다. 라이브와 다시보기의 시각 표시는 각각 켜고 끌 수 있으며 기본값은 꺼짐입니다.
• 블라인드 채팅은 페이지에서 확인할 수 있는 원문만 표시합니다. 원문이 없으면 기존 안내를 유지합니다.
• 다시보기 우측 패널에서 댓글·답글·타임코드를 확인할 수 있습니다. 라이브 채팅 다시보기가 없는 영상에도 댓글 패널을 제공합니다.
• 페이지 내부 이동 후 누락된 다시보기 채팅을 복구하는 보조 기능을 제공합니다.

[팔로잉과 방송 탐색]
• 설정의 방송 알림 탭에서 등록한 채널이 방송을 시작하면 데스크톱 알림을 받거나 해당 방송을 배경 탭으로 자동으로 열 수 있습니다. 치지직 우측 상단의 방송 알림 버튼에서 채널명을 검색하고 데스크톱 알림·자동 입장을 각각 켜고 끌 수 있습니다. 버튼 표시는 옵션으로 끌 수 있으며, 숨겨도 기존 알림·자동 열기는 유지됩니다. 알림과 자동 열기는 채널별로 각각 선택하며 기본값은 꺼짐입니다. 켜진 대상만 약 1분마다 확인하고, 같은 방송을 반복해서 알리거나 열지 않습니다.
• 치지직 상단의 스튜디오·치즈·알림 버튼을 각각 숨길 수 있습니다. 기본값은 모두 꺼짐입니다.
• 팔로잉 채널 고정과 오프라인 채널 최상단 고정, 사이드바 치즈팜·인기 카테고리·다가오는 방송 일정·파트너 스트리머·서비스 바로가기 숨김을 지원합니다.
• 접힌 목록 밖의 고정 채널을 보충하고, 선택한 채널로 페이지 내부에서 이동합니다.
• 팔로잉 오프라인 채널 숨기기를 켜면 고정 여부와 관계없이 사이드바의 오프라인 채널을 숨깁니다. 기본값은 꺼짐입니다.
• 팔로잉 목록 자동 새로고침과 현재 라이브의 제목 변경 이력을 제공합니다.
• 팔로잉 목록 상태 기억을 켜면 구역 접기와 더보기의 마지막 선택을 새로고침·페이지 이동 후 복원합니다. 기본값은 꺼짐입니다.
• 전체 방송 목록에는 시청자 10명 이상인 방송 수와 해당 방송의 동시 시청자 합계를 표시합니다. 같은 사람이 여러 방송을 보는 경우의 중복을 제거한 인원 수는 아닙니다.
• 팔로잉·방송 목록에서 라이브를 미리 볼 수 있으며, 소리와 볼륨을 조절할 수 있습니다. 전체 방송 목록 미리보기는 우클릭으로 확대할 수 있습니다.
• 팔로잉 미리보기의 카테고리 링크를 누르면 같은 탭에서 해당 카테고리의 방송 목록으로 이동합니다. 진행 시간은 오른쪽 끝에 선명하게 표시합니다.
• 라이브·영상·클립 목록 검색, 팔로워·시청자·조회수·진행 시간 필터, 팔로워 수 표시와 긴 제목 툴팁을 제공합니다.
• 채널 다시보기를 제목과 댓글 내용으로 검색할 수 있습니다.

[방송 통계와 기록]
• 채널별 평균 방송 시간과 월간 방송 달력을 제공합니다. 다시보기로 확인된 여러 날의 연속 방송도 달력에 표시하고, 방송 시간을 3시간 단위의 9단계 색상과 범례로 구분합니다. 내 시청 시간은 해당 시청 기록이 있을 때만 표시합니다.
• 라이브 시청 시간을 이 브라우저에 기록하고, 전용 시청 기록 페이지에서 목록·달력·통계를 확인할 수 있습니다.
• 시청 기록 페이지의 라이브 내역·많이 본 채널·내 채팅·후원 탭에서 기간·날짜·검색 조건을 함께 적용합니다.
• 내 채팅·일반 후원 기록 저장을 각각 켜면 로그인한 계정의 라이브 채팅에서 전송이 확인된 새 내역을 이 기기에 저장합니다. 기본값은 꺼짐이며 최소 시청 시간에 도달하기 전에도 활동을 기록합니다.
• 로그인된 치지직 탭을 열어 두고 후원 내역 갱신을 누르면 처음에는 전체 기간을, 이후에는 새 내역이 생길 수 있는 달과 미조회 달만 확인합니다. 내 후원에서 갱신한 내역과 새 실시간 후원을 하나의 목록·합계로 보고 같은 기간은 중복 집계하지 않습니다. 후원 갱신 초기화로 조회 상태를 지우면 다음 갱신에서 전체 기간을 다시 확인합니다.
• 시청 기록은 자동 백업되지 않습니다. 확장 프로그램이나 브라우저 프로필·확장 데이터를 삭제하면 기록도 지워질 수 있으며, 별도 백업 없이는 재설치해도 복구할 수 없습니다. 설정과 시청 기록 페이지에 주의 안내를 제공합니다.
• 통나무 보상 자동 받기와 시청 방해 팝업 제거를 제공합니다.

[기본 설정과 이용 안내]
• 업데이트 후에는 열려 있는 치지직 탭을 직접 새로고침해 주세요. 1.3.8부터는 이전 버전의 화질 기능 변경 공지 팝업을 표시하지 않습니다.
• 동영상 광고 차단과 스트림 정보는 기본으로 켜져 있습니다. 기존에 저장한 설정은 유지합니다.
• 통나무 보상 자동 받기는 기본으로 켜져 있습니다. 1시간 시청 보상은 치지직이 표시한 수령 버튼으로 받고, 그 외 대기 중인 보상은 치지직이 제공한 claim 목록과 보상 API로 처리합니다. 시청 시간을 조작하지 않습니다.
• 배너 광고 숨기기, 채팅 타임스탬프, 환영 메시지 제거, 블라인드 원문 표시, 방송자·운영자 모아보기, 볼륨 표시, 컴프레서 버튼, 기본 단축키 복구, 휠로 화면 확대, 라이브 멀티뷰, 라이브 호버 미리보기는 기본으로 꺼져 있습니다.
• 라이브 멀티뷰 또는 라이브 호버 미리보기를 켤 때 영상 제공 호스트(pstatic.net)의 추가 접근 권한을 요청합니다. 미리보기 소리 설정은 켜짐, 볼륨은 15%가 기본이며 브라우저의 자동재생 제한에 따라 음소거로 시작할 수 있습니다.
• 방송 시작 확인에는 alarms 권한을 사용하며, 데스크톱 알림을 켤 때만 선택 권한인 notifications 승인을 요청합니다. 기능이 꺼져 있으면 방송 시작 확인을 중단합니다.
• 스킵 시간, 배속 키, 볼륨 조절 단위, 검색 범위, 필터 기준, 새로고침 주기, 채팅 보관 개수 등을 조정할 수 있습니다.

멀티뷰 배치·크기·박스 안 영상 위치·자리별 소리와 자유 배치 사용 여부·창 위치·겹침 순서는 탭 세션에 보관되며 치지직 페이지 스크립트에서도 읽을 수 있습니다. 채널별 목표 딜레이는 확장 로컬 저장소에 보관해 다음 방송에도 불러옵니다.
설정과 고정 채널 목록은 Chrome 동기화 저장소에 보관됩니다. 시청 기록, 팔로잉 라이브 제목 이력, 팔로잉 목록과 설정 묶음의 펼침·접힘 선택, 컴프레서의 탭별 선택과 출력 볼륨, 댓글 요청용 임의 식별자는 이 기기의 로컬 저장소에 보관됩니다. 댓글 요청용 식별자는 댓글을 불러올 때 네이버 댓글 API에 전달합니다. 이 데이터를 개발자 서버로 전송하지 않습니다.
1.3.8부터 화질 기능 변경 공지 정보를 더 이상 저장하지 않으며, 로컬 저장소에 남은 공지 정보는 확장 시작·설치·업데이트 시 정리합니다. 글꼴은 확장에 포함된 Pretendard를 사용하며 외부 폰트 서버에 접속하지 않습니다.

방송자·운영자 모아보기 패널의 채팅과 사용자 목록, 미확인 상태는 현재 페이지 메모리에서만 유지하며 새로고침하거나 다른 방송으로 이동하면 초기화됩니다. 별도 옵션인 내 채팅·일반 후원 기록과 사용자가 가져온 과거 후원은 이 기기의 로컬 확장 저장소에 보관하며 개발자 서버로 전송하지 않습니다. 활동 내용은 방송별 최근 500개·전체 최근 3,000개, 가져온 후원은 전체 3,000개까지 보관합니다. 해당 기록이나 전체 기록을 삭제하면 함께 삭제됩니다.

방송 시작 알림·자동 열기의 대상 채널과 중복 방지 상태도 이 기기의 로컬 확장 저장소에 보관합니다. 알림에는 치지직에서 확인한 채널명·방송 제목을 표시하며, 다른 사이트의 탭 목록이나 방문 기록을 수집하지 않습니다.
