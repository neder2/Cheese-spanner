치즈 스패너는 치지직 시청과 탐색을 편하게 만드는 비공식 Chrome 확장 프로그램입니다. 대부분의 기능을 설정에서 개별로 켜고 끌 수 있습니다.

[광고 차단]
• 라이브·다시보기의 방송 시작 전 광고, 중간 광고와 배너 광고 차단을 지원합니다.
• 동영상 광고 차단은 기본 켜짐, 배너 광고 숨기기는 기본 꺼짐입니다. 동영상 광고 차단을 켜고 저장한 뒤에는 치지직 탭을 새로고침해 주세요.
• 간편 플레이어에서도 동영상 광고 차단을 지원합니다.

[라이브 멀티뷰]
• 최대 6개 방송을 한 화면에서 시청합니다. 라이브 URL, 닉네임 검색, 팔로잉 채널 드래그로 방송을 추가합니다.
• 영상 위치·크기와 자유 배치를 조절하고, 화면별 재생·볼륨·싱크를 따로 관리합니다.
• 보조 영상을 메인으로 바꾸면 채팅과 방송 정보도 함께 전환됩니다. 배치와 소리는 같은 탭에서 새로고침 후에도 유지됩니다.
• 보조 영상도 확대할 수 있습니다. 각 영상의 확대 배율과 이동 위치를 따로 조절하며, 확대 버튼·휠·단축키와 Alt 드래그 배치 이동을 지원합니다.

[영상 녹화]
• 라이브·다시보기 플레이어 오른쪽 아래의 녹화 버튼을 누르면 현재 영상과 소리를 저장합니다. 다시 누르면 녹화를 멈추고 파일을 완성합니다.
• 녹화 중에는 빨간 정지 버튼과 경과 시간을 표시합니다. 녹화 버튼은 기본 꺼짐이며, 설정의 플레이어 → 영상 녹화에서 켤 수 있습니다.
• Chrome이 지원하면 MP4, 아니면 WebM으로 저장합니다. 파일 이름에는 녹화 시작일·방송 제목·스트리머 이름을 넣습니다.
• 확장 설정의 폴더 선택에서 원하는 저장 폴더를 지정합니다. 작은 설정 팝업에서는 전체 설정 탭을 먼저 엽니다. 선택한 폴더는 이 기기의 브라우저 프로필에만 기억합니다.
• 플레이어 톱니바퀴의 녹화 저장 폴더에서도 탐색기를 바로 열 수 있습니다. 여기서 선택한 폴더는 현재 탭의 다음 녹화부터 우선 적용하며, 새로고침하면 확장 설정의 기본 폴더를 사용합니다.
• 폴더를 따로 선택하지 않으면 Chrome 다운로드 폴더에 저장합니다. 다운로드 폴더 안의 하위 폴더를 지정하려면 선택 권한인 다운로드 관리를 허용해야 합니다.
• 전체 영상을 탭 메모리에 쌓지 않고 녹화 조각을 순서대로 저장합니다. 파일을 완성하려면 탭을 닫거나 새로고침하기 전에 녹화를 멈춰 주세요.
• 녹화는 사용자가 버튼을 누를 때만 시작하며, 파일은 이 기기에만 저장합니다. 녹화한 콘텐츠의 이용은 방송 저작권과 치지직 이용약관을 따라 주세요.

[플레이어와 시청 편의]
• 1080p·720p·480p 중 목표 화질을 자동 적용하고, 없으면 가능한 하위 화질을 선택합니다.
• 시청 방해 팝업 제거, 오프라인 방송 자동 새로고침, 다시보기·타임머신 스킵과 일시정지 중 실시간 복귀 방지를 지원합니다.
• Space·좌클릭 홀드 2배속, 0.25~4배속 단축키와 기본 단축키 복구 옵션을 제공합니다.
• 볼륨 휠 조절·볼륨 표시·오디오 컴프레서, 최대 5배 영상 확대, 채팅·사이드바 너비와 채팅 높이 조절, 채팅·사이드바 좌우 위치 변경을 지원합니다.
• 영상 색을 플레이어 바깥의 상단·채팅창·사이드바 가장자리까지 은은하게 번지게 하는 앰비언트 효과를 제공합니다(기본 꺼짐).
• 스트림 정보에서 해상도·라이브 비트레이트 설정값·버퍼·FPS와 라이브 지연 추정 그래프를 확인합니다.
• 방송 시작 시각, 다시보기 장면의 방송 시각과 방송 시작·종료 시각, 타임머신 지연을 표시하고, LIVE 배지와 클립·PIP 버튼을 숨길 수 있습니다.
• 미니 플레이어와 확장 패널의 겹침을 줄이고, 같은 영상을 페이지 안 작은 플레이어로 보고 돌아오면 확대 배율과 위치를 유지합니다.

[채팅과 다시보기 댓글]
• 방송자·운영자 채팅 모아보기, 사용자별 필터, 미확인 개수, 선택·복사와 원본 채팅 강조를 제공합니다.
• 채팅창 오른쪽 위 ⋯ → 문구 숨김에서 숨길 문구를 추가·관리합니다. 확장 설정의 채팅 → 문구 숨김에서도 관리할 수 있습니다.
• 문구 숨김은 라이브·다시보기 채팅과 채팅 모아보기에 적용됩니다. 전체 적용은 모든 문구에 같은 조건을, 부분 적용은 문구마다 완전 일치·포함 조건을 지정합니다. 닉네임은 검사하지 않으며 영문 대소문자는 구분하지 않습니다.
• 숨길 문구는 최대 50개, 한 문구 100자, 전체 2,000자까지 등록합니다. 기본 켜짐이지만 빈 목록에서는 아무 채팅도 숨기지 않습니다. 문구 삭제·기능 해제로 다시 표시하며, 채팅 삭제나 사용자 차단은 하지 않습니다.
• 채팅창 후원 메시지 숨기기를 켜면 라이브·채팅 팝업·다시보기·채팅 멀티뷰의 일반·미션·파티 후원 메시지를 숨깁니다(기본 꺼짐). 후원 기록과 영상·음성은 유지합니다.
• 라이브·다시보기 채팅 작성 시각을 표시하고, 환영·필터링 안내와 주간 후원·통나무 랭킹을 숨길 수 있습니다.
• 페이지에서 확인할 수 있는 블라인드 채팅 원문을 표시합니다.
• 다시보기 댓글·답글·타임코드와 채널 채팅 바로가기를 제공합니다.
• 로그인하면 다시보기 채팅에서 내가 쓴 채팅을 강조합니다.
• 채팅 멀티뷰로 다른 채널의 채팅을 최대 4개까지 치지직 채팅 팝업 화면으로 함께 봅니다.

[팔로잉과 방송 탐색]
• 팔로잉 채널 고정·오프라인 채널 숨김, 목록 자동 새로고침과 펼침 상태 기억을 지원합니다.
• 사이드바에서 팔로잉 채널을 끌어 폴더로 묶고 접고 펼치며, 팔로잉 목록의 최대 표시 줄 수를 정할 수 있습니다.
• 팔로잉·방송 목록의 라이브 미리보기와 소리 조절을 제공합니다.
• 팔로우한 라이브 채널의 방송 제목을 약 1분마다 모아, 방송 화면과 팔로잉 화면의 제목 옆에서 다시보기처럼 이전 방제를 보여 줍니다.
• 라이브·영상·클립 검색과 팔로워·시청자·조회수·진행 시간의 이상·이하·범위 필터(탭 안에서 목록별 유지), 팔로워 수 표시와 긴 제목 툴팁을 지원합니다.
• 전체 방송 정렬 줄의 + 제외 추가에서 카테고리를 검색해 선택하거나 태그를 입력하고 Enter를 눌러 숨길 수 있습니다. 제외 목록은 이 Chrome 프로필에 보관하며 각 박스의 ×로 해제합니다.
• 전체 방송 목록의 새로고침 버튼으로 현재 정렬을 유지하면서 방송 목록과 시청자 수를 다시 불러옵니다.
• 전체 방송 목록에서 시청자 10명 이상인 방송 수와 동시 시청자 합계를 표시합니다. 여러 방송을 보는 시청자의 중복은 제거하지 않습니다.
• 등록한 채널의 방송 시작 알림·배경 탭 자동 입장, 사이드바 메뉴와 상단 버튼 숨기기를 제공합니다.
• 채널 다시보기를 제목과 댓글 내용으로 검색합니다.

[방송 통계와 기록]
• 다시보기 자료를 기준으로 채널별 일평균 방송 시간과 월간 방송 달력을 제공합니다.
• 라이브 시청 기록을 목록·달력·많이 본 채널 통계로 확인하고, 로그인한 계정의 내 채팅·일반 후원 기록을 선택적으로 저장합니다.
• 후원 내역 갱신과 시청 기록·내 채팅의 파일 백업·불러오기를 지원합니다. 후원 기록은 백업에서 제외됩니다.
• 통나무 보상 자동 받기를 제공합니다.

[기본 설정과 이용 안내]
• 자동 화질·동영상 광고 차단·통나무 보상 자동 받기·라이브 시청 기록·팔로잉 라이브 제목 이력·채팅 문구 숨김은 기본 켜짐입니다. 기존에 저장한 설정은 유지합니다.
• 멀티뷰·채팅 멀티뷰·팔로잉 폴더·라이브 미리보기·앰비언트 효과·영상 녹화 버튼·채팅창 후원 메시지 숨기기·방송 시작 알림·자동 입장·내 채팅·후원 기록 저장은 기본 꺼짐입니다. 필요한 기능을 설정에서 켜고 저장해 주세요.
• 멀티뷰·미리보기를 켤 때 영상 제공 호스트(pstatic.net)의 접근 권한을, 데스크톱 알림을 켤 때 알림 권한을 요청합니다.
• 녹화 파일을 Chrome 다운로드 폴더의 하위 폴더에 저장할 때 다운로드 관리 권한을 요청합니다. 이 권한을 허용하지 않아도 기본 다운로드 폴더에 저장할 수 있습니다. 탐색기로 직접 선택한 폴더는 해당 폴더의 접근 허용을 사용합니다.
• 스킵 시간, 배속 키, 볼륨 조절 단위와 검색·필터 범위 등을 조정할 수 있습니다.
• 설정을 JSON 파일로 저장하고, 바뀌는 항목을 확인한 뒤 불러올 수 있습니다. 시청·채팅·후원 기록과 탐색기로 선택한 녹화 폴더의 접근 정보는 설정 파일에 넣지 않습니다.
• 업데이트 후에는 열린 치지직 탭을 새로고침해 주세요. 새 기능 안내는 설정에서 끄거나 다시 볼 수 있습니다.
• 기록은 자동 백업되지 않습니다. 확장이나 브라우저 프로필·확장 데이터를 삭제하면 기록도 지워질 수 있습니다. 이미 저장한 녹화 파일은 남으며 사용자가 직접 관리합니다.

[데이터와 개인정보]
설정·고정 채널·팔로잉 폴더는 Chrome 동기화 저장소에, 시청·내 채팅·후원 기록, 팔로잉 방제 이력과 알림 대상·기능별 기억값은 이 기기의 로컬 저장소에 보관합니다. 개발자 서버로 전송하지 않습니다.
팔로잉 방제 이력은 치지직에 로그인돼 있으면 팔로잉 라이브 목록을 약 1분마다 한 번 조회해 모읍니다.
멀티뷰 배치·소리는 탭 세션에 보관되며 치지직 페이지 스크립트에서도 읽을 수 있습니다. 방송자·운영자 모아보기의 채팅은 페이지 메모리에서만 유지하며 새로고침·방송 이동 시 초기화됩니다.
녹화 파일·영상 프레임·소리는 외부 서버로 전송하지 않습니다. 확장 설정에서 선택한 녹화 폴더의 접근 정보는 이 기기의 확장 전용 저장소에 보관하며 동기화하지 않습니다. 플레이어에서 선택한 폴더의 접근 정보는 현재 탭의 확장 전용 메모리에만 유지합니다.
다운로드 관리 권한은 확장에서 생성한 녹화 다운로드의 저장 경로를 지정하는 데 사용합니다. 다른 다운로드의 주소·파일 이름은 저장하거나 변경하지 않습니다.
댓글 조회용 임의 식별자는 네이버 댓글 API에 전달합니다. 백업 파일에는 시청 기록과 채팅 내용 등 개인정보가 암호화 없이 포함됩니다.

NAVER·치지직과 제휴한 프로그램이 아니며, 치지직의 화면·API 변경에 따라 일부 기능이 동작하지 않을 수 있습니다.
