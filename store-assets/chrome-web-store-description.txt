치즈 스패너(이전 이름: Better Chzzk)는 치지직 시청과 탐색을 편하게 만드는 비공식 Chrome 확장 프로그램입니다. 대부분의 기능을 설정에서 개별로 켜고 끌 수 있습니다.

[광고 차단]
• 라이브·다시보기의 방송 시작 전 광고, 중간 광고와 배너 광고 차단을 지원합니다.
• 동영상 광고 차단은 기본 켜짐, 배너 광고 숨기기는 기본 꺼짐입니다. 동영상 광고 차단을 켜고 저장한 뒤에는 치지직 탭을 새로고침해 주세요.

[라이브 멀티뷰]
• 최대 6개 방송을 한 화면에서 시청합니다. 라이브 URL, 닉네임 검색, 팔로잉 채널 드래그로 방송을 추가합니다.
• 영상 위치·크기와 자유 배치를 조절하고, 화면별 재생·볼륨·싱크를 따로 관리합니다.
• 보조 영상을 메인으로 바꾸면 채팅과 방송 정보도 함께 전환됩니다. 배치와 소리는 같은 탭에서 새로고침 후에도 유지됩니다.

[플레이어와 시청 편의]
• 1080p·720p·480p 중 목표 화질을 자동 적용하고, 없으면 가능한 하위 화질을 선택합니다.
• 시청 방해 팝업 제거, 오프라인 방송 자동 새로고침, 다시보기·타임머신 스킵과 일시정지 중 실시간 복귀 방지를 지원합니다.
• Space·좌클릭 홀드 2배속, 0.25~4배속 단축키와 기본 단축키 복구 옵션을 제공합니다.
• 볼륨 휠 조절·볼륨 표시·오디오 컴프레서, 최대 5배 영상 확대와 채팅·사이드바 너비 조절을 지원합니다.
• 스트림 정보에서 해상도·라이브 비트레이트 설정값·버퍼·FPS와 라이브 지연 추정 그래프를 확인합니다.
• 방송 시작 시각·다시보기 방송 시각·타임머신 지연을 표시하고, LIVE 배지와 클립·PIP 버튼을 숨길 수 있습니다.

[채팅과 다시보기 댓글]
• 방송자·운영자 채팅 모아보기, 사용자별 필터, 미확인 개수, 선택·복사와 원본 채팅 강조를 제공합니다.
• 라이브·다시보기 채팅 작성 시각을 표시하고, 환영·필터링 안내와 주간 후원·통나무 랭킹을 숨길 수 있습니다.
• 페이지에서 확인할 수 있는 블라인드 채팅 원문을 표시합니다.
• 다시보기 댓글·답글·타임코드와 채널 채팅 바로가기를 제공합니다.

[팔로잉과 방송 탐색]
• 팔로잉 채널 고정·오프라인 채널 숨김, 목록 자동 새로고침과 펼침 상태 기억을 지원합니다.
• 팔로잉·방송 목록의 라이브 미리보기와 소리 조절, 팔로잉 페이지의 방송 제목 이력을 제공합니다.
• 라이브·영상·클립 검색과 팔로워·시청자·조회수·진행 시간 필터, 팔로워 수 표시와 긴 제목 툴팁을 지원합니다.
• 전체 방송 목록에서 시청자 10명 이상인 방송 수와 동시 시청자 합계를 표시합니다. 여러 방송을 보는 시청자의 중복은 제거하지 않습니다.
• 등록한 채널의 방송 시작 알림·배경 탭 자동 입장, 사이드바 메뉴와 상단 버튼 숨기기를 제공합니다.
• 채널 다시보기를 제목과 댓글 내용으로 검색합니다.

[방송 통계와 기록]
• 다시보기 자료를 기준으로 채널별 일평균 방송 시간과 월간 방송 달력을 제공합니다.
• 라이브 시청 기록을 목록·달력·많이 본 채널 통계로 확인하고, 로그인한 계정의 내 채팅·일반 후원 기록을 선택적으로 저장합니다.
• 후원 내역 갱신과 시청 기록·내 채팅의 파일 백업·불러오기를 지원합니다. 후원 기록은 백업에서 제외됩니다.
• 통나무 보상 자동 받기를 제공합니다.

[기본 설정과 이용 안내]
• 자동 화질·동영상 광고 차단·통나무 보상 자동 받기·라이브 시청 기록은 기본 켜짐입니다. 기존에 저장한 설정은 유지합니다.
• 멀티뷰·라이브 미리보기·방송 시작 알림·자동 입장·내 채팅·후원 기록 저장은 기본 꺼짐입니다. 필요한 기능을 설정에서 켜고 저장해 주세요.
• 멀티뷰·미리보기를 켤 때 영상 제공 호스트(pstatic.net)의 접근 권한을, 데스크톱 알림을 켤 때 알림 권한을 요청합니다.
• 스킵 시간, 배속 키, 볼륨 조절 단위와 검색·필터 범위 등을 조정할 수 있습니다.
• 업데이트 후에는 열린 치지직 탭을 새로고침해 주세요. 새 기능 안내는 설정에서 끄거나 다시 볼 수 있습니다.
• 기록은 자동 백업되지 않습니다. 확장이나 브라우저 프로필·확장 데이터를 삭제하면 기록도 지워질 수 있습니다.

[데이터와 개인정보]
설정과 고정 채널은 Chrome 동기화 저장소에, 시청·내 채팅·후원 기록과 알림 대상·기능별 기억값은 이 기기의 로컬 저장소에 보관합니다. 개발자 서버로 전송하지 않습니다.
멀티뷰 배치·소리는 탭 세션에 보관되며 치지직 페이지 스크립트에서도 읽을 수 있습니다. 방송자·운영자 모아보기의 채팅은 페이지 메모리에서만 유지하며 새로고침·방송 이동 시 초기화됩니다.
댓글 조회용 임의 식별자는 네이버 댓글 API에 전달합니다. 백업 파일에는 시청 기록과 채팅 내용 등 개인정보가 암호화 없이 포함됩니다.

NAVER·치지직과 제휴한 프로그램이 아니며, 치지직의 화면·API 변경에 따라 일부 기능이 동작하지 않을 수 있습니다.
