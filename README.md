# 치즈 스패너

> 치지직(CHZZK) 시청·탐색 편의를 개선하는 비공식 Chrome 확장 프로그램

![치즈 스패너 아이콘](icons/cheese-spanner128.png)

자동 화질 복구, 스킵·배속·볼륨 조절, 방송자·운영자 채팅 모아보기, 팔로잉 고정·폴더·미리보기, 다시보기 검색·댓글, 방송 목록 검색·필터, 방송 시간 통계, 라이브 시청 기록, 통나무 보상 자동 수령, 시청 방해 팝업 제거를 지원합니다. 대부분의 기능은 설정에서 개별로 켜거나 끄고 세부 수치를 조절할 수 있습니다.

- **버전:** 1.4.7
- **플랫폼:** Chrome (Manifest V3)
- **대상 사이트:** `https://chzzk.naver.com/*`
- **언어:** 한국어

[Chrome 웹 스토어에서 설치](https://chromewebstore.google.com/detail/cheese-spanner/dbpnbemehejfmobkemhpebomhabpljeb) · [전체 업데이트 내역](docs/update-history.md)

## 1.4.7 변경 사항

- **채팅창 후원 메시지 숨기기:** 설정의 **채팅 → 채팅 표시**에서 켜요(기본 꺼짐). 라이브·채팅 팝업·다시보기·채팅 멀티뷰의 일반·미션·파티 후원 메시지를 숨기며, 후원 기록과 영상·음성은 유지해요.

- **채팅 문구 숨김:** 채팅창 오른쪽 위 **⋯ → 문구 숨김**에서 숨길 문구를 한 줄에 하나씩 적고 저장해요. 확장 설정의 **채팅 → 문구 숨김**에서도 관리해요. ‘전체 적용’은 모든 문구에 같은 조건을, ‘부분 적용’은 문구마다 ‘완전 일치·포함’을 선택해요. 완전 일치는 본문 전체가 문구와 같을 때, 포함은 본문 안에 문구가 들어 있을 때 라이브·다시보기 채팅과 채팅 모아보기 항목을 숨겨요. 기존 문구는 전체 적용·포함을 유지하고, 두 방식을 전환해도 문구별 조건은 보존해요. 닉네임은 검사하지 않고 영문 대소문자는 구분하지 않아요. 기본 켜짐이며 빈 목록에서는 아무 채팅도 숨기지 않아요. 기존에 저장한 켜짐·꺼짐 선택은 유지하고 문구 삭제·기능 해제로 다시 표시해요. 최대 50개, 한 문구 100자, 전체 2,000자예요.

- **영상 녹화:** 플레이어 오른쪽 아래 녹화 버튼을 누르면 다운로드 폴더에 계속 저장하고, 다시 누르면 MP4·WebM 파일을 마무리해요. 톱니바퀴 메뉴와 설정에서 다운로드 폴더 안의 저장 폴더를 정할 수 있어요.
- **미니 플레이어·화면 확대 개선:** 미니 플레이어와 확장 패널의 겹침을 줄이고, 같은 영상의 페이지 안 작은 플레이어에서 돌아왔을 때 확대 상태를 유지해요. 좁힌 채팅의 프로필 닫기 버튼과 광고 중 조작 문제도 고쳤어요.

자세한 변경 내용은 [1.4.7 업데이트 내역](docs/update-history.md#147-2026-11-08)에 있어요.

## 1.4.6 변경 사항

- **다시보기 시작·종료 시각:** 조회수 옆 날짜 자리에 한국 시간(KST) 기준 방송 시작·종료 시각을 표시합니다(예: `10.25(일) 17:56 ~ 23:08`). 분할 다시보기는 현재 구간 기준이며, `다시보기에 당시 시간 표시`를 끄면 원래 날짜를 표시합니다.
- **방송 알림 사이트 액세스 안내:** 확장 사이트 액세스에서 `api.chzzk.naver.com` 접근이 꺼져 있으면 설정의 **방송 알림** 탭에 안내와 **치지직 API 접근 허용** 버튼을 표시합니다. 다시 허용하면 이후 새 방송부터 동작합니다.
- **새 기능 안내:** 1.4.6 업데이트 시 변경 사항을 한 줄로 요약해 표시합니다.

상세 내역: [1.4.6 업데이트 내역](docs/update-history.md#146-2026-10-28)

## 스트림 정보

- **열기·닫기:** 플레이어 **톱니바퀴 → 스트림 정보 열기/닫기**에서 조작합니다. 기본 켜짐이며 `플레이어 → 시청 화면·멀티뷰 → 스트림 정보`에서 설정할 수 있습니다. 패널 닫기 버튼·`Esc`·키보드 `Enter`/`Space`를 지원합니다.
- **공통 항목:** 현재 해상도, 비트레이트, 남은 재생 버퍼, 최근 구간 FPS, 하드웨어 가속 정보, 재생 상태·속도를 표시합니다. 비트레이트는 실제 전송 속도가 아닌 라이브 API 설정값이며 다시보기에서는 측정할 수 없습니다. 하드웨어 가속 정보는 WebGL 렌더러 기준으로 현재 영상의 디코딩 여부와 다를 수 있으며, CPU·GPU 사용률은 제공하지 않습니다.
- **일반 라이브 추가 항목** (자동 화질 설정과 무관하게 표시):

| 항목              | 설명                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------ |
| 현재 재생 방식    | 현재 선택 트랙의 저지연/일반 여부(설정 스위치 상태와 별개)                           |
| 라이브 지연(추정) | 플레이어 라이브 끝과 현재 시청 위치의 차이(촬영~화면 전체 지연 아님)                 |
| 최근 60초 그래프  | 실선: 지연 추정, 점선: 재생 버퍼, 세로 점선: 재생 방식 변경 시점(미측정 구간 미연결) |
| 관측 끊김         | 최근 60초 버퍼 대기 횟수·합산 시간(초기 로딩·일시정지·탐색·광고·전환·탭 숨김 제외)   |
| 프레임 누락       | 관측 구간 누락 프레임 수·비율(값 미제공 시 측정 대기/불가 표시)                      |

- **측정·보관 기준:** 패널을 연 채 탭이 보일 때만 약 1초 간격으로 측정하며, 닫거나 탭을 숨기면 중단합니다. 패널을 닫으면 측정 기록을 버리며, 외부로 전송하거나 저장하지 않습니다. 탭 복귀·화질/방식 전환 시 그래프 선을 끊고 이어 측정하며, 다른 방송으로 바뀌면 측정을 새로 시작합니다. 재생 위치·화질·배속을 변경하거나 저지연 안정성을 자동 판정하지 않으며, 되감기 시청은 별도 상태로 표시합니다.

## 채팅창·사이드바 크기·위치 조절

- **설정:** `채팅 → 채팅 표시 → 채팅창 너비·높이 조절`(기본 켜짐), `화면 정리 → 상단·사이드바 → 사이드바 너비 조절`(기본 켜짐).

| 대상           | 조절 위치                         | 적용 범위                                   |
| -------------- | --------------------------------- | ------------------------------------------- |
| 사이드바 너비  | 펼친 사이드바의 본문 쪽 가장자리  | 치지직 페이지 전반의 펼친 사이드바          |
| 채팅·댓글 너비 | 채팅·댓글 영역의 영상 쪽 가장자리 | 일반 라이브·다시보기의 채팅과 다시보기 댓글 |
| 채팅·댓글 높이 | 채팅·댓글 영역의 아래 가장자리    | 일반 라이브·다시보기의 채팅과 다시보기 댓글 |

- **조작·초기화:** 경계를 드래그해 조절하며, 채팅 높이는 240px부터 원래 높이까지 조절할 수 있고 입력창은 유지됩니다. 경계를 더블클릭하면 해당 크기만 기본값으로 돌아갑니다. 키보드로는 `채팅 표시 → 저장한 채팅·사이드바 크기 초기화`에서 전체 크기를 초기화할 수 있습니다.
- **저장·반영:** 현재 Chrome 프로필의 로컬 저장소에 각각 저장하며 새 탭·새로고침·재시작 후에도 유지합니다. 이미 열린 다른 탭에는 새로고침 시 반영됩니다. 기능을 끄면 기본 배치로 돌아가지만 저장값은 보존합니다.
- **위치 변경:** `채팅창 위치`는 오른쪽(기본)·왼쪽, `사이드바 위치`는 왼쪽(기본)·오른쪽으로 선택할 수 있습니다. 같은 쪽에 배치하면 사이드바가 바깥쪽, 채팅이 안쪽에 놓이며 저장한 크기는 유지됩니다.
- **제한:** 접힌 사이드바나 좁은 화면에서 본문과 겹치는 사이드바에는 조절 경계를 표시하지 않습니다. 창이 좁아 채팅이 아래로 내려가면 기본 순서로 표시하며, 치지직 최소 폭 미만에서는 사이드바가 임시로 왼쪽에 놓입니다. 채팅 팝업·임베드·클립·같이보기 우측 배치는 제외됩니다.

상단 배너가 없는 화면에서 일부 외부 스타일 때문에 사이드바 아래쪽이 잘리면, 확인된 치지직의 원래 세로 위치·높이로 보정해요. 사이드바의 좌우 위치·너비 설정은 그대로 따라요.

## 팔로잉 폴더

- **설정:** `팔로잉·미리보기 → 채널·팔로잉 → 팔로잉 폴더`에서 켤 수 있으며 기본 꺼짐입니다. 최대 10개 폴더·총 150개 채널을 지정할 수 있고, 채널당 하나의 폴더에만 넣을 수 있습니다. Chrome 동기화 저장소에 보관하며 폴더를 삭제해도 팔로우는 유지됩니다.

| 동작             | 방법                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| 새 폴더 만들기   | 채널 드래그 중 하단 **+ 새 폴더로**에 놓기, 또는 폴더 **⋯ → 새 폴더 만들기** |
| 채널 추가·이동   | 채널을 폴더 머리나 폴더 내 채널 위에 놓기(접힌 폴더에 0.5초 유지 시 펼침)    |
| 폴더에서 제외    | 채널을 **폴더 밖 채널**에 놓기                                               |
| 키보드 채널 선택 | 폴더 **⋯ → 채널 선택…**에서 체크·해제                                        |
| 접기·펼치기      | 화살표·빈 공간 클릭(즉시) 또는 폴더 이름 클릭                                |
| 이름·순서 변경   | 이름 더블클릭/`F2`(`Enter` 저장, `Esc` 취소), 폴더 드래그 또는 **⋯** 메뉴    |
| 폴더 삭제        | **⋯ → 폴더 삭제** 두 번 클릭                                                 |

- **표시·보조 동작:** 이동·삭제 직후 5초간 **되돌리기**를 지원하며, 다른 탭에서 변경한 값은 덮어쓰지 않습니다. 접힌 폴더 머리에 방송 중인 채널 수를 표시합니다. 펼친 폴더의 채널이 기본 5개 목록 밖에 있으면 나타날 때까지 `더보기`를 자동으로 실행합니다(50개 단위, 최대 505개). 직접 `접기`를 누르면 다음에 폴더를 펼칠 때까지 접힌 상태를 유지합니다. 아이콘만 보이는 접힌 사이드바에는 놓을 수 없으며, 사이드바 밖에서는 기존 채널 링크 드래그로 멀티뷰에 추가하거나 새 탭으로 열 수 있습니다. 저장값을 읽지 못하거나 손상된 경우 목록 상단에 **다시 읽기**·**폴더 정보 초기화**를 표시하며, 초기화는 두 번 확인합니다.
- **팔로잉 목록 최대 줄 수:** `0`은 제한 없음이며 최대 `30`줄까지 지정할 수 있습니다. 목록 높이만 제한해 내부 스크롤을 적용하고, 하단 구역·더보기 버튼은 유지합니다.

## 채팅 멀티뷰

- **설정:** `채팅 → 채팅 표시 → 채팅 멀티뷰`에서 켤 수 있으며 기본 꺼짐입니다. 상단 우측 **채팅 멀티뷰** 버튼으로 최대 4개 채널의 채팅을 나란히 표시합니다.
- **채널 추가:** 채널명 검색 결과에서 선택하거나 채널 URL·32자리 ID를 입력해 추가합니다. 검색 결과에는 생방송 여부·팔로워 수를 표시하며, 팔로잉 채널을 끌어 놓아 추가할 수도 있습니다.
- **화면·조작:** 각 칸에 채널명·채팅만 표시하고 상단 헤더·배너·주간 랭킹·후원 버튼은 숨깁니다. **채팅 입력창**은 설정에서 켤 때만 하단에 표시합니다. 패널 상단 조작 막대에서 배율(70~150%)·채널 추가·설정·닫기를 조작하며, 칸별 앞뒤 이동·제거와 모서리 크기 조절을 지원합니다. 채널명 줄을 드래그하면 패널을 옮길 수 있고 가까운 화면 모서리를 기준으로 위치를 저장합니다. 공간이 부족하면 줄바꿈·스크롤을 적용하며, 이전/다음 버튼과 채널 칩으로 이동할 수 있습니다.
- **제한:** 각 칸은 치지직 채팅 팝업이므로 해당 채널로 실제 입력·전송됩니다. 내 채팅 기록 등 확장 채팅 기능은 칸 내부에 적용되지 않습니다. 구성은 로컬에 저장하지만 패널 열림 상태는 새로고침 시 자동 복원하지 않습니다. 불러오지 못하면 새 창으로 대체하지 않고 해당 칸에만 안내를 표시합니다.

## 설정 파일 저장·불러오기

- **위치:** 설정 우측 상단 **⋯ → 설정 파일 저장 / 설정 파일 불러오기**.
- **포함·제외:** 모든 옵션, 팔로잉 고정·폴더, 채팅·사이드바 크기, 방송 알림·자동 입장 채널, 멀티뷰 채널별 딜레이·화질, 채팅 멀티뷰 구성을 포함합니다. 시청·채팅·후원 기록, 카테고리 제외, 로그인 정보는 제외합니다.
- **적용 규칙:** 저장하지 않은 변경이 있으면 먼저 저장하거나 취소합니다. 변경 구역을 미리 확인한 뒤 **불러오기 적용**을 누르면 반영됩니다. 파일에 없는 구역은 현재 값을 유지하며, 포함된 고정 채널·폴더·방송 알림 대상 목록은 교체합니다. 멀티뷰 값은 파일에 있는 채널만 바꿉니다. 미리보기 뒤 설정이 바뀌면 다시 확인하며, 저장에 실패하면 이전 값으로 복구를 시도하고 복구하지 못한 구역을 안내합니다. 파일이 새로 켜는 기능에만 알림·영상 권한을 요청합니다. 권한을 거부하면 전체를 취소하거나 해당 기능은 켜지 않고 불러올 수 있습니다. 진행 중인 방송은 건너뛰고 다음 새 방송부터 알림·자동 열기를 적용합니다. 열린 치지직 탭은 새로고침하면 모두 반영됩니다.

## 상단 버튼 숨기기

- **설정:** `화면 정리 → 상단·사이드바`의 **스튜디오 버튼 숨기기**, **치즈 버튼 숨기기**(사이드바 치즈팜 숨김과 별개), **알림 버튼 숨기기**(모두 기본 꺼짐, 저장 즉시 반영).
- **배치 보정:** 상단 배너와 외부 광고 차단 스타일의 충돌로 검색창이 가려지면 헤더·사이드바 위치와 본문 여백을 유지하며, 배너가 사라지면 보정을 해제합니다. 같이보기 목록에서 배너를 숨긴 뒤 고정 제목 위에 빈틈이 생기면 제목을 헤더 바로 아래로 정렬합니다. 배너가 없을 때도 외부 스타일로 사이드바 위치·높이가 바뀌어 하단이 잘리면 치지직의 기본 위치·높이를 유지합니다.

## 설치 방법

- **웹 스토어 설치:** [Chrome 웹 스토어](https://chromewebstore.google.com/detail/cheese-spanner/dbpnbemehejfmobkemhpebomhabpljeb)에서 **Chrome에 추가**를 선택합니다. 심사 시점에 따라 저장소 버전과 다를 수 있습니다.
- **수동 설치(ZIP·소스):**
    1. 배포 ZIP의 압축을 해제하거나 다음 명령으로 저장소를 복제합니다.
        ```bash
        git clone https://github.com/neder2/Chzzk.git
        ```
    2. `chrome://extensions`로 이동해 우측 상단 **개발자 모드**를 켭니다.
    3. **압축해제된 확장 프로그램을 로드합니다**를 선택한 뒤 `manifest.json`이 있는 폴더를 지정합니다. 별도 빌드는 필요하지 않습니다.

- **탭 구성:** `플레이어 · 소리 · 시청 기록 · 채팅 · 화면 정리 · 방송 시간 · 다시보기 · 팔로잉·미리보기 · 방송 목록 · 방송 알림` 순서입니다. 마우스 세로 휠로 가로 스크롤할 수 있으며, 방향키·`Home`·`End` 이동도 지원합니다.
- **검색·편집·저장:** 상단 검색창에 입력하면 관련 묶음이 자동으로 펼쳐집니다. 변경 건수는 하단에 표시되며 **옵션 저장**을 눌러 적용합니다. 확장 업데이트 직후나 동영상 광고 차단을 새로 켰을 때는 탭 새로고침이 필요합니다. 저장하지 않은 수정은 **변경 취소**, 전체 초기화는 상단 **⋯ → 기본값 복원**에서 실행합니다.
- **테마·글꼴:** 설정창 상단 테마 버튼으로 `시스템 설정 → 화이트 → 다크`를 전환하며, 치지직 본체 테마에는 영향을 주지 않습니다. 설정·기록 화면과 확장 자체 패널은 내장 Pretendard를 사용하고, 치지직의 기존 글꼴을 따르는 요소는 해당 글꼴을 유지합니다. 외부 폰트 서버에는 접속하지 않습니다.
- **새 기능 안내:** 업데이트 후 변경 요약을 한 번, 20초간 표시합니다. 안내 위에 마우스를 두거나 안내 안에 키보드 초점을 두면 시간이 멈춥니다. 자동 안내는 전체화면·입력 중이거나 표시 공간이 부족하면 기다리며, 신규 설치에는 표시하지 않습니다. `화면 정리 → 새 기능 안내`에서 자동 표시를 끄거나 **새 기능 다시보기**를 이용할 수 있습니다. 이전 1.3.7 공지 팝업은 표시하지 않습니다.

## 기능 상세

### 1. 자동 화질 복구

- 라이브·다시보기 입장과 선호 화질 설정 저장 시 `고정할 화질`(1080p·720p·480p, 기본 1080p)을 우선 적용합니다. 해당 화질이 없으면 가능한 가장 높은 하위 화질을 선택하며, 시청 중 설정을 저장하면 현재 영상에도 적용합니다.
- 라이브는 초기 재생이 시작된 뒤 화질을 적용해 재생 충돌을 줄이며, 사용자가 직접 일시정지한 영상은 자동 재생하지 않습니다.
- 관련 설정: `자동 화질 복구`(기본 켜짐), `고정할 화질`(기본 1080p).

### 2. 스킵과 시간 이동

- **방향키 스킵:** `←` / `→`로 `기본 스킵` 초만큼 이동합니다. 라이브는 타임머신 범위 안에서 동작하며, 입력창에 초점이 있거나 조합키를 누른 경우는 제외합니다. 일시정지 중에는 프레임 이동을 지원합니다.
- **스킵 알약 버튼:** 재생 시각 옆 버튼에서 휠(`휠 기본`), `Shift`+휠, `Alt`+휠로 스킵 시간을 조절하고, 클릭하면 기본값으로 되돌립니다. 라이브 컨트롤에는 실시간 끝으로 이동하는 **빨리 감기** 버튼도 제공합니다.
- **일시정지 중 실시간 복귀 방지:** 일시정지 후 다시 재생할 때 멈춘 위치를 이어 볼 수 있도록 실시간 위치로의 강제 복귀를 완화합니다.
- **Space·좌클릭 홀드 2배속:** Space 또는 영상 좌클릭을 0.35초 이상 길게 누르는 동안 2배속을 적용하고, 놓거나 드래그하면 해제합니다. 짧은 Space는 재생·일시정지를 전환하며, 길게 누르는 동작만으로는 일시정지한 영상을 재생하지 않습니다.
- **배속 조절 단축키:** `[`로 0.25배 감소, `]`로 0.25배 증가하며, 0.25~4배 범위에서 길게 눌러 연속 조절할 수 있습니다. `\`로 1배속을 복원합니다. 설정에서 키를 바꿀 수 있으며, 입력창과 기존 플레이어 단축키는 제외합니다.
- 관련 설정: `다시보기·타임머신 스킵`, `일시정지 중 실시간 복귀 방지`, `타임머신 지연 표시`, `스킵 시간 조절 버튼 표시`, `라이브에도 스킵 시간 조절 버튼 표시`, `방향키·프레임 이동`, `기본 스킵`/`휠 기본`/`Shift+휠`/`Alt+휠`, `Space·좌클릭 홀드 2배속`, `배속 조절 단축키` 및 감소·증가·복원 키.

### 3. 볼륨 조절과 오디오 컴프레서

- **우상단 LIVE 숨기기 / 방송 시작 시각 표시:** 각각 `화면 정리 → 플레이어 표시`, `플레이어 → 시청 화면·멀티뷰`에서 설정하며 기본 꺼짐입니다. 시작 시각은 ‘스트리밍 중’ 옆에 KST 기준으로 표시합니다. 당일에는 `14:30 시작`처럼 표시하고 다른 날이면 날짜도 포함하며, 타임머신 위치와는 무관합니다.
- **방송 시작 시 자동 새로고침:** `다음 라이브를 기대해주세요!` 화면에서 30초마다 방송 상태를 확인하고, 방송이 시작되면 한 번 새로고침합니다. 기본 켜짐이며 재생 시작·페이지 이동 시 확인을 중단합니다.
- **볼륨 휠·툴팁:** 볼륨 영역에서 휠로 `1틱 볼륨` 단위만큼 조절하며 멀티뷰 보조 방송에도 동일하게 적용합니다. 메인 스피커·볼륨바와 상하 8px 영역에 마우스를 올리면 볼륨(%) 툴팁을 표시합니다. 음소거 중에도 표시하며 멀티뷰 보조 방송은 툴팁 대상에서 제외합니다.
- **오디오 컴프레서:** 볼륨바 옆에 컴프레서 토글 버튼과 압축 후 출력 볼륨바를 추가합니다. 출력 볼륨은 0~100%(기본 100%)이며 방향키·휠로 조절할 수 있습니다. 원래 스피커 볼륨·음소거는 유지합니다.
- **컴프레서 상태 기억:** 새 탭의 첫 라이브·다시보기 진입 시 마지막 켜짐 여부·출력 볼륨을 복원하고, 이후에는 탭별 선택을 독립적으로 유지합니다. 로컬 저장소에 최대 128개 탭의 기록을 보관합니다. 옵션을 끄거나 `cheese-knife` 컴프레서를 감지하면 적용만 일시 해제하며 저장값은 보존합니다.
- 관련 설정: `휠로 볼륨 조절`, `1틱 볼륨`, `볼륨 % 표시`, `컴프레서 버튼 표시` 및 임계값·압축 전환 폭·비율·어택·릴리즈·보정 게인.

### 화면 확대

**휠로 화면 확대**는 `플레이어 → 시청 화면·멀티뷰`에서 켤 수 있어요(기본 꺼짐). 적용 방식은 세 가지입니다.

- **확대 버튼을 켠 동안:** 플레이어 오른쪽 하단의 돋보기 버튼으로 확대 모드를 켜고 끕니다. 모드를 끄면 원래 크기로 돌아갑니다.
- **영상 위에서 항상:** 확대 버튼을 누르지 않아도 영상 위의 휠로 바로 확대·축소합니다. 최소 배율인 100%에서 아래로 휠을 내리면 페이지가 스크롤됩니다. 다만 휠로 100%까지 축소한 직후에는 이어지는 아래 휠 입력을 막고, 휠을 멈춘 뒤 1초가 지나면 페이지 스크롤을 허용합니다. 대기 중에도 위 휠로 바로 다시 확대할 수 있습니다.
- **단축키를 누른 채 휠:** 확대 버튼 없이, 지정한 키(`Alt`(Mac은 `Option`)·`Ctrl`·`Shift`·`Command` 중 하나, 기본 `Alt`)를 누른 채 영상 위에서 휠을 돌리면 확대·축소합니다. 키 없이 돌린 휠은 페이지 스크롤에 그대로 넘기고, 키를 떼도 확대 상태는 유지됩니다. 키를 누른 휠은 100%에서도 페이지 스크롤에 넘기지 않으며, `Ctrl`을 지정하면 영상 위에서는 브라우저 확대 대신 화면 확대가 동작합니다.

모든 방식에서 휠로 커서 위치를 중심으로 1–5배까지 확대하며, 확대한 화면은 왼쪽 버튼으로 드래그해 이동합니다. 오른쪽 아래 확대 박스는 배율 표시, **슬라이더**, **되돌리기 아이콘**을 한 줄로 배치합니다. 슬라이더는 현재 화면 중심을 유지하며 **100–500%를 1% 단위**로 조절합니다. 키보드 방향키·Home·End로도 조절할 수 있고, 오른쪽 되돌리기 아이콘을 누르면 1배로 돌아갑니다. 버튼 방식에서는 확대 모드를 켜면 100%부터 슬라이더를 사용할 수 있습니다.

확대 박스는 하단 재생 컨트롤보다 조금 위에 고정됩니다. 컨트롤이 나타나거나 사라지고 되돌리기 아이콘에 마우스를 올려도 위치가 바뀌지 않습니다.

볼륨·재생바·설정 메뉴의 휠과 기본 클릭·더블클릭은 유지합니다. 라이브·타임머신·다시보기와 멀티뷰의 메인·보조 영상에 적용되며, 영상마다 확대 배율과 이동 위치를 따로 조절합니다. 확대 중에는 해당 영상 드래그를 확대 영역 이동에 사용합니다. 보조 영상의 버튼 조작 모드도 각 영상 하단의 확대 버튼으로 켭니다. 멀티뷰의 `Alt` 드래그는 유지합니다. 방송 이동·영상 교체·옵션 해제 시 확대를 초기화합니다.

확대·드래그 중에도 왼쪽 스킵·빨리 감기·컴프레서 버튼은 원래 컨트롤 위치를 유지합니다.

### 앰비언트 효과

- **설정:** `플레이어 → 앰비언트 효과`에서 켤 수 있으며 기본 꺼짐입니다. `효과 강도`는 10~100%, 5% 단위로 조절하며 기본 60%입니다. 영상 색이 상단·채팅창·사이드바·하단 정보 주변으로 은은하게 번지며, 다크·라이트 테마에 대응합니다.
- **플레이어 제어:** 톱니바퀴 메뉴에 **앰비언트** 스위치와 **세기** 슬라이더를 제공합니다. 스위치 선택은 현재 프로필의 로컬 저장소에 기억합니다.
- **중단 조건:** 전체 화면, 라이브 멀티뷰 활성, 백그라운드 탭, 플레이어 화면 이탈 시 색 갱신·표시를 중단합니다. 영상 프레임은 브라우저 안에서 색상 효과에만 이용하며, 영상을 녹화하거나 외부에 저장하지 않습니다.

### 영상 녹화

**녹화 버튼**은 `플레이어 → 영상 녹화`에서 켜고 끌 수 있어요(기본 꺼짐). 라이브·다시보기 플레이어 오른쪽 아래 버튼 줄 맨 앞의 녹화 버튼(동그라미)을 누르면 지금 보는 영상과 소리를 녹화하며 다운로드 폴더에 계속 저장해요. 다시 누르면 멈추고 파일을 마무리해요. 녹화 중에는 버튼이 빨간 정지 모양으로 바뀌고 영상 왼쪽 위에 경과 시간이 보여요.

- **파일 형식:** Chrome이 MP4 녹화를 지원하면 MP4, 아니면 WebM으로 저장해요. 파일 이름은 `치지직 라이브 <채널 ID> <날짜 시각>` 또는 `치지직 다시보기 <영상 번호> <날짜 시각>`이에요.
- **저장 폴더:** 기본은 Chrome 다운로드 폴더예요. 설정의 **녹화 저장 폴더** 또는 플레이어 톱니바퀴 메뉴의 **녹화 저장 폴더**에서 다운로드 폴더 안에 만들 폴더 이름(예: `치지직 녹화`, `/`로 하위 폴더)을 정할 수 있어요. 폴더에 저장하려면 처음 한 번 Chrome의 ‘다운로드 관리’(`downloads`) 권한을 허용해야 해요. 설정에서 폴더를 저장할 때 묻고, 거부했거나 톱니바퀴 메뉴에서만 정했다면 설정의 **다운로드 권한 허용** 버튼으로 허용할 수 있어요. 권한이 없으면 다운로드 폴더에 바로 저장해요. Chrome의 ‘다운로드 전에 각 파일의 저장 위치 확인’을 켜 두었다면 저장 창이 열려요.
- **자동으로 멈추는 경우:** 페이지 안에서 다른 방송으로 이동하거나, 영상이 다시 불러와지거나 바뀌거나, 녹화 버튼 옵션을 끄면 그때까지 녹화한 파일을 마무리해요. 녹화 중에 탭을 닫거나 새로고침하면 Chrome이 페이지를 떠날지 먼저 물어요. 파일을 완성하려면 녹화를 먼저 멈추고 이동해 주세요.
- **저장 방식:** 녹화 중에는 Chrome의 다운로드 임시 파일(`.crdownload`)이 커지고, 멈추면 MP4·WebM 파일로 완성돼요. 길이 제한은 없으며 전체 영상을 탭 메모리에 쌓지 않아요. 다운로드를 취소하거나 저장이 끊기면 녹화도 멈춰요.
- 녹화 파일은 이 기기의 다운로드로만 저장하고 어디에도 보내지 않아요. 녹화는 버튼을 누를 때만 시작해요. 녹화한 콘텐츠의 이용은 방송 저작권과 치지직 이용약관을 따라 주세요.

### 4. 단축키 안내

- `Space`·`M`·`F`·`T` 기본 단축키가 동작하지 않을 때 `플레이어 → 배속·단축키 → 기본 단축키 복구`를 켭니다(기본 꺼짐). 입력창·조합키에는 개입하지 않으며, `Space·좌클릭 홀드 2배속`을 켜면 Space는 홀드 기능이 우선 처리합니다.
- 자막 키 `C` 등 기존 플레이어 조작 키는 배속 단축키로 지정할 수 없습니다. 중복되거나 `C`로 저장된 값은 기본 키로 복원합니다.

### 5. 다시보기 방송시각 표시

- 방송 시작 시각과 재생 위치를 합산해 현재 장면의 **실제 방송 시각(KST)**을 표시하며, 제목 옆에 이전 방제 패널을 제공합니다.
- **제목 아래 시작·종료 시각:** KST 기준 시작·종료 시각과 `영상 기준` 표기를 함께 표시합니다. 종료 시각은 영상 길이로 계산하므로 편집·누락 구간이 있으면 실제 종료와 다를 수 있습니다. 자정이 지나면 날짜를 표시하고, 길이를 확인할 수 없으면 `확인 불가`로 표시합니다. 분할 다시보기는 현재 영상 구간 기준이며 시청 기록 저장 여부와 무관합니다. `다시보기에 당시 시간 표시`를 끄면 함께 숨깁니다.
- **조회수 옆 날짜 자리:** 공개일 대신 `10.25(일) 17:56 ~ 23:08` 형식으로 KST 시작·종료 시각을 표시합니다. 다른 날 종료되면 날짜·요일을, 이전 연도 방송에는 연도를 추가합니다. 분할 다시보기는 현재 구간 기준이며 일반 업로드 영상은 원래 날짜를 유지합니다.
- **분할 연결:** 17시간 제한으로 나뉜 다시보기는 연결된 이전 구간 길이를 이어 계산해 장면 시각을 표시합니다. 방송 시작 시각을 확인할 수 없으면 표시하지 않습니다.
- 관련 설정: `다시보기에 당시 시간 표시`(기본 켜짐).

### 6. 타임머신 지연 표시

- 라이브 타임머신 시청 중 실시간 대비 지연 시간을 표시합니다.
- 관련 설정: `타임머신 지연 표시`(기본 켜짐).

### 7. 다시보기 채팅창 댓글 탭

- 우측 `라이브 채팅 다시보기` 옆에 `댓글` 탭을 추가하며, 채팅이 없는 VOD에는 댓글 전용 패널을 표시합니다. 전체화면에서는 그 안에 열린 VOD 채팅 패널에만 표시하며, 닫힌 패널을 자동으로 열지는 않습니다.
- 인기순(기본)·최신순·등록순 정렬, 새로고침·무한 스크롤, 답글 펼치기, 긴 글 더보기, 첨부 이미지·타임코드 이동을 지원합니다.
- 하단 원본 댓글에 같은 댓글이 표시되어 있으면 프로필 보기·버프 동작과 상태를 원본 컨트롤에 연동합니다. 아직 표시되지 않으면 안내와 함께 비활성화하며, 작성·삭제·신고는 하단 원본 댓글을 이용합니다.
- 관련 설정: `다시보기 채팅창 댓글 탭`(기본 켜짐).

### 8. 채팅 도구

`라이브 채팅 타임스탬프 표시`를 켜면 라이브 채팅의 닉네임 왼쪽과 방송자/채팅 운영자 모아보기에 **서버 메시지에 기록된 실제 작성 시각**을 브라우저 현지 `HH:MM` 형식으로 표시합니다. 입장·스크롤·재연결 때 서버에서 불러온 기존 채팅도 원본 시각을 사용하며, 유효한 서버 시각을 확인할 수 없는 행에는 현재 시각을 대신 붙이지 않습니다. 기본값은 꺼짐입니다.

`다시보기 채팅 타임스탬프 표시`는 다시보기의 `라이브 채팅 다시보기`에서 **방송 당시 채팅이 작성된 시각**을 같은 형식으로 표시합니다. 영상의 경과 시간이 아니라 원래 작성 시각이며, 재생 위치를 옮기거나 채팅을 다시 불러와도 각 메시지의 원본 시각을 사용합니다. 라이브 옵션과 별도로 켜고 끌 수 있으며 기본값은 꺼짐입니다. 두 옵션은 **채팅 도구 → 채팅 표시**에서 설정할 수 있습니다.

`다시보기 내 채팅 강조`는 치지직에 로그인돼 있으면 다시보기의 `라이브 채팅 다시보기`에서 **지금 로그인한 계정이 쓴 채팅**을 옅은 배경과 왼쪽 선으로 강조합니다. 다시보기 채팅은 작성 당시의 닉네임을 보여 주므로 닉네임이 아니라 계정 식별값(작성자 해시 ID)으로 비교하며, 닉네임을 바꾸기 전에 쓴 채팅도 찾습니다. 로그인하지 않았거나 계정을 확인하지 못하면 강조하지 않고, 계정을 바꾸면 다시 확인합니다. 계정 식별값은 현재 페이지 메모리에서 비교에만 쓰고 저장하지 않습니다. 기본값은 켜짐이며 같은 묶음에서 끌 수 있습니다.

`채팅방 환영 메시지 제거`를 켜면 라이브 채팅을 처음 열거나 다시 불러올 때 표시되는 “채팅방에 오신 것을 환영합니다!” 환영 행과 “쾌적한 시청 환경을 위해 일부 메시지는 필터링 됩니다.” 안내 행을 함께 숨깁니다. 기본값은 꺼짐입니다.

라이브 채팅에서 블라인드 처리된 메시지의 원문을 확인하고, 채팅창 우측 상단 아이콘에서 방송자/채팅 운영자 채팅을 모아 볼 수 있습니다. 두 기능은 각각 독립적으로 켜며 기본값은 모두 꺼짐입니다.

- **블라인드 채팅 원문 표시:** 현재 메시지와 작성자가 확인된 원문을 취소선으로 보여 줍니다. 다른 계정·메시지·이전 방송의 원문은 섞지 않으며, 네이티브 원문이 없거나 확인할 수 없으면 기존 안내를 유지합니다. 기존 DOM 행은 메시지 ID·작성자·재사용 표식이 일치하는 원문 캐시만 사용합니다.
- **방송자/채팅 운영자 모아보기:** 방송자나 채팅 운영자(구 매니저)로 확인되는 채팅만 채팅창 우측 상단 아이콘에서 여는 패널에 모읍니다. 별도 채팅 팝업에서는 채팅 크기 조절 버튼과 겹치지 않도록 아이콘과 패널을 좌측에 표시합니다.
- **일반 채팅 하이라이트:** 모아보기를 켜면 대상 메시지를 원래 채팅창에서도 닉네임 색상의 옅은 배경과 얇은 테두리로 강조합니다. 긴 제목 툴팁이 뜰 때 제목을 감싸는 박스처럼 모서리를 둥글게 표시하고, 라이트·다크 모드에 맞춰 농도를 조절합니다. 본문 글자색과 채팅 줄 크기는 유지하며, 패널을 닫아도 강조는 남고 모아보기 옵션을 끄면 함께 사라집니다.
- **사용자별 보기와 새 채팅 알림:** 보관 중인 채팅을 닉네임별로 정리하며, `전체` 또는 사용자 버튼으로 표시 대상을 선택할 수 있습니다. 상단 모아보기 아이콘의 숫자와 강조 표시는 미확인 채팅 수이며, 사용자 버튼에도 각 사용자의 미확인 개수가 표시됩니다. 패널을 연 상태에서 채팅 행의 절반 이상이 화면에 보이면 확인 처리되어 알림이 사라집니다. 목록보다 긴 행은 목록 높이의 절반을 기준으로 합니다. 다른 사용자 필터에 가려진 채팅이나 백그라운드 탭의 채팅은 확인 처리하지 않습니다. 패널에서 위로 스크롤하면 아래쪽 꺾쇠 모양의 `맨 아래로` 버튼이 나타나며, 누르면 현재 필터의 마지막 채팅으로 이동하고 버튼은 사라집니다.
- **채팅 선택과 복사:** 모아 둔 채팅은 여러 행에 걸쳐 드래그한 뒤 `Ctrl+C`(Mac은 `Command+C`)로 복사할 수 있습니다. 선택 중에는 자동으로 맨 아래로 스크롤하지 않습니다. 일반 클릭 또는 행에 초점을 맞춘 뒤 Enter·Space를 누르면, 같은 메시지가 원본 채팅창에 남아 있을 때 해당 위치로 이동합니다.
- 모아 둔 채팅 메시지는 현재 페이지에서만 유지되며 새로고침하면 사라집니다.
- 사용자 목록과 미확인 상태도 현재 페이지 메모리에서만 관리하며 다른 방송으로 이동하면 초기화됩니다. 보관 개수를 넘겨 삭제된 채팅은 알림에서도 제외하고, 보관된 채팅이 없는 사용자는 목록에서 정리합니다. 사용자 분류는 현재 확인된 닉네임 기준이며, 배지 없는 모든 스트리머나 인증 사용자를 추가로 자동 판별하는 기능은 포함하지 않습니다.
- 서버 권한을 우회하거나, 비공개 moderation API를 호출하거나, 페이지가 이미 사용하지 않는 엔드포인트에서 삭제/숨김 메시지를 가져오지 않습니다.
- 관련 설정: `라이브 채팅 타임스탬프 표시`, `다시보기 채팅 타임스탬프 표시`, `채팅방 환영 메시지 제거`, `블라인드 채팅 원문 표시`, `방송자·운영자 채팅 모아보기`(기본값: 모두 꺼짐), `다시보기 내 채팅 강조`(기본값: 켜짐), `모아보기 보관 개수`.

### 9. 통나무 보상 자동 받기

- 라이브 채팅의 **시청 통나무 파워 배달 완료** 버튼과 보상 창의 **1시간 시청 보상**(`WATCH_1_HOUR`) 버튼을 상태당 한 번 자동으로 누릅니다. 확인된 보상 UI만 대상으로 하며 일반 채팅·프로필·링크는 제외합니다.
- 라이브 채널의 대기 중인 비시청 통나무 claim을 30초마다 확인해 `log-power` API로 자동 수령합니다. 시청 시간을 조작하거나 서버 제한을 우회하지 않습니다.
- 관련 설정: `통나무 보상 자동 받기`(기본 켜짐).

### 10. 팔로잉 사이드바

- **팔로잉 목록 펼침·접힘 기억 / 오프라인 숨기기:** 구역 접기·`더보기` 상태를 로컬에 기억하고, 오프라인 채널은 고정 여부와 관계없이 숨길 수 있습니다. 두 옵션 모두 기본 꺼짐입니다.
- **사이드바 항목 숨기기:** `사이드바 치즈팜 숨김`, `인기 카테고리 숨기기`, `다가오는 방송 일정 숨기기`, `파트너 스트리머 숨기기`, `서비스 바로가기 숨기기`를 각각 설정할 수 있습니다. 기본값은 모두 꺼짐입니다.
- **팔로잉 채널 고정:** 팔로잉 헤더의 핀 버튼으로 고정 모드를 켠 뒤 채널을 선택합니다. 최대 64개까지 고정할 수 있으며 Chrome 동기화 저장소에 보관합니다. 기본 순서는 고정 라이브 → 일반 라이브 → 고정 오프라인 → 일반 오프라인입니다. `오프라인이어도 최상단 고정`을 켜면 고정 채널 전체를 최상단에 배치합니다. 접힌 5개 목록 밖의 고정 채널도 보충해 표시합니다.
- **채널 링크 드래그:** 팔로잉 채널 링크를 탭 표시줄이나 멀티뷰 영역으로 끌어 열거나 추가할 수 있습니다.
- **팔로잉 라이브 제목 이력:** 로그인 상태에서 팔로우한 라이브 방제를 1분마다 로컬에 기록하고, 라이브 시청 화면·`/following` 카드의 제목 옆 버튼으로 이전 방제를 표시합니다. 기본 켜짐이며 로그아웃·브라우저 종료 중의 변경은 수집하지 않습니다.
- **자동 새로고침:** 설정 주기(기본 30초)와 장기 비활성 탭 복귀 시 라이브 상태를 갱신합니다.
- **팔로잉 호버 미리보기(기본 꺼짐):** 사이드바 라이브에 마우스를 올리면 카드 안에서 HLS 미리보기를 재생합니다. `pstatic.net` 선택 권한이 필요하며 새 창으로 대체하지 않습니다. 고정 볼륨(기본 15%)·우클릭 소리 전환·카테고리 이동 링크·채널 홈 새 탭 링크를 지원합니다.
- 관련 설정: `사이드바 치즈팜 숨김`, `팔로잉 목록 펼침·접힘 기억`, `팔로잉 채널 고정`, `오프라인이어도 최상단 고정`, `팔로잉 오프라인 채널 숨기기`, `팔로잉 라이브 제목 이력`, `팔로잉 목록 자동 새로고침`, `자동 새로고침 주기`, `방송 목록 호버 미리보기`, `호버 미리보기 소리`, `미리보기 볼륨`, `우클릭으로 미리보기 소리 전환`.

### 11. 방송 목록 도구

전체 방송(`/lives`)과 카테고리 라이브·영상·클립 목록 상단에 검색·필터·집계 도구를 추가하고 카드에 부가 정보를 표시합니다.

- **전체 방송 집계 표시:** 전체 방송 상단에 시청자 10명 이상인 방송 수와 동시 시청자 합계를 표시합니다. 검색·필터와 독립적으로 동작하며 중복 시청자는 제거하지 않습니다. 신규 설치 시 기본 꺼짐이고, 같은 세션에서 집계 결과를 5분간 재사용합니다.
- **현재 목록 검색·적용 조건 줄:** 제목·스트리머·카테고리·태그로 필터링합니다. 띄어쓰기로 나눈 단어는 모두 포함해야 하며, `-단어`는 제외합니다. 전체 방송에서는 `Enter`로 적용하고 `Esc`로 복원합니다. 활성 검색어·숫자 필터는 상단 칩과 `모두 해제`로 관리합니다. 현재 탭의 목록 주소별로 조건을 기억해 방송 시청 후 복귀하거나 새로고침해도 유지합니다.
- **숫자 필터 메뉴:** 팔로워 수, 시청자 수/조회수, 진행 시간별로 `전체·이상·이하·범위`를 지정할 수 있습니다. 기준값 6개의 빠른 선택 버튼과 `2천`·`1.5만` 등의 직접 입력을 지원하며, `필터 초기화`는 숫자 필터만 해제합니다.
- **카테고리·태그 제외:** 전체 방송(`/lives`)의 인기·최신·추천 정렬 줄 우측 `+ 제외 추가`에서 카테고리를 검색해 선택하거나, 단어 입력 후 `Enter`로 `#태그`를 제외합니다. 최대 100개까지 현재 프로필의 로컬 저장소에 보관하며 열린 전체 방송 탭에 동기화합니다. 태그는 전체가 일치할 때만 제외합니다.
- **카드 배지·미리보기:** 팔로워 수 축약 배지, 썸네일에 마우스를 올렸을 때의 진행 시간 표시, 전체 방송·필터 카드의 즉시 호버 미리보기를 지원합니다. 우클릭 집중 모드에서는 확대·최대 1080p와 설정에 따른 소리 재생을 제공하며, 기본 태그 검색창을 숨길 수도 있습니다.
- 관련 설정: `방송 목록 검색·필터`, `전체 방송 집계 표시`, `전체 방송 태그 검색 숨김`, `팔로워 수 표시`, `호버로 진행 시간 표시`, `카테고리·태그 제외`, `팔로워/시청자·조회수/진행 시간 1~6`, `추가 조회 페이지`, `팔로워 조회 묶음`, `동시 조회`, `조회 간격`.

### 14. 채널 방송 시간 통계

- **채널 채팅 바로가기:** 채널 탭의 `정보` 옆에 오프라인에서도 들어갈 수 있는 일반 라이브 화면(`/live/{채널 ID}`) 링크를 표시하며 기본 켜짐입니다.
- **평균 방송 시간·월간 달력:** 다시보기 시작·종료 시각을 기준으로 최근 평균 방송 시간 스티커와 월별 달력을 표시합니다. 달력 색은 3시간 단위 9단계이며 가장 진한 색은 24시간 이상입니다. 날짜를 누르면 첫 다시보기로, 툴팁 항목을 누르면 개별 다시보기로 이동합니다. 17시간 제한으로 나뉜 다시보기는 하나의 구간으로 합산하며, 다시보기가 생성되지 않은 라이브 구간은 제외합니다.
- **내 시청 표시·조회 상한:** `달력에 내 시청 시간 표시`(기본 꺼짐)를 켜면 시청 기록이 있는 방송에만 내 시청 시간을 표시합니다. 평균 기간·페이지 조회 상한을 조절할 수 있으며, 상한에 도달하면 일부만 표시한다는 안내를 제공합니다.
- 관련 설정: `채널 채팅 바로가기`, `평균 방송 시간 표시`, `방송일 월간 달력`, `달력에 내 시청 시간 표시`, `평균 기간`, `평균 조회 상한`, `달력 조회 상한`.

### 15. 라이브 시청 기록

- 실제 영상 재생 위치가 전진한 라이브 시청 시간만 이 브라우저의 로컬 저장소에 기록합니다. 일시정지·멈춤 시간은 제외하며, 전체 시청 시간 집계에서는 다중 탭의 동시 시청 구간을 한 번만 합산합니다.
- `최소 저장 시간`(기본 1분)보다 짧게 시청하면 통계에서 제외하지만, 내 채팅·일반 후원은 즉시 저장하고 `활동만 기록`으로 표시합니다. 확인된 방송 제목·방제 이력도 함께 보관합니다.
- 관련 설정: `라이브 시청 기록 저장`, `최소 저장 시간`, `내 채팅 기록 저장`, `내 일반 후원 기록 저장`.

### 16. 시청 방해 팝업 제거

광고 차단 안내를 먼저 숨긴 뒤 닫기 버튼을 자동으로 눌러 팝업을 닫습니다. 닫기 버튼이 없거나 닫히지 않는 안내는 직접 확인할 수 있도록 화면에 남깁니다. 닫기 버튼 없이 **확인** 버튼만 있는 일부 안내도 자동으로 닫습니다. 자동으로 닫히지 않거나 같은 방송에서 반복해서 다시 뜨면 **확인**을 직접 누를 수 있도록 남깁니다. 고화질 설치 안내는 설치 없이 일반 화질 또는 기본 화질로 시청하는 버튼을 선택합니다. 네이버 라이브 스트리밍 커넥터 안내와, 크롬·엣지에서 표시되는 브라우저 확장 프로그램 설치 안내를 모두 처리합니다. 같은 안내임을 확인할 수 있는 제한된 문구·배치 변화에도 대응하며, 다른 안내나 모호한 버튼은 그대로 남깁니다.

화면에 표시된 활성 버튼만 누르며, 저장된 설정을 확인한 뒤 자동 닫기를 시작합니다. 옵션을 끄면 페이지에 처음 들어갈 때도 안내를 자동으로 닫지 않습니다.

- 관련 설정: `시청 방해 팝업 제거`(기본 켜짐).

**플레이어 → 광고·팝업**에는 다음 두 옵션이 별도로 있어요. 동영상 광고 차단은 기본 켜짐, 배너 광고 숨기기는 기본 꺼짐이며, 시청 방해 팝업 제거와 독립적으로 동작합니다. 기존에 저장된 설정값은 유지되며, 새 설치나 기본값 복원 시 동영상 광고 차단이 켜집니다.

- **동영상 광고 차단 — 실험적:** 확인된 치지직 광고 표시 응답의 프리롤·미드롤 값을 처리합니다. 켜고 저장한 뒤 치지직 탭을 새로고침해야 합니다. 자동으로 새로고침하지 않습니다. 끄면 이후 광고 처리를 멈추며, 이미 반영한 플레이어 상태는 새로고침하면 복원됩니다. 알 수 없는 응답과 본방송 스트림·화질 정보는 그대로 통과합니다.
- **배너 광고 숨기기:** 홈·라이브·VOD에서 확인한 광고 배너 슬롯만 CSS로 숨깁니다. 기능을 끄면 원래 표시로 돌아갑니다. 이 옵션 자체는 광고 요청을 차단하지 않습니다.

동영상 광고 차단은 본영상 재생을 우선하는 실험 기능이에요. 광고 계약과 현재 플레이어의 소유 관계가 맞으면 새로운 광고 ID와 추가 필드도 처리해요. 확인된 라이브·다시보기 광고 소스는 초기화 전에 비우고, 일반·간편 라이브의 입장·중간 광고 일정은 항목·순서·시간을 유지한 채 광고 소스 목록만 비워 네이티브 완료로 이어지게 해요. 별도 광고용 영상과 본영상은 구분해요. 적용하려면 치지직 탭을 새로고침해야 하며, 이미 시작된 광고를 즉시 제거하는 기능은 아니에요.

라이브의 본방송 상태를 연결하는 바깥 객체는 유지하고, 확인된 별도 광고 요청만 생략해요. 내부 요청이 없는 바깥 객체와 별도 입장·중간 광고 일정도 각각 처리해요. 라이브 PiP를 유지하며 홈·목록으로 이동해도 현재 본영상과 광고 영역의 소유가 일치하는 중간 일정을 처리해요. 치지직 응답·플레이어의 필수 구조나 소유 관계가 달라지거나 지원하는 처리 지점을 지나지 않으면 원래 동작을 유지하므로 광고가 재생될 수 있어요. 방송 스트림에 포함된 광고와 모든 광고 경로를 지원하지 않으며 SDK 교체나 광고 서버 전체 차단도 하지 않아요.

배너 숨기기는 홈·라이브·다시보기의 기본 배너와 광고 재생에 연동되는 라이브·다시보기 배너 슬롯을 포함합니다. 일반 이벤트·콘텐츠 안내 영역은 숨기지 않습니다. 배속·시간 이동·자동 화질의 본영상 선택에서는 확인된 광고 영상을 제외합니다.

### 17. 라이브 멀티뷰

팔로잉 라이브 링크나 다른 탭의 치지직 라이브 URL을 **드래그해서 놓아도 방송을 추가**할 수 있습니다. 분할 배치에서는 켜진 멀티뷰 영상 영역에 놓습니다. **자유 배치에서는 보조 화면 기본 크기의 안내가 포인터 중심을 따라 움직이고, 기존 영상 밖의 사이드바·채팅·빈 공간에도 놓은 위치에 방송을 추가**합니다. 화면 가장자리에서는 창 전체가 보이도록 위치를 맞춥니다. 입력칸과 멀티뷰 설정창에서는 방송을 배치하지 않습니다. 중복·최대 6개 제한을 안내하며, 추가된 서브 방송은 음소거로 시작합니다. 드래그를 취소하거나 배치 영역 밖에 놓으면 멀티뷰 구성을 바꾸지 않습니다.

설정에서 **라이브 멀티뷰**를 켜고 영상 호스트 권한을 허용한 뒤, 라이브 플레이어 하단의 **넓은 화면 버튼 왼쪽에 있는 격자 모양 멀티뷰 버튼**을 누릅니다. 켜진 상태는 초록색으로 표시되며, 다시 누르면 멀티뷰를 끕니다. 서브 방송이 없는 상태에서 켜면 방송 추가 입력창이 열립니다. 이후에는 **채팅창 상단의 멀티뷰 설정 → 팝업 상단의 + 방송 추가**에서 방송인 닉네임으로 검색하거나 치지직 라이브 URL을 입력해 최대 6개 방송을 함께 볼 수 있습니다.

- **닉네임 검색:** 닉네임을 입력한 뒤 검색 버튼이나 Enter를 누르면 팔로워순 상위 5개 결과에 프로필 사진·닉네임·방송 여부·방송 중인 채널의 시청자 수를 표시합니다. 방송 중인 결과를 누르면 음소거 상태로 추가됩니다. 오프라인·이미 추가한 방송은 선택할 수 없습니다. 원하는 방송이 없으면 닉네임을 더 자세히 입력해 검색해 주세요. 시청자 수는 검색 시점의 조회값이며 조회 실패 시 확인 불가로 표시합니다.

- 멀티뷰 안내·컨트롤·설정은 치지직에서 사용하는 글꼴 계열로 표시합니다. 방송 종료·재생 실패·저장 오류 안내와 재시도 버튼은 해당 방송 화면의 중앙에 모아 표시하며, 좁은 화면에서는 문구를 줄바꿈합니다.
- 멀티뷰 설정은 방송 목록과 조작 버튼을 함께 표시합니다. 배치는 아이콘과 문구를 함께 표시하는 한 줄 메뉴로, 추가는 민트색 버튼으로 제공합니다. 각 방송의 싱크 버튼은 옅은 민트색으로, 제거는 방송명 옆 붉은 휴지통 아이콘으로 구분합니다. 긴 상태 문구는 마우스를 올리면 전체 내용을 확인할 수 있습니다.
- **앞으로 / 늦추기**는 목표 딜레이를 0.1초 또는 1초씩 조절하고 영상과 소리에 함께 적용합니다. 라이브 위치나 이전 측정 기준에서 처음 조절할 때 현재 추정 지연을 기준으로 잡고, 이후에는 목표값에 조절량만 더하므로 측정값의 흔들림이 저장 값에 누적되지 않습니다. 채널별 목표 딜레이를 이 기기에 저장하여 새로고침·브라우저 재시작·다음 방송에도 불러옵니다. 방송을 제거하거나 위치를 바꿔도 채널별 값은 유지됩니다.
- 딜레이는 방송 정보 갱신 사이의 경과 시간을 보정한 라이브 끝 지점 기준입니다. 보조 방송은 HLS의 시간 정보를 사용하고, 메인은 실제 끝 지점의 진행 간격을 관찰한 뒤 추정합니다. **빨리 감기**는 저장 값을 0으로 바꾸고 재생 가능한 라이브 위치로 복귀합니다. 0초여도 송출·전송·재생 버퍼에 따른 실제 지연은 존재합니다. 서로 다른 방송의 같은 장면을 자동 정렬하는 기능은 아닙니다.
- 목록에는 **현재 추정 지연**, **저장된 딜레이**, **복원 대기 / 적용 완료 / 적용 불가**를 구분해 표시합니다. 현재 값은 싱크 버튼을 누르지 않아도 재생 정보가 준비되면 자동으로 표시되며, 아직 측정할 수 없으면 0초 대신 **현재 측정 대기**로 표시합니다. 처음의 저장값 0초는 재생 가능한 라이브 위치를 사용한다는 의미이며 현재 지연이 0초라는 뜻은 아닙니다. 측정값이 바뀌어도 저장값을 자동으로 덮어쓰지 않습니다. 광고 중이나 탐색 범위가 부족할 때는 저장 값을 줄이지 않고 기다립니다. 시간 정보가 오래 갱신되지 않으면 측정 대기로 표시합니다. `이전 기준`으로 표시된 저장 값은 종전 방식으로 복원하고, 방송을 다시 조절하면 보정된 기준으로 저장합니다. 보조 방송에서 저장된 딜레이를 읽지 못하거나 재생 오류가 나면 해당 영상의 **재생 재시도** 버튼으로 저장값을 다시 읽고 그 방송만 재생을 다시 시작할 수 있습니다. 조절한 딜레이의 저장만 실패한 경우에는 **다시 저장** 버튼을 사용합니다.
- 방송 구성·크기·박스 안 영상 위치·볼륨·자유 배치 사용 여부와 창 위치·겹침 순서는 현재 탭의 세션 저장소에 보관합니다. 채널별 딜레이와 보조 화질은 확장 로컬 저장소에 계속 보관합니다. 멀티뷰를 끄면 보조 재생과 관련 리소스를 정리합니다.

## 시청 기록 페이지

설정 화면의 **시청 기록 보기**로 열며(`history.html`), **라이브 내역 · 많이 본 채널 · 내 채팅·후원** 탭과 월별 달력·백업·삭제 도구를 제공합니다.

- **요약·달력·채널 사진:** 총 시청 시간·라이브 수·월별 합계를 표시합니다. 다중 방송의 동시 시청 구간은 총합·월 합계·달력에서 한 번만 합산합니다. 날짜를 눌러 일별로 필터링할 수 있으며, 공개 채널 프로필 사진은 자동으로 조회해 표시하고 저장하지 않습니다.
- **라이브 내역:** 기간(선택 월/전체), 제목/채널 검색, 정렬(`최근 본 순`/`예전에 본 순`/`시청 시간 긴 순`/`시청 시간 짧은 순`)을 지원합니다. **내 채팅 ○개**를 펼쳐 50개 단위로 더 볼 수 있고, **세부**에서 전체 제목·방제 이력·입장 기록·개별 삭제를 제공합니다. 여러 항목을 골라 **선택 삭제**할 수도 있습니다. 항목을 누르면 다시보기 탐색 안내(`replay-pending.html`)를 거쳐 이동합니다.
- **많이 본 채널:** 선택 기간·검색 조건에 따라 채널별 누적 시청 시간·방송 수·채팅·일반 후원 합계를 표시합니다. 같은 채널의 겹친 시청 시간은 한 번만 계산합니다.
- **내 채팅·후원:**
    - `내 채팅 기록 저장`·`내 일반 후원 기록 저장`을 켜면 로그인 계정의 라이브 채팅·본인 일반 후원을 즉시 저장하며, 두 옵션 모두 기본 꺼짐입니다. 익명·미션·영상·파티·외부 후원·구독은 제외하고 메시지 없는 일반 후원은 포함합니다. 본문은 방송별 최근 500개·전체 최근 3,000개까지 보관하며 누적 횟수·치즈 합계는 유지합니다.
    - **후원 내역 갱신:** 치지직에 로그인된 탭을 열어 둔 상태에서 2023년 1월 이후 사용 내역을 월 단위로 조회해 통합합니다. 이후에는 진행 중이던 달·새 달·미조회 달만 조회하며 최대 3,000개까지 보관합니다. 다른 계정으로 조회하기 전에는 **후원 갱신 초기화**가 필요합니다.
- **기록 백업·관리:**
    - **백업 파일 저장 / 불러오기:** 전체 기간의 시청 기록·내 채팅을 JSON 파일(최대 16 MiB)로 내보내고, 미리보기 확인 후 중복 없이 합칩니다. 실시간·갱신 후원은 제외하며 파일은 암호화하지 않습니다.
    - **삭제·주의:** 로컬 저장소에만 보관하므로 확장 삭제·프로필 초기화 시 기록도 함께 삭제되며, 별도 백업이 없으면 복구할 수 없습니다. **전체 삭제**는 시청·채팅·후원 기록을 모두 지우고, **후원 갱신 초기화**는 갱신한 내역만 삭제합니다.

배속 값은 고정이며 단축키만 변경할 수 있습니다. 세 키가 중복된 저장값은 기본 키로 복원합니다. 배속 키 입력칸을 선택한 뒤 영문·숫자·일부 기호 키를 누르면 변경됩니다. Space, `c`/`m`/`f`/`t`, `j`/`k`/`l`, 방향키, 쉼표·마침표처럼 기존 재생 조작과 겹치는 키와 조합키는 지정할 수 없습니다. 기존에 C를 배속 키로 저장했다면 해당 항목을 기본 키로 복원합니다.

**단축키 기본값 복원**을 누르면 감소·증가·1배속 복원 키를 `[`·`]`·`\`로 되돌립니다. **옵션 저장**을 누르면 적용되며, 저장 전에는 **변경 취소**로 되돌릴 수 있습니다.

## 방송 시작 알림·지정 채널 자동 탭 열기

- **등록·관리:** 설정 **방송 알림** 탭에서 채널 주소·32자리 ID를 입력하거나, 치지직 우측 상단 **방송 알림** 버튼에서 채널명을 검색해 등록합니다. 검색 결과는 상위 5개이며 최대 32개 채널을 등록할 수 있습니다. 채널별 **알림**·**자동 열기(자동 입장)**를 개별로 전환하며 로컬에 즉시 저장하고 설정창과 실시간으로 동기화합니다.
- **전체 스위치·권한:** 상위 옵션(`방송 시작 데스크톱 알림`, `지정 채널 자동 탭 열기`, 기본 모두 꺼짐)을 켜고 **옵션 저장**을 눌러야 동작합니다. 데스크톱 알림에는 `notifications` 권한이 필요하지만, 거부해도 자동 열기는 별도로 사용할 수 있습니다. OS 집중 모드·차단 설정은 따로 확인해야 합니다. 확장 사이트 액세스에서 `api.chzzk.naver.com`이 꺼져 있으면 설정 탭에서 **치지직 API 접근 허용**을 눌러야 합니다.
- **확인·실행 기준:** Chrome 실행 중 약 1분 간격으로 확인하며 치지직 탭이 열려 있을 필요는 없습니다. 브라우저 종료·절전 중에는 확인하지 않습니다. 최초 등록·활성화·브라우저 시작 시 이미 진행 중인 방송은 건너뛰고, 이후 새 방송을 확인하면 채널별 선택한 동작을 중복 실행하지 않도록 처리합니다. 알림을 누르면 열린 방송 탭으로 이동하며, 자동 열기는 **배경 탭**으로 열되 같은 채널의 라이브·대기 탭이 이미 있으면 중복으로 열지 않습니다.

## 권한 및 개인정보

이 확장 프로그램이 사용하는 권한은 최소한으로 유지됩니다.

- **`storage`** — 설정값과 고정 채널 목록은 Chrome 동기화 저장소에, 컴프레서의 마지막 기본 선택과 탭별 켜짐·꺼짐·출력 볼륨·라이브 시청 기록·팔로잉 라이브 제목 이력·댓글 API 요청용 임의 식별자는 이 기기의 로컬 확장 저장소에 저장합니다.
- **`scripting`** — 동영상 광고 차단을 켜면 패키지 내부 광고 처리 스크립트를 치지직 문서 시작 시점에 실행하도록 등록하고, 끄면 등록을 해제합니다. 팔로잉 라이브 제목 이력은 열린 일반 치지직 탭이 있으면 그 탭에서 팔로잉 라이브 목록을 읽는 패키지 내부 함수를 실행합니다. 대상은 `https://chzzk.naver.com/*`입니다.
- **`alarms`** — 방송 시작 알림·자동 열기가 켜진 채널과, 팔로잉 라이브 제목 이력이 켜져 있으면 팔로우한 라이브 목록을 약 1분마다 확인하도록 예약합니다.
- **선택 권한 `notifications`** — 방송 시작 데스크톱 알림을 켜고 옵션을 저장할 때 요청합니다. 자동 탭 열기에는 필요하지 않습니다. 열린 치지직 방송 탭 확인은 기존 치지직 호스트 권한을 사용합니다.
- **선택 권한 `downloads`** — 영상 녹화 파일을 다운로드 폴더 안의 지정한 폴더에 저장할 때만 씁니다. 설정에서 녹화 저장 폴더를 정해 저장하거나 **다운로드 권한 허용**을 누를 때 요청합니다. 확장이 녹화를 내려받기 직전에 기억한 그 파일 하나에만 폴더를 붙이고, 다른 다운로드는 읽거나 바꾸지 않습니다. 녹화 버튼 자체에는 필요하지 않습니다.
- **호스트 권한** — 방송 정보, 다시보기·댓글, 카테고리 메타데이터, 방송 시간 통계와 통나무 claim을 조회·수령하기 위해 다음 도메인에 요청합니다.
    - `https://chzzk.naver.com/*`
    - `https://api.chzzk.naver.com/*`
    - `https://apis.naver.com/*`
- **선택 호스트 권한** — `https://*.pstatic.net/*`: 라이브 미리보기 영상을 불러오는 네이버 CDN입니다. 설치할 때가 아니라 설정에서 **방송 목록 호버 미리보기** 또는 **라이브 멀티뷰**를 켜는 순간에 허용 여부를 묻고, 한 번 허용하면 다시 묻지 않습니다.

- **`storage`:** 옵션·고정 채널·폴더는 Chrome 동기화 저장소에 보관합니다. 컴프레서 상태·채팅/사이드바 크기·카테고리 제외(최대 100개)·방송 알림 채널·멀티뷰 딜레이/화질·라이브 시청 기록·팔로잉 방제 이력·댓글 요청용 임의 식별자는 로컬 저장소에 보관합니다.
- **`scripting`:** `동영상 광고 차단`을 켜면 패키지의 메인 월드 스크립트를 `https://chzzk.naver.com/*` 문서 시작 시점에 실행하도록 등록하고, 끄면 등록을 해제합니다. `팔로잉 라이브 제목 이력`을 켜면 열린 치지직 탭에서 목록 조회 함수를 실행합니다.
- **`alarms`:** 방송 시작 알림·자동 열기와 팔로잉 방제 이력의 1분 주기 확인을 예약합니다.
- **선택 권한 `notifications`:** 방송 시작 데스크톱 알림을 켤 때만 요청합니다.
- **선택 권한 `downloads`:** 녹화 파일을 다운로드 폴더 안의 지정한 하위 폴더에 저장할 때 사용해요. 옵션에서 새 폴더를 저장하거나 **다운로드 권한 허용**을 누를 때만 요청하며, 녹화 버튼 자체에는 필요하지 않아요. 녹화 직전에 기억한 파일 하나에만 저장 폴더를 제안해요.
- **필수 호스트 권한 (`chzzk.naver.com`, `api.chzzk.naver.com`, `apis.naver.com`):** 방송·다시보기·댓글·카테고리·통계 조회와 로그인 세션 기반 `log-power` 보상 수령에 사용합니다.
- **선택 호스트 권한 (`*.pstatic.net`):** `방송 목록 호버 미리보기` 또는 `라이브 멀티뷰`를 켤 때 네이버 CDN 영상 스트림 수신을 위해 요청합니다.
- **메모리 전용 처리:** 채팅 모아보기 메시지·미확인 상태, 다시보기 내 채팅 비교용 해시 ID, 카테고리 제외 메뉴의 검색어·결과는 페이지 메모리에서만 처리하며 브라우저 저장소에 보관하지 않습니다.

## 문제 해결

### List-KR 필터 사용 시 플레이어 단축키 미동작

List-KR 필터 환경에서는 `Space`, `M`, `T`, `F` 등 기본 단축키가 간헐적으로 막힐 수 있습니다. 광고 차단 확장 프로그램에서 `chzzk.naver.com`을 예외 처리한 뒤 새로고침하거나, 설정의 **기본 단축키 복구**를 켜는 것을 권장합니다.

### 확인 버튼만 있는 안내 팝업이 남을 때

다른 확장 프로그램을 함께 사용하는 등의 이유로 같은 방송에서 **확인** 전용 팝업이 반복되거나 치지직 구조가 바뀌면, 자동 닫기를 멈추고 팝업을 남깁니다. 직접 **확인**을 누르거나 함께 쓰는 확장 프로그램에서 `chzzk.naver.com`을 예외 처리해야 합니다. 치즈 스패너의 `동영상 광고 차단` 옵션은 별개로 동작합니다.

## 개발

번들러나 빌드 단계 없이 동작하는 순수 Manifest V3 확장 프로그램입니다. 저장소에는 개발 편의를 위한 도구만 포함되어 있습니다.

```powershell
npm.cmd ci
npm.cmd run test:all -- --test-concurrency=2
npm.cmd run lint
npm.cmd run format:check
git diff --check
```

- 전체 검증은 위 순서로 실행해요. 기본 `npm.cmd test -- --test-concurrency=2`는 공개 기능 중심이며 개발 전용·저장한 실측 자료 검사까지 포함하려면 `test:all`을 사용해요. 실측 자료 테스트 통과와 현재 Chrome의 실제 재생·화면 확인은 별개예요.
- 작은 기능 수정은 관련 검사와 변경 파일 lint·포맷으로 확인해요. 전체 자동 포맷으로 기존 작업을 일괄 바꾸지 않아요. 자세한 검사·브라우저·배포 절차는 [운영 문서](docs/operations.md)를 따라요.
- 작업 지침(아키텍처, 하드 제약, 검증 절차, 릴리스 규칙)은 [AGENTS.md](AGENTS.md)에 정리되어 있습니다.
- 주요 런타임 JS 파일 최상단에는 역할·의존·구조를 설명하는 헤더 주석이 있으므로, 파일을 통독하기 전에 헤더부터 읽으면 됩니다.
- 모든 설정 옵션은 `shared/settings.js`의 `OPTION_SCHEMA`에서 단일하게 정의되며, 설정 화면(`options.html`)의 항목과 기본값·정규화 규칙이 여기서 파생됩니다.
