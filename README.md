# 치즈 스패너

> 치지직(CHZZK) 시청·탐색 편의를 개선하는 비공식 Chrome 확장 프로그램입니다.

![치즈 스패너 아이콘](icons/cheese-spanner128.png)

자동 화질 복구, 스킵·배속·볼륨 조절, 방송자·운영자·파트너·챌린저 채팅 모아보기, 팔로잉 고정·폴더·미리보기, 다시보기 검색·댓글, 방송 목록 검색·필터, 방송 시간 통계, 라이브 시청 기록, 통나무 보상 자동 수령, 시청 방해 팝업 제거를 지원합니다. 대부분의 기능은 설정에서 개별로 켜거나 끄고 세부 수치를 조절할 수 있습니다.

- **버전:** 1.4.9
- **플랫폼:** Chrome (Manifest V3)
- **대상 사이트:** `https://chzzk.naver.com/*`
- **언어:** 한국어

[Chrome 웹 스토어에서 설치](https://chromewebstore.google.com/detail/cheese-spanner/dbpnbemehejfmobkemhpebomhabpljeb) · [전체 업데이트 내역](docs/update-history.md)

## 최신 변경 사항

### 1.4.9

- **다시보기 댓글 챕터**는 영상 아래의 댓글 **⋯ → 챕터 추가**에서 선택할 수 있습니다. 시각이 3개 이상인 인기 댓글의 챕터는 자동으로 추가됩니다.
- **채팅 모아보기**를 열거나 작성자를 바꾸면 빨간 `새 메시지` 선에서 첫 미확인 채팅부터 읽을 수 있습니다.
- **라이브·다시보기 멀티뷰**에서 빈 하단 줄을 접고, 플레이어 하단 경계에 마우스를 올려 강조된 선을 위로 끌면 다시 펼칠 수 있습니다. 플레이어의 검은 영역은 원래 화면 비율을 유지합니다.
- **전체 방송 → + 제외 추가**에서 이름 일부로 카테고리, 방송 태그와 배지를 함께 검색해 숨길 수 있습니다.
- **다시보기 댓글**의 첨부 사진을 눌러 확대하고, 채널 다시보기 검색 결과에서 댓글 안의 재생 시각을 눌러 해당 장면으로 이동할 수 있습니다.
- **스트림 정보 → 진단 복사**에서 현재 화질·해상도·버퍼·FPS를 한 번에 복사할 수 있습니다.

자세한 변경 내용은 [1.4.9 업데이트 내역](docs/update-history.md#149)에서 확인할 수 있습니다.

### 1.4.8

- **다시보기 멀티뷰:** 설정의 **플레이어 → 다시보기 멀티뷰**에서 켭니다(기본 꺼짐). 플레이어 하단 멀티뷰 버튼으로 최대 6개 영상을 같은 방송 시각에 맞춰 시청하며, **＋ 추가 → 검색·주소 / 팔로잉** 또는 링크 드래그로 영상을 추가합니다. 영상별 동기화 켜기·끄기와 제거(`X`)를 지원합니다([상세 보기](#10-다시보기-멀티뷰)).
- **멀티뷰 타임라인:** 추가한 영상 위의 **타임라인**을 펼치면 얇은 막대 하나에 각 방송의 시작·종료 프로필을 한 줄로 표시합니다. 마우스를 올리거나 키보드로 선택하면 시각을 확인할 수 있으며, 공통 구간이 있으면 **공통 구간으로 이동**으로 해당 시작 시각에 맞춥니다.
- **채팅·댓글 분할 보기:** 다시보기 댓글의 **표시 방식 → 분할**에서 두 내용을 위아래로 함께 보고, 경계선을 끌어 비율을 조절합니다.
- **스트리머 등급 필터:** 방송 목록에서 파트너·챌린저·프로·일반을 복수 선택합니다. 프로·일반은 공개 구독 지원 여부로 구분하며 실제 등급의 확정값은 아닙니다.
- **채팅창 닉네임 숨기기:** **채팅 → 채팅 표시**에서 켭니다(기본 꺼짐). 배지와 모아보기 대상(방송자·운영자·파트너·챌린저)의 이름은 유지합니다.
- **라이브 자동 배속 방지:** **플레이어 → 배속·단축키**에서 기본 켜짐으로 동작하며, 늦게 시청할 때의 자동 따라잡기 가속을 차단해 1배속을 유지합니다.

자세한 변경 내용은 [1.4.8 업데이트 내역](docs/update-history.md#148)에서 확인할 수 있습니다.

### 1.4.7

- **채팅창 후원 메시지 숨기기:** **채팅 → 채팅 표시**에서 켜면(기본 꺼짐) 라이브·채팅 팝업·다시보기·채팅 멀티뷰의 일반·미션·파티 후원 메시지를 숨깁니다. 후원 기록과 영상·음성은 유지합니다.
- **채팅 문구 숨김:** 채팅창 오른쪽 위 **⋯ → 문구 숨김** 또는 설정의 **채팅 → 문구 숨김**에서 숨길 문구를 지정합니다([상세 보기](#14-채팅-도구)).
- **영상 녹화:** 플레이어 오른쪽 아래 녹화 버튼으로 보는 영상을 MP4·WebM 파일로 저장하며, 설정의 **폴더 선택…**에서 저장 위치를 지정할 수 있습니다([상세 보기](#7-영상-녹화)).
- **미니 플레이어·화면 확대 개선:** 미니 플레이어와 확장 패널의 겹침을 줄이고, 페이지 내 작은 플레이어에서 돌아왔을 때 확대 상태를 유지합니다. 좁힌 채팅의 프로필 닫기 버튼과 광고 중 조작 문제도 수정했습니다.

자세한 변경 내용은 [1.4.7 업데이트 내역](docs/update-history.md#147-2026-11-08)에서 확인할 수 있습니다.

### 1.4.6

- **다시보기 시작·종료 시각:** 조회수 옆 날짜 자리에 한국 시간(KST) 기준 방송 시작·종료 시각을 표시합니다(예: `10.25(일) 17:56 ~ 23:08`). 분할 다시보기는 현재 구간 기준이며, `다시보기에 당시 시간 표시`를 끄면 원래 날짜를 표시합니다.
- **방송 알림 사이트 액세스 안내:** 확장 사이트 액세스에서 `api.chzzk.naver.com` 접근이 꺼져 있으면 설정의 **방송 알림** 탭에 안내와 **치지직 API 접근 허용** 버튼을 표시합니다.
- **새 기능 안내:** 업데이트 시 변경 사항을 한 줄로 요약해 표시합니다.

자세한 변경 내용은 [1.4.6 업데이트 내역](docs/update-history.md#146-2026-10-28)에서 확인할 수 있습니다.

## 설치 방법

- **웹 스토어 설치:** [Chrome 웹 스토어](https://chromewebstore.google.com/detail/cheese-spanner/dbpnbemehejfmobkemhpebomhabpljeb)에서 **Chrome에 추가**를 선택합니다. 심사 시점에 따라 저장소 버전과 다를 수 있습니다.
- **수동 설치(ZIP·소스):**
    1. 배포 ZIP의 압축을 해제하거나 다음 명령으로 저장소를 복제합니다.
        ```bash
        git clone https://github.com/neder2/Chzzk.git
        ```
    2. `chrome://extensions`로 이동해 우측 상단 **개발자 모드**를 켭니다.
    3. **압축해제된 확장 프로그램을 로드합니다**를 선택한 뒤 `manifest.json`이 있는 폴더를 지정합니다. 별도 빌드는 필요하지 않습니다.

## 빠른 시작

- **설정 열기:** 브라우저 툴바의 치즈 스패너 아이콘을 눌러 설정창(`options.html`)을 엽니다. `chrome://extensions`의 세부정보 → **확장 프로그램 옵션**에서도 열 수 있습니다.
- **탭 구성:** `플레이어 · 소리 · 시청 기록 · 채팅 · 화면 정리 · 방송 시간 · 다시보기 · 팔로잉·미리보기 · 방송 목록 · 방송 알림` 순서로 구성됩니다. 마우스 세로 휠로 가로 스크롤할 수 있으며, 방향키·`Home`·`End` 이동도 지원합니다.
- **검색·편집·저장:** 상단 검색창에 `녹화 폴더`처럼 여러 단어를 입력하면 순서에 관계없이 모두 일치하는 설정의 묶음이 펼쳐집니다. `합방`·`동시시청`으로 멀티뷰를, `도네`로 후원 관련 설정을 찾을 수 있습니다. **설정으로 이동**에서 결과를 선택하면 해당 설정에 초점이 갑니다. 검색창에서 ↓로 결과를 열고 Tab과 Enter로 선택할 수 있습니다. 다시보기의 **시청 화면**과 플레이어의 **다시보기 멀티뷰** 설정은 서로 바로 이동할 수 있습니다. 변경 건수는 하단에 표시되며 **옵션 저장**을 눌러 적용합니다. 확장 업데이트 직후나 동영상 광고 차단을 새로 켰을 때는 탭 새로고침이 필요합니다. 저장하지 않은 수정은 **변경 취소**, 전체 초기화는 상단 **⋯ → 기본값 복원**에서 실행합니다.
- **테마·글꼴:** 설정창 상단 테마 버튼으로 `시스템 설정 → 화이트 → 다크`를 전환합니다. 저장하면 열린 시청 기록과 다시보기 대기 화면에도 같은 테마가 적용됩니다. 설정·기록 화면과 확장 자체 패널은 내장 Pretendard를 사용하고, 치지직의 기존 글꼴을 따르는 요소는 해당 글꼴을 유지합니다. 외부 폰트 서버에는 접속하지 않습니다.
- **새 기능 안내:** 업데이트 후 변경 요약을 1회, 20초간 표시합니다. 안내 위에 마우스를 두거나 안내 안에 키보드 초점을 두면 시간이 멈춥니다. 자동 안내는 전체화면·입력 중이거나 표시 공간이 부족하면 대기하며, 신규 설치에는 표시하지 않습니다. **화면 정리 → 새 기능 안내**에서 자동 표시를 끄거나 **새 기능 다시보기**를 이용할 수 있습니다. 이전 1.3.7 공지 팝업은 표시하지 않습니다.

## 기능 상세

### 플레이어·재생

#### 1. 자동 화질 복구

- 라이브·다시보기 입장과 선호 화질 설정 저장 시 `고정할 화질`(1080p·720p·480p, 기본 1080p)을 우선 적용합니다.
- 해당 화질이 없으면 가능한 가장 높은 하위 화질을 선택하며, 시청 중 설정을 저장하면 현재 영상에도 바로 적용합니다.
- 라이브는 초기 재생이 시작된 뒤 화질을 적용해 재생 충돌을 줄이며, 사용자가 직접 일시정지한 영상은 자동 재생하지 않습니다.
- **관련 설정:** `자동 화질 복구`(기본 켜짐), `고정할 화질`(기본 1080p).

#### 2. 스킵·배속·단축키

- **방향키 스킵:** `←` / `→`로 `기본 스킵` 초만큼 이동합니다. 라이브는 타임머신 범위 안에서 동작하며, 입력창에 초점이 있거나 조합키를 누른 경우는 제외합니다. 일시정지 중에는 프레임 이동을 지원합니다.
- **스킵 알약 버튼:** 재생 시각 옆 버튼에서 휠(`휠 기본`), `Shift`+휠, `Alt`+휠로 스킵 시간을 조절하고, 버튼에 초점을 둔 채 `↑`·`↓`를 누르면 `휠 기본` 단위로 늘리거나 줄입니다. 클릭하면 기본값으로 되돌립니다. 라이브 컨트롤에는 실시간 끝으로 이동하는 **빨리 감기** 버튼도 제공합니다.
- **일시정지 중 실시간 복귀 방지:** 일시정지 후 다시 재생할 때 멈춘 위치를 이어 볼 수 있도록 실시간 위치로의 강제 복귀를 완화합니다.
- **타임머신 지연 표시:** 라이브 타임머신 시청 중 실시간 대비 지연 시간을 표시합니다.
- **Space·좌클릭 홀드 2배속:** `Space` 또는 영상 좌클릭을 0.35초 이상 길게 누르는 동안 2배속을 적용하고, 놓거나 드래그하면 해제합니다. 짧은 `Space`는 재생·일시정지를 전환하며, 길게 누르는 동작만으로는 일시정지한 영상을 재생하지 않습니다.
- **배속 조절 단축키:** `[`로 0.25배 감소, `]`로 0.25배 증가하며 0.25~4배 범위에서 길게 눌러 연속 조절할 수 있습니다. `\`로 1배속을 복원합니다. 설정에서 키를 바꿀 수 있으며, 입력창과 기존 플레이어 조작 키(`Space`, `c`/`m`/`f`/`t`, `j`/`k`/`l`, 방향키, 쉼표·마침표, 조합키)는 지정할 수 없습니다. 중복되거나 `C`로 저장된 값은 기본 키로 복원합니다.
- **라이브 자동 배속 방지:** **플레이어 → 배속·단축키 → 라이브 자동 배속 방지**는 기본 켜짐입니다. 실시간보다 늦게 볼 때 네이티브 자동 따라잡기 가속을 막아 기본 1배속을 유지하며, 홀드 2배속과 수동 배속 조절은 그대로 사용할 수 있습니다. 버퍼링으로 늘어난 지연을 특정 초로 고정하지는 않으며, 끄면 치지직의 자동 따라잡기로 돌아갑니다.
- **기본 단축키 복구:** `Space`·`M`·`F`·`T` 기본 단축키가 동작하지 않을 때 **플레이어 → 배속·단축키 → 기본 단축키 복구**를 켭니다(기본 꺼짐). 입력창·조합키에는 개입하지 않으며, `Space·좌클릭 홀드 2배속`을 켜면 `Space`는 홀드 기능이 우선 처리합니다.
- **관련 설정:** `다시보기·타임머신 스킵`, `일시정지 중 실시간 복귀 방지`, `타임머신 지연 표시`, `스킵 시간 조절 버튼 표시`, `라이브에도 스킵 시간 조절 버튼 표시`, `방향키·프레임 이동`, `기본 스킵`/`휠 기본`/`Shift+휠`/`Alt+휠`, `라이브 자동 배속 방지`, `기본 단축키 복구`, `Space·좌클릭 홀드 2배속`, `배속 조절 단축키` 및 감소·증가·복원 키.

#### 3. 볼륨 조절·오디오 컴프레서

- **볼륨 휠·툴팁:** 볼륨 영역에서 휠로 `1틱 볼륨` 단위만큼 조절하며 멀티뷰 보조 방송에도 동일하게 적용합니다. 메인 스피커·볼륨바와 상하 8px 영역에 마우스를 올리면 볼륨(%) 툴팁을 표시합니다. 음소거 중에도 표시하며 멀티뷰 보조 방송은 툴팁 대상에서 제외합니다.
- **오디오 컴프레서:** 볼륨바 옆에 컴프레서 토글 버튼과 압축 후 출력 볼륨바를 추가합니다. 출력 볼륨은 0~100%(기본 100%)이며 방향키·휠로 조절할 수 있습니다. 원래 스피커 볼륨·음소거 상태는 유지합니다.
- **컴프레서 상태 기억:** 새 탭의 첫 라이브·다시보기 진입 시 마지막 켜짐 여부·출력 볼륨을 복원하고, 이후에는 탭별 선택을 독립적으로 유지합니다. 로컬 저장소에 최대 128개 탭의 기록을 보관합니다. 옵션을 끄거나 `cheese-knife` 컴프레서를 감지하면 적용만 일시 해제하며 저장값은 보존합니다.
- **관련 설정:** `휠로 볼륨 조절`, `1틱 볼륨`, `볼륨 % 표시`, `컴프레서 버튼 표시`, 임계값·압축 전환 폭·비율·어택·릴리즈·보정 게인.

#### 4. 스트림 정보·화면 표시·자동 새로고침

- **스트림 정보:**
    - **진단 복사:** 현재 화질·재생 해상도·버퍼·FPS를 텍스트로 복사합니다. 클립보드 접근이 차단되면 표시된 텍스트를 선택해 복사할 수 있습니다.
    - **열기·닫기:** 플레이어 **톱니바퀴 → 스트림 정보 열기/닫기**에서 조작합니다. 기본 켜짐이며 `플레이어 → 시청 화면·멀티뷰 → 스트림 정보`에서 설정합니다. 패널 닫기 버튼·`Esc`·키보드 `Enter`/`Space`를 지원합니다.
    - **공통 항목:** 현재 해상도, 비트레이트, 남은 재생 버퍼, 최근 구간 FPS, 하드웨어 가속 정보, 재생 상태·속도를 표시합니다. 비트레이트는 실제 전송 속도가 아닌 라이브 API 설정값이며 다시보기에서는 측정할 수 없습니다. 하드웨어 가속 정보는 WebGL 렌더러 기준으로 현재 영상의 디코딩 여부와 다를 수 있으며, CPU·GPU 사용률은 제공하지 않습니다.
    - **일반 라이브 추가 항목** (자동 화질 설정과 무관하게 표시):

        | 항목              | 설명                                                                                 |
        | ----------------- | ------------------------------------------------------------------------------------ |
        | 현재 재생 방식    | 현재 선택 트랙의 저지연/일반 여부(설정 스위치 상태와 별개)                           |
        | 라이브 지연(추정) | 플레이어 라이브 끝과 현재 시청 위치의 차이(촬영~화면 전체 지연 아님)                 |
        | 최근 60초 그래프  | 실선: 지연 추정, 점선: 재생 버퍼, 세로 점선: 재생 방식 변경 시점(미측정 구간 미연결) |
        | 관측 끊김         | 최근 60초 버퍼 대기 횟수·합산 시간(초기 로딩·일시정지·탐색·광고·전환·탭 숨김 제외)   |

    - **측정·보관 기준:** 패널을 연 채 탭이 보일 때만 약 1초 간격으로 측정하며, 닫거나 탭을 숨기면 중단합니다. 패널을 닫으면 측정 기록을 버리며 외부로 전송하거나 저장하지 않습니다. 탭 복귀·화질/방식 전환 시 그래프 선을 끊고 이어 측정하며, 다른 방송으로 바뀌면 측정을 새로 시작합니다. 재생 위치·화질·배속을 변경하거나 저지연 안정성을 자동 판정하지 않으며, 되감기 시청은 별도 상태로 표시합니다.

- **우상단 LIVE 숨기기 / 방송 시작 시각 표시:** 각각 `화면 정리 → 플레이어 표시`, `플레이어 → 시청 화면·멀티뷰`에서 설정하며 기본 꺼짐입니다. 시작 시각은 ‘스트리밍 중’ 옆에 KST 기준으로 표시합니다. 당일에는 `14:30 시작`처럼 표시하고 다른 날이면 날짜도 포함하며, 타임머신 위치와는 무관합니다.
- **플레이어 버튼 숨기기:** `화면 정리 → 플레이어 표시`의 **클립 버튼 숨기기**, **PIP 버튼 숨기기**(모두 기본 꺼짐)는 저장 즉시 라이브·다시보기 플레이어에 반영됩니다. 버튼 표시만 숨기며 이미 실행 중인 PIP는 유지합니다.
- **방송 시작 시 자동 새로고침:** `"다음 라이브를 기대해주세요!"` 화면에서 30초마다 방송 상태를 확인하고, 방송이 시작되면 한 번 새로고침합니다. 기본 켜짐이며 재생 시작·페이지 이동 시 확인을 중단합니다.

#### 5. 화면 확대

`플레이어 → 시청 화면·멀티뷰 → 휠로 화면 확대`에서 켤 수 있으며 기본 꺼짐입니다. 적용 방식은 세 가지입니다.

- **확대 버튼을 켠 동안:** 플레이어 오른쪽 하단의 돋보기 버튼으로 확대 모드를 켜고 끕니다. 모드를 끄면 원래 크기로 돌아갑니다.
- **영상 위에서 항상:** 확대 버튼을 누르지 않아도 영상 위의 휠로 바로 확대·축소합니다. 최소 배율인 100%에서 아래로 휠을 내리면 페이지가 스크롤됩니다. 다만 휠로 100%까지 축소한 직후에는 이어지는 아래 휠 입력을 막고, 휠을 멈춘 뒤 1초가 지나면 페이지 스크롤을 허용합니다. 대기 중에도 위 휠로 바로 다시 확대할 수 있습니다.
- **단축키를 누른 채 휠:** 지정한 키(`Alt`(Mac은 `Option`)·`Ctrl`·`Shift`·`Command` 중 하나, 기본 `Alt`)를 누른 채 영상 위에서 휠을 돌리면 확대·축소합니다. 키 없이 돌린 휠은 페이지 스크롤에 그대로 넘기고, 키를 떼도 확대 상태는 유지됩니다. 키를 누른 휠은 100%에서도 페이지 스크롤에 넘기지 않으며, `Ctrl`을 지정하면 영상 위에서는 브라우저 확대 대신 화면 확대가 동작합니다.

**공통 조작 및 제한:**

- 모든 방식에서 휠로 커서 위치를 중심으로 **1–5배**까지 확대하며, 확대한 화면은 왼쪽 버튼으로 드래그해 이동합니다.
- 오른쪽 아래 확대 박스는 배율 표시, **슬라이더**, **되돌리기 아이콘**을 한 줄로 배치합니다. 슬라이더는 현재 화면 중심을 유지하며 **100–500%를 1% 단위**로 조절하고 키보드 방향키·`Home`·`End`를 지원합니다. 버튼 방식에서는 확대 모드를 켜면 100%부터 슬라이더를 사용할 수 있습니다.
- 확대 박스는 처음에는 하단 재생 컨트롤 위쪽에 표시되며, **퍼센트 표시나 빈 여백을 잡아 영상 영역 안에서 이동**할 수 있습니다. 슬라이더와 되돌리기 버튼은 기존 조작을 유지합니다. 옮긴 위치는 창 크기·전체화면 변경에 맞춰 영역 안에 유지되며, 컨트롤 표시 여부나 호버에 따라 바뀌지 않습니다.
- 볼륨·재생바·설정 메뉴의 휠과 기본 클릭·더블클릭은 유지되며, 확대·드래그 중에도 왼쪽 스킵·빨리 감기·컴프레서 버튼은 원래 위치를 유지합니다.
- 라이브·타임머신·다시보기와 멀티뷰의 메인·보조 영상에 적용되며, 영상마다 배율과 위치를 따로 조절합니다. 보조 영상의 버튼 조작 모드도 각 영상 하단의 확대 버튼으로 켭니다. 멀티뷰의 `Alt` 드래그는 유지하며, 방송 이동·영상 교체·옵션 해제 시 확대를 초기화합니다.

#### 6. 앰비언트 효과

- **설정:** `플레이어 → 앰비언트 효과`에서 켤 수 있으며 기본 꺼짐입니다. `효과 강도`는 10~100%, 5% 단위로 조절하며 기본 60%입니다. 영상 색이 상단·채팅창·사이드바·하단 정보 주변으로 은은하게 번지며, 다크·라이트 테마에 대응합니다.
- **플레이어 제어:** 톱니바퀴 메뉴에 **앰비언트** 스위치와 **세기** 슬라이더를 제공합니다. 스위치 선택은 현재 프로필의 로컬 저장소에 기억합니다.
- **중단 조건:** 전체 화면, 라이브 멀티뷰 활성, 미니 플레이어/페이지 내 작은 플레이어, 백그라운드 탭, 플레이어 화면 이탈 시 색 갱신·표시를 중단합니다. 영상 프레임은 브라우저 안에서 색상 효과에만 이용하며, 영상을 녹화하거나 외부에 저장하지 않습니다.

#### 7. 영상 녹화

`플레이어 → 영상 녹화 → 녹화 버튼`에서 켜고 끌 수 있습니다(기본 꺼짐). 라이브·다시보기 플레이어 오른쪽 아래 버튼 줄 맨 앞의 녹화 버튼(동그라미)을 누르면 현재 시청 중인 영상과 소리를 저장하며, 다시 누르면 멈추고 파일을 마무리합니다. 녹화 중에는 버튼이 빨간 정지 모양으로 바뀌고 영상 왼쪽 위에 경과 시간이 표시됩니다.

- **화면 캡처 버튼:** 같은 묶음에서 캡처 버튼을 켜고 옵션을 저장한 뒤, 메인 플레이어 오른쪽 아래의 카메라를 누르세요. 그 순간의 원본 영상 프레임을 PNG로 만듭니다. 화면 확대·컨트롤·채팅은 사진에 들어가지 않습니다. 기본 동작은 Chrome 다운로드 위치에 파일 저장이며 클립보드 복사 또는 두 동작을 함께 선택할 수 있습니다. 녹화용 저장 폴더 설정은 녹화 파일에만 적용됩니다. 현재 방송의 새 영상 로드를 확인한 뒤 캡처할 수 있습니다. 재생 중에 처음 켰거나 방송을 전환한 뒤 안내가 계속되면 해당 방송 페이지를 새로고침하세요. 광고, 보호된 영상, 브라우저가 읽기를 차단한 영상, 완전히 검거나 투명한 프레임에는 안내가 표시됩니다.
- **파일 형식·이름:** Chrome이 MP4 녹화를 지원하면 MP4, 아니면 WebM으로 저장합니다. 파일 이름은 `날짜 방송 제목 - 스트리머 이름.mp4`(또는 `.webm`) 형식이며 날짜는 녹화 시작일의 한국 시간입니다(예: `2026-11-08 오늘 방송 - 스트리머.mp4`). 파일 이름에 쓸 수 없는 문자는 치환하고 긴 이름은 줄입니다. 방송 정보를 확인하지 못하면 현재 채널·영상 번호와 `스트리머 정보 없음`을 사용합니다.
- **저장 폴더 선택:** 설정의 `플레이어 → 영상 녹화 → 폴더 선택…`에서 탐색기를 열어 원하는 폴더를 지정합니다. 확장 아이콘의 작은 팝업에서는 전체 설정 탭을 먼저 연 뒤 **폴더 선택…**을 누릅니다. 플레이어 톱니바퀴의 **녹화 저장 폴더**를 누르면 이 설정이 열립니다. 선택은 다음 녹화부터 적용됩니다. 선택한 폴더는 이 기기의 브라우저 프로필에만 기억하며, 접근 권한이 사라지면 다시 선택해야 합니다. **다운로드 폴더 사용**으로 기본 방식으로 돌아갈 수 있습니다.
- **다운로드 폴더 사용:** 기본 저장 위치는 Chrome 다운로드 폴더입니다. 하위 폴더 이름(예: `치지직 녹화`, `/`로 최대 5단계)을 입력할 수 있으며, 이 방식에만 선택 권한 `downloads`가 필요합니다. 권한이 없으면 다운로드 폴더에 바로 저장합니다. Chrome의 ‘다운로드 전에 각 파일의 저장 위치 확인’을 켜 두면 저장 창이 열립니다.
- **저장 방식·자동 중지:** 선택한 폴더에는 녹화 조각을 파일에 순서대로 쓰고 같은 이름이 있으면 `(1)`, `(2)`를 붙여 기존 파일을 보존합니다. 기본 다운로드 방식에서는 Chrome 임시 파일(`.crdownload`)이 커진 뒤 중지 시 완성됩니다. 길이 제한이 없으며 전체 영상을 탭 메모리에 쌓지 않습니다. 페이지 안에서 다른 방송으로 이동하거나, 영상이 교체되거나, 녹화 옵션을 끄면 그때까지의 녹화를 마무리합니다. 녹화 중 탭 닫기·새로고침 시 확인 창이 뜨므로 파일을 완성하려면 녹화를 먼저 멈춘 뒤 이동하시기 바랍니다.
- **보안·저작권:** 녹화 파일은 이 기기에만 저장하고 외부로 전송하지 않습니다. 녹화는 버튼을 누를 때만 시작하며, 녹화한 콘텐츠의 이용은 방송 저작권과 치지직 이용약관을 따르시기 바랍니다.

#### 8. 시청 방해 팝업 제거·광고 처리

- **시청 방해 팝업 제거** (`adblockPopupEnabled`, 기본 켜짐):
    - 광고 차단 안내를 먼저 숨긴 뒤 닫기 버튼을 자동으로 눌러 팝업을 닫습니다. 닫기 버튼이 없거나 닫히지 않는 안내는 직접 확인할 수 있도록 화면에 남깁니다.
    - 닫기 버튼 없이 **확인** 버튼만 있는 일부 안내도 자동으로 닫으며, 닫히지 않거나 같은 방송에서 반복해서 다시 뜨면 직접 누를 수 있도록 남깁니다.
    - 고화질 설치 안내는 네이버 라이브 스트리밍 커넥터와 크롬·엣지 확장 프로그램 설치 안내를 모두 처리하며, 설치 없이 일반 화질 또는 기본 화질로 시청하는 버튼을 선택합니다.
    - 화면에 표시된 활성 버튼만 누르며 저장된 설정을 확인한 뒤 자동 닫기를 시작합니다. 옵션을 끄면 페이지에 처음 들어갈 때도 안내를 자동으로 닫지 않습니다.
- **동영상 광고 차단 — 실험적** (`adVideoEnabled`, 기본 켜짐):
    - 본영상 재생을 우선하는 실험 기능으로, 확인된 라이브·다시보기 광고 표시 응답의 프리롤·미드롤 값, 광고 소스, 입장·중간 광고 일정을 처리합니다.
    - 켜고 저장한 뒤 치지직 탭을 새로고침해야 적용됩니다(자동 새로고침 없음). 이미 시작된 광고를 즉시 제거하지는 않습니다. 끄면 이후 처리를 멈추며, 이미 반영한 플레이어 상태는 새로고침 시 복원됩니다.
    - 라이브 PiP를 유지한 채 홈·목록으로 이동해도 현재 본영상과 소유가 일치하는 중간 일정을 처리합니다. 치지직 응답·플레이어 구조나 소유 관계가 달라지거나 지원 처리 지점을 지나지 않으면 원래 동작을 유지하므로 광고가 재생될 수 있습니다. 방송 스트림에 포함된 광고나 모든 광고 경로를 차단하지 않으며, SDK 교체나 광고 서버 전체 차단도 수행하지 않습니다.
- **배너 광고 숨기기** (`adBannerEnabled`, 기본 꺼짐):
    - 홈·라이브·VOD의 기본 배너와 광고 재생 연동 배너 슬롯만 CSS로 숨깁니다. 일반 이벤트·콘텐츠 안내 영역은 숨기지 않으며, 광고 요청 자체를 차단하지는 않습니다.
    - 배속·시간 이동·자동 화질의 본영상 선택에서는 확인된 광고 영상을 제외합니다.

### 멀티뷰

#### 9. 라이브 멀티뷰

라이브 멀티뷰 설정에서 **현재 구성 저장**을 누르면 채널 목록 하나를 이 프로필에 보관합니다. **저장 목록 열기**에서 후보를 살펴보고 원하는 방송을 하나씩 추가할 수 있습니다. 채팅 멀티뷰를 켠 경우 **보조 방송 채팅 선택**에서 남은 칸에 넣을 채널을 고른 뒤 확인합니다. 이 선택은 열려 있는 다른 채팅 멀티뷰에도 적용됩니다. 직접 제거한 라이브 보조 방송 한 개는 같은 탭에서 5분간 **이전 소리로 다시 추가**할 수 있습니다. 버튼에 표시된 음량·음소거를 적용해 새로 재생하며, 일반 추가는 30%·음소거로 시작합니다.

목록에서 **이 방송만 듣기**를 누르면 원래 믹스를 기억한 채 그 방송만 들을 수 있습니다. 같은 버튼을 다시 누르면 원래 믹스로 돌아갑니다. 보조만 들으려면 메인이 이미 음소거·0%이거나 이 탭의 메인 컴프레서를 한 번 켜서 오디오 경로가 연결돼 있어야 합니다. 음소거하거나 정지해 둔 방송은 먼저 직접 소리나 재생을 켜야 선택할 수 있습니다.

설정에서 **플레이어 → 라이브 멀티뷰**를 켜고(기본 꺼짐) 영상 호스트 권한(`*.pstatic.net`)을 허용한 뒤, 라이브 플레이어 하단의 **넓은 화면 버튼 왼쪽 격자 모양 멀티뷰 버튼**을 누릅니다. 켜진 상태는 초록색으로 표시되며 다시 누르면 끕니다.

- **방송 추가 방법:**
    - 패널 상단 **＋ 추가**를 누르면 패널 안에 **검색·주소 / 팔로잉** 탭이 펼쳐지고, 추가를 마치면 추가 영역만 접혀 목록·설정을 계속 사용할 수 있습니다. 메인 포함 최대 6개 방송을 지원합니다. 추가 영역에서 `Esc`를 누르면 해당 영역만 접고, 한 번 더 누르면 패널을 닫습니다.
    - **팔로잉:** 로그인한 계정에서 방송 중인 팔로잉 채널을 선택해 추가합니다. 채널명으로 목록을 좁힐 수 있으며 탭을 열거나 새로고침할 때만 조회합니다. 이미 추가된 방송은 선택할 수 없으며, 로그인 필요·조회 실패·방송 중인 채널 없음을 구분해 안내합니다.
    - **닉네임 검색:** 닉네임 입력 후 검색 버튼이나 `Enter`를 누르면 팔로워순 상위 5개 결과에 프로필 사진·닉네임·방송 여부·시청자 수를 표시합니다. 방송 중인 결과를 누르면 음소거 상태로 추가됩니다.
    - **드래그 앤 드롭:** 팔로잉 라이브 링크나 다른 탭의 치지직 라이브 URL을 멀티뷰 영역으로 끌어다 놓아 추가할 수 있습니다. 분할 배치에서는 켜진 영상 영역에 놓으며, 자유 배치에서는 기존 영상 밖의 사이드바·채팅·빈 공간에도 포인터가 가리키는 위치에 추가합니다(입력칸·멀티뷰 설정창 제외).
- **화면 배치 (분할 배치 / 자유 배치):**
    - **분할 배치(기본):** 메인만 있을 때는 전체 영역을 사용하며, 보조가 추가되면 기본 배치는 메인 가로·세로 각 2/3(면적 4/9), 보조 각 1/3(면적 1/9)입니다. 실제 영상 비율(정보 확인 전에는 16:9)에 맞춰 박스 크기를 보정합니다. 아래가 비어 있으면 가로 경계선을 맨 아래까지 끌어 빈 줄을 접을 수 있습니다. 접어도 검은 플레이어 영역은 같은 너비에서 원래 높이를 유지합니다. 접힌 줄은 플레이어 하단 경계를 원하는 높이까지 위로 끌어 다시 펼칩니다. 경계에 마우스를 올리면 선이 강조됩니다. 영상이나 채널명을 플레이어 아래 가장자리로 끌어 하단 줄에 바로 배치할 수도 있습니다. 원하는 칸에서 놓거나 `Esc`로 취소할 수 있습니다.
    - **이동·분할·교환:** 분할 배치에서 보조 영상을 다른 영상의 상하좌우 가장자리로 드래그하면 해당 방향에 새 분할 영역을 만들고, 중앙은 순서 이동, 메인 영상 중앙에 놓으면 페이지 내부 이동으로 메인 방송을 전환합니다. 메인 영상을 보조 영역 위로 드래그하면 메인 쪽 묶음과 보조 묶음의 위치를 교환합니다. `Alt`를 누른 채 드래그하면 박스 여백 안에서 영상 위치만 조절합니다. 드래그 중 `Esc` 또는 우클릭은 취소입니다.
    - **크기 조절·정렬:** 각 영상 모서리를 대각선으로 드래그하거나 공유 구분선을 끌어 비율을 조절합니다(초점 후 방향키 조절, `Esc` 취소 지원). 설정의 **보조 방송 정렬**은 2개 이상 묶인 보조 영역을 균등 분할해 정리합니다.
    - **자유 배치:** 채팅창 상단 **멀티뷰 설정 → 자유 배치**에서 켜고 끕니다(기본 꺼짐). 메인·보조 창을 페이지 표시 영역 안에서 사이드바·채팅 위까지 자유롭게 옮기고 네 모서리로 비율을 유지하며 크기를 조절합니다. `Tab`으로 초점을 둔 뒤 방향키(모서리는 크기 조절, `Shift`와 함께 더 크게)로 조작할 수 있으며, 전체화면에서는 잠시 접었다가 해제 시 복원합니다.
    - 기존 `T` 전환(기본·넓은 화면)을 강제하지 않으며, 하단 제목·채널 상호작용·채팅은 메인 방송을 따릅니다.
- **조작·소리·화질:**
    - 보조 영상 하단에 **재생·일시 정지 → 빨리 감기 → 음소거·볼륨 슬라이더 → 싱크 −0.1s·+0.1s** 순서(화면 확대 버튼 모드 시 확대 버튼 포함)로 표시되며 마우스를 치우면 숨겨집니다. 우측 상단 **×**로 제거합니다.
    - 보조 화면을 **우클릭**하면 해당 방송의 음소거를 전환합니다(드래그 중 우클릭은 이동 취소). 스피커·볼륨 슬라이더 위 휠 조절은 `1틱 볼륨` 설정을 따릅니다.
    - **분할 배치나 설정 목록에서 방송 자리를 교환하면 소리 설정은 자리를 따르고, 딜레이는 채널을 따릅니다.** 새 보조 자리는 음소거로 시작합니다.
    - 채팅창 상단 **멀티뷰 설정** 버튼(모아보기 왼쪽, 꺼진 경우 더보기 버튼 옆)으로 목록 팝업을 열며, 목록 행 드래그나 키보드(`Space`/`Enter` + `↑`/`↓`)로 순서를 바꾸고 맨 위 메인 행에 놓아 메인을 교체할 수 있습니다. 각 보조 방송의 **화질**(`자동` 또는 480p 이상 고정)은 채널별로 저장합니다.
- **싱크(딜레이) 조절:**
    - **앞으로 / 늦추기**(±0.1s·±1s)로 채널별 목표 딜레이를 조절·저장해 새로고침·재시작·다음 방송에도 불러옵니다. **빨리 감기**는 저장 딜레이를 0초로 초기화하고 라이브 위치로 복귀합니다.
    - 목록에 **현재 추정 지연**, **저장된 딜레이**, **복원 대기 / 적용 완료 / 적용 불가**를 표시하며, 측정 전에는 **현재 측정 대기**로 표시합니다. 재생 실패 시 **재생 재시도**, 저장 실패 시 **다시 저장** 버튼을 제공합니다.
- **저장·보관 범위:** 방송 구성·크기·박스 안 위치·볼륨·자유 배치 상태는 현재 탭 세션 저장소에, 채널별 딜레이와 보조 화질은 확장 로컬 저장소에 보관합니다.

#### 10. 다시보기 멀티뷰

설정에서 **플레이어 → 시청 화면·멀티뷰 → 다시보기 멀티뷰**를 켭니다(기본 꺼짐). 다시보기(`/video/...`) 플레이어 하단의 멀티뷰 버튼으로 메인 포함 최대 6개 영상을 같은 방송 시각에 맞춰 시청합니다.

- **켜기·패널 열기:** 하단 멀티뷰 버튼으로 멀티뷰를 켜면 채팅창 상단 더보기(`⋯`) 왼쪽에 설정 버튼이 나타납니다. 이 버튼으로 조작 패널을 열거나 닫습니다. 패널을 숨겨도 추가한 영상은 계속 재생됩니다.
- **영상 추가·제거:**
    - 상단 **＋ 추가**의 **검색·주소** 탭에서 채널을 검색하거나 다시보기 주소를 입력하며, 다시보기 링크를 끌어 놓아 추가할 수도 있습니다.
    - **팔로잉** 탭에서는 로그인 계정의 팔로잉 채널을 선택하면 메인 방송과 시간이 겹치는 공개 다시보기를 찾아 추가합니다.
    - 목록에는 **메인 · 채널명**, **서브 1 · 채널명** 순으로 표시하고, 각 채널명 아래에 다시보기 제목을 표시합니다. 목록 오른쪽 **휴지통** 또는 보조 영상 우측 상단 **X**로 해당 영상을 제거합니다. 보조 화면 채널명이나 목록 제목을 누르면 해당 다시보기로 이동합니다.
    - 직접 제거한 보조 한 개는 같은 메인 다시보기에서 5분간 **이전 음소거 상태로 다시 추가**할 수 있습니다. 이전에 소리가 켜져 있었고 같은 영상·음량이 확인될 때 소리를 복원합니다. 음량이 다르거나 확인할 수 없으면 음소거로 열고 안내합니다.
- **이 영상만 듣기**를 누르면 다른 영상의 소리만 잠시 끕니다. 모든 영상이 재생 중이고 다른 영상마다 이미 음소거·0%이거나 컴프레서 출력이 연결돼 있을 때 사용할 수 있습니다. **단독 듣기 취소**를 누르면 원래 믹스로 돌아갑니다. 탭을 떠나거나 재생·음량을 직접 바꿔도 취소됩니다.
- **타임라인·공통 구간 이동:**
    - `추가한 영상` 위의 **타임라인**(기본 접힘)을 펼치면 공통 시간축 막대 하나에 각 방송의 시작·종료 시각(KST)과 스트리머 프로필을 한 줄로 표시합니다. 마우스를 올리거나 키보드 초점을 두면 시각과 상세 정보를 확인할 수 있습니다.
    - 모든 영상의 방송 시각이 확인되고 겹치는 구간이 있으면 공통 구간을 강조하며, **공통 구간으로 이동**을 눌러 메인을 해당 시작 시각으로 맞출 수 있습니다.
- **동기화·배치·조작:**
    - 영상을 추가하면 **동기화**가 켜진 상태로 시작해 메인의 방송 시각·재생 상태·배속에 맞춰 동작하며, 범위를 벗어나면 정지합니다.
    - 목록 오른쪽 **동기화 아이콘**을 끄면 해당 영상만 따로 탐색·재생·배속 조절을 할 수 있고, 다시 켜면 현재 메인의 시각과 상태에 맞춥니다. 아이콘에 마우스를 올리거나 키보드 초점을 두면 상태를 확인할 수 있습니다. 시각 맞추기가 반복해서 실패하면 **다시 맞추기**를 누르거나 동기화를 끄고 계속 시청할 수 있습니다.
    - 기본 배치는 메인을 왼쪽 위에 크게, 첫 보조 영상을 오른쪽 위에 작게 놓습니다. 빈 하단 영역은 가로 경계선을 맨 아래까지 끌어 접을 수 있습니다. 접어도 검은 플레이어 영역은 같은 너비에서 원래 높이를 유지합니다. 접힌 줄은 플레이어 하단 경계를 위로 끌어 펼칩니다. 경계에 마우스를 올리면 선이 강조됩니다. 영상이나 채널명을 아래 가장자리로 끌면 놓은 칸으로 영상이 이동합니다. 경계선을 끌어 크기를 바꾸거나 **보조 방송 정렬**로 같은 영역의 보조 영상들을 균등하게 맞출 수 있습니다. **자유 배치**에서는 영상을 개별적으로 옮깁니다. 보조 영상은 음소거 상태로 시작해 각 영상의 볼륨·화질·확대·방송 시계·컴프레서·녹화를 독립적으로 조작할 수 있습니다(녹화는 탭당 한 번에 한 영상만 진행).

### 채팅·다시보기·채널

#### 11. 채팅창·사이드바 크기·위치 조절

- **설정:** `채팅 → 채팅 표시 → 채팅창 너비·높이 조절`(기본 켜짐), `화면 정리 → 상단·사이드바 → 사이드바 너비 조절`(기본 켜짐).

| 대상           | 조절 위치                         | 적용 범위                                   |
| -------------- | --------------------------------- | ------------------------------------------- |
| 사이드바 너비  | 펼친 사이드바의 본문 쪽 가장자리  | 치지직 페이지 전반의 펼친 사이드바          |
| 채팅·댓글 너비 | 채팅·댓글 영역의 영상 쪽 가장자리 | 일반 라이브·다시보기의 채팅과 다시보기 댓글 |
| 채팅·댓글 높이 | 채팅·댓글 영역의 아래 가장자리    | 일반 라이브·다시보기의 채팅과 다시보기 댓글 |

- **조작·초기화:** 경계를 드래그해 조절하며, 채팅 높이는 240px부터 원래 높이까지 조절할 수 있고 입력창은 유지됩니다. 경계를 더블클릭하면 해당 크기만 기본값으로 돌아갑니다. 키보드 사용자는 `채팅 표시 → 저장한 채팅·사이드바 크기 초기화`에서 전체 크기를 초기화할 수 있습니다.
- **저장·반영:** 현재 Chrome 프로필의 로컬 저장소에 각각 저장하며 새 탭·새로고침·재시작 후에도 유지합니다. 이미 열린 다른 탭에는 새로고침 시 반영됩니다. 기능을 끄면 기본 배치로 돌아가지만 저장값은 보존합니다.
- **위치 변경:** `채팅창 위치`는 오른쪽(기본)·왼쪽, `사이드바 위치`는 왼쪽(기본)·오른쪽으로 선택할 수 있습니다. 같은 쪽에 배치하면 사이드바가 바깥쪽, 채팅이 안쪽에 놓이며 저장한 크기는 유지됩니다.
- **제한 및 보정:** 접힌 사이드바나 좁은 화면에서 본문과 겹치는 사이드바에는 조절 경계를 표시하지 않습니다. 창이 좁아 채팅이 아래로 내려가면 기본 순서로 표시하며, 치지직 최소 폭 미만에서는 사이드바가 임시로 왼쪽에 놓입니다. 채팅 팝업·임베드·클립·같이보기 우측 배치는 제외됩니다. 상단 배너가 없는 화면에서 외부 스타일로 사이드바 아래쪽이 잘리면 확인된 치지직 원래 세로 위치·높이로 보정하며 좌우 위치·너비 설정은 유지합니다.

#### 12. 채팅 멀티뷰

- **설정:** `채팅 → 채팅 표시 → 채팅 멀티뷰`에서 켤 수 있으며 기본 꺼짐입니다. 상단 우측 **채팅 멀티뷰** 버튼으로 최대 4개 채널의 채팅을 한 패널에 나란히 표시합니다.
- **채널 추가:** 채널명 검색 결과(생방송 여부·팔로워 수 표시)에서 선택하거나, 채널 URL·32자리 ID를 입력하거나, 팔로잉 채널을 끌어 놓아 추가합니다.
- **화면·조작:** 각 칸에 채널명·채팅만 표시하고 상단 헤더·배너·주간 랭킹·후원 버튼은 숨깁니다. **채팅방 환영 메시지 제거**를 켜면 각 칸에서도 환영·필터링 안내를 숨깁니다. **채팅 입력창**은 멀티뷰 설정에서 켤 때만 하단에 표시합니다. 패널 상단 조작 막대에서 배율(70~150%)·채널 추가·설정·닫기를 조작하며, 칸별 앞뒤 이동·제거와 모서리 크기 조절을 지원합니다. 채널명 줄을 드래그해 패널을 옮기면 가장 가까운 화면 모서리를 기준으로 위치를 저장합니다. 공간이 부족하면 줄바꿈·스크롤을 적용하며 이전/다음 버튼과 채널 칩으로 이동할 수 있습니다.
- **제한:** 각 칸은 치지직 채팅 팝업(`/live/{채널}/chat`)이므로 해당 채널로 실제 입력·전송됩니다. 내 채팅 기록 등 확장 채팅 기능은 칸 내부에 적용되지 않습니다. 구성은 로컬에 저장하지만 패널 열림 상태는 새로고침 시 자동 복원하지 않으며, 불러오지 못하면 새 창으로 대체하지 않고 해당 칸에만 안내를 표시합니다.

#### 13. 다시보기 채팅창 댓글 탭

- 우측 채팅창에 `댓글` 탭을 추가하고, 기능이 켜진 동안 `라이브 채팅 다시보기` 제목을 `채팅`으로 줄여 상단 공간을 확보합니다. 채팅이 없는 VOD에는 댓글 전용 패널을 표시합니다. 전체화면에서는 그 안에 열린 VOD 채팅 패널에만 표시하며, 닫힌 패널을 자동으로 열지는 않습니다.
- `표시 방식`에서 기존 `탭 전환`(기본)과 채팅·댓글을 위아래로 함께 보는 `분할`을 선택합니다. `분할 상단`에서 위에 둘 내용을 고르고, 두 영역 사이 경계선을 끌어 비율(20~80%)을 조절합니다. 경계선을 더블클릭하면 반반(50%)으로 돌아가며, 키보드로는 경계선에 초점을 둔 뒤 위·아래 방향키·`Home`·`End`로 조절합니다. 조절한 비율은 현재 페이지에서 표시 방식·순서를 바꾸거나 전체화면을 오갈 때 유지합니다.
- 인기순(기본)·최신순·등록순 정렬, 새로고침·무한 스크롤, 답글 펼치기와 타임코드 이동을 지원합니다. 250자를 넘는 댓글은 본문 끝의 `더보기`로 펼칩니다.
- 첨부 사진은 한 줄로 표시합니다. 패널이 좁으면 좌우로 스크롤하고, 사진을 누르면 같은 화면에서 확대해 볼 수 있습니다. 뷰어에서는 좌우 방향키로 사진을 바꾸고 Esc로 닫습니다.
- 하단 원본 댓글에 같은 댓글이 표시되어 있으면 프로필 보기·버프 동작과 상태를 원본 컨트롤에 연동합니다. 아직 표시되지 않으면 안내와 함께 비활성화하며, 작성·삭제·신고는 하단 원본 댓글을 이용합니다.
- 영상 아래 댓글의 **⋯ → 챕터 추가**로 그 댓글의 타임코드와 제목을 재생바에 표시합니다. 챕터에 마우스를 올리면 제목과 프레임을 미리 보고, 누르면 구간 시작으로 이동합니다. 선택한 댓글의 메뉴에서 **챕터 해제**를 누릅니다. 공식 챕터가 있는 영상은 공식 챕터를 표시합니다.
- 서로 다른 시각이 3개 이상인 인기 댓글 중 버프가 가장 많은 댓글은 자동으로 적용됩니다. 자동으로 붙은 챕터를 해제한 영상은 이 브라우저에서 다시 열어도 자동으로 적용되지 않습니다. **설정 → 다시보기 → 시청 화면 → 댓글 챕터 자동 추가**에서 자동 적용을 끌 수 있습니다.
- **관련 설정:** `다시보기 채팅창 댓글 탭`(기본 켜짐), `표시 방식`(기본 탭 전환), `분할 상단`(기본 채팅).

#### 14. 채팅 도구

**타임스탬프·표시 정리:**

- **라이브 채팅 타임스탬프 표시** (`chatTimestampEnabled`, 기본 꺼짐): 라이브 채팅 닉네임 왼쪽과 채팅 모아보기에 **서버 메시지에 기록된 실제 작성 시각**을 브라우저 현지 `HH:MM` 형식으로 표시합니다. 입장·스크롤·재연결 때 불러온 기존 채팅도 원본 시각을 사용하며, 유효한 서버 시각이 없으면 현재 시각을 대신 붙이지 않습니다.
- **다시보기 채팅 타임스탬프 표시** (`vodChatTimestampEnabled`, 기본 꺼짐): 다시보기의 `라이브 채팅 다시보기`에서 영상 경과 시간이 아닌 **방송 당시 채팅 작성 시각**을 같은 형식으로 표시합니다.
- **타임머신 채팅 동기화 (실험)** (`timeMachineChatEnabled`, 기본 꺼짐)를 켜면 라이브를 3초 넘게 되감았을 때 실시간 채팅 목록을 가립니다. 이 탭에서 수신했고 현재 상태를 확인할 수 있는 일반 채팅 본문을 영상 위치에 맞춰 최대 24줄 표시합니다. 수신 뒤 최대 2분간 128건까지 보관하고 탭을 숨기면 비웁니다. 플레이어가 탐색 위치를 확정하면 해당 시점의 채팅을 표시합니다. 입장 전 구간과 현재 상태를 다시 확인할 수 없는 메시지는 제외합니다.
- **다시보기 내 채팅 강조** (`vodOwnChatHighlightEnabled`, 기본 켜짐): 로그인 상태에서 다시보기 채팅 중 **현재 로그인 계정이 작성한 채팅**을 옅은 배경과 왼쪽 선으로 강조합니다. 닉네임이 아닌 작성자 해시 ID로 비교해 닉네임 변경 전 채팅도 찾으며, 해시 ID는 페이지 메모리에서 비교에만 쓰고 저장하지 않습니다.
- **채팅창 닉네임 숨기기** (`chatNicknameHidden`, 기본 꺼짐): 라이브·채팅 팝업·다시보기·채팅 멀티뷰에서 배지는 그대로 두고 일반 닉네임만 화면에서 숨깁니다. 모아보기 대상(방송자·운영자·파트너·챌린저)의 이름은 모아보기 기능 사용 여부와 관계없이 계속 표시합니다. 채팅 본문·원본 작성자 정보·화면 낭독기 접근성 이름·모아보기 표시는 유지합니다.
- **주간 후원 랭킹 숨기기** (`chatWeeklyRankingHidden`, 기본 꺼짐): 채팅 상단의 주간 후원 랭킹 및 통나무 파워 랭킹을 숨깁니다.
- **채팅창 후원 메시지 숨기기** (`chatDonationMessagesHidden`, 기본 꺼짐): 라이브·채팅 팝업·다시보기·채팅 멀티뷰의 일반·미션·파티 후원 메시지를 숨기며, 후원 기록과 영상·음성은 유지합니다.
- **채팅방 환영 메시지 제거** (`chatWelcomeMessageRemovalEnabled`, 기본 꺼짐): 라이브 채팅 로드 시 표시되는 `"채팅방에 오신 것을 환영합니다!"` 환영 행과 `"쾌적한 시청 환경을 위해 일부 메시지는 필터링 됩니다."` 안내 행을 함께 숨깁니다.

**채팅 문구 숨김** (`chatKeywordFilterEnabled`, 기본 켜짐):

- 채팅창 오른쪽 위 **⋯ → 문구 숨김** 또는 설정의 **채팅 → 문구 숨김**에서 숨길 문구를 한 줄에 하나씩 입력해 저장합니다(빈 목록에서는 아무것도 숨기지 않습니다).
- ‘전체 적용’은 모든 문구에 같은 조건을, ‘부분 적용’은 문구마다 **완전 일치·포함**을 선택합니다. 완전 일치는 본문 전체가 문구와 같을 때, 포함은 본문 안에 문구가 들어 있을 때 라이브·다시보기 채팅과 채팅 모아보기의 해당 항목을 숨깁니다. 두 방식을 전환해도 문구별 조건은 보존됩니다.
- 모아보기 대상인 방송자·운영자·파트너·챌린저 채팅은 숨기지 않습니다. 닉네임은 검사하지 않으며 영문 대소문자와 Unicode 조합 차이는 구분하지 않습니다.
- 최대 50개, 한 문구 100자, 전체 2,000자까지 지원하며 문구 삭제 또는 기능 해제 시 다시 표시합니다.

**블라인드 채팅 원문 표시** (`chatToolsShowBlindEnabled`, 기본 꺼짐):

- 현재 메시지와 작성자가 확인된 블라인드 원문을 취소선으로 표시합니다. 치지직이 원문을 비우면 같은 메시지 ID·작성 계정·시각으로 확인해 둔 원문을 사용하며, 확인할 수 없는 행은 기존 안내를 유지합니다.
- 기존 DOM 행은 메시지 ID·작성자·재사용 표식이 일치하는 원문 캐시만 사용합니다. 서버 권한을 우회하거나 비공개 moderation API, 페이지가 사용하지 않는 엔드포인트에서 삭제/숨김 메시지를 가져오지 않습니다.

**채팅 모아보기** (`chatToolsModeratorBoxEnabled`, 기본 꺼짐):

- **수집 대상:** 방송자·채팅 운영자(구 매니저)와 닉네임에 파트너 또는 챌린저 인증 배지가 있는 스트리머의 채팅을 채팅창 우측 상단(채팅 팝업은 좌측) 아이콘 패널에 모읍니다. 본문의 등급 단어나 프로필 팝업의 배지는 수집 근거로 쓰지 않습니다.
- **일반 채팅 하이라이트:** 모아보기를 켜면 대상 메시지를 원래 채팅창에서도 닉네임 색상의 옅은 배경과 얇은 테두리로 강조합니다. 패널을 닫아도 강조는 유지되며 모아보기 옵션을 끄면 함께 사라집니다.
- **사용자별 보기·새 채팅 알림:** 아이콘과 사용자 버튼에 미확인 개수가 표시됩니다. 패널을 열거나 `전체`·사용자 버튼으로 보기를 바꾸면 빨간 `새 메시지` 선 아래에서 가장 오래된 미확인 채팅부터 읽을 수 있습니다. 채팅 행의 절반 이상(목록보다 긴 행은 목록 높이의 절반)이 화면에 보이면 확인 처리되며, 다른 사용자 필터에 가려진 항목이나 백그라운드 탭 항목은 미확인으로 남습니다. `맨 아래로` 버튼으로 최신 채팅에 바로 이동할 수 있습니다.
- **선택·복사·원본 이동:** 여러 행을 드래그해 `Ctrl+C`(Mac은 `Command+C`)로 복사할 수 있으며 선택 중에는 자동 스크롤하지 않습니다. 행 클릭 또는 초점 후 `Enter`·`Space`를 누르면 원본 채팅창에 남아 있는 해당 메시지 위치로 이동합니다.
- **보관 범위:** 모아 둔 메시지, 사용자 목록, 미확인 상태는 현재 페이지 메모리에서만 관리하며 새로고침하거나 다른 방송으로 이동하면 초기화됩니다. 보관 개수(`모아보기 보관 개수`, 기본 100개)를 넘겨 삭제된 채팅은 알림에서도 제외됩니다.

#### 15. 다시보기 방송 시각 표시·검색

- **다시보기 방송 시각 표시** (`vodBroadcastClockEnabled`, 기본 켜짐):
    - 방송 시작 시각과 재생 위치를 합산해 현재 장면의 **실제 방송 시각(KST)**을 표시하고 제목 옆에 이전 방제 패널을 제공합니다.
    - **제목 아래 시작·종료 시각:** KST 기준 시작·종료 시각과 `영상 기준` 표기를 표시합니다(편집·누락 구간이 있으면 실제 종료와 다를 수 있으며, 길이 미확인 시 `확인 불가` 표시).
    - **조회수 옆 날짜 자리:** 공개일 대신 `10.25(일) 17:56 ~ 23:08` 형식으로 KST 시작·종료 시각을 표시합니다. 다른 날 종료되면 날짜·요일을, 이전 연도 방송에는 연도를 추가하며 일반 업로드 영상은 원래 날짜를 유지합니다.
    - **분할 연결:** 17시간 제한으로 나뉜 다시보기는 연결된 이전 구간 길이를 이어 계산합니다. 방송 시작 시각을 확인할 수 없으면 표시하지 않습니다.
- **다시보기 검색** (`videoSearchEnabled`, 기본 켜짐):
    - 채널 다시보기 목록(`/.../videos`)에서 제목을 검색하고, `제목에 없으면 댓글까지 검색`을 켜면 제목에 검색어가 없는 영상의 댓글도 찾습니다. 댓글 아이콘을 누르면 일치한 댓글 목록이 열립니다. 댓글 안의 재생 시각을 누르면 해당 장면을 엽니다. 검색할 때는 조회 페이지 수·대기 시간·영상당 댓글 페이지를 조절할 수 있습니다.

#### 16. 채널 방송 시간 통계·바로가기

- **채널 채팅 바로가기** (`channelChatLinkEnabled`, 기본 켜짐): 채널 탭의 `정보` 옆에 오프라인에서도 들어갈 수 있는 일반 라이브 화면(`/live/{채널 ID}`) 링크를 표시합니다.
- **평균 방송 시간·월간 달력:** 다시보기 시작·종료 시각을 기준으로 최근 평균 방송 시간 스티커와 월별 달력을 표시합니다. 달력 색은 3시간 단위 9단계이며 가장 진한 색은 24시간 이상입니다. 날짜를 누르면 첫 다시보기로, 툴팁 항목을 누르면 개별 다시보기로 이동합니다. 17시간 제한으로 나뉜 다시보기는 하나의 구간으로 합산하며, 다시보기가 생성되지 않은 라이브 구간은 제외합니다.
- **내 시청 표시·조회 상한:** `달력에 내 시청 시간 표시`(기본 꺼짐)를 켜면 시청 기록이 있는 방송에만 내 시청 시간을 표시합니다. 평균 기간·페이지 조회 상한에 도달하면 일부만 표시한다는 안내를 제공합니다.

#### 17. 통나무 보상 자동 받기

- 라이브 채팅의 **시청 통나무 파워 배달 완료** 버튼과 보상 창의 **1시간 시청 보상**(`WATCH_1_HOUR`) 버튼을 상태당 한 번 자동으로 누릅니다. 확인된 보상 UI만 대상으로 하며 일반 채팅·프로필·링크는 제외합니다.
- 라이브 채널의 대기 중인 비시청 통나무 claim을 30초마다 확인해 `log-power` API로 자동 수령합니다. 시청 시간을 조작하거나 서버 제한을 우회하지 않습니다.
- **관련 설정:** `통나무 보상 자동 받기`(기본 켜짐).

### 팔로잉·탐색·방송 알림

#### 18. 팔로잉 사이드바·폴더

- **목록 상태 기억 / 오프라인 숨기기:** `팔로잉 목록 펼침·접힘 기억`으로 구역 접기·`더보기` 상태를 로컬에 기억하고, `팔로잉 오프라인 채널 숨기기`로 오프라인 채널을 고정 여부와 관계없이 숨깁니다(모두 기본 꺼짐).
- **사이드바 항목 숨기기:** `사이드바 치즈팜 숨김`, `인기 카테고리 숨기기`, `다가오는 방송 일정 숨기기`, `파트너 스트리머 숨기기`, `서비스 바로가기 숨기기`를 각각 설정할 수 있습니다(모두 기본 꺼짐).
- **팔로잉 채널 고정:** 팔로잉 헤더의 핀 버튼으로 고정 모드를 켠 뒤 채널을 선택합니다. 최대 64개까지 고정해 Chrome 동기화 저장소에 보관합니다. 기본 순서는 `고정 라이브 → 일반 라이브 → 고정 오프라인 → 일반 오프라인`이며, `오프라인이어도 최상단 고정`을 켜면 고정 채널 전체를 최상단에 배치합니다. 접힌 5개 목록 밖의 고정 채널도 보충해 표시합니다.
- **팔로잉 폴더** (`followingFoldersEnabled`, 기본 꺼짐): 최대 10개 폴더·총 150개 채널을 지정할 수 있으며(채널당 1개 폴더) Chrome 동기화 저장소에 보관합니다. 폴더를 삭제해도 팔로우는 유지됩니다.

    | 동작             | 방법                                                                         |
    | ---------------- | ---------------------------------------------------------------------------- |
    | 새 폴더 만들기   | 채널 드래그 중 하단 **+ 새 폴더로**에 놓기, 또는 폴더 **⋯ → 새 폴더 만들기** |
    | 채널 추가·이동   | 채널을 폴더 머리나 폴더 내 채널 위에 놓기(접힌 폴더에 0.5초 유지 시 펼침)    |
    | 폴더에서 제외    | 채널을 **폴더 밖 채널**에 놓기                                               |
    | 키보드 채널 선택 | 폴더 **⋯ → 채널 선택…**에서 체크·해제                                        |
    | 접기·펼치기      | 화살표·빈 공간 클릭(즉시) 또는 폴더 이름 클릭                                |
    | 이름·순서 변경   | 이름 더블클릭/`F2`(`Enter` 저장, `Esc` 취소), 폴더 드래그 또는 **⋯** 메뉴    |
    | 폴더 삭제        | **⋯ → 폴더 삭제** 두 번 클릭                                                 |
    - 이동·삭제 직후 5초간 **되돌리기**를 지원하며, 다른 탭에서 변경한 값은 덮어쓰지 않습니다. 접힌 폴더 머리에 방송 중인 채널 수를 표시하고, 펼친 폴더의 채널이 기본 5개 목록 밖에 있으면 나타날 때까지 `더보기`를 자동으로 실행합니다(50개 단위, 최대 505개). 직접 `접기`를 누르면 다음에 폴더를 펼칠 때까지 접힌 상태를 유지합니다. 저장값을 읽지 못하거나 손상된 경우 **다시 읽기**·**폴더 정보 초기화**(2회 확인)를 표시합니다.
    - `팔로잉 목록 최대 줄 수`는 `0`(제한 없음)부터 최대 `30`줄까지 지정해 목록 높이만 내부 스크롤로 제한할 수 있습니다.

- **채널 링크 드래그:** 팔로잉 채널 링크를 탭 표시줄이나 멀티뷰 영역으로 끌어 열거나 추가할 수 있습니다. 아이콘만 보이는 접힌 사이드바에서는 폴더 놓기를 지원하지 않습니다.
- **팔로잉 라이브 제목 이력:** 로그인 상태에서 팔로우한 라이브 방제를 1분마다 로컬에 기록하고, 라이브 시청 화면·`/following` 카드의 제목 옆 버튼으로 이전 방제를 표시합니다(기본 켜짐, 로그아웃·브라우저 종료 중 변경 미수집).
- **자동 새로고침:** 설정 주기(기본 30초)와 장기 비활성 탭 복귀 시 라이브 상태를 갱신합니다.
- **팔로잉 호버 미리보기:** 사이드바 라이브에 마우스를 올리면 카드 안에서 HLS 미리보기를 재생합니다(기본 꺼짐, `*.pstatic.net` 선택 권한 필요). 고정 볼륨(기본 15%)·우클릭 소리 전환·카테고리 이동 링크·채널 홈 새 탭 링크를 지원합니다.

#### 19. 상단 버튼 숨기기·배치 보정

- **상단 버튼 숨기기:** `화면 정리 → 상단·사이드바`에서 **스튜디오 버튼 숨기기**, **치즈 버튼 숨기기**(사이드바 치즈팜 숨김과 별개), **알림 버튼 숨기기**를 설정합니다(모두 기본 꺼짐, 저장 즉시 반영).
- **배치 보정:** 상단 배너와 외부 광고 차단 스타일의 충돌로 검색창이 가려지면 헤더·사이드바 위치와 본문 여백을 유지하며 배너가 사라지면 보정을 해제합니다. 같이보기 목록에서 배너를 숨긴 뒤 고정 제목 위에 빈틈이 생기면 제목을 헤더 바로 아래로 정렬합니다. 배너가 없을 때도 외부 스타일로 사이드바 하단이 잘리면 치지직 기본 위치·높이를 유지합니다.

#### 20. 방송 목록 도구·긴 제목 툴팁

전체 방송(`/lives`)과 카테고리 라이브·영상·클립 목록 상단에 검색·필터·집계 도구를 추가하고 카드에 부가 정보를 표시합니다.

- **방송 목록 새로고침:** 전체 방송의 추천순 오른쪽에서 현재 정렬과 검색·필터 조건을 유지한 채 목록만 다시 불러옵니다(목록 도구 설정과 무관하게 사용 가능).
- **전체 방송 집계 표시:** 전체 방송 상단에 시청자 10명 이상인 방송 수와 동시 시청자 합계를 표시합니다. 검색·필터와 독립적으로 동작하며 중복 시청자는 제거하지 않습니다. 신규 설치 시 기본 꺼짐이며, 같은 세션에서 집계 결과를 5분간 재사용합니다.
- **현재 목록 검색·적용 조건 줄:** 제목·스트리머·카테고리·태그로 필터링합니다. 띄어쓰기로 나눈 단어는 모두 포함해야 하며, `-단어`는 제외합니다. 전체 방송에서는 `Enter`로 적용하고 `Esc`로 복원합니다. 활성 검색어·숫자·등급 필터는 상단 칩과 `모두 해제`로 관리하며, 현재 탭의 목록 주소별로 조건을 기억해 방송 시청 후 복귀·새로고침해도 유지합니다.
- **숫자 필터 메뉴:** 팔로워 수, 시청자 수/조회수, 진행 시간별로 `전체·이상·이하·범위`를 지정합니다. 기준값 6개의 빠른 선택 버튼과 `2천`·`1.5만` 등의 직접 입력을 지원합니다.
- **스트리머 등급 필터:** `파트너·챌린저·프로·일반`을 여러 개 선택할 수 있으며, 탭의 목록 주소별로 선택을 기억합니다. 파트너·챌린저는 인증 배지 기준이며, 공개 API에 프로·루키의 실제 등급이 없어 **프로는 구독 지원, 일반은 구독 미지원 기준**으로 구분하고 등급 자체는 보장하지 않습니다. 공식 채널·미확인·조회 실패는 결과에 포함하지 않습니다. `필터 초기화`는 숫자·등급 조건을 함께 해제하고 카테고리·태그 제외는 유지합니다.
- **카테고리·태그 제외:** 전체 방송 정렬 줄 우측 `+ 제외 추가`에 이름 일부를 입력하면 카테고리, 스트리머가 붙인 회색 태그, 같이보기·대회명·드롭스 등의 방송 배지를 함께 찾습니다. 원하는 결과의 `제외`를 누르세요. 태그 전체 이름을 입력하고 `Enter`로 미리 등록할 수도 있습니다. 전체 이름이 일치하는 태그가 붙은 방송을 숨깁니다. 카테고리와 태그를 합쳐 최대 100개까지 이 기기의 Chrome 프로필에 저장하며, 열려 있는 전체 방송 탭에도 반영합니다.
- **카드 배지·미리보기·긴 제목 툴팁:** 팔로워 수 축약 배지, 썸네일 호버 시 진행 시간 표시, 전체 방송·필터 카드의 즉시 호버 미리보기를 지원합니다(우클릭 안내는 1초 표시 후 숨김, 우클릭 집중 모드에서 확대·최대 1080p·소리 재생). `긴 제목 툴팁`(기본 켜짐)은 실제로 말줄임된 제목에 마우스를 올리면 전체 제목을 표시합니다.

#### 21. 방송 시작 알림·지정 채널 자동 탭 열기

- **등록·관리:** 설정 **방송 알림** 탭에서 채널 주소·32자리 ID를 입력하거나, 치지직 우측 상단 **방송 알림** 버튼에서 채널명을 검색해 등록합니다. 라이브나 채널 페이지에서는 **현재 채널**에서 바로 등록할 수 있습니다. **팔로잉**을 열면 내가 팔로우한 채널을 이름으로 찾을 수 있습니다. 채널명 검색 결과는 상위 5개이며 최대 32개 채널을 등록할 수 있습니다. 채널별 **알림**·**자동 열기(자동 입장)** 전환은 로컬에 즉시 저장하고 설정창과 실시간으로 동기화합니다.
- **전체 스위치·권한:** 상위 옵션(`방송 시작 데스크톱 알림`, `지정 채널 자동 탭 열기`, 기본 모두 꺼짐)을 켜고 **옵션 저장**을 눌러야 동작합니다. 데스크톱 알림에는 `notifications` 권한이 필요하지만, 거부해도 자동 열기는 별도로 사용할 수 있습니다. OS 집중 모드·차단 설정은 따로 확인해야 합니다. 확장 사이트 액세스에서 `api.chzzk.naver.com`이 꺼져 있으면 설정 탭에서 **치지직 API 접근 허용**을 눌러야 합니다.
- **확인·실행 기준:** Chrome 실행 중 약 1분 간격으로 확인하며 치지직 탭이 열려 있을 필요는 없습니다(브라우저 종료·절전 중 제외). 최초 등록·활성화·브라우저 시작 시 이미 진행 중인 방송은 건너뛰고, 이후 새 방송을 확인하면 중복 실행되지 않도록 처리합니다. 알림을 클릭하면 열린 방송 탭으로 이동하며, 자동 열기는 **배경 탭**으로 열되 같은 채널의 라이브·대기 탭이 이미 있으면 중복으로 열지 않습니다.

### 시청 기록·설정 관리

#### 22. 라이브 시청 기록·시청 기록 페이지

- **기록 기준:** 실제 영상 재생 위치가 전진한 라이브 시청 시간만 이 브라우저의 로컬 저장소에 기록합니다. 일시정지·멈춤 시간은 제외하며, 전체 시청 시간 집계에서는 다중 탭의 동시 시청 구간을 한 번만 합산합니다. `최소 저장 시간`(기본 1분)보다 짧게 시청하면 통계에서 제외하지만, 내 채팅·일반 후원은 즉시 저장하고 `활동만 기록`으로 표시합니다. 확인된 방송 제목·방제 이력도 함께 보관합니다.
- **시청 패턴:** 기록 화면에서 펼치면 선택한 기간과 검색 조건에 맞는 요일별·시간대별 시청 시간을 볼 수 있습니다. 시간대 정보가 없는 누적 시간은 별도로 표시합니다.
- **시청 기록 페이지 (`history.html`):** 설정 화면의 **시청 기록 보기**로 열며 **라이브 내역 · 많이 본 채널 · 내 채팅·후원** 탭과 월별 달력·백업·삭제 도구를 제공합니다.
    - **요약·달력·채널 사진:** 총 시청 시간·라이브 수·월별 합계를 표시하고 날짜별 필터링을 지원합니다. 공개 채널 프로필 사진은 자동으로 조회해 표시하며 저장하지 않습니다.
    - **라이브 내역:** 기간(선택 월/전체), 제목/채널 검색, 정렬(`최근 본 순`/`예전에 본 순`/`시청 시간 긴 순`/`시청 시간 짧은 순`)을 지원합니다. **내 채팅 ○개**를 50개 단위로 펼쳐 보고 **세부**에서 전체 제목·방제 이력·입장 기록·개별 삭제를, 목록에서 **선택 삭제**를 실행합니다. 항목 클릭 시 다시보기 탐색 안내(`replay-pending.html`)를 거쳐 이동합니다.
    - **많이 본 채널:** 선택 기간·검색 조건에 따라 채널별 누적 시청 시간·방송 수·채팅·일반 후원 합계를 표시합니다(겹친 시청 시간 중복 제외).
    - **내 채팅·후원:** `내 채팅 기록 저장`·`내 일반 후원 기록 저장`(기본 꺼짐)을 켜면 로그인 계정의 라이브 채팅·본인 일반 후원(익명·미션·영상·파티·외부 후원·구독 제외, 메시지 없는 일반 후원 포함)을 저장합니다. 본문은 방송별 최근 500개·전체 최근 3,000개까지 보관하며 누적 횟수·치즈 합계는 유지합니다. **후원 내역 갱신**은 로그인된 치지직 탭이 열린 상태에서 2023년 1월 이후 내역을 월 단위로 조회·통합하며(최대 3,000개), 다른 계정 조회 전에는 **후원 갱신 초기화**가 필요합니다.
    - **활동 시각 다시보기:** 방송에 연결된 내 채팅이나 실시간 일반 후원의 시각을 누르면 해당 장면을 엽니다. 공개 영상의 방송 시각과 분할 구간을 확인할 수 없으면 다시보기 기본 위치로 이동합니다. 월별로 가져온 후원은 시각만 표시합니다.
    - **기록 백업·관리:** **백업 파일 저장 / 불러오기**로 전체 기간의 시청 기록·내 채팅을 JSON 파일(최대 16 MiB, 비암호화)로 내보내고 미리보기 확인 후 중복 없이 합칩니다(후원은 제외). 로컬 저장소에만 보관하므로 확장 삭제·프로필 초기화 시 복구할 수 없습니다. **전체 삭제**는 모든 기록을 지우고, **후원 갱신 초기화**는 갱신한 내역만 삭제합니다.

#### 23. 설정 파일 저장·불러오기

- **위치:** 설정 우측 상단 **⋯ → 설정 파일 저장 / 설정 파일 불러오기**. 설정 검색 아래 **기본값과 다른 설정만 보기**에서 현재 편집 중인 값까지 확인할 수 있습니다.
- **포함·제외:** 모든 옵션, 팔로잉 고정·폴더, 채팅·사이드바 크기, 방송 알림·자동 입장 채널, 멀티뷰 채널별 딜레이·화질, 채팅 멀티뷰 구성을 포함합니다. 카테고리·태그 제외 목록은 내보낼 때 선택할 수 있습니다. 불러오기 미리보기에서 합치기를 선택하면 현재 목록을 보존하고 새 항목만 추가합니다. 시청·채팅·후원 기록과 로그인 정보는 제외합니다.
- **적용 규칙:** 저장하지 않은 변경이 있으면 먼저 저장하거나 취소합니다. 변경 구역을 미리 확인한 뒤 **불러오기 적용**을 누르면 반영합니다. 파일에 없는 구역은 현재 값을 유지하며, 포함된 고정 채널·폴더·방송 알림 대상 목록은 교체하고 멀티뷰 값은 파일에 있는 채널만 바꿉니다. 미리보기 뒤 설정이 바뀌면 다시 확인하며, 저장에 실패하면 이전 값으로 복구를 시도하고 복구하지 못한 구역을 안내합니다. 파일이 새로 켜는 기능에만 알림·영상 권한을 요청하며, 거부 시 전체를 취소하거나 해당 기능만 켜지 않고 불러올 수 있습니다. 진행 중인 방송은 건너뛰고 다음 새 방송부터 알림·자동 열기를 적용하며, 열린 치지직 탭은 새로고침 시 모두 반영됩니다.

## 설정 항목 전체 표

설정 팝업의 10개 탭 순서 기준입니다. 카드 접힘 상태는 기기에 자동으로 기억하며, 굵은 항목은 상위 기능 토글입니다. 옵션창 자체 테마(`optionsTheme`: `system` 기본·`light`·`dark`)는 상단 테마 버튼으로 전환합니다. 허용 범위를 벗어난 숫자 입력값은 유효한 범위로 자동 보정됩니다.

### List-KR 필터 사용 시 플레이어 단축키 미동작

List-KR 필터 환경에서는 `Space`, `M`, `T`, `F` 등 기본 단축키가 간헐적으로 막힐 수 있습니다. 광고 차단 확장 프로그램에서 `chzzk.naver.com`을 예외 처리한 뒤 새로고침하거나, 설정의 **기본 단축키 복구**를 켜는 것을 권장합니다.

### 확인 버튼만 있는 안내 팝업이 남을 때

다른 확장 프로그램을 함께 사용하는 등의 이유로 같은 방송에서 **확인** 전용 팝업이 반복되거나 치지직 구조가 바뀌면, 자동 닫기를 멈추고 팝업을 남깁니다. 직접 **확인**을 누르거나 함께 사용하는 확장 프로그램에서 `chzzk.naver.com`을 예외 처리해야 합니다. 치즈 스패너의 `동영상 광고 차단` 옵션은 별개로 동작합니다.

## 개발

번들러나 빌드 단계 없이 동작하는 순수 Manifest V3 확장 프로그램입니다. 저장소에는 개발 편의를 위한 도구만 포함되어 있습니다.

```powershell
npm.cmd ci
npm.cmd run test:all -- --test-concurrency=2
npm.cmd run lint
npm.cmd run format:check
git diff --check
```

- 전체 검증은 위 순서로 실행합니다. 기본 `npm.cmd test -- --test-concurrency=2`는 공개 기능 중심이며 개발 전용·저장한 실측 자료 검사까지 포함하려면 `test:all`을 사용합니다. 실측 자료 테스트 통과와 현재 Chrome의 실제 재생·화면 확인은 별개입니다.
- 작은 기능 수정은 관련 검사와 변경 파일 lint·포맷으로 확인하며, 전체 자동 포맷으로 기존 작업을 일괄 바꾸지 않습니다. 자세한 검사·브라우저·배포 절차는 [운영 문서](docs/operations.md)를 따릅니다.
- 작업 지침(아키텍처, 하드 제약, 검증 절차, 릴리스 규칙)은 [AGENTS.md](AGENTS.md)에 정리되어 있습니다.
- 주요 런타임 JS 파일 최상단에는 역할·의존·구조를 설명하는 헤더 주석이 있으므로, 파일을 통독하기 전에 헤더부터 읽으면 됩니다.
- 모든 설정 옵션은 `shared/settings.js`의 `OPTION_SCHEMA`에서 단일하게 정의되며, 설정 화면(`options.html`)의 항목과 기본값·정규화 규칙이 여기서 파생됩니다.
