# 치즈 스패너

> 치지직(CHZZK) 시청과 탐색을 더 편하게 만들어 주는 비공식 Chrome 확장 프로그램입니다.

![치즈 스패너 아이콘](icons/cheese-spanner128.png)

**치즈 스패너**는 자동 화질 복구, 스킵·배속·볼륨 조절, 방송자·운영자 채팅 모아보기, 팔로잉 고정·라이브 미리보기, 다시보기 검색·댓글, 방송 목록 필터, 방송 시간 통계와 라이브 시청 기록을 한곳에 모은 확장 프로그램입니다. 통나무 보상 자동 받기와 시청 방해 팝업 제거도 지원합니다. 대부분의 기능은 설정 화면에서 개별로 켜고 끌 수 있으며, 세부 수치까지 직접 조절할 수 있습니다.

- **버전:** 1.3.8
- **플랫폼:** Chrome (Manifest V3)
- **대상 사이트:** `https://chzzk.naver.com/*`
- **언어:** 한국어

[Chrome 웹 스토어에서 설치](https://chromewebstore.google.com/detail/better-chzzk/dbpnbemehejfmobkemhpebomhabpljeb) · [전체 업데이트 내역](docs/update-history.md)

## 1.3.8 변경 사항

- **Space·좌클릭 홀드 2배속**으로 조작을 확장했습니다. Space 또는 영상 화면의 왼쪽 버튼을 길게 누르는 동안 2배속을 적용하고, 놓으면 원래 배속으로 돌아옵니다. 기존 Space 홀드 설정을 이어받습니다.
- **휠로 화면 확대**를 추가했습니다. 커서 중심으로 최대 5배까지 확대하고 드래그로 이동하며, 슬라이더로 1%씩 조절할 수 있습니다. 버튼을 켠 동안만 적용하거나 영상 위에서 항상 적용하도록 선택할 수 있으며 기본값은 꺼짐입니다.
- **멀티뷰 자유 배치**를 추가했습니다. 메인·보조 방송을 사이드바·채팅 위까지 자유롭게 옮기고 크기·겹침 순서를 조절하며, 같은 탭의 새로고침 후에도 배치를 복원합니다. 멀티뷰 설정에서 켤 수 있고 기본값은 꺼짐입니다.
- 자유 배치에서는 방송 링크를 끌어 **원하는 위치에 새 방송을 추가**할 수 있습니다. 보조 창 크기의 배치 미리보기가 포인터를 따라 움직입니다.
- **방송 시작 시각**에 오늘이 아닌 시작 날짜를 함께 표시합니다. 한국 시간 기준으로 시청 중 자정이 지나도 자동으로 갱신합니다.
- **스트림 정보**를 영상의 톱니바퀴 설정 메뉴로 옮기고 키보드 조작을 지원합니다. 스킵 시간 조절 버튼이 깜빡이던 문제도 수정했습니다.
- **방송 달력**에서 여러 날 이어지는 방송의 날짜 누락을 수정하고 색상을 3시간 단위의 9단계로 세분화했습니다. 내 시청 시간은 해당 기록이 있을 때만 표시합니다.
- 설정 카테고리 탭의 **휠 스크롤**과 배속 **단축키 기본값 복원** 버튼을 추가했습니다.

자세한 변경 내용과 조작법은 [1.3.8 업데이트 내역](docs/update-history.md#138-2026-09-15)에서 확인할 수 있습니다.

## 스트림 정보

영상의 **톱니바퀴 설정 → 스트림 정보 열기**에서 현재 해상도, 비트레이트(kbps), 남은 재생 버퍼와 FPS를 확인할 수 있습니다. 확장 설정의 **플레이어 → 라이브 표시 → 스트림 정보**에서 켜고 끌 수 있으며 기본값은 켜짐입니다. 패널의 닫기 버튼, 패널 안에서 Escape, 톱니바퀴 설정 메뉴의 **스트림 정보 닫기**로 닫을 수 있습니다. 키보드로 메뉴 항목에 포커스를 옮긴 뒤 Enter 또는 Space로도 열고 닫을 수 있습니다.

비트레이트는 현재 해상도와 일치하는 라이브 API 제공값이며 실제 네트워크 전송 속도는 아닙니다. 남은 재생 버퍼는 현재 위치부터 미리 받아둔 영상의 길이입니다. FPS는 최근 측정 구간의 출력 프레임 수입니다. 하드웨어 가속은 패널을 열 때 WebGL 렌더러를 확인해 **사용 중**, **미사용 (소프트웨어)** 또는 **확인 불가**로 표시합니다. 현재 영상의 하드웨어 디코딩 여부와는 다를 수 있으며, CPU·GPU 사용률은 제공하지 않습니다. 다시보기의 비트레이트와 브라우저에서 제공하지 않는 값은 측정 불가로 표시합니다. 패널을 열었을 때만 측정하며, 닫거나 탭을 숨기면 중단합니다.

## 플레이어 버튼 숨기기

**플레이어 → 라이브 표시**에서 **클립 버튼 숨기기**, **PIP 버튼 숨기기**를 각각 설정할 수 있습니다. 기본값은 모두 꺼짐이며, 저장하면 라이브·다시보기 플레이어에 바로 적용됩니다. 옵션을 끄고 저장하면 버튼이 다시 표시됩니다. 버튼 표시만 조절하며 이미 실행 중인 PIP를 종료하지 않습니다.

## 상단 버튼 숨기기

**팝업·알림 → 상단 버튼**에서 **스튜디오 버튼 숨기기**, **치즈 버튼 숨기기**, **알림 버튼 숨기기**를 각각 설정할 수 있습니다. 기본값은 모두 꺼짐이며, 옵션을 저장하면 현재 치지직 페이지에도 적용됩니다. 옵션을 끄고 저장하면 버튼이 다시 표시됩니다. 헤더의 치즈 버튼은 사이드바 치즈팜 숨김과 별도로 설정합니다.

## 설치 방법

일반 사용자는 [Chrome 웹 스토어](https://chromewebstore.google.com/detail/better-chzzk/dbpnbemehejfmobkemhpebomhabpljeb)에서 **Chrome에 추가**를 눌러 설치할 수 있습니다. 스토어에 표시되는 버전은 심사·게시 시점에 따라 이 저장소의 버전과 다를 수 있습니다.

소스나 배포 ZIP으로 직접 설치하려면 다음 순서를 따르세요.

1. 배포 ZIP을 내려받아 압축을 풀거나, 이 저장소를 클론합니다.
    ```bash
    git clone https://github.com/neder2/Chzzk.git
    ```
2. Chrome 주소창에 `chrome://extensions` 를 입력해 확장 프로그램 페이지를 엽니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 누르고, 내려받은 폴더(`manifest.json`이 있는 위치)를 선택합니다.
5. 설치가 끝나면 툴바에 치즈 스패너 아이콘이 나타납니다.

> 빌드 과정은 필요 없습니다. 이 저장소는 번들러 없이 그대로 로드되는 순수 확장 프로그램입니다.

## 빠른 시작

업데이트 후에는 열려 있는 치지직 탭을 직접 새로고침해 주세요. NEW 배지와 튜토리얼 다시보기는 제공하지 않습니다.

- **설정 열기:** 툴바의 치즈 스패너 아이콘을 클릭하면 설정 팝업(`options.html`)이 열립니다. `chrome://extensions`의 확장 프로그램 세부정보 → **확장 프로그램 옵션**으로도 열 수 있습니다.
- **카테고리 탭 이동:** 탭이 가로로 넘칠 때 탭 위에서 마우스 휠을 굴리면 좌우로 스크롤합니다. 트랙패드 가로 스크롤과 방향키·Home·End를 이용한 탭 선택도 지원합니다.
- **설정 화면 글꼴:** 옵션 창은 확장에 포함된 Pretendard를 사용합니다. 제목·탭·설정 이름은 굵기로 구분하고, 설명과 입력창은 읽기 편한 크기와 줄 간격으로 표시합니다.
- **아이콘:** 치즈 조각과 금속 스패너를 조합한 모양을 사용합니다. 툴바·설정·시청 기록 화면에 동일한 아이콘이 표시됩니다.
- **릴리즈 노트:** 설정창 오른쪽 위 **설정 더보기(···)** 메뉴의 **릴리즈 노트**를 누르면 GitHub 릴리스 목록이 새 탭으로 열립니다.
- **이전 변경 공지:** 1.3.8부터는 1.3.7의 **중요!!! 공지** 팝업을 표시하지 않습니다. 아직 읽지 않은 공지가 남아 있거나 더 오래된 버전에서 바로 업데이트해도 표시하지 않습니다. 공지 내용은 [1.3.7 업데이트 내역](docs/update-history.md#137-2026-09-14)에서 확인할 수 있습니다.
- **기능 켜고 끄기:** 카테고리 탭을 고른 뒤 관련 기능 묶음을 펼쳐 토글 스위치로 켜고 끕니다. 일부 세부 옵션은 상위 기능이 켜져 있을 때만 활성화됩니다.
- **다시보기 설정:** **다시보기** 탭에서 당시 시간 표시, 채팅창 댓글 탭, 영상·댓글 검색을 조절합니다. 라이브와 함께 쓰는 스킵·배속·볼륨은 **플레이어** 탭에 있습니다.
- **설정 찾기:** 상단 검색창에서 기능명이나 수치 이름을 찾으면 관련 묶음이 자동으로 펼쳐집니다. 카테고리는 아이콘과 이름이 있는 한 줄 탭으로 표시되며, 좁은 팝업에서는 가로로 스크롤할 수 있습니다. 탭에 포커스를 둔 상태에서 좌우 방향키로 이동하면 선택한 탭이 보이도록 스크롤됩니다.
- **세부 수치 조절:** 관련 기능 묶음 안에서 스킵 초, 조회 페이지 수, 필터 기준값 등을 직접 입력할 수 있습니다.
- **저장:** 값을 바꾸면 하단에 `변경 3개`처럼 수정한 항목 수가 표시됩니다. **옵션 저장** 버튼을 눌러 적용합니다. 저장 실패 안내는 다시 저장하거나 직접 닫을 때까지 유지됩니다.
- **변경 취소:** 저장하지 않은 변경을 마지막으로 저장한 값으로 되돌립니다. 현재 탭과 검색어는 유지하며 저장소에 쓰지 않습니다. 권한 승인 대기와 저장 중에는 사용할 수 없습니다.
- **목록 필터 키보드 조작:** 필터를 열면 항목으로 포커스가 이동합니다. `Esc`를 누르면 입력한 범위를 유지한 채 닫히고 필터 버튼으로 돌아갑니다.
- **초기화:** **설정 더보기(···)** 메뉴에서 **기본값 복원**을 선택하고 확인하면 모든 설정을 기본값으로 저장합니다.
- **적용 시점:** 대부분의 설정은 열려 있는 치지직 탭에 새로고침 없이 곧바로 반영됩니다. 확장 업데이트 후에는 열려 있던 탭을 새로고침해 주세요.

## 기능 상세

### 1. 자동 화질 복구

라이브와 다시보기에 입장할 때 **설정한 화질을 우선 적용**합니다. `고정할 화질`에서 1080p·720p·480p를 선택할 수 있으며 기본값은 1080p입니다. 선택한 화질이 없으면 가능한 가장 높은 하위 화질을 선택하고, 시청 도중 화질이 바뀌면 같은 기준으로 복구를 시도합니다. 설정을 저장하면 현재 시청 중인 페이지에도 반영됩니다.

- 입장 직후, 페이지 전환 직후, 그리고 플레이어가 화질을 낮췄을 때 자동으로 다시 적용합니다. 지원되는 라이브에서는 첫 재생이 시작된 뒤 목표 화질을 적용해 초기 자동 재생과 화질 전환이 겹치지 않게 합니다. 직접 일시정지한 영상은 자동으로 재생하지 않습니다.
- 지원되는 라이브 플레이어에서는 프로그램 미설치로 취소되던 1080p·720p 저지연 화질 선택을 유지합니다. 화질 적용 여부는 현재 플레이어와 방송 형식에 따라 달라질 수 있습니다.
- 팝업 제거는 `시청 방해 팝업 제거`에서 별도로 설정합니다.
- 기존 그리드 우회 방식이 서비스·소프트웨어의 수정·변형을 제한하는 [네이버 이용약관](https://policy.naver.com/rules/service.html)에 저촉될 소지를 고려해, 1.3.7에서 해당 옵션과 P2P 재생정보를 수정하던 방식을 제거했습니다. 현재 화질 선택 방식은 원래 플레이어의 선택 처리를 사용하며, 설치된 그리드 프로그램의 사용을 차단하지 않습니다.
- 관련 설정: `자동 화질 복구`(기본 켜짐), `고정할 화질`(기본값: 1080p).

### 2. 스킵과 시간 이동

다시보기와 라이브 타임머신에서 설정한 시간만큼 앞뒤로 이동할 수 있는 도구를 제공합니다.

- **방향키 스킵:** `←` / `→` 방향키로 설정한 **기본 스킵** 시간만큼 뒤로/앞으로 이동합니다. 라이브에서는 현재 플레이어가 제공하는 타임머신 범위 안에서 동작합니다. (입력창에 포커스가 있을 때나 Ctrl·Alt·⌘ 조합일 때는 동작하지 않습니다.)
- **플레이어 버튼(스킵 알약):** 플레이어의 시간 표시 옆에 현재 스킵 초가 적힌 작은 버튼이 붙습니다.
    - **마우스 휠**로 스킵 초를 늘리거나 줄입니다. 기본 휠은 **휠 기본** 단위, `Shift`+휠은 **Shift+휠** 단위, `Alt`+휠은 **Alt+휠** 단위로 조절됩니다.
    - 버튼을 **클릭**하면 스킵 초가 기본값으로 초기화됩니다.
- **라이브 플레이어 버튼:** 라이브와 타임머신에서도 스킵 버튼을 표시합니다. 라이브 컨트롤에는 플레이어가 제공하는 실제 라이브 끝 지점으로 이동하는 **빨리 감기** 버튼도 함께 제공됩니다.
- **라이브 위치 유지:** 켜면 일시정지 또는 타임머신 시청 중 치지직이 실시간 위치로 강제 복귀시키는 동작을 줄입니다. 끄면 치지직 기본 동작대로 실시간 위치로 이동합니다.
- **Space·좌클릭 홀드 2배속:** 라이브와 다시보기에서 Space 또는 영상 화면의 마우스 왼쪽 버튼을 0.35초 이상 길게 누르면 누르는 동안만 2배속이 적용되고, 놓으면 원래 배속으로 돌아옵니다. 두 조작은 옵션 하나로 함께 켜고 끕니다. Space를 짧게 누르면 재생/일시정지를 한 번 전환하며, 짧은 좌클릭·더블클릭은 기본 동작을 유지합니다. 마우스를 드래그하면 홀드가 해제되어 화면 확대·멀티뷰 이동을 계속 사용할 수 있습니다. 입력창·실제 버튼에서는 개입하지 않고, 일시정지 상태에서 길게 눌러도 자동 재생하지 않습니다.
- **재생 배속 단축키:** 라이브와 다시보기에서 `[`를 누르면 0.25배 감소하고, `]`를 누르면 0.25배 증가합니다. 감소·증가 키를 꾹 누르면 키보드 반복 입력 속도에 따라 연속으로 조절합니다. 최소 0.25배, 최대 4배까지 조절하며 `\`를 누르면 1배속으로 돌아옵니다. 조절 간격·범위·복원 배속은 고정이고, 설정에서 기능을 끄거나 세 단축키만 원하는 키로 바꿀 수 있으며, 입력창·실제 버튼과 기존 재생 조작에 쓰이는 키는 가로채지 않습니다.
- 관련 설정: `다시보기·타임머신 스킵`, `방향키·프레임 이동`, `스킵 시간 조절 버튼 표시`, `라이브에도 스킵 시간 조절 버튼 표시`, `일시정지 중 실시간 복귀 방지`, `Space·좌클릭 홀드 2배속`, `배속 조절 단축키`와 감소·증가·복원 키, 그리고 `기본 스킵`/`휠 기본`/`Shift+휠`/`Alt+휠` 수치.

### 3. 볼륨 조절과 오디오 컴프레서

라이브 표시 설정에서 **우상단 LIVE 숨기기**와 **방송 시작 시각 표시**를 각각 켤 수 있습니다(기본 꺼짐). 시작 시각은 라이브 화면의 ‘스트리밍 중’ 오른쪽에 한국 시간 기준으로 표시합니다. 오늘 시작한 방송은 `14:30 시작`, 다른 날짜에 시작한 방송은 `2026.09.14 14:30 시작`처럼 날짜를 함께 표시하며, 시청 중 자정이 지나도 자동으로 반영합니다. API에서 확인되지 않으면 표시하지 않습니다. 타임머신 재생 위치와 관계없이 실제 방송 시작 시각을 보여 줍니다.

**방송 시작 시 자동 새로고침**은 기본으로 켜져 있습니다. `다음 라이브를 기대해주세요!` 화면에서만 30초 간격으로 방송 상태를 확인하고, 오프라인에서 방송 중으로 전환되면 한 번 새로고침합니다. 재생이 시작되거나 페이지를 이동하면 확인을 멈춥니다. `플레이어 → 자동 처리` 설정에서 끌 수 있습니다.

플레이어 볼륨 컨트롤 주변에서 쓰는 세 가지 보조 기능입니다.

- **볼륨 휠 조절:** 볼륨 영역에서 마우스 휠로 볼륨을 올리거나 내립니다. 휠 1틱당 변화량은 직접 조절할 수 있습니다. 멀티뷰 보조 방송의 스피커 아이콘·볼륨 슬라이더에서도 같은 켜기·끄기 옵션과 1틱 볼륨 설정을 사용합니다.
- **볼륨 툴팁:** 기본 라이브·다시보기와 멀티뷰 메인의 스피커와 재생 볼륨바에서 볼륨바 높이 기준 위아래 8px 범위에 마우스를 올리면 바 위에 설정된 재생 볼륨(%)을 표시합니다. 상하 감지 범위를 벗어나면 툴팁이 사라집니다. 음소거 상태에서도 볼륨값을 표시하며, 멀티뷰 보조 방송에서는 표시하지 않습니다.
- **오디오 컴프레서:** 옵션을 켜면 기존 스피커·재생 볼륨바 오른쪽에 컴프레서 버튼을 표시합니다. 버튼을 눌러 압축 적용 여부를 전환합니다. 컴프레서에 마우스를 올리거나 키보드로 포커스하면 버튼 오른쪽에 **컴프레서 볼륨바**가 펼쳐집니다. 이 볼륨바는 압축 후 출력 크기를 0–100%로 조절하며 기본값은 100%입니다. 스피커의 재생 볼륨값과 음소거 상태는 바꾸지 않습니다. 컴프레서 영역의 휠은 컴프레서 볼륨만 조절하며 `휠로 볼륨 조절`·`1틱 볼륨` 설정을 따릅니다. 볼륨바에 포커스한 뒤 방향키·Home·End로도 조절할 수 있습니다. 컴프레서를 끄면 별도 출력 볼륨은 적용하지 않습니다.
- **컴프레서 상태 기억:** 켜짐·꺼짐과 컴프레서 볼륨은 확장 저장소에서 탭별로 기억하며, 같은 탭의 새로고침과 페이지 이동 뒤에도 유지됩니다. 다른 탭의 상태를 함께 바꾸지 않습니다. 새 탭은 꺼짐·100%로 시작하고, 탭을 닫거나 브라우저를 다시 시작하면 해당 선택은 초기화됩니다. 최근 조작한 최대 128개 탭의 상태를 보관합니다. 옵션을 끄거나 치즈나이프(cheese-knife) 확장의 컴프레서가 감지되면 충돌을 피하기 위해 치즈 스패너의 버튼·볼륨바와 압축 적용만 일시적으로 해제하며, 탭에 기억한 선택은 바꾸지 않습니다.
- 관련 설정: `휠로 볼륨 조절`, `1틱 볼륨`, `볼륨 % 표시`, `컴프레서 버튼 표시`와 압축 세부 수치(임계값·압축 전환 폭·비율·어택·릴리즈·보정 게인).
- 볼륨 퍼센트·빨리 감기·컴프레서·멀티뷰 버튼 툴팁은 치지직 기본 버튼 툴팁의 글꼴과 박스 스타일을 따릅니다. 멀티뷰 버튼은 마우스를 올리거나 키보드로 초점을 맞추면 켜기·끄기 안내를 표시합니다.

### 화면 확대

**휠로 화면 확대**는 `플레이어 → 화면 확대`에서 켤 수 있습니다(기본 꺼짐). 적용 방식은 두 가지입니다.

- **확대 버튼을 켠 동안:** 플레이어 오른쪽 하단의 돋보기 버튼으로 확대 모드를 켜고 끕니다. 모드를 끄면 원래 크기로 돌아갑니다.
- **영상 위에서 항상:** 확대 버튼을 누르지 않아도 영상 위의 휠로 바로 확대·축소합니다.

두 방식 모두 휠로 커서 위치를 중심으로 1–5배까지 확대하며, 확대한 화면은 왼쪽 버튼으로 드래그해 이동합니다. 오른쪽 아래 확대 박스는 배율 표시, **슬라이더**, **되돌리기 아이콘**을 한 줄로 배치합니다. 슬라이더는 현재 화면 중심을 유지하며 **100–500%를 1% 단위**로 조절합니다. 키보드 방향키·Home·End로도 조절할 수 있고, 오른쪽 되돌리기 아이콘을 누르면 1배로 돌아갑니다. 버튼 방식에서는 확대 모드를 켜면 100%부터 슬라이더를 사용할 수 있습니다.

확대 박스는 하단 재생 컨트롤보다 조금 위에 고정됩니다. 컨트롤이 나타나거나 사라지고 되돌리기 아이콘에 마우스를 올려도 위치가 바뀌지 않습니다.

볼륨·재생바·설정 메뉴의 휠과 기본 클릭·더블클릭은 유지합니다. 라이브·타임머신·다시보기와 멀티뷰 메인 영상에 적용되며, 확대 중에는 메인 영상 드래그를 확대 영역 이동에 사용합니다. 멀티뷰의 `Alt` 드래그는 유지합니다. 방송 이동·영상 교체·옵션 해제 시 확대를 초기화합니다.

확대·드래그 중에도 왼쪽 스킵·빨리 감기·컴프레서 버튼은 원래 컨트롤 위치를 유지합니다.

### 4. 단축키 안내

Space(재생·일시정지)·M(음소거)·F(전체 화면)·T(넓은 화면)가 반응하지 않으면 설정의 **재생·단축키 → 기본 단축키 복구**를 켜세요. 기본값은 꺼짐이며, 현재 플레이어의 해당 버튼을 한 번 실행합니다. 채팅·검색 입력 중이나 조합키에는 개입하지 않습니다. Space·좌클릭 홀드 2배속이 켜져 있으면 기존 짧게 누르기·길게 누르기를 유지하고, 꺼져 있을 때 복구 옵션이 Space를 처리합니다. 배속·시간 이동 기능은 기존 설정을 따릅니다. 과거 단축키 복구 설정값으로 자동 활성화되지 않습니다.

치지직의 자막 전환 키인 `C`는 배속 단축키로 지정할 수 없습니다. 이전에 `C`를 저장한 경우 해당 배속 키는 기본값으로 돌아갑니다.

- **Space·좌클릭 홀드 2배속**을 켜면 짧은 Space 입력은 재생·일시정지를 전환하고, Space 또는 영상 화면 좌클릭을 길게 누르면 일시적으로 2배속을 적용합니다.
- **배속 조절 단축키**와 **시간 이동 단축키**는 각각의 설정을 따릅니다.

### 5. 다시보기 방송시각 표시

다시보기에서 방송 시작 시각과 현재 재생 위치를 더해, 지금 보고 있는 장면이 **실제로 방송된 시각**을 표시합니다. 방송 제목 옆에는 지난 방송 제목을 모아 보는 패널도 함께 제공됩니다.

- 17시간 제한으로 여러 다시보기로 나뉜 방송은 연결된 이전 세그먼트의 길이까지 이어 계산해, 현재 장면의 실제 방송 시각을 표시합니다.
- 방송 시작 시각을 확인할 수 없는 다시보기에서는 표시가 나타나지 않습니다.
- 관련 설정: `다시보기에 당시 시간 표시`(기본값: 켜짐).

### 6. 타임머신 지연 표시

라이브 타임머신으로 과거 구간을 볼 때, 실시간 방송과 비교한 **지연 시간**을 표시합니다.

- 관련 설정: `타임머신 지연 표시`.

### 7. 다시보기 채팅 복구

SPA(페이지 내 이동)로 다시보기에 들어갔을 때 "라이브 채팅 다시보기"가 빠지는 경우, 해당 다시보기를 **한 번만 자동 새로고침**해 채팅을 복구합니다.

- 같은 다시보기에서 반복 새로고침되지 않도록 짧은 시간 동안 중복을 방지합니다.
- 채팅 복구는 별도 설정 없이 기본으로 작동합니다.
- **다시보기 채팅창 댓글 탭:** 우측의 `라이브 채팅 다시보기` 디자인은 유지하면서 옆에 `댓글` 탭을 추가합니다. 채팅 다시보기가 없는 VOD에서는 같은 위치와 탭 디자인으로 댓글 전용 패널을 바로 표시하며, 전체화면이나 채팅 접기로 네이티브 패널이 잠시 사라진 상태에서는 별도 댓글창을 띄우지 않습니다. VOD 화면이 유휴 상태일 때 치지직 댓글 API에서 첫 10개를 미리 받아 두고, 댓글 탭을 열면 같은 결과를 바로 표시합니다. 패널을 내리면 모바일 웹 방식의 다음 offset을 사용해 이어 붙입니다. 원본과 같은 인기순(기본)·최신순·등록순과 새로고침을 지원하고, 작성자·시각·본문·답글·타임코드·첨부 이미지를 우측 폭에 맞춰 표시합니다. 긴 글은 `더보기`로 펼치고 다시 접을 수 있습니다. 답글은 원본처럼 기본으로 접혀 있으며 `답글 N` 문구는 유지한 채 화살표 방향으로 펼침 상태를 표시합니다. 펼친 답글은 22px 프로필과 좁은 들여쓰기를 사용하고 본문 앞에 답글 대상 이름을 표시합니다. 원본 댓글의 작성자·날짜·본문 글꼴 값을 반영하고 라이트·다크 색상 토큰을 따릅니다. 같은 하단 원본 댓글의 타임코드 버튼을 확인할 수 있으면 그 버튼의 표시 시각과 이동 동작을 그대로 사용하고, 원본 버튼이 없을 때만 현재 영상에서 직접 이동합니다. 하단 원본 댓글에서 같은 댓글의 컨트롤을 확인할 수 있을 때는 우측 아바타와 작성자 이름을 각각 대응하는 원본 프로필 버튼에 연결합니다. 버프 버튼도 원본 동작을 한 번 호출하며, 원본의 일시적인 초록색 버튼·숫자 상태와 증가한 개수를 그대로 동기화합니다. 원본 컨트롤이 없거나 비활성 상태이면 우측 버튼도 이유 안내와 함께 비활성화하며, 댓글 작성·삭제·신고는 하단 원본 댓글에서만 사용합니다.
- 관련 설정: `다시보기 채팅창 댓글 탭`.

### 8. 채팅 도구

`타임스탬프 표시`를 켜면 라이브 채팅의 닉네임 왼쪽과 방송자/채팅 운영자 모아보기에 **서버 메시지에 기록된 실제 작성 시각**을 브라우저 현지 `HH:MM` 형식으로 표시합니다. 입장·스크롤·재연결 때 서버에서 불러온 기존 채팅도 원본 시각을 사용하며, 유효한 서버 시각을 확인할 수 없는 행에는 현재 시각을 대신 붙이지 않습니다. 기본값은 꺼짐입니다.

`채팅방 환영 메시지 제거`를 켜면 라이브 채팅을 처음 열거나 다시 불러올 때 표시되는 “채팅방에 오신 것을 환영합니다!” 환영 행과 “쾌적한 시청 환경을 위해 일부 메시지는 필터링 됩니다.” 안내 행을 함께 숨깁니다. 기본값은 꺼짐입니다.

라이브 채팅에서 블라인드 처리된 메시지의 원문을 확인하고, 채팅창 우측 상단 아이콘에서 방송자/채팅 운영자 채팅을 모아 볼 수 있습니다. 두 기능은 각각 독립적으로 켜며 기본값은 모두 꺼짐입니다.

- **블라인드 채팅 원문 표시:** 페이지에서 확인한 원문이 있으면 블라인드 안내 대신 취소선을 그은 원문을 보여 줍니다. 작성자 역할이나 원문에 포함된 역할 단어와 관계없이 표시하며, 원문 속성이 나중에 추가되는 경우에도 반영합니다. 같은 채팅 목록에서 메시지 ID·작성자·재사용 표식이 일치하면 채팅 행이 교체되어도 저장한 원문을 표시합니다. 복원 가능한 원문이 없으면 치지직의 기존 안내를 그대로 유지합니다.
- **방송자/채팅 운영자 모아보기:** 방송자나 채팅 운영자(구 매니저)로 확인되는 채팅만 채팅창 우측 상단 아이콘에서 여는 패널에 모읍니다. 별도 채팅 팝업에서는 채팅 크기 조절 버튼과 겹치지 않도록 아이콘과 패널을 좌측에 표시합니다.
- **일반 채팅 하이라이트:** 모아보기를 켜면 대상 메시지를 원래 채팅창에서도 닉네임 색상의 옅은 배경과 얇은 테두리로 강조합니다. 긴 제목 툴팁이 뜰 때 제목을 감싸는 박스처럼 모서리를 둥글게 표시하고, 라이트·다크 모드에 맞춰 농도를 조절합니다. 본문 글자색과 채팅 줄 크기는 유지하며, 패널을 닫아도 강조는 남고 모아보기 옵션을 끄면 함께 사라집니다.
- **사용자별 보기와 새 채팅 알림:** 보관 중인 채팅을 닉네임별로 정리하며, `전체` 또는 사용자 버튼으로 표시 대상을 선택할 수 있습니다. 상단 모아보기 아이콘의 숫자와 강조 표시는 미확인 채팅 수이며, 사용자 버튼에도 각 사용자의 미확인 개수가 표시됩니다. 패널을 연 상태에서 채팅 행의 절반 이상이 화면에 보이면 확인 처리되어 알림이 사라집니다. 목록보다 긴 행은 목록 높이의 절반을 기준으로 합니다. 다른 사용자 필터에 가려진 채팅이나 백그라운드 탭의 채팅은 확인 처리하지 않습니다. 패널에서 위로 스크롤하면 아래쪽 꺾쇠 모양의 `맨 아래로` 버튼이 나타나며, 누르면 현재 필터의 마지막 채팅으로 이동하고 버튼은 사라집니다.
- **채팅 선택과 복사:** 모아 둔 채팅은 여러 행에 걸쳐 드래그한 뒤 `Ctrl+C`(Mac은 `Command+C`)로 복사할 수 있습니다. 선택 중에는 자동으로 맨 아래로 스크롤하지 않습니다. 일반 클릭 또는 행에 초점을 맞춘 뒤 Enter·Space를 누르면, 같은 메시지가 원본 채팅창에 남아 있을 때 해당 위치로 이동합니다.
- 모아 둔 채팅 메시지는 현재 페이지에서만 유지되며 새로고침하면 사라집니다.
- 사용자 목록과 미확인 상태도 현재 페이지 메모리에서만 관리하며 다른 방송으로 이동하면 초기화됩니다. 보관 개수를 넘겨 삭제된 채팅은 알림에서도 제외하고, 보관된 채팅이 없는 사용자는 목록에서 정리합니다. 사용자 분류는 현재 확인된 닉네임 기준이며, 배지 없는 모든 스트리머나 인증 사용자를 추가로 자동 판별하는 기능은 포함하지 않습니다.
- 서버 권한을 우회하거나, 비공개 moderation API를 호출하거나, 페이지가 이미 사용하지 않는 엔드포인트에서 삭제/숨김 메시지를 가져오지 않습니다.
- 관련 설정: `타임스탬프 표시`, `채팅방 환영 메시지 제거`, `블라인드 채팅 원문 표시`, `방송자·운영자 채팅 모아보기`(기본값: 모두 꺼짐), `모아보기 보관 개수`.

### 9. 통나무 보상 자동 받기

시청 중 치지직 채팅창에 **시청 통나무 파워 배달 완료** 알림의 수령 버튼이나 보상 창 안의 **1시간 시청 보상** 수령 버튼이 확인된 구조로 표시되면, 잠시 뒤 버튼 상태를 다시 확인하고 보상 상태별로 한 번만 클릭합니다. 같은 보상의 버튼이 재렌더되더라도 중복 클릭하지 않으며, 다음 보상 상태나 다른 방송의 보상은 새로 수집합니다. 또한 라이브 채널의 통나무 claim 목록을 30초마다 확인해 팔로우 등 대기 중인 비시청 보상을 자동으로 받습니다. 이 기능은 기본값이 켜짐입니다.

프로필 팝업의 **보유 파워**와 **통나무 파워 획득 방법** 목록은 수령 버튼이 아니므로 자동 클릭하지 않습니다. 이 목록은 보상을 받은 뒤에도 그대로 남습니다.

- 시청 시간을 조작하거나 서버 확인을 우회하지 않습니다.
- `WATCH_1_HOUR` 보상은 API로 직접 수령하지 않고 치지직이 표시한 화면 버튼으로만 받습니다.
- 그 외 치지직이 claim 목록으로 제공한 보상은 로그인 세션을 사용해 치지직 `log-power` API로 받으며, 성공한 claim ID는 중복 요청하지 않습니다.
- 자동 클릭은 확인된 보상 알림의 문구·아이콘·버튼 구조와 보상 창 안의 수령 행 구조를 함께 검사합니다. 문구만 비슷한 채팅·랭킹·프로필·링크는 클릭하지 않습니다. 치지직의 보상 UI 구조가 달라져 확인되지 않는 버튼은 자동으로 누르지 않으므로 직접 수령해 주세요.
- 관련 설정: `통나무 보상 자동 받기`(기본값: 켜짐).

### 10. 팔로잉 사이드바

팔로잉 본문과 사이드바에서 라이브를 더 빠르게 확인할 수 있게 합니다.

- **팔로잉 목록 상태 기억:** 팔로잉 구역을 펼치거나 접은 상태와 `더보기`로 전체 목록을 펼친 상태를 각각 기억합니다. 새로고침·페이지 이동·사이드바 재생성 뒤에도 마지막 선택을 복원합니다. 선택은 이 브라우저에 저장하며, 이미 열린 다른 탭의 목록은 함께 바꾸지 않습니다. 처음 사용할 때는 치지직의 현재 상태를 그대로 두고 직접 누른 선택부터 기억합니다. 기본값은 꺼짐이며, 옵션을 켜면 상태 저장과 자동 복원을 시작합니다.
- **팔로잉 오프라인 채널 숨기기:** 설정에서 켜면 사이드바의 오프라인 채널을 숨깁니다. 기본값은 꺼짐이며, 채널 고정 기능과 독립적으로 동작합니다. 고정 채널도 오프라인이면 숨기고, 목록 갱신으로 라이브 상태가 확인되면 다시 표시합니다. 옵션을 끄면 오프라인 채널을 다시 표시하며 고정 목록은 유지합니다.

- **채널 링크 드래그:** 사이드바 팔로잉 채널의 프로필·이름 링크를 끌어 브라우저 탭 표시줄 등에 놓을 수 있습니다. 채널 고정 옵션과 관계없이 링크 주소를 전달하며, 멀티뷰를 켠 상태에서 영상 영역에 놓으면 해당 라이브 방송을 추가합니다. 자유 배치에서는 보조 화면 기본 크기의 안내가 포인터를 따라 움직이며, 페이지의 원하는 위치에 놓아 방송을 추가할 수 있습니다. 드래그 중에는 팔로잉 미리보기를 닫습니다.

- **사이드바 치즈팜 숨김:** 사이드바의 치즈팜 메뉴만 숨깁니다. 헤더의 치즈 아이콘과 치즈팜 페이지 자체는 그대로 유지합니다.
- **사이드바 항목 숨기기:** 설정의 사이드바에서 `인기 카테고리 숨기기`, `다가오는 방송 일정 숨기기`, `파트너 스트리머 숨기기`, `서비스 바로가기 숨기기`를 각각 선택할 수 있습니다. 모두 기본값은 꺼짐이며, 저장하면 해당 제목과 목록이 함께 숨겨지고 해제 후 저장하면 다시 표시됩니다.
- **팔로잉 채널 고정:** 사이드바 팔로잉 헤더에서 새로고침 왼쪽의 핀 버튼으로 고정 모드를 켠 뒤 채널을 선택해 고정하거나 해제합니다. 고정된 채널은 채널명 오른쪽에 작은 핀 아이콘을 항상 표시하고, 고정 모드에서만 행에 어두운 초록색 테두리를 표시합니다. 기본 순서는 고정 라이브 → 일반 라이브 → 고정 오프라인 → 일반 오프라인입니다. `오프라인이어도 최상단 고정`을 켜면 방송 여부와 관계없이 고정 채널을 일반 라이브보다 위에 모읍니다. 이 옵션의 기본값은 꺼짐이며, 같은 그룹 안에서는 치지직이 제공한 상대 순서를 유지합니다. 고정 목록과 설정은 Chrome 동기화 설정에 저장합니다.
- **팔로잉 라이브 제목 이력:** 팔로잉(`/following`) 본문에 현재 라이브 중인 방송의 제목을 방송별로 이 브라우저에만 저장합니다. 제목이 바뀌면 현재 제목 오른쪽 버튼으로 이전 제목과 확인 시각을 펼쳐 볼 수 있으며, 같은 채널의 다음 방송은 새 라이브 ID를 확인해 이력을 새로 시작합니다.
- **팔로잉 목록 자동 새로고침:** 사이드바 팔로잉 채널의 라이브 상태를 설정한 주기마다 갱신하며, 다른 탭을 오래 본 뒤 돌아오면 즉시 한 번 갱신합니다.
- **팔로잉 호버 미리보기:** 사이드바 팔로잉 라이브에 마우스를 올리면 `live-detail` 메타데이터와 탐색 hover와 같은 `auto-play-info` HLS 정보를 받아 카드 안에서 미리보기를 재생합니다. 자동 재생 정보에 사용할 수 있는 HLS가 없으면 `live-detail`의 정상 재생 정보를 사용합니다. 미리보기 소리는 설정한 고정 볼륨(기본 15%)을 사용하며, 브라우저가 소리 자동재생을 막으면 음소거로 먼저 재생한 뒤 카드 안 버튼으로 소리를 켤 수 있습니다. `우클릭으로 미리보기 소리 전환`을 켜면 영상 좌측 하단의 작은 스피커 아이콘으로 현재 상태를 표시하고, 우클릭할 때 `소리 켜짐` 또는 `소리 꺼짐` 문구가 옆으로 펼쳐졌다가 다시 아이콘으로 접힙니다. 진행 시간은 `00:00:00` 형식으로 표시하고, 새 창이나 외부 프레임으로의 대체 재생은 사용하지 않습니다.
- **미리보기 글꼴:** 팔로잉 미리보기의 채널명·방송 제목·시청자 정보와 미리보기 소리·우클릭 안내에는 확장에 포함된 Pretendard를 사용합니다. 진행 시간은 정보 줄 오른쪽 끝에 더 크고 선명하게 표시합니다. 외부 폰트 서버에 접속하지 않으며 치지직의 기존 라이트·다크 색상을 유지합니다.
- **멀티뷰와 미리보기:** 자유 배치 중에도 팔로잉 미리보기가 메인·보조 창 위에 표시됩니다. 자유 배치를 켜고 끄거나 플레이어가 교체돼도 열려 있는 미리보기의 재생을 유지합니다.
- **미리보기 카테고리 이동:** 팔로잉 미리보기의 카테고리를 치지직 그린 배경의 작은 링크로 표시합니다. 누르면 같은 탭에서 해당 카테고리의 라이브 방송 목록으로 이동하며, Ctrl/Command+클릭·가운데 클릭도 일반 링크처럼 사용할 수 있습니다. 이동 정보를 확인할 수 없으면 카테고리 이름만 표시합니다.
- **미리보기 채널명 링크:** 호버 미리보기 카드 안의 채널명 옆에 치지직의 새 탭 아이콘을 표시하며, 일반 클릭하면 해당 채널 홈을 새 탭에서 엽니다. Ctrl/Command+클릭이나 가운데 클릭도 일반 링크처럼 사용할 수 있습니다.
- 관련 설정: `사이드바 치즈팜 숨김`(기본값: 꺼짐), `팔로잉 목록 상태 기억`(기본값: 꺼짐), `팔로잉 채널 고정`, `오프라인이어도 최상단 고정`(기본값: 꺼짐), `팔로잉 라이브 제목 이력`, `팔로잉 목록 자동 새로고침`, `자동 새로고침 주기`, `방송 목록 호버 미리보기`(기본값: 꺼짐), `호버 미리보기 소리`, `미리보기 볼륨`, `우클릭으로 미리보기 소리 전환`.

> 기본 목록 구조를 유지하되, 접힌 5개 행 밖의 고정 채널은 치지직 팔로잉 응답을 바탕으로 접힌 목록에 보충합니다. 목록을 펼치면 치지직이 생성한 원본 전체 행의 표시 순서만 변경합니다.

> 접힌 목록에 보충된 고정 채널도 일반 클릭과 Enter로 페이지 내부에서 이동합니다. Ctrl·Shift 클릭 등 브라우저의 링크 조작은 유지하며, 고정 모드에서는 이동 대신 고정·해제를 처리합니다.

> `방송 목록 호버 미리보기`를 켜면 미리보기 영상을 불러오는 `pstatic.net` 호스트 권한을 그 시점에 요청합니다. [권한 및 개인정보](#권한-및-개인정보)를 참고하세요.

### 11. 방송 목록 도구

전체 방송(`/lives`)과 카테고리의 라이브·영상·클립 목록 위에 **검색창 · 결과 수 표시 · 필터 메뉴**를 추가하고, 각 카드에 팔로워 수와 목록에 맞는 부가 정보를 더합니다.

- **전체 방송 집계:** 전체 방송 탭의 검색창 옆에 시청자 10명 이상인 **방송 수와 해당 방송의 동시 시청자 수 합계**를 표시합니다. 기존 목록 조회로 두 값을 함께 계산하며 검색·필터와는 무관합니다. 방송 ID별 마지막 조회값을 한 번만 합산하지만, 같은 사람이 여러 방송을 시청하는 경우의 중복까지 제거한 인원 수는 아닙니다. 마우스를 올리면 집계 시각을 확인할 수 있습니다. 완료한 결과는 같은 페이지 세션에서 5분간 재사용하고, 탭을 떠나면 진행 중 조회를 취소합니다. 자동 주기 갱신은 하지 않습니다.

- **현재 목록 검색:** 목록 위에 검색창(`현재 목록 검색`)을 추가해, 지금 불러온 목록을 제목·스트리머·카테고리·태그 기준으로 걸러 줍니다. 검색어나 필터가 적용되면 검색창 옆에 `표시된 결과 수 / 확인한 목록 수`가 표시되고, 정보를 더 불러오는 동안에는 스피너가 돕니다. 검색 결과는 팔로워 배지 조회를 기다리지 않고 먼저 표시합니다. 추가 카드는 24개씩 만들고 목록 아래로 스크롤하면 확보한 결과부터 이어서 표시하며, 썸네일은 화면에 가까워질 때 불러옵니다. 결과를 확인하는 중에는 진행 상태를 표시하고, 확인이 끝난 뒤 조건에 맞는 결과가 없으면 "조건에 맞는 결과가 없습니다."를 보여 줍니다.
- **필터 메뉴:** `필터` 버튼을 누르면 필터 메뉴가 열립니다. 항목 선택·직접 입력·스크롤·팔로잉 자동 새로고침 중에는 열린 상태를 유지하며, 메뉴 밖을 직접 클릭하거나 `필터` 버튼을 다시 누르면 닫힙니다. 적용된 필터가 있으면 버튼이 `필터 N`(개수)으로 바뀝니다.
    - **팔로워 수 필터:** 설정한 기준값으로 만들어진 구간 버튼(`○명 이하`, `○명 ~ △명`, `○명 ~ 최대`)을 누르거나, `직접` 입력란에 최소·최대(`최소 ~ 최대`)를 직접 적어 거를 수 있습니다.
    - **시청자 수 / 조회수 필터:** 라이브 목록에서는 **시청자 수**, 그 외 목록에서는 **조회수** 기준으로 같은 방식의 구간 버튼과 직접 입력을 제공합니다.
    - **진행 시간 필터:** 라이브 목록에서 방송 시작 후 지난 시간을 기준으로 구간 버튼을 누르거나, 최소·최대 시간을 직접 입력해 거를 수 있습니다. 현재 목록과 설정한 추가 조회 범위 안에서만 적용됩니다.
    - **필터 초기화:** 메뉴 아래 `필터 초기화` 버튼으로 모든 필터를 한 번에 해제합니다.
- **팔로워 수 표시:** 화면 근처의 방송 카드에 축약된 팔로워 수 배지(예: `1.2만`, `5천`)를 표시합니다. 팔로워 수만 제공하는 API를 채널별로 조회하며, 조회 수치 설정으로 조회량과 속도를 조절합니다. 팔로워 필터는 다른 조건에 맞는 후보를 차례로 확인하고, 확인된 결과부터 표시합니다.
- **진행 시간 표시:** 라이브 썸네일에 마우스를 올리면 방송이 시작된 뒤 얼마나 지났는지 진행 시간 배지가 나타나고, 1초마다 갱신됩니다.
- **방송 미리보기:** 전체 방송(`/lives`)의 기본 카드와 검색·필터 결과 카드에서 호버 미리보기를 재생합니다. 기본 카드는 치지직 플레이어와 API를 그대로 사용하면서 네이티브 300ms/600ms 호버 대기만 없애고, 검색·필터 결과 카드는 호버 즉시 HLS 요청과 플레이어 시작을 진행합니다. 호버 중에는 `우클릭 시 확대` 안내를 표시하며, `우클릭으로 미리보기 소리 전환`을 켜면 `우클릭 시 확대 및 소리 재생`으로 안내합니다. 우클릭하면 안내를 숨기고 영상을 확대하며 진행 시간 배지도 숨겨 화면에 집중할 수 있습니다. 확장 소유 HLS는 집중 모드에서 가능한 최고 1080p까지 상한을 높이며, 소리 전환 옵션을 켠 경우에만 고정 볼륨으로 소리도 켭니다.
- **전체 방송 태그 검색 숨김:** 전체 방송 목록의 기본 태그 검색창을 숨기고, 위의 확장 검색/필터만 표시합니다.
- **필터 버튼 기준값:** 팔로워, 시청자/조회수, 진행 시간 필터의 구간 버튼 값 6개를 각각 지정할 수 있습니다. 1번 값은 "이하" 버튼 기준이고, 이후 값들은 구간 경계로 쓰입니다.
- **조회 범위·속도:** 추가로 조회할 페이지 수, 팔로워 수 묶음 처리량, 동시 조회 수, 조회 간격(ms)을 조절합니다. 추가 조회 페이지를 낮추면 반응이 빨라지고, 높이면 더 멀리 있는 방송까지 필터링합니다.
- 관련 설정: `방송 목록 검색·필터`, `전체 방송 태그 검색 숨김`, `팔로워 수 표시`, `호버로 진행 시간 표시`, `미리보기 볼륨`, `우클릭으로 미리보기 소리 전환`, `팔로워 버튼 1~6`, `시청자/조회수 1~6`, `진행 시간 1~6`, `추가 조회 페이지`, `팔로워 조회 묶음`, `동시 조회`, `조회 간격`.

### 12. 긴 제목 툴팁

말줄임 처리된 방송·영상 제목에 마우스를 올리면 전체 제목을 별도 툴팁으로 보여 줍니다.

- 실제로 잘려 있는 제목에만 툴팁을 띄우며, 치지직 전 페이지의 카드형 목록에서 동작합니다.
- 관련 설정: `긴 제목 툴팁`.

### 13. 다시보기 검색

채널의 다시보기 목록에 **검색창**을 추가해 제목으로 영상을 찾을 수 있게 합니다. 제목만으로 결과가 부족하면 댓글 내용까지 확인하도록 확장할 수 있습니다.

- **제목 검색:** 채널의 다시보기를 여러 페이지까지 모아 제목으로 필터링합니다.
- **댓글 검색:** 제목 검색 결과가 부족할 때 영상별 댓글을 순차 조회해, 검색어가 댓글에서 발견된 영상을 함께 보여 줍니다.
- **댓글 일치 표시:** 댓글에서 검색어가 발견된 영상에는 댓글 아이콘이 붙고, 아이콘에 마우스를 올리면 일치한 댓글 내용을 미리 보여 줍니다.
- **부하 조절:** 댓글 검색은 요청량이 크므로, 조회 지연(ms)·영상 수·영상당 댓글 페이지 수를 낮추면 페이지 반응이 빨라집니다. 한 번에 표시할 결과 개수도 조절할 수 있습니다.
- 관련 설정: `다시보기 검색`, `제목에 없으면 댓글까지 검색`, `영상 조회 페이지`, `한 번에 표시`, `댓글 검색 지연`, `댓글 조회 영상`, `영상당 댓글 페이지`.

### 14. 채널 방송 시간 통계

채널 홈에서 다시보기의 방송 시작·종료 시각을 모아 **최근 평균 방송 시간**과 **월별 방송일**을 보여 줍니다.

**채널 채팅 바로가기:** 채널의 홈·동영상·클립·커뮤니티·정보 화면에서 `정보` 탭 바로 오른쪽에 `채팅` 링크를 표시합니다. 방송이 꺼져 있어도 같은 탭에서 플레이어 영역과 채팅이 함께 있는 일반 라이브 화면(`/live/{채널 ID}`)으로 이동합니다. 탐색 설정의 `채널 채팅 바로가기`로 표시를 끌 수 있으며, 기본값은 켜짐입니다. 실제 메시지 작성에는 치지직의 로그인·채팅 이용 조건이 적용됩니다.

- **방송 시간 스티커:** 채널 액션 영역에 최근 평균 방송 시간을 표시합니다.
- **월간 달력:** 방송한 날짜를 색으로 칠하고, 날짜에 마우스를 올리면 그날의 시작/종료/진행 시간을 보여 줍니다. 하단의 월평균은 월 총 방송 시간을 현재 달은 오늘까지의 일수로, 지난달은 해당 월의 전체 일수로 나눠 표시합니다. 날짜를 클릭하면 그날 첫 방송 다시보기로 이동하고, 툴팁의 방송 항목을 누르면 해당 방송으로 이동합니다. (Ctrl/Shift/가운데 클릭은 새 탭) 읽어 온 페이지는 잠시 캐시되어 다시 볼 때 빠르게 표시됩니다.
- **분할 방송 연결:** 같은 시작 시각에서 이어진 17시간 분할 다시보기는 하나의 방송 구간으로 합칩니다. 전체 시간과 다시보기 링크는 시작 날짜에 모아 표시하고, 다시보기로 확인된 방송 구간이 걸친 날짜는 달이 바뀌어도 색을 채워 방송일 수에 반영합니다. 아직 다시보기로 남지 않은 라이브 구간은 포함하지 않습니다.
- **달력 색 농도:** 방송 시간을 3시간 단위의 9단계로 표시합니다. 3시간 미만부터 단계가 올라가며, 24시간 이상이 가장 진한 색입니다. 달력 아래의 색상 범례에서 기준을 확인할 수 있습니다. 시작 날짜는 합산된 전체 방송 시간, 이어진 날짜는 해당 날짜에 걸친 방송 시간을 기준으로 하며, 이어진 날짜에 마우스를 올리면 그 시간을 보여 줍니다.
- **내 시청 표시(기본 꺼짐):** 켜면 시청 기록이 있는 방송에만 점과 툴팁의 내 시청 시간을 표시합니다. 시청하지 않은 방송의 `내 시청 0분 (0%)`는 숨기며, 달력 하단의 내 시청 합계도 해당 채널의 기록이 있을 때만 표시합니다.
- **조회 범위 조절:** 평균을 계산할 기간(일), 평균·달력을 위해 조회할 다시보기 페이지 상한을 직접 정할 수 있습니다. 이번 달과 과거 달 모두 달력 조회 상한을 적용하며, 상한까지 읽어도 해당 월의 조회가 끝나지 않으면 달력에 일부만 표시했다는 안내가 나타납니다. 최신 영상부터 조회하므로 영상이 많은 채널의 오래된 달을 보려면 달력 조회 상한을 높여야 할 수 있습니다. 평균과 달력은 같은 페이지 요청을 공유하며, 상한을 낮출수록 조회량이 줄어듭니다.
- 관련 설정: `평균 방송 시간 표시`, `방송일 월간 달력`, `달력에 내 시청 시간 표시`, `평균 기간`, `평균 조회 상한`, `달력 조회 상한`.

### 15. 라이브 시청 기록

라이브를 보는 동안의 재생 시간을 **이 브라우저에만** 저장하고, 월별 달력과 라이브별 누적 시간을 확인할 수 있게 합니다.

- 영상 재생 위치가 실제로 전진한 시간만 기록합니다. 일시정지하거나 재생이 멈춘 구간은 제외하며, 백그라운드에서도 영상이 계속 재생되면 기록됩니다.
- 같은 방송을 여러 탭에서 동시에 재생한 경우 서로 겹치는 실제 시청 구간은 한 번만 합산합니다.
- **최소 저장 시간**보다 짧게 본 라이브는 기록하지 않습니다.
- 방송 제목과 방제 이력은 현재 라이브의 방송 정보로 확인된 값만 저장합니다. 방송 정보 확인 전이나 조회 실패 시에는 시청 시간을 제목 없이 저장하며, 기존에 저장된 제목 이력은 자동으로 삭제하지 않습니다.
- 기록은 Chrome 동기화가 아닌 **이 브라우저의 로컬 저장소**에만 저장됩니다.
- 관련 설정: `라이브 시청 기록 저장`, `최소 저장 시간`. 자세한 확인·관리는 [시청 기록 페이지](#시청-기록-페이지)에서 합니다.

### 16. 시청 방해 팝업 제거

시청에 방해되는 팝업을 제거합니다.

- 관련 설정: `시청 방해 팝업 제거`(기본 켜짐).

**플레이어 → 치지직 광고**에는 다음 두 옵션이 별도로 있습니다. 동영상 광고 차단은 기본 켜짐, 배너 광고 숨기기는 기본 꺼짐이며, 시청 방해 팝업 제거와 독립적으로 동작합니다. 기존에 저장된 설정값은 유지되며, 새 설치나 기본값 복원 시 동영상 광고 차단이 켜집니다.

- **동영상 광고 차단 — 실험적:** 확인된 치지직 광고 표시 응답의 프리롤·미드롤 값을 처리합니다. 켜고 저장한 뒤 치지직 탭을 새로고침해야 합니다. 자동으로 새로고침하지 않습니다. 끄면 이후 광고 처리를 멈추며, 이미 반영한 플레이어 상태는 새로고침하면 복원됩니다. 알 수 없는 응답과 본방송 스트림·화질 정보는 그대로 통과합니다.
- **배너 광고 숨기기:** 홈·라이브·VOD에서 확인한 광고 배너 슬롯만 CSS로 숨깁니다. 기능을 끄면 원래 표시로 돌아갑니다. 이 옵션 자체는 광고 요청을 차단하지 않습니다.

동영상 광고 차단은 실험 기능으로, 치지직 응답이나 플레이어가 바뀌면 광고가 재생될 수 있습니다. 확인된 라이브·다시보기 광고 소스의 플레이어 연결과 라이브 중간 광고 항목을 차단해 광고 준비와 다시보기 암전 카운트다운이 시작되지 않도록 처리합니다. 적용하려면 치지직 탭을 새로고침해야 하며, 이미 시작된 광고를 즉시 제거하는 기능은 아닙니다. SDK 교체나 광고 서버 전체 차단은 하지 않습니다.

라이브에서 본방송 상태 처리와 함께 전달되는 광고는 확인된 별도 광고 요청만 차단하고 본방송 상태 연결은 유지합니다. 방송 스트림 자체에 포함된 광고는 제거하지 않습니다.

배너 숨기기는 홈·라이브·다시보기의 기본 배너와 광고 재생에 연동되는 라이브·다시보기 배너 슬롯을 포함합니다. 일반 이벤트·콘텐츠 안내 영역은 숨기지 않습니다. 배속·시간 이동·자동 화질의 본영상 선택에서는 확인된 광고 영상을 제외합니다.

### 17. 라이브 멀티뷰

팔로잉 라이브 링크나 다른 탭의 치지직 라이브 URL을 **드래그해서 놓아도 방송을 추가**할 수 있습니다. 분할 배치에서는 켜진 멀티뷰 영상 영역에 놓습니다. **자유 배치에서는 보조 화면 기본 크기의 안내가 포인터 중심을 따라 움직이고, 기존 영상 밖의 사이드바·채팅·빈 공간에도 놓은 위치에 방송을 추가**합니다. 화면 가장자리에서는 창 전체가 보이도록 위치를 맞춥니다. 입력칸과 멀티뷰 설정창에서는 방송을 배치하지 않습니다. 중복·최대 6개 제한을 안내하며, 추가된 서브 방송은 음소거로 시작합니다. 드래그를 취소하거나 배치 영역 밖에 놓으면 멀티뷰 구성을 바꾸지 않습니다.

설정에서 **라이브 멀티뷰**를 켜고 영상 호스트 권한을 허용한 뒤, 라이브 플레이어 하단의 **넓은 화면 버튼 왼쪽에 있는 격자 모양 멀티뷰 버튼**을 누릅니다. 켜진 상태는 초록색으로 표시되며, 다시 누르면 멀티뷰를 끕니다. 서브 방송이 없는 상태에서 켜면 방송 추가 입력창이 열립니다. 이후에는 **채팅창 상단의 멀티뷰 설정 → 팝업 상단의 + 방송 추가**에서 방송인 닉네임으로 검색하거나 치지직 라이브 URL을 입력해 최대 6개 방송을 함께 볼 수 있습니다.

- **닉네임 검색:** 닉네임을 입력한 뒤 검색 버튼이나 Enter를 누르면 팔로워순 상위 5개 결과에 프로필 사진·닉네임·방송 여부·방송 중인 채널의 시청자 수를 표시합니다. 방송 중인 결과를 누르면 음소거 상태로 추가됩니다. 오프라인·이미 추가한 방송은 선택할 수 없습니다. 원하는 방송이 없으면 닉네임을 더 자세히 입력해 검색해 주세요. 시청자 수는 검색 시점의 조회값이며 조회 실패 시 확인 불가로 표시합니다.

메인만 있을 때는 전체 영역을 사용합니다. 기본 배치는 메인에 가로·세로 각각 2/3, 보조 방송마다 각각 1/3(면적 1/9)의 영역을 배정합니다. 사용자가 변경하기 전까지 보조 영상을 임의로 확대하지 않습니다. 영상이 잘리지 않도록 실제 영상 비율에 맞춰 박스 크기를 보정하며, 영상 정보를 확인하기 전에는 16:9를 사용합니다. 영상 박스 안에 비율 차이로 생기던 검은 여백을 줄이는 방식이며, 방송이 적을 때 전체 화면에 남는 빈 공간은 유지됩니다. 변경한 영역 분할과 크기는 탭 세션에 저장하고 화면 모드 전환·새로고침 후에도 복원합니다. 방송 추가·제거 시에는 주변 공간을 정리하며, **기본 배치**를 누르면 메인 4/9·보조 1/9 기준으로 돌아갑니다.

- **자유 배치:** 채팅창 상단의 **멀티뷰 설정 → 자유 배치**에서 켜고 끕니다. 기본값은 꺼짐입니다. 켜면 메인·보조 창을 각각 드래그해 옮기고, 네 모서리로 영상 비율을 유지하며 크기를 조절할 수 있습니다. 창끼리 겹칠 수 있으며 누르거나 키보드 초점을 둔 창이 앞으로 나옵니다. 창은 브라우저의 페이지 표시 영역 안에서 플레이어 밖의 사이드바·채팅 위까지 옮길 수 있으며, 이동·크기 조절로 다른 창의 크기나 소리가 바뀌지 않습니다. 창이 페이지 표시 영역 밖으로 사라지지 않도록 경계를 유지합니다. 창에 Tab으로 초점을 둔 뒤 방향키로 이동하고, 모서리에 초점을 두면 방향키로 크기를 조절합니다. Shift를 함께 누르면 더 크게 조절합니다. 드래그·크기 조절 중 Esc나 우클릭은 취소입니다. 선택·창 위치·크기·겹침 순서는 현재 탭에 기억하며 새로고침 후에도 복원합니다. 끄면 기존 분할 배치로 돌아가고, 다시 켜면 마지막 자유 배치를 복원합니다. 전체화면에서는 자유 배치를 잠시 접고, 전체화면을 나올 때 복원합니다. **기본 배치**는 두 모드의 위치·크기를 초기화하며, **보조 방송 정렬**은 분할 배치에서 사용합니다.
- 기본·넓은 화면을 강제하지 않습니다. 기존 `T` 전환을 사용하며, 하단 제목·채널 상호작용과 채팅은 메인 방송을 따릅니다.
- 별도 상단 도구 줄 없이 영상 영역 전체를 사용합니다. 메인 영상에는 방송명이나 추가 조작 버튼을 겹쳐 표시하지 않으며 네이티브 조작부를 사용합니다. 멀티뷰 중에는 메인 좌상단 음소거 안내를 숨기고 하단 스피커 버튼으로 소리를 조절합니다. 격자 버튼은 멀티뷰 온·오프만 담당합니다. 보조 영상 하단에는 **재생·일시 정지 → 빨리 감기 → 음소거·볼륨 슬라이더 → 싱크 −0.1s·+0.1s** 순서로 표시합니다. 빨리 감기는 해당 채널의 저장 딜레이를 0초로 바꾸고 라이브 위치로 복귀합니다. 마우스를 치우면 숨겨지고 키보드 초점이 있을 때는 유지됩니다.
- 채팅창 상단 **모아보기 왼쪽의 멀티뷰 설정 버튼**으로 설정 팝업을 엽니다. 모아보기를 꺼도 더보기 버튼 옆에 붙어 있으며, 다시 누르거나 Esc로 닫으면 설정 버튼으로 초점이 돌아갑니다. 서브 방송명은 표시와 드래그 이동에만 사용합니다. 상단에는 **자유 배치·기본 배치·보조 방송 정렬**, 그 아래 목록 맨 위에는 **메인 방송**, 이어서 **서브 방송 이름·저장된 딜레이·적용 상태·제거 버튼**을 표시합니다. 서브 목록은 현재 방송 박스의 위→아래, 같은 줄에서는 왼쪽→오른쪽 순서이며, 위치나 크기 조절을 확정하면 함께 갱신합니다. **목록의 방송 행을 드래그**하면 놓일 위치가 표시되고, 놓으면 실제 화면의 자리도 바뀝니다. **서브를 맨 위 메인 행에 놓으면 메인 방송을 교체**하고 채팅·하단 정보도 함께 전환합니다. 목록에서는 각 자리의 크기를 유지하며 소리는 해당 자리의 볼륨·음소거 상태를 따릅니다. 긴 목록은 가장자리에서 자동 스크롤됩니다. 방송 이동 버튼에 초점을 두고 **Space 또는 Enter로 선택 → ↑↓로 대상 이동 → Space 또는 Enter로 적용**할 수도 있습니다. 드래그 중 **Esc·우클릭**은 취소이며 팝업은 유지합니다. 방송 제거·메인 교체 후에도 팝업을 복구하며, 바깥 클릭·Esc·닫기 버튼으로 닫습니다. 채팅이 접혀 있으면 영상 영역 우상단에 표시합니다. 볼륨과 세밀한 위치 조절은 영상에서 직접 하고, 싱크는 각 서브 행의 **−0.1s / +0.1s** 버튼으로도 조절합니다. 설정 팝업과 플레이어의 버튼은 같은 채널별 딜레이를 조절·저장합니다.
- 멀티뷰 설정의 각 보조 방송에서 **화질**을 선택할 수 있습니다. **자동**은 영상 크기와 네트워크에 맞춰 조절하고, 제공되는 480p 이상 해상도를 선택하면 해당 화질로 고정합니다. 선택은 채널별로 저장하며, 다음 방송에 저장된 해상도가 없으면 자동으로 재생하고 안내합니다. 화질 변경은 다음 영상 조각부터 반영될 수 있습니다. 메인 화질은 기존 플레이어에서 조절합니다.
- 보조 화면에서 **우클릭**하면 해당 방송의 **음소거를 전환**합니다. 영상 위 버튼·방송명·오류 안내 영역에서도 사용할 수 있으며, 설정 창은 채팅창 상단의 멀티뷰 설정 버튼으로 엽니다. 드래그 중 우클릭은 음소거를 바꾸지 않고 이동을 취소합니다. 분할 배치에서 **영상을 잡아 다른 영상의 왼쪽·오른쪽·위·아래 가장자리로 드래그**하면 그 방향에 새 분할 영역을 만듭니다. 중앙은 순서 이동, 빈 공간은 해당 영역으로 이동합니다. 놓기 전에 반투명 초록색으로 실제 배치될 박스를 표시하며, 취소하면 원래대로 돌아옵니다. 메인 영상의 중앙에 놓을 때만 방송을 메인으로 전환합니다.
- 분할 배치에서 **각 영상의 모서리를 대각선으로 드래그**하면 영상 비율을 유지하며 크기를 조절합니다. 움직일 수 있는 모서리에 표시가 나타나며, 화면 외곽에 붙은 경계는 안쪽의 가용 공간에서 조절됩니다. 공유 구분선은 해당 분할 영역의 비율을 따로 조절합니다. 기본 비율·중앙·최소 크기 경계 근처에서 스냅되며, **Esc**로 조절을 취소할 수 있습니다. 모서리나 구분선에 초점을 맞춰 방향키로도 조절할 수 있습니다. 매우 작은 박스에서는 버튼을 줄여 표시하고 아주 작은 박스에서는 볼륨 슬라이더를 숨깁니다.
- 분할 배치에서 **보조 영상 자체를 왼쪽 버튼으로 잡아 끌면 이동**합니다. 조금 움직이면 배치 가이드가 나타나며, 기본 브라우저 드래그 대신 포인터 이동으로 처리합니다. 별도 이동 손잡이는 없고, 하단 버튼·볼륨 슬라이더는 원래 조작을 유지합니다.
- 분할 배치에서 **메인 영상도 왼쪽 버튼으로 잡아 드래그**할 수 있습니다. 이동할 보조 영역 위로 끌면 메인 쪽 영역과 보조 묶음의 위치를 교환하며, 각 영역 안의 분할·순서·크기는 유지합니다. 예를 들어 메인이 위에 있고 보조 방송들이 아래 한 줄에 있다면, 메인을 아래 줄로 끌어 메인은 아래로, 보조 줄 전체는 위로 옮길 수 있습니다. 메인과 함께 묶인 보조가 있으면 그 보조도 같이 이동하며, 놓기 전에 가이드로 결과를 표시합니다. 채팅·방송 정보는 같은 메인 방송을 유지합니다. 일반 클릭·네이티브 버튼·탐색바는 기존 조작을 사용하며, **드래그 중 우클릭 또는 Esc**로 취소합니다.
- 분할 배치에서 **Alt를 누른 채 메인·보조 영상을 드래그**하면 분할 박스의 여백 안에서 영상 위치만 조절합니다. 박스 경계를 표시하며 가장자리·가운데 근처에 붙습니다. 영상 크기와 비율은 유지하고 박스 밖으로는 나가지 않습니다. **왼쪽 버튼을 누른 채 우클릭하면 취소**하며 이때는 음소거가 바뀌지 않습니다. 일반 방송 이동 드래그도 우클릭으로 취소할 수 있습니다. Esc를 쓰려면 Alt를 먼저 놓습니다. 채널별 위치는 탭에 저장해 화면 모드 전환·새로고침·메인 교체 후에도 유지하며, **기본 배치**는 모든 영상의 정렬도 가운데로 초기화합니다.
- 채팅창 상단의 멀티뷰 설정에서 **보조 방송 정렬**을 선택하면, 메인과 나뉜 모든 보조 영역을 한 번에 정돈합니다. 각 영역 안의 방송들을 같은 크기로 나누며, 오른쪽처럼 세로로 긴 영역은 위아래로, 아래쪽처럼 가로로 넓은 영역은 좌우로 균등하게 나눕니다. 메인의 위치·크기와 영역 사이 경계는 유지하고, 정렬한 영역의 여백·영상 정렬을 함께 정리합니다. 방송이 2개 이상인 보조 영역이 하나라도 있을 때 사용할 수 있으며, 방송이 하나뿐인 영역은 유지합니다. 정렬한 배치는 탭에 저장되고 이후에도 직접 크기와 위치를 조절할 수 있습니다. 영상 비율은 유지하므로 원본 비율이 다른 방송들은 실제 영상 크기에 차이가 있을 수 있습니다.
- 보조 영상에 마우스를 올리면 오른쪽 위의 **× 방송 제거** 버튼이 나타납니다. 제거하면 남은 방송이 자동으로 재배치되며, 제거한 채널의 저장 딜레이는 유지됩니다.
- **보조 영상을 메인 영상 중앙으로 드래그**하면 치지직 페이지 내부 이동으로 큰 영상·채팅·하단 정보를 함께 전환합니다. 페이지 내부 이동을 사용할 수 없으면 현재 방송을 유지하고 오류를 표시합니다.
- 음소거와 볼륨은 각 자리에서 독립적으로 조절합니다. **분할 배치나 설정 목록에서 방송 자리를 교환하면 해당 자리의 소리 설정을 이어받습니다.** 소리가 켜진 메인과 음소거된 서브를 교환하면 새 메인은 소리가 켜지고 이전 메인은 서브 자리에서 음소거됩니다. 서브끼리 중앙에 놓아 순서를 바꿀 때도 각 자리의 소리 설정을 유지하며, 가장자리 분할이나 메인 묶음 이동은 옮긴 방송과 놓은 대상 방송의 소리 설정을 교환합니다. 이동 미리보기·취소·메인 전환 실패 때는 소리가 바뀌지 않습니다. **딜레이는 계속 채널을 따릅니다.** 새 보조 자리는 음소거로 시작하며, 하단 **재생** 버튼으로 자동재생 제한을 해제할 수 있습니다. 볼륨을 높이면 음소거도 해제됩니다. **스피커 아이콘·볼륨 슬라이더 위에서 휠**을 돌리면 해당 자리의 소리만 조절하며, **휠로 볼륨 조절·1틱 볼륨** 설정 변경이 즉시 반영됩니다. 휠로 0%까지 내리면 음소거되고, 음소거 상태에서 올리면 0%를 기준으로 설정한 만큼 소리가 켜집니다. 자리의 소리 설정은 현재 방송 배치와 함께 탭 세션에 저장됩니다.
- 보조 재생·일시정지·음소거 아이콘은 치지직 네이티브 플레이어의 도형에 맞췄습니다. 소리가 켜져 있을 때는 볼륨에 따라 파형을 한 개 또는 두 개로 표시하며, 빨리 감기는 메인 라이브 컨트롤에 추가되는 버튼과 같은 아이콘을 사용합니다.
- 멀티뷰 안내·컨트롤·설정은 치지직에서 사용하는 글꼴 계열로 표시합니다. 방송 종료·재생 실패·저장 오류 안내와 재시도 버튼은 해당 방송 화면의 중앙에 모아 표시하며, 좁은 화면에서는 문구를 줄바꿈합니다.
- 멀티뷰 설정은 방송 목록과 조작 버튼을 함께 표시합니다. 배치는 아이콘과 문구를 함께 표시하는 한 줄 메뉴로, 추가는 민트색 버튼으로 제공합니다. 각 방송의 싱크 버튼은 옅은 민트색으로, 제거는 방송명 옆 붉은 휴지통 아이콘으로 구분합니다. 긴 상태 문구는 마우스를 올리면 전체 내용을 확인할 수 있습니다.
- **앞으로 / 늦추기**는 목표 딜레이를 0.1초 또는 1초씩 조절하고 영상과 소리에 함께 적용합니다. 라이브 위치나 이전 측정 기준에서 처음 조절할 때 현재 추정 지연을 기준으로 잡고, 이후에는 목표값에 조절량만 더하므로 측정값의 흔들림이 저장 값에 누적되지 않습니다. 채널별 목표 딜레이를 이 기기에 저장하여 새로고침·브라우저 재시작·다음 방송에도 불러옵니다. 방송을 제거하거나 위치를 바꿔도 채널별 값은 유지됩니다.
- 딜레이는 방송 정보 갱신 사이의 경과 시간을 보정한 라이브 끝 지점 기준입니다. 보조 방송은 HLS의 시간 정보를 사용하고, 메인은 실제 끝 지점의 진행 간격을 관찰한 뒤 추정합니다. **빨리 감기**는 저장 값을 0으로 바꾸고 재생 가능한 라이브 위치로 복귀합니다. 0초여도 송출·전송·재생 버퍼에 따른 실제 지연은 존재합니다. 서로 다른 방송의 같은 장면을 자동 정렬하는 기능은 아닙니다.
- 목록에는 **현재 추정 지연**, **저장된 딜레이**, **복원 대기 / 적용 완료 / 적용 불가**를 구분해 표시합니다. 현재 값은 싱크 버튼을 누르지 않아도 재생 정보가 준비되면 자동으로 표시되며, 아직 측정할 수 없으면 0초 대신 **현재 측정 대기**로 표시합니다. 처음의 저장값 0초는 재생 가능한 라이브 위치를 사용한다는 의미이며 현재 지연이 0초라는 뜻은 아닙니다. 측정값이 바뀌어도 저장값을 자동으로 덮어쓰지 않습니다. 광고 중이나 탐색 범위가 부족할 때는 저장 값을 줄이지 않고 기다립니다. 시간 정보가 오래 갱신되지 않으면 측정 대기로 표시합니다. `이전 기준`으로 표시된 저장 값은 종전 방식으로 복원하고, 방송을 다시 조절하면 보정된 기준으로 저장합니다. 보조 방송에서 저장된 딜레이를 읽지 못하거나 재생 오류가 나면 해당 영상의 **재생 재시도** 버튼으로 저장값을 다시 읽고 그 방송만 재생을 다시 시작할 수 있습니다. 조절한 딜레이의 저장만 실패한 경우에는 **다시 저장** 버튼을 사용합니다.
- 방송 구성·크기·박스 안 영상 위치·볼륨·자유 배치 사용 여부와 창 위치·겹침 순서는 현재 탭의 세션 저장소에 보관합니다. 채널별 딜레이와 보조 화질은 확장 로컬 저장소에 계속 보관합니다. 멀티뷰를 끄면 보조 재생과 관련 리소스를 정리합니다.

## 시청 기록 페이지

설정 화면의 **시청 기록 보기** 버튼을 누르면 별도 탭에서 시청 기록 페이지(`history.html`)가 열립니다.

옵션창과 같은 글꼴·카드·입력창 스타일을 사용하며, 화면이 좁아지면 달력과 목록을 세로로 배치합니다. 검색·정렬은 목록 위에서, 모든 달의 기록을 지우는 **전체 삭제**는 목록 아래에서 사용할 수 있습니다.

- **요약:** 총 시청 시간, 시청한 라이브 수, 선택한 연월의 시청 시간을 한눈에 보여 줍니다.
- **저장 위치 안내:** 옵션창의 시청 기록 탭과 시청 기록 페이지에서 `시청 기록 저장 위치`를 펼치면 Chrome 프로필 경로와 확장 ID로 실제 저장 폴더를 찾는 방법을 확인할 수 있습니다.
- **삭제 주의:** 시청 기록은 이 브라우저에만 저장되며 자동 백업되지 않습니다. 확장 프로그램을 삭제하거나 브라우저 프로필·확장 데이터를 지우면 기록도 함께 삭제됩니다. 별도 백업이 없으면 재설치해도 복구할 수 없습니다. 옵션창의 시청 기록 탭에는 본문을 표시하고, 시청 기록 페이지 상단에서는 **시청 기록 삭제 주의** 제목을 눌러 접거나 펼칠 수 있습니다. 페이지에서는 처음에 접힌 상태로 표시합니다.
- **동시 시청 집계:** 여러 방송을 동시에 본 시간대는 총합·월 합계·달력에서 한 번만 계산합니다. 방송별 시청 시간은 그대로 표시하며, 정확한 시간대가 남아 있지 않은 과거 기록은 기존 누적 시간을 보존합니다.
- **월별 달력:** `‹` / `›` 버튼으로 달을 이동하고, `↻` 버튼으로 달력을 새로고침합니다. 날짜를 클릭하면 그날 본 라이브만 골라서 보여 줍니다. **이 달 전체 보기**로 날짜 필터를 해제할 수 있으며, 검색어·정렬·항목 선택은 유지됩니다.
- **라이브 내역:**
    - **검색:** 제목 또는 채널명으로 기록을 검색합니다.
    - **정렬:** `시청시간 순` / `실제시간 순` 기준과 `내림차순` / `오름차순` 방향을 고를 수 있습니다.
    - **새로고침:** 최신 기록을 다시 불러옵니다.
    - **선택 삭제:** `현재 목록 선택` 체크박스로 보이는 항목을 한꺼번에 고른 뒤 **선택 삭제**로 지웁니다. 검색이나 월 이동으로 숨겨진 선택이 있으면 개수를 별도로 표시하고 삭제 확인문에도 안내합니다.
    - **선택 해제:** 보이는 항목과 목록 밖의 선택을 모두 해제합니다. 검색어·선택한 달·기록은 유지합니다.
    - **키보드 조작:** 행 선택·세부 펼치기·날짜 선택이나 기록 갱신 후에도 같은 항목의 포커스를 유지합니다.
    - **전체 삭제:** 저장된 모든 시청 기록을 삭제합니다.
- **바로가기:** 기록의 라이브 항목에서 다시보기를 찾는 동안에는 안내 페이지(`replay-pending.html`)가 잠시 표시되며, 다시보기를 찾으면 해당 탭에서 바로 이동합니다.

## 설정 항목 전체 표

설정 팝업에서 조절할 수 있는 모든 항목입니다. 항목이 많은 탭은 관련 기능끼리 얇은 접이식 묶음으로 나뉩니다. 직접 접거나 펼친 상태는 저장 버튼을 누르지 않아도 이 기기에 자동으로 기억되어 옵션창을 다시 열 때 복원됩니다. 설정 검색으로 자동으로 열린 묶음은 검색을 마치면 원래 상태로 돌아가며, 검색 중 직접 접거나 펼친 선택은 유지됩니다. 굵게 표시된 항목은 해당 기능 전체를 켜고 끄는 **기능 토글**입니다.

## 권한 및 개인정보

이 확장 프로그램이 사용하는 권한은 최소한으로 유지됩니다.

- **`storage`** — 설정값과 고정 채널 목록은 Chrome 동기화 저장소에, 컴프레서의 탭별 켜짐·꺼짐과 출력 볼륨·라이브 시청 기록·팔로잉 라이브 제목 이력·댓글 API 요청용 임의 식별자는 이 기기의 로컬 확장 저장소에 저장합니다.
- **`scripting`** — 동영상 광고 차단을 켜면 패키지 내부 광고 처리 스크립트를 치지직 문서 시작 시점에 실행하도록 등록하고, 끄면 등록을 해제합니다. 대상은 `https://chzzk.naver.com/*`입니다.
- **호스트 권한** — 방송 정보, 다시보기·댓글, 카테고리 메타데이터, 방송 시간 통계와 통나무 claim을 조회·수령하기 위해 다음 도메인에 요청합니다.
    - `https://chzzk.naver.com/*`
    - `https://api.chzzk.naver.com/*`
    - `https://apis.naver.com/*`
- **선택 호스트 권한** — `https://*.pstatic.net/*`: 라이브 미리보기 영상을 불러오는 네이버 CDN입니다. 설치할 때가 아니라 설정에서 **방송 목록 호버 미리보기** 또는 **라이브 멀티뷰**를 켜는 순간에 허용 여부를 묻고, 한 번 허용하면 다시 묻지 않습니다.

설정값과 고정 채널 목록은 브라우저 프로필 설정에 따라 같은 계정의 다른 Chrome에 동기화될 수 있습니다. 이 데이터는 개발자 서버로 전송되지 않으며, 시청 기록은 시청 기록 페이지의 **전체 삭제**, 브라우저의 확장 프로그램 데이터 삭제 또는 확장 제거를 통해 지울 수 있습니다. 댓글 요청용 식별자는 치지직 댓글을 불러올 때 네이버 댓글 API에만 전달됩니다.

채팅 도구가 모은 채팅 메시지·사용자 목록·미확인 상태는 현재 페이지 메모리에서만 유지되며 저장소에 저장하지 않습니다. 새로고침하거나 다른 방송으로 이동하면 초기화됩니다. 통나무 보상 자동 받기는 치지직 로그인 세션으로 `log-power` API를 호출하며, 결과를 개발자 서버로 전송하거나 별도 저장하지 않습니다.

자세한 내용은 [PRIVACY.md](PRIVACY.md)를 참고해 주세요.

## 문제 해결

### List-KR 필터 사용 시 플레이어 단축키가 동작하지 않을 때

List-KR 필터를 사용하는 경우 Chrome, Whale 등 브라우저와 관계없이 스페이스(재생/일시정지), `m`(음소거), `t`(넓은 화면), `f`(전체 화면) 등 치지직 기본 단축키가 간헐적으로 동작하지 않을 수 있습니다.

문제가 반복되면 광고 차단/필터 설정에서 치지직을 예외 처리한 뒤, 치지직 탭을 새로고침해 주세요.

```
chzzk.naver.com
```

## 개발

번들러나 빌드 단계 없이 동작하는 순수 Manifest V3 확장 프로그램입니다. 저장소에는 개발 편의를 위한 도구만 포함되어 있습니다.

```bash
npm install          # 개발 의존성 설치

npm run lint         # ESLint 검사
npm run format       # Prettier 자동 정리
npm run format:check # Prettier 검사만 수행
npm test             # node:test + jsdom 회귀 테스트
```

- 작업 지침(아키텍처, 하드 제약, 검증 절차, 릴리스 규칙)은 [AGENTS.md](AGENTS.md)에 정리되어 있습니다.
- 주요 런타임 JS 파일 최상단에는 역할·의존·구조를 설명하는 헤더 주석이 있으므로, 파일을 통독하기 전에 헤더부터 읽으면 됩니다.
- 모든 설정 옵션은 `shared/settings.js`의 `OPTION_SCHEMA`에서 단일하게 정의되며, 설정 화면(`options.html`)의 항목과 기본값·정규화 규칙이 여기서 파생됩니다.
