# VOD 댓글 모듈

## 책임

`model.js`는 댓글·답글·시각·첨부·타임코드의 순수 정규화와 한도를 소유해요. `repository.js`는 VOD·정렬별 상태와 요청을, `nativeAdapter.js`는 현재 원본 댓글의 외형 측정·동작 위임을, `view.js`는 확장 소유 탭·목록·접기 DOM을 소유해요. 상위 `vodCommentTabs.js`가 옵션·경로·mount를 조정하고 조회 함수를 주입해요.

이 모듈은 네이티브 댓글 트리를 옮기거나 비우지 않아요. 원본 댓글 작성·수정·신고 서버 API를 새로 흉내 내지 않고, 확인된 현재 댓글의 조작만 원본 컨트롤로 위임해요. 시청 기록 저장과 라이브 채팅 수집도 범위 밖이에요.

## 상태와 경계

- 정렬별 캐시를 분리하고 prefetch와 사용자의 첫 열기가 진행 중인 같은 페이지를 공유하게 해요. 숨은 prefetch 실패는 조용히 남기되 foreground에서 재시도할 수 있어야 해요.
- 잘못된 응답을 빈 댓글로 바꾸지 않아요. 초기 실패·추가 페이지 실패·빈 목록·댓글 비활성·상한 도달은 다른 상태예요.
- `page.next`와 관측한 offset 폴백을 보존하고 중복 load-more를 합쳐요. BEST·일반 목록의 같은 댓글과 답글을 중복 삽입하지 않아요.
- VOD·정렬·세대 변경과 reset 뒤 늦은 응답은 새 상태에 쓰지 않아요. 루트 remount와 데이터 reset을 동일하게 취급해 매번 재조회하지 않아요.
- 원본 위임은 댓글 ID와 현재 DOM·버튼 사용 가능 여부를 다시 확인해요. 같은 위치의 다른 댓글·재사용된 노드로 전달하지 않아요.
- 채팅이 없을 때 댓글 전용 패널을 쓸 수 있지만 잠시 숨은 정상 채팅을 없다고 판정하지 않아요. 네이티브 렌더로 빠진 확장 요소만 재부착해요.
- 긴 본문·답글 한도·이미지 URL·타임코드는 확인한 입력 범위에서 표시해요. DOM 삽입을 위해 원격 문자열을 실행하지 않아요. 키보드 탭의 roving tabindex와 focus 복원을 유지해요.

## 검증

`tests/vod-comment-model.test.js`에서 무변이 정규화·중복·날짜·잘못된 페이지·첨부를, `tests/vod-comment-repository.test.js`에서 공유 요청·정렬·페이지·상한·취소를 확인해요. `tests/vod-comment-tabs.test.js`에서 채팅 유무·지연 mount·재마운트·원본 버튼·타임코드 위임·키보드·비활성화를 검증해요.
