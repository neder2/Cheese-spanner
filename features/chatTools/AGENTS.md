# 채팅 파싱·수집·패널

## 소유권

`parser.js`는 현재 DOM에서 작성자·본문·역할·원문 후보를 읽는 무상태 파서예요. `messageStore.js`는 행 binding, 메시지 정체성, 블라인드 원문 캐시, 수집·읽음·재사용 안정화를 소유해요. `panel.js`는 DOM·필터·선택·스크롤·노출 판정을 소유해요. 상위 `chatTools.js`가 옵션·채팅 루트 수명주기를 조립해요.

파서는 영구 행 ID나 수집 marker를 만들지 않아요. 패널은 store의 binding을 직접 고치지 않고 읽음·원본 이동 명령을 전달해요. 영구 본인 채팅·후원 저장, 타임스탬프의 MAIN React 조회, VOD 댓글은 이 모듈의 책임이 아니에요.

## 유지할 조건

- DOM 노드·닉네임·동일 본문만으로 새 메시지를 확정하지 않아요. ID·작성자·재사용 신호·mutation revision을 함께 사용해요.
- 혼합된 재사용 후보가 오래 남았더라도 같은 세대의 최종 상태가 일반 시청자면 잘못 수집한 후보를 철회할 수 있어야 해요. 대기시간 증가로 이를 대체하지 않아요.
- 같은 작성자의 실제 반복 메시지는 유지하고, 같은 메시지 재마운트는 중복 수집하지 않아요. 원본 이동은 실행 시 현재 binding을 확인해요.
- 원문 캐시는 메시지와 작성자가 일치하는 경우에만 사용해요. 새 ID·다른 작성자·이전 루트의 원문을 섞지 않아요. 캐시 상한과 reset을 유지해요.
- onChange 스냅샷은 DOM 참조 없는 수집 결과예요. 패널이 수정해 store 상태를 바꾸는 공유 객체를 만들지 않아요.
- 읽음은 현재 필터에서 실제 보이는 항목에만 적용해요. 닫힌 패널·숨은 탭·화면 밖은 미확인이에요. capacity 정리 시 사라진 메시지의 알림도 함께 정리해요.
- 역할은 배지·확인된 역할 구조에서 판단해요. 본문·프로필 팝업·sr-only 설명의 역할 단어를 닉네임·본문·수집 근거에 섞지 않아요.
- 한 mutation 배치에서 변경 행을 모으고 최종 목록을 한 번 표시해요. 새 행마다 전체 목록을 다시 파싱하거나 확장 marker가 observer 루프를 만들지 않아요.

## 회귀

`tests/chat-tools-modules.test.js`는 parser 무상태, 스냅샷 소유권, reset·재사용·교체 수명을 확인해요. `tests/chat-tools.test.js`는 혼합 재사용 철회, 원문 캐시, 반복 메시지, 읽음·필터·복사·원본 이동, 루트 재마운트·증분 처리·옵션 OFF를 보호해요. fixture를 닫기 전에 observer와 예약 콜백을 정리해요.
