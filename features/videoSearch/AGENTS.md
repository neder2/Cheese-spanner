# 채널 다시보기 검색 데이터

## 책임

`model.js`는 영상·댓글 정규화, 제목·댓글 검색 일치, 실제 제공된 시청 진행률 계산을 소유해요. `repository.js`는 채널 인덱스·댓글 조회·캐시·요청 세대·스케줄을 소유해요. 상위 `videoSearch.js`가 옵션·검색 입력·원본 카드·결과 DOM·focus와 위치를 관리해요.

repository에 DOM이나 네이티브 스타일을 넣지 않아요. model은 현재 검색 UI의 상태·네트워크·저장소를 소유하지 않아요. 댓글 쓰기·반응 API, 시청 기록 영구 저장은 이 모듈의 책임이 아니에요.

## 유지할 조건

- 페이지 상한 안의 검색과 전체 조회 완료를 구분해요. 상한에서 멈춘 인덱스는 유효기간 동안 캐시하되 `limitReached`로 표시하고, 상태 문구는 일부 조회 실패·상한·댓글 조회 실패를 완료 결과와 다르게 보여 줘요. 실패한 인덱스 일부를 완성 캐시로 저장하지 않고 다음 검색에서 회복할 수 있어야 해요.
- `fetchJson`의 내부 타임아웃은 호출자 취소와 같은 `AbortError`라서, 외부 signal이 중단된 경우만 조용한 취소로 보고 나머지는 조회 실패로 기록해요. 실패한 댓글 조회는 같은 세대에서 반복하지 않고 다음 검색 세대에서 다시 시도해요.
- 공백만 있는 검색어는 검색이 아니에요. 원본 목록·페이지 버튼을 유지해요.
- 조회 페이지·댓글 상한이 바뀌면 다시보기 탭 밖이나 기능 OFF 중이어도 기존 인덱스·댓글 캐시를 무효화해요. 댓글 검색이 꺼지면 이미 받은 댓글도 일치 판정에 쓰지 않아요.
- 채널별 캐시의 상한·유효기간과 repository 인스턴스 간 독립성을 유지해요. 입력·채널·옵션 변경 뒤 늦은 응답이 새 인덱스나 진행 상태를 덮지 않게 해요.
- 댓글 조회는 설정된 영상 수·페이지·대기·동시성 범위를 지켜요. 정리 뒤 늦은 댓글 응답이 비운 필드를 다시 채우지 않아야 해요.
- 실행 중에 대기 타이머가 끝나 미뤄 둔 댓글 조회 시작은 그 세대에만 속해요. 새 검색어를 예약하면 이전 세대의 미룬 시작을 버리고, 새 세대는 자기 대기 타이머가 끝난 뒤에만 시작해요.
- 여러 줄 댓글의 검색 의미를 보존해요. 일치 판정 단위는 댓글 하나이고, 서로 다른 댓글의 경계를 넘는 검색어는 일치로 보지 않아요(`buildCommentNorm`). 댓글 API의 알려진 필드를 읽고, 임의로 모든 중첩 문자열을 댓글로 수집하는 폴백을 추가하지 않아요.
- 진행률은 관측된 영상 길이와 재생 진행 값으로 계산해요. 숫자 하나뿐인 `watchTimeline`은 지금은 초 위치로 가정해서 계산하고, 비율·백분율로 해석하지 않으며 영상 길이가 없으면 진행률을 만들지 않아요. 이 초 단위는 상세 API(`/service/v3/videos/{videoNo}`)의 복원 위치 의미를 근거로 한 가정이에요. 채널 목록 API가 로그인 상태에서 `watchTimeline`을 어떤 타입·단위로 주는지는 실측하지 않았어요(비로그인 목록 표본은 모두 null이었어요). 실측 전에는 이 단위를 확인된 계약으로 쓰지 않아요. 결과 카드는 썸네일·길이·날짜가 없으면 템플릿 영상의 값을 비워요. 불명확한 숫자 필드·일반 offset을 다른 목적의 값과 혼동해 가짜 진행률로 만들지 않아요.
- 로딩·완료·오류 callback은 현재 요청의 상태만 알리고 같은 작업을 화면과 repository 양쪽에서 예약하지 않아요.

## 검증

`tests/refactoring-data-modules.test.js`에서 여러 줄 검색·실제 진행률·독립 캐시·취소·댓글 초기화를 확인해요. `tests/navigation-data.test.js`는 인덱스 유효기간과 네이티브 색 동기화, `tests/extension-pages.test.js`는 댓글 deviceId·가짜 폴백 방지·조회 실패 후 복구를 보호해요. UI 수명·중복 예약은 `tests/dom-scheduling.test.js`도 확인해요. `tests/video-search-regressions.test.js`는 부분 조회·상한·댓글 오류 표시, 타임아웃 분류, 댓글 세대 대기, 댓글 경계, 공백 검색어, 템플릿 값 잔존, 탭 밖·OFF 중 상한 변경을 확인해요.

## 원본 페이지 버튼

검색 결과를 표시할 때 현재 영상 grid의 원본 페이지 버튼만 숨겨요. 검색 결과의 더 보기·다른 목록의 숫자 버튼은 유지해요. 숫자만 있는 원본 ordered list도 지원하되 해시 클래스 고정이나 페이지 전체 숫자 버튼 탐색으로 확대하지 않아요. 숨긴 노드는 검색 해제·DOM/grid 교체·SPA 종료 때 분리된 노드까지 복원해요. 인덱스·카드 템플릿 준비 전에는 원본 목록을 유지해요.
