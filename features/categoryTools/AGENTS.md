# 방송 목록 데이터·탐색

## 책임

`filterModel.js`는 단위·프리셋·포함 범위, 전체·이상·이하·범위 모드와 실제 조건, 조건 칩 문구, 검색 단어 해석·칸 단위 일치, 탭 기록 검증과 정확한 카테고리 제외 판정을 소유해요. UI 상태·설정을 자체로 저장하지 않고 sessionStorage에도 접근하지 않아요. `repository.js`는 목록 커서·메타데이터·팔로워·카테고리 이름 요청과 bounded 캐시를 소유해요. `searchController.js`는 추가 탐색의 실행·대기·취소를 조정해요. DOM 카드와 toolbar·필터 메뉴·적용 조건 줄·제외 선택 UI, 탭 sessionStorage 읽기·쓰기는 상위 `categoryTools.js`가 소유해요. 지속 선택의 검증·실제 저장은 공용 categoryExclusions와 서비스 워커의 전용 큐가 맡아요.

여기에 DOM 조작·네이티브 카드 복제·옵션 폼을 넣지 않아요. 상위 화면에서도 별도 페이지 조회·캐시·반복 타이머를 만들어 같은 일을 중복 소유하지 않아요.

## 유지할 조건

- 전체 라이브·카테고리 라이브·영상·클립의 endpoint, 항목 ID와 커서 형태를 구분해요. 0인 커서값을 없는 값으로 버리지 않아요.
- 같은 진행 페이지는 요청을 공유해요. 동일한 경로로 reset했더라도 이전 세대 응답이 새 상태를 덮지 못하게 해요.
- 실패·타임아웃·상한 도달·완료 상태를 구분해요. 메타데이터 재시도는 기존 bounded backoff와 취소를 지키며 새 무제한 반복을 추가하지 않아요.
- 팔로워 0명과 미조회·조회 실패는 다르게 캐시해요. 상한·실패 캐시 만료를 유지해요. 채널 수는 경로 독립 자료여서 기존 bounded 캐시를 이동마다 무조건 지우는 것도 계약 변경이에요.
- 조회 batch·동시성·간격은 설정을 따르고, 화면 바깥 결과를 위해 무한 페이지 탐색하지 않아요. 로딩 중 새 요청은 동일 탐색을 다시 시작하지 않아요.
- 범위는 양끝 포함이며 입력 순서와 무관해요. 모드만 고르고 값이 없으면 조건이 아니에요(배지 수·칩·결과 수에 넣지 않아요). 모델의 누락 숫자 처리와 화면의 ‘확인 중/조회 실패’ 표현은 구분해요.
- 검색은 띄어쓰기 단어 AND와 `-단어` 제외예요. 단어마다 메타데이터 필드와 카드 텍스트 노드 조각 중 한 칸 안에서 찾고 칸을 이어 붙인 문자열로 비교하지 않아요. 적용 키·시청자 표시 보존 키는 정규화한 단어 목록을 써서 띄어쓰기만 다른 검색이 새 탐색을 만들지 않게 해요.
- 적용 조건 줄(`#cheese-spanner-category-filter-chips`)은 툴바와 같은 host 안에 두고 CSS order로 맨 아래 줄을 차지해요. 제외 줄이 host의 마지막 자리를 지키므로 그 앞에 끼워 넣고, 같은 내용이면 다시 그리지 않아요. 확장 소유 노드로 관찰에서 빼되 사이트가 지우면 다시 붙여요. 결과 수(`.bcgt-status`, aria-live)는 이 줄에만 있고 검색어·숫자 조건이 없으면 줄을 숨겨요. 검색어 칩은 사용자 입력이라 글자로만 넣어요.
- 탭 기록은 사이트 sessionStorage `betterChzzkListFilterSession`(version 1, 목록 주소 키별, 최대 20개, 검색어 100자, 인원·횟수 1천만·진행 시간 168시간 상한)이에요. 읽을 때마다 모델로 검증해 틀린 항목·종류만 버리고, 사용자 조작(검색 적용, 칩 해제, 모두 해제, 메뉴 조작, 필터 초기화)에서만 그 주소 항목을 고쳐 써요. 경로 이동·`removeTools()`·기능 OFF의 자동 초기화는 기록을 쓰지 않고 다음 장착에서 다시 읽어요. 저장소 예외는 메모리 조건만으로 계속 동작해요.
- 전체 라이브 집계는 liveId로 중복을 제거하고 시청자 10명 이상이라는 현재 집계 범위를 표시해요. 사이트 전체의 완전한 총계로 바꾸지 않아요.
- `globalLiveCountEnabled`는 검색·필터와 독립이에요. 집계만 켜면 검색 UI·배지·카드 변경·태그 검색 숨김을 실행하지 않아요. 어느 한 기능을 끌 때 다른 소비자가 사용하는 페이지 요청은 보존해요.
- 전체 방송의 공유 페이지는 제한된 캐시를 사용하고, 집계로 읽은 연속 페이지도 검색 메타데이터에 한 번만 반영해요. 집계 캐시가 만료된 뒤 오래된 자료에 새 시각만 붙이지 않아요. 완료 집계의 시각과 캐시 기준은 사용한 페이지 중 가장 오래된 자료 시각이에요. 직접 제거된 toolbar는 복구하되 자체 삽입·옵션 OFF가 다시 예약을 만들지 않도록 확인해요.

- 카드는 방송 id마다 한 entry로 추적해요. 격자 안의 카드 링크는 카드(격자의 자식)마다 하나씩 모으므로 같은 열·다른 행의 같은 방송 카드도 빠지지 않아요(링크 주소·열 기준 중복 제거는 문서 전체에서 격자를 찾을 때만 써요). 추가 카드 뒤에 같은 id의 원본 카드가 붙으면 추가 카드를 지우고 원본을 판정해요. 원본 카드끼리 겹치면 뒤 카드는 entry의 duplicates로 남고, 숨김을 쓰기 직전에 카드마다 연결·카드 id·현재 링크 id를 다시 확인해요. 다른 방송으로 재사용된 카드는 entry에서 빼고 옛 판정을 쓰지 않으며, 남은 카드는 후보 수집부터 대표 행의 메타데이터와 그 카드의 현재 글자·카테고리·태그로 따로 판정해요(현재 카드 우선). 어느 카드든 통과하면 그 방송을 한 번만 후보·결과 수·빈 결과 판단·시청자 표시 이력·팔로워 조회 대상에 넣어요. 행 순회는 24행마다 양보하므로, 결과 수·표시 이력·팔로워 조회 후보를 확정하기 직전에 모아 둔 카드 판정 행을 다시 걸러요. 마지막 양보 이전에 판정한 행은 연결·카드 id·현재 링크 id를, 그 뒤 행은 연결만 확인해요(같은 동기 구간이라 카드마다 링크를 다시 읽지 않아요). 남은 카드가 없는 방송은 그 적용의 결과에서 빠지고, 양보 동안 다른 방송으로 재사용된 대표 카드에는 옛 방송의 숨김을 쓰지 않고 숨김을 풀어 다음 적용이 새 정체성으로 판정해요. 결과 수·스냅숏·주입 판단은 entry 기준이라 겹친 카드가 늘리지 않아요. 메타데이터 병합은 화면이 붙인 검색 글자·칸 캐시를 버려 새 제목·태그로 다시 판정해요.
- 적용은 무관한 DOM 변화마다 다시 돌므로 카드 수에 비례하는 문서 탐색을 늘리지 않아요. 정렬 버튼·라이브/동영상 탭 줄은 찾은 요소를 적용 사이에 재사용하고, 떨어지거나 문구가 바뀌었을 때·정렬 클릭·도구 해제 때만 다시 찾아요. 확장이 표시한 카드 안의 링크는 문구가 같아도 정렬·탭 후보가 아니에요. 정렬 버튼의 위치 기준(뷰포트 위 220px 미만)은 확장이 그 위에 끼운 적용 조건 줄·제외 줄의 높이를 빼고 비교해요. 검색을 적용해 조건 줄이 보여도 같은 버튼을 읽어야 최신·추천을 인기로 오판하지 않아요. 버튼에서 선택을 읽으면 그 값을 같은 목록 주소의 확인한 정렬로 기억하고, 버튼을 잠시 못 읽을 때만 그 값을 써요. 정렬 클릭은 누른 정렬을, 경로 이동·도구 해제는 빈 값을 기억으로 둬요. 클릭 처리기는 capture 단계라 누른 순간 버튼에는 이전 선택이 보여요. 누른 곳이 찾은 정렬 버튼이면 그 이전 선택을 함께 남겨, 사이트가 새 선택을 그리기 전에 읽은 이전 선택은 그 판정에만 쓰고 누른 정렬의 기억을 덮지 않아요. 보이는 선택이 이전 선택과 다르면 그 값으로 기억을 바꿔요. 한 번도 읽지 못한 경우의 인기 기본값은 그대로예요. 카드 링크의 카테고리·태그 해석은 href 문자열별 캐시(최대 2,000개)를 쓰고, 카드 링크 목록은 같은 동기 구간에서만 재사용해 await로 양보한 뒤의 최종 재판정은 현재 DOM을 새로 읽어요.
- 배지 처리는 모든 카드의 이미지 크기 읽기를 마친 뒤 쓰기를 해요. 진행 시간 배지는 CSS상 썸네일 호버·초점일 때만 보이므로 처음 값을 쓴 뒤에는 호버·초점이 시작될 때와 1초 타이머에서 보이는 배지만 고쳐요. 숨은 배지를 매초 고치면 카드 수만큼 DOM 변경이 생겨요.
- 툴바·태그 검색 표식·위치 스타일은 바뀐 값만 써요. 이미 제자리인 툴바를 다시 끼우면 툴바 제거 기록으로 보여 적용이 다시 예약돼요. 태그 검색 표식은 붙인 요소를 기억해 고치고, 도구를 뗄 때만 문서 전체에서 남은 표식을 지워요.
- 전체 방송의 현재 목록 검색은 입력 초안과 적용 검색어를 분리해요. 별도 적용 버튼 없이 Enter에서만 갱신하고 IME 확정 Enter·반복 키·동일 값 재제출은 새 작업을 만들지 않아요. 지우기 클릭은 빈 검색어를 한 번 제출하고 Escape는 적용값으로 되돌려요. 카테고리 경로의 기존 입력 검색과 숫자 필터·카테고리 이름 검색은 유지해요. 카테고리 경로 입력의 지연 적용은 목록 상태 키 변경(첫 카드 렌더·정렬)에서 취소하지 않고 경로 이동·도구 해제에서만 취소해요. 팔로워 조회 예약·진행이 없는데 조회할 채널도 없으면 팔로워 로딩 표시를 꺼요. 툴바를 정렬 줄에서 대체 위치로 구출했다면 같은 정렬 줄이 남아 있는 동안 대체 위치를 유지해요.

## 카테고리 제외

- 적용·조회·UI는 `categoryToolsEnabled`와 `categoryToolsExclusionsEnabled`가 모두 켜진 `global-lives`에 한정해요. 제외 옵션 OFF는 줄·패널·구독·카드 판정만 멈추고 저장 목록은 지우지 않아요. 인기·최신·추천의 현재 원본 카드에 적용하되 최신·추천에 인기 API 결과를 주입하지 않고 스크롤로도 인기 API 페이지를 받지 않아요. 집계만 켠 상태나 다른 경로에서는 제외 목록·이름 검색을 요청하지 않아요.
- 최초 옵션 `getOptions` 완료 전에는 기본값이나 일반 옵션 변경 콜백만으로 제외 조회·구독·UI를 시작하지 않아요. DOM 준비와 옵션 준비를 구분하고 공용 진행 읽기를 공유해 중복 sync 조회를 만들지 않아요.
- 태그 제외는 예약 유형 `CHEESE_SPANNER_TAG` 항목이며 정규화한 태그 전체의 일치로만 판정해요. 원본 카드는 현재 `tags` 링크와 같은 채널의 유효 메타데이터 태그를, 추가 카드·후보는 결합이 확인된 메타데이터 태그만 써요. 추가는 패널 입력의 신뢰한 Enter에서만 하고 한글 조합 확정·반복 키·합성 키는 저장하지 않아요. 카테고리 검색 결과의 예약 유형은 버려요.
- 워커는 발신 문서의 치지직 출처와 Chrome이 제공한 현재 탭의 `/lives` 경로를 함께 확인해요. SPA 이전 문서 URL과 현재 탭 URL을 구분하며 메시지 본문의 URL은 신뢰하지 않아요.
- 카테고리는 유형·ID의 정확한 쌍으로 판정해요. 이름·태그·제목의 부분 일치, ID 대소문자 변환과 확인되지 않은 소문자 유형 호환 분기를 추가하지 않아요. 원본 카드는 현재 카테고리 링크를 우선하고 링크 없음·충돌을 오래된 API 값으로 메우지 않아요. 추가 카드는 채널·liveId binding이 일치하는 메타데이터로 판정하고 템플릿의 옛 링크·이름을 남기지 않아요.
- 메타데이터 후보와 추가 카드 모두 비어 있지 않은 id·channelId 일치와 양의 안전 정수 liveId를 요구해요. 결측·0·음수·소수·안전 범위 초과 liveId는 제외 판정에서 통과시켜요. 원본 카드의 현재 유효 링크 판정은 API liveId 결측과 독립이에요.
- 시청자 필터의 기존 표시 보존 행에도 제외를 AND 조건으로 적용해요. 원본 href 변경·행 재사용·순회 중 정체성 변경을 마지막 표시 전에 다시 확인하며 확장 소유 변경은 반복 예약을 만들지 않아요. 제외한 후보의 불필요한 팔로워 조회도 막아요.
- 이름 검색은 keyword·size 50만 보내고 응답의 세 카테고리 필드를 검증해요. 검색어는 최대 100자, 결과는 최대 50개, 메모리 캐시는 최대 20개 검색어·5분이에요. 동일 입력의 진행 요청을 공유하되 취소·실패 결과가 캐시를 채우지 않아요. 검색 후보 상세의 정확한 유형·ID와 concurrentUserCount로 내림차순 정렬하고 확인된 0명 후보만 제외해요. 수치 미확인은 뒤에 남기며 기존 저장 선택은 보존해요. 상세 조회는 동시 4개·각 3초·전체 5초, 정상 수치 캐시는 200개·5분으로 제한해요. 상위 UI의 300ms 대기·한글 조합·닫기·SPA·OFF 취소는 선택 목록 삭제와 구분해요.
- 선택은 현재 소유 버튼의 `isTrusted` 클릭과 isolated 처리 함수의 카테고리 자료로만 개별 요청해요. 합성 키·클릭, 복제한 버튼과 바뀐 DOM 속성으로 저장 명령을 만들지 않아요. 콘텐츠 전체 배열 저장은 추가하지 않아요. 저장 성공·검증한 local 변경 이후 반영하고 늦은 revision과 실제 키 삭제 전 응답을 차단해요.
- 마지막 정상 상태는 오류 중 보존하지만 새 구독의 첫 정상 읽기·변경을 새 기준으로 받아 OFF 중 놓친 삭제·재생성도 복원해요. 구독 함수의 현재 소유를 확인하고 손상 변경 알림에서 이전 읽기·변경·대기를 무효화해 늦은 콜백이 오류·재시도를 지우지 못하게 해요. 빈 상태·검색 해제·오류 해제에서는 상태 문구도 실제로 비워요.
- `필터 초기화`는 숫자 조건만 해제하고 숫자가 없으면 비활성화해요. 제외 목록·이름 검색 캐시·집계 설정을 초기화에 묶지 않아요. OFF·이동·닫기는 UI·검색 예약을 정리하며 선택을 지우거나 늦은 변경 응답으로 옛 추가 패널을 다시 만들지 않아요.

## 검증

`tests/category-tools-filter-model.test.js`는 단위·프리셋·모드·조건 문구·검색 단어·탭 기록 검증, `tests/category-tools-list-filters.test.js`는 칩 줄·검색 단어·떠났다 돌아오기·새로고침·주소별 분리·자동 초기화와 모두 해제·손상/차단 저장소·메뉴 모드와 초기화 뒤 초점, `tests/category-tools-repository.test.js`는 커서·공유·중복·캐시·상한·취소·재시도를 보호해요. `tests/category-tools-apply-cost.test.js`는 안정 상태 적용의 문서 전체 링크 탐색 0회, href 재해석 0회, 숨은 진행 시간 배지 무변경, 배지의 읽기·쓰기 순서, 툴바·태그 검색 표식의 재기록 없음을 호출 횟수로 지켜요. `tests/category-tools-regressions.test.js`는 2026-10-29 보고의 정렬별 스크롤 탐색·툴바 구출 왕복·KST 진행 시간·같은 id 카드·입력 지연 적용·팔로워 로딩 해제와, 실측 배치(탭 줄 툴바·조건 줄로 밀린 정렬 줄)의 Enter→스크롤 정렬 판정·인기순 양성 대조·정렬 전환 취소·누른 뒤 사이트가 새 선택을 그리며 정렬 줄을 숨기는 순서와 클릭 미반영 대조, 같은 열 중복 카드 수집, 겹친 카드의 카드별 판정·재사용 정체성, 겹친 카드만 통과할 때의 결과 수·빈 결과·팔로워 조회 후보·시청자 표시 이력, 행 순회 양보에서 빠지거나 재사용된 카드의 결과 수·빈 결과·표시 이력·팔로워 조회 제외를 지켜요. `tests/category-tools-lifecycle.test.js`는 오래된 팔로워 결과가 재사용 카드에 붙지 않는지, 검색과 배지가 서로 지연시키지 않는지, disable·SPA가 예약을 끝내는지 확인해요. 통합 목록 동작은 `tests/extension-pages.test.js`, 중복 예약은 `tests/dom-scheduling.test.js`에서도 확인해요.

제외 변경은 `tests/category-exclusions-store.test.js`, `tests/category-tools-exclusions.test.js`와 filter-model·repository에서 두 탭의 개별 변경·지속 복원·상한·실패 보존·정확한 정체성·신뢰한 버튼·검색 취소를 확인해요. 공용 선행 로드를 바꾸면 lifecycle·extension-pages·refactoring-data-modules의 실제 로드도 맞춰요. 실제 Chrome의 이름 검색 요청·현재 카드 링크·SPA 발신 URL·기본 Enter/Space·두 테마·새로고침과 재시작은 자동 fixture와 별도로 확인해요.

카테고리 제외 줄(`#cheese-spanner-category-exclusions`)은 검색·필터와 독립된 UI예요. 전체 방송 정렬 줄의 오른쪽 끝에 두고, 정렬 줄을 찾지 못하면 검색 바 다음 형제로 둬요. 정렬 줄 탐색은 툴바 장착이나 줄 분리 때만 하고 정렬 버튼 판정·정렬 클릭 판정에서 이 줄을 제외해요. 직접 제거되면 다음 적용에서 다시 붙이고, 해제·추가 요청은 이 id의 현재 줄인지로 확인해요. 추가 팝오버는 이 줄 오른쪽 버튼에서 열고 선택 박스는 이 줄에만 이름만 표시해요. Escape·바깥 신뢰 클릭·숫자 필터 열기·SPA·OFF·문서 종료에서 검색을 취소해요. Escape는 추가 버튼으로 초점을 돌리고 패널 닫기는 저장 선택을 지우지 않아요.
