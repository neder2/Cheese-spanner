# 통나무 자동 수집 회귀 확인

- 확인일: 2026-09-12
- 대상: https://chzzk.naver.com/live/1c231568d0b13de5703b3f6a5e86dc47
- 현재 페이지에서 확인한 배포 스크립트: https://ssl.pstatic.net/static/nng/glive/resource/p/static/js/index-C4sif-4p.js
- 배포 스크립트의 보상 알림 컴포넌트는 `button[type=button]` 안에 제목 `span`, 파워 아이콘, 수령 문구를 렌더링한다. 클래스 맵의 값은 `_button_1v78k_21`, `_text_1v78k_13`, `_icon_power_1v78k_17`이다.
- 1.3.4의 랭킹 오클릭 방지 변경은 아이콘 접두어를 `icon_power_`로만 검사했다. 기존 수동 재현 fixture에는 밑줄 없는 클래스가 있어 기존 테스트가 문제를 감지하지 못했다.
- 현재 접두어 `_icon_power_`와 기존 fixture의 `icon_power_`를 모두 허용한다. 랭킹 클래스, 팝업 속성, 보상 문구 및 자식 구조 검사는 유지한다.
- 현재 아이콘 클래스의 회귀 테스트는 수정 전 클릭 대기 시간 초과로 실패했다. 같은 구조의 랭킹 버튼은 클릭하지 않는지도 함께 검사한다.
- 실제 라이브 탭에서는 대기 중인 시청 보상 알림이 없어 실제 수령 완료는 확인하지 못했다. 배포 코드 확인과 자동 테스트는 실제 계정의 수령 성공을 대신하지 않는다.
- 검증: 기능 테스트 19개 및 `npm.cmd run test:all` 608개 통과, `npm.cmd run lint` 통과.
- 브라우저 도구가 `chrome://extensions/` 접근을 차단하여 확장 다시 로드 및 수정본 주입 확인은 하지 못했다. 수동 확인은 확장 관리 화면에서 다시 로드 → 치지직 탭 새로고침 → 다음 시청 보상 알림의 자동 수령과 랭킹이 열리지 않는지 확인하는 순서다.
