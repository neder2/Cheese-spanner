# 치지직 광고 기능 실측 및 검증

## 현재 공개 범위 — 2026-09-08

사용자 요청으로 광고 자동 건너뛰기를 임시 비공개로 전환했어요. 설정 UI·검색·옵션 스키마·manifest 자동 로드와 사용자 안내에서 제외했으며, `features/adAutoSkip.js` 구현과 기능 테스트는 다시 검증할 수 있도록 보관해요. 과거 `adAutoSkipEnabled: true` 저장값은 삭제하지 않고 현재 옵션 정규화에서 무시하므로 새로 로드한 확장에서 기능을 활성화하지 않아요. 이미 열려 있는 이전 문서에는 확장 재로드와 치지직 탭 새로고침이 필요해요.

현재 제공하는 광고 옵션은 기본 꺼짐인 동영상 광고 차단(실험적)과 배너 광고 숨기기 두 가지예요. 아래 세 옵션 관련 실측·검증 기록은 비공개 전 개발 과정의 결과예요. 스토어 게시용 설명 파일도 두 옵션에 맞췄으며, 실제 스토어 문구는 게시할 때 함께 반영해야 해요.

옵션·검색에서 제외, 과거 켜짐 값 무시, 나머지 옵션 저장과 자동 주입 제외를 검사하는 두 회귀 테스트가 수정 전 실패하고 수정 후 통과했어요. 전체 테스트는 507개 중 506개 통과했으며, 기존 단축키 복구 임시 비활성화에 따른 실패 1개와 린트 경고 1개가 남아 있어요. 린트 오류는 없고 전체 포맷 검사는 통과했어요. 실제 옵션 파일을 제공한 로컬 브라우저의 콘텐츠 너비 392px에서 라이트·다크의 두 광고 옵션 표시와 가로 넘침 없음을 확인했고, 검색 결과 0개와 동영상 옵션에서 Tab을 누르면 배너 옵션으로 이동하는 것도 확인했어요. 실제 확장 재로드·저장소 연동은 브라우저 도구의 확장 관리 접근 제한으로 이번 변경에서 검증하지 못했어요.

## 구현 경계와 수명주기

- 세 광고 옵션은 각각 기본 꺼짐이며 기존 광고 차단 안내 팝업 옵션과 독립적이에요.
- 동영상 처리는 2,048자 이하 문자열의 일반 `JSON.parse` 결과에서 실측한 구조만 바꿔요. 일반 재생 정보, 추가 내부 키, 오류 응답, 다른 타입과 reviver가 있는 파싱은 그대로 통과시켜요. URL로 요청을 가로채는 구현은 아니에요.
- MAIN 처리는 비활성 상태로 시작하고 isolated bridge가 실제 저장 옵션을 읽어 켜짐을 전달한 뒤에만 활성화돼요. 이전 등록이 잠시 남아 있어도 설정을 읽기 전 데이터를 변경하지 않아요. 이 준비보다 빠른 응답은 처리하지 못할 수 있어요.
- background는 `document_start`·MAIN 등록을 저장 옵션과 직렬로 동기화해요. 빠른 연속 변경은 마지막 값을 따르며, 과거 등록의 불필요한 CSS·제외 규칙·관련 프레임 설정도 자신의 등록을 해제한 뒤 정확한 구성으로 다시 등록해 정리해요.
- 설정 저장 화면은 background의 등록 완료 응답을 기다려 준비 완료·실패를 구분해요. 켠 뒤에는 사용자가 새로고침하며 자동 새로고침은 하지 않아요.
- 끄면 열린 문서의 이후 처리가 중단되고 향후 문서의 주입이 해제돼요. 한 문서에서 중단한 처리는 다시 켜도 재개하지 않고 새로고침 필요 상태를 표시해요. 이미 바꾼 플레이어 상태는 즉시 되돌릴 수 없어요.
- 자동 건너뛰기는 실제 광고 상태에서 활성·가시 상태인 정확한 버튼이 하나일 때만 클릭해요. 광고 주기, 버튼 재사용·분리 후 재삽입, 같은 mutation 묶음의 숨김·비활성 전환, 플레이어 교체·SPA 이동·옵션 해제를 처리해요.
- 버튼 판단에 사용하는 관찰 범위는 플레이어 하위 변경과 부모 체인의 가시성 관련 속성이에요. 부모 가시성 관찰에는 `subtree`를 사용하지 않아요. 플레이어 탐색·교체 감지는 기존 `createMutationObserverSync`를 재사용하며, 공용 도우미는 문서의 childList 변경에서 관찰 노드의 연결 여부를 확인해요. 짧은 반복 검색 타이머를 새로 추가하지 않았어요.
- 배너 기능은 확인한 세 슬롯의 CSS를 추가·제거해요. React 노드 삭제, 본방송 시간·배속 변경, 플레이어 전체 숨김을 하지 않아요.
- `changedParses`와 `clickAttempts`는 각각 일치한 데이터의 파싱 변경 횟수와 클릭 시도 횟수예요. 요청 수·광고 수·차단 성공 수를 의미하지 않아요. 상태와 확장 ID는 페이지 DOM에만 노출하며 별도로 저장·전송하지 않아요.
- crackle·List-KR·AdGuard IMA 대체는 설계 참고 자료예요. 서드파티 소스 복사, SDK 대체, 네트워크 규칙·권한 추가와 원격 실행 코드는 포함하지 않았어요. 서드파티 고지 대상이 추가되지 않았어요.

## 설정 화면과 코드 검사

- 설정 화면은 Chrome 권한 API가 없는 로컬 미리보기로 CSS 너비 390px의 라이트·다크 화면을 확인했어요. 가로 넘침 없음, 긴 한글 안내, 세 옵션 기본 꺼짐·독립 토글, 키보드 Space·Tab과 포커스 표시를 확인했어요. 실제 확장 팝업의 저장·등록 승인 흐름은 사용자 조작 및 자동 테스트로 확인했으며 미리보기로 대체 검증했다고 주장하지 않아요.
- 관련 테스트는 광고 판단 변환과 본방송 정보 보존, 원본 파서 예외·reviver·다른 wrapper 보존, 실제 옵션을 기다리는 초기 상태를 검사해요.
- 등록 테스트는 초기 꺼짐, 등록 유지, 연속 변경, 이전 등록 정리와 실패 후 복구를 검사해요. 옵션 페이지는 background 응답을 기다리는 저장 완료와 등록 실패 안내를 검사해요.
- 자동 건너뛰기 테스트는 기본 무개입, 광고 상태·활성 버튼, 중복 방지, 숨긴 옛 버튼·다중 버튼, 재사용·재마운트·라우트 이탈·옵션 해제·부모 가시성 전환을 검사해요.

## Pro 교차검토

사용자 요청으로 공식 ChatGPT의 [독립 코드 리뷰 요청](https://chatgpt.com/c/6a9fe7ba-a820-83ee-9902-0e57a1029e94)에서 **6 Pro** 선택을 확인하고 두 차례 검토했어요. 새 광고 코드·관련 테스트·비식별 실측 구조만 전달했으며 HAR 원본·인증정보는 전달하지 않았어요.

1. 초기 활성 상태의 오래된 등록 문제, 남은 등록 필드, 진단 횟수의 의미, 실제 소비 경로 증거의 한계를 지적받았어요. 실제 설정 전에는 비활성으로 기다리도록 수정하고 과거 등록을 완전히 교체하며 횟수를 `changedParses`로 구분했어요.
2. 자동 건너뛰기 전체 코드 검토에서 같은 버튼의 분리·재삽입, 같은 mutation 묶음의 활성 상태 변경, 먼 부모의 숨김 해제 누락을 지적받았어요. 세 회귀 테스트가 수정 전에 모두 실패하는 것을 확인하고 원인 관찰·클릭 기록 로직을 수정했어요. 수정 후 자동 건너뛰기 테스트 10개가 통과했어요.

Pro의 판단만으로 통과 처리하지 않고 저장소 테스트와 실제 브라우저 관측으로 확인했어요.

## 남은 검증 범위

- 실제 중간 광고 배정과 자동 SKIP 성공, 다양한 계정·채널·광고 형식.
- 라이브 타임머신 수동 조작: 시험 방송의 네이티브 진행 막대가 숨김 상태여서 직접 조작하지 못했어요. 기존 관련 자동 테스트는 전체 검사에 포함해요.
- AdGuard 동시 사용, 광고 SDK 재생성·다른 차단기 wrapper의 실제 조합. wrapper 보존은 자동 테스트로 확인했어요.
- 치지직 응답 또는 DOM이 달라지면 미확인 형식은 그대로 통과시키고 새 실측·회귀 테스트 뒤 범위를 추가해야 해요.
