## 확장 페이지 임시 확인 화면

**방법**: 저장소 사본(`mktemp -d`)에 확장 API 흉내 스크립트를 넣었어요. 이 스크립트가 가짜 기록 6개와 메모리 저장소를 제공해요. 사본을 `127.0.0.1`로 띄워 내장 브라우저에서 측정했어요.

**설정 화면** (`options.html`)

- 320·420·800·1280px × 다크·라이트에서 가로 넘침은 0px였고, 화면 밖으로 잘린 조작(input·select·button·summary)도 0개였어요.
- 시안 A 모습을 확인했어요: 알약 분류 칩(선택 반전), 카드 안 평평한 줄과 구분선, 치지직식 토글, 하단 저장 막대.
- 설정 화면 작업에서 키보드 초점 고리가 보이는지 확인했어요. 대상은 검색, 칩(End 이동), 토글, 변경 취소, 옵션 저장이에요.
- 고전형 스크롤바(12px)가 있는 환경의 320px 팝업에서는 12px 가로 넘침이 남을 수 있어요(설정 화면 작업의 iframe 측정). 원인은 공용 `html, body { min-width: 320px }`예요. 이를 바꾸면 팝업 크기 결정 방식이 달라지므로(팝업 크기 결정 방식은 이번 작업에서 바꾸지 않기로 함) 고치지 않았어요. 실제 Chrome 팝업에서는 미확인이에요.

**시청 기록** (`history.html`)

- 1280·375px × 다크·라이트에서 가로 넘침 0px, 잘린 조작 0개였어요.
- 기록 페이지 작업에서는 320px와 빈 기록까지 확인했어요.
- 아이콘 조회가 실패하면(가짜 채널 ID라 응답 없음) 아이콘 자리 없이 글자만 보이고, 오류 안내도 뜨지 않았어요.
- 성공 상태는 기록 페이지 작업이 fetch를 흉내 낸 사본에서 확인했어요.
- 많이 본 채널 막대는 이름 열에서 시작해 시간 끝에서 끝나요(차이 0px).
- 저장소 쓰기는 0회였어요.
- 로그인 정보 없이 보낸 `GET https://api.chzzk.naver.com/service/v1/channels/a6c4ddb09cdb160478996007bff35296`은 2026-10-17에 `code 200`과 `nng-phinf.pstatic.net` 프로필 주소를 돌려줬어요(`curl`, 쿠키 없음).

**새 버전 안내**: 작은 표시 작업에서 확인했어요. 같은 Chromium 계산값으로 치지직 맥락(공통 변수)과 옵션 페이지 맥락(확장 페이지 토큰)의 카드가 다크·라이트 모두 같은 모양이었어요. 높이는 173.69px로 같았어요. 단, 다크 초점 고리 색은 각 맥락의 토큰을 따라 치지직 `#00ffa3`, 옵션 `#00e693`으로 달라요.

## 치지직 안 확장 UI — 정적 캡처 확인

**방법**

- 저장소 테스트 15개 파일의 JSDOM 화면에 기록용 preload를 걸어, 실제 코드가 만든 DOM과 주입 스타일을 캡처했어요.

## 실제 Chrome 점검 목록 (사용자 확인 전 미확인)

확장 관리에서 치즈 스패너를 다시 불러오고 치지직 탭을 새로고침한 뒤 확인해요.

1. 설정 팝업과 옵션 페이지를 다크·라이트·시스템으로 바꿔 봐요. 분류 칩, 묶음 카드, 토글, 저장·변경 취소, 더보기 메뉴, 설정 파일 미리보기가 시안 A대로 보이는지 확인해요. 좁은 팝업에서 가로 스크롤이 생기는지도 봐요(위 12px 건).
2. 시청 기록을 열어 봐요. 채널 프로필 사진이 줄 앞에 보이는지, 사진이 없는 예전 기록은 글자만 보이는지 확인해요. 달력, 많이 본 채널 막대, 내 채팅·후원, 기록 백업·관리를 다크·라이트로 봐요.
3. 라이브 화면을 확인해요.
    - 멀티뷰 설정·안내
    - 채팅 멀티뷰 패널(4px 여백, 마우스를 올렸을 때만 보이는 조작)
    - 스트림 정보
    - 채팅 모아보기
    - 플레이어 툴팁·확대 패널·홀드 배속·패널 크기 조절선
    - 앰비언트 스위치
4. 방송 목록을 확인해요.
    - 검색·필터 메뉴와 배지
    - 썸네일 위 진행 시간 배지
    - 카테고리 제외
5. 채널 화면을 확인해요.
    - 월간 달력(화면 왼쪽 끝에서 잘리는지)
    - 영상·댓글 검색 바와 결과
6. 다시보기 화면을 확인해요.
    - 댓글 탭과 패널
    - 당시 시간 표시
    - 이전 방제 패널
7. 사이드바를 확인해요.
    - 팔로잉 폴더 머리 행
    - ⋯ 메뉴, 채널 선택, 되돌리기 안내
    - 고정 표시
    - 미리보기 카드
    - 헤더 방송 알림 등록 패널

9. SPA 이동, 옵션 끄기/켜기 뒤 중복 UI와 콘솔 오류가 없는지 확인해요.
10. 설정의 새 버전 안내 다시보기와 치지직 안 자동 안내가 같은 모양인지, 20초 게이지·호버 정지가 동작하는지 확인해요.
