## 동작 계약

- 기간·날짜·검색은 세 탭에 공통으로 적용된다. 변경하면 각 탭의 첫 페이지로 돌아가고, 단순 탭 이동은 해당 탭의 페이지를 유지한다. 시청 시간 정렬은 라이브 내역에서 사용한다.
- 달력은 날짜 선택·이 달 전체 보기·Escape·바깥 클릭·바깥으로의 포커스 이동으로 닫힌다. 날짜 확정과 Escape 뒤에는 달력 버튼으로 포커스가 돌아온다. 월 이동은 달력을 열어 둔다.
- 탭은 방향키·Home·End로 이동하며 RTL 방향도 반영한다. 접힌 탭과 조작부는 키보드 탐색에서 제외한다.
- 선택 모드의 전체 선택은 현재 페이지에만 적용한다. 다른 페이지와 필터 밖의 선택은 유지하고 개수를 안내하며, 선택 취소는 전체 선택을 해제한다. 삭제 후 마지막 페이지가 사라지면 남은 마지막 페이지로 이동한다.
- 방송별 내 채팅 펼침은 세부 보기와 독립적이다. 기존 50개씩 추가 표시, 새 기록 반영 중 펼침 상태·포커스·스크롤 유지 동작을 보존한다. 전체 내 채팅·후원 탭은 10개씩 표시한다.
- 기록 관리·저장 위치·삭제 주의·전체 삭제는 페이지 아래에서 펼쳐 확인한다.
