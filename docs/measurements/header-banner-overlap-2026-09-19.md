## 최초로 틀어지는 위치

현재 [치지직 스타일](https://ssl.pstatic.net/static/nng/glive/resource/p/static/css/index-DGkZNTRv.css)과 DOM·Chrome CSS matched rules를 확인했다.

- 치지직이 지정한 헤더 inline 값은 `transform: translateY(51px)`였으나 최종 계산값은 `none`이었다. 헤더와 검색창의 y 좌표가 각각 0px·12px라서 y=0~51px 배너 아래에 가려졌다. 검색창 중앙의 hit test도 input보다 배너 링크·제목을 먼저 반환했다.
- 삽입된 constructed stylesheet에 광고 숨김 규칙들과 함께 `#header`의 transform 초기화, `#sidebar`의 60px 이동·100% 높이, `#layout-body`의 0px 위쪽 여백을 강제하는 important 규칙이 있었다. 해당 stylesheet의 URL과 소유 프로그램은 확인되지 않았으므로 특정 광고 차단 제품의 문제라고 단정하지 않는다.
- 사이드바의 원래 inline 값은 111px 이동과 `calc(100vh - 111px)`, 본문 padding-top은 51px이었다. 충돌 상태에서는 사이드바가 60px부터 시작하고 본문 여백은 0px이 됐다.
- 위 수치는 당시 접힌 배너의 측정값이다. 치지직 CSS에는 펼친 배너 높이도 존재하며, 수치를 런타임에 고정하지 않았다.

## 구현

- `features/headerBannerLayout.js`를 기존 공용 유틸 이후에 등록했다. 상단 배너가 보이고 치지직이 양의 세로 이동 값을 지정한 경우에만 헤더 transform, 사이드바 transform·height, 본문 padding-top을 보존한다.
- 치지직의 원래 inline 속성과 우선순위는 변경하지 않는다. 현재 값을 확장 소유 CSS 변수에 복사하고 해당 노드의 한정된 선택자로 적용한다. 배너를 숨기거나 다른 기능을 끄는 방식으로 문제를 가리지 않는다.
- 배너 숨김·화면 밖 이동·제거·native offset 0에서는 보정 스타일과 변수를 제거한다. 속성이 없어지면 그 속성만 해제한다.
- 공용 observer 연결·라우트 브리지를 사용한다. 레이아웃의 직계 자식, 관련 노드의 속성, 배너 크기만 관찰하고 재마운트·페이지 종료 때 이전 노드·observer·스타일을 정리한다. 폴링 타이머나 높이 상수는 추가하지 않았다.
- README에 동작을 반영했다. 저장 데이터·네트워크 요청·권한은 변경하지 않았다.
