# 플레이어 클립·PIP 버튼 실측

- 날짜: 2026-09-14
- URL: https://chzzk.naver.com/live/feb20a676694b1163fed010da0848303 및 https://chzzk.naver.com/video/15180427
- 조건: 로그인한 데스크톱 Chrome, 브라우저 도구의 실제 DOM 조회.
- 두 화면 모두 `.pzp-pc__bottom-buttons-right` 안에 `button.custom__clip-button`과 `button.pzp-pc__pip-button`이 있음.
- 클립 버튼의 툴팁은 `클립 만들기`, PIP 버튼은 `aria-label="PIP 보기"`, `slot="pip-button"`을 가짐.
- 클립·스트리머 샵·설정 버튼은 `pzp-pc__setting-button`을 공유하므로 이 공통 클래스는 숨김 선택에 사용하지 않음.
- 두 옵션은 각각 전용 CSS를 추가·제거함. 원본 버튼·이벤트와 영상은 변경하지 않고 PIP 종료도 호출하지 않음. SPA 이동·재마운트는 CSS가 자동으로 처리하므로 관찰자·타이머를 추가하지 않음.
- 자동 테스트: 모든 옵션 조합, 저장된 옵션의 최초 적용, 원본 DOM 보존, 다른 컨트롤과 플레이어 밖 동일 클래스 보호, SPA·재마운트·테마 속성 변경, 비활성화 복원, 옵션 기본값·UI·로드 등록.
- 실브라우저 한계: 앞선 상단 버튼 작업에서 브라우저 URL 정책이 확장 관리 페이지를 차단했으므로 재접근·우회를 하지 않음. 새 코드로 확장 다시 로드, 라이트·다크·좁은 팝업 및 실제 숨김은 미검증.
- 수동 확인: 확장 다시 로드 → 치지직 새로고침 → 플레이어 → 라이브 표시에서 각각 켜고 저장 → 해당 버튼만 숨겨지는지 확인 → 끄고 저장해 복원 확인. 라이브·다시보기 이동과 테마 전환 후 반복.
