## 미검증과 최소 수동 확인

브라우저 도구가 `chrome://extensions/` 탭 접근을 거부했다. 우회하지 않았으며 확장 재로드, 실제 확장 ID/isolated context 확인, 새 코드 주입은 수행하지 못했다. 확인한 치지직 탭에는 Better Chzzk DOM 마커가 없었다.

1. 확장 관리에서 Better Chzzk를 다시 로드하고 치지직 탭을 새로고침한다.
2. 설정 팝업과 시청 기록을 열어 저장·새로 열기·라이트/다크를 확인한다.
3. 채널 영상 검색, 목록 필터의 Esc, 방송 달력의 월 이동, 운영자 채팅·미리보기·댓글·멀티뷰를 확인한다.
4. SPA 이동과 옵션 끄기/켜기 후 중복 UI나 콘솔 오류가 없는지 확인한다.

실제 기록이 채워진 시청 기록의 최종 화면, 최종 멀티뷰 패널의 실브라우저 배치, 스크린리더, 명시적인 200% 확대, 선택 권한 승인/거부는 이번 브라우저 확인 범위에 포함하지 않았다. 관련 자동 테스트 결과와 구분한다.

## 후속 UX 수정 — 리뷰의 여섯 항목

- 옵션·기록의 오류 안내는 직접 닫거나 해당 작업이 성공할 때까지 유지한다. 성공 안내만 자동으로 닫힌다. 안내를 닫거나 재시도가 다시 실패하여 닫기 버튼이 교체될 때도 키보드 포커스를 이어 준다.
- 기록 선택·상세 펼침과 달력 날짜 선택 후 같은 기록 ID/날짜의 조작부로 포커스를 복원한다. 비동기 갱신 도중 검색창으로 이동한 경우에는 포커스를 가져오지 않는다.
- 월 요약과 달력 하단은 실제 선택한 연월을 표시한다. 기록이 없는 달에도 같은 기준을 적용한다.
- 검색·월 이동으로 숨겨진 선택은 `현재 목록 밖 N개`로 표시하고 삭제 확인에도 포함한다. `선택 해제`는 숨겨진 선택까지 해제하면서 검색어·선택 월·기록을 유지한다.
- 옵션 하단에 변경 개수와 `변경 취소`를 추가한다. 취소는 기본값이 아닌 마지막 저장값을 복원하며 저장소에 쓰지 않는다. 권한 승인 대기와 저장 중에는 취소·재저장·초기화를 막는다. 승인 후에는 저장 버튼을 누른 시점의 값만 저장하고 대기 중 추가 편집은 미저장 상태로 남긴다.
- 헤더의 부가 설명을 줄이고 릴리즈 노트·기본값 복원을 `설정 더보기` 메뉴로 옮겼다. 320px에서 헤더 높이는 106px에서 40px로 줄었다. 메뉴는 Escape·바깥 클릭·바깥으로 포커스 이동 시 닫힌다.

## 후속 조정 — 다시보기 탭
