# 팔로잉 고정 채널의 파티 표시 혼입 확인

## 확인 범위

2026-09-30에 치지직 공개 홈페이지가 참조하는 배포 JavaScript·CSS를 읽어 현재 사이드바 파티 표시의 생성 조건과 형태를 확인했어요. 로그인 계정·브라우저·팔로우 관계는 조작하지 않았어요. 공개 코드 확인과 합성 DOM 회귀는 실제 Chrome 화면에서의 재현·해소를 증명하지 않아요.

표시와 함께 화면 읽기용 안내도 만들어요. 이 클래스의 해시 부분은 당시 배포 자료의 식별자이며 런타임에 고정할 계약이 아니에요. 인원 수는 해당 채널의 현재 파티 상태에 속해요.

## 기존 복제 경로

접힌 팔로잉 목록의 원본 5개 밖에 고정 채널이 있으면 확장은 같은 라이브 상태의 첫 원본 행을 복제해 보충해요. 기존 생성 경로는 이름·프로필·배지·링크·카테고리·시청자 수를 바꾸지만 파티 인원 링크와 프로필 아이콘을 제거하지 않았어요. 그래서 첫 일반 채널의 파티 표시와 다른 파티로 가는 주소가 보충 고정 행에 남을 수 있어요.

준비 단계의 합성 DOM에서는 일반 `channel-a`의 `+3`이 `channel-pinned` 보충 행에 남는 것을 확인했어요. 기존 사이드바 검사 26개는 통과했지만 파티 링크·아이콘을 가진 템플릿의 혼입은 검사하지 않았어요.

## 수정과 자동 검증

`features/sidebarCustomization.js`의 보충 행 생성 경계에서 복제본의 파티 인원 링크와 프로필 파티 SVG를 제거해요. 원본 행은 수정하지 않아요. 채널명에 들어 있는 `+숫자`, 보충 대상의 프로필·인증·채널 배지·고정 핀·카테고리·시청자 수·라이브 이동 링크는 보존해요. 파티 인원 신규 조회·설정·저장 형식·권한·로딩 변경은 없어요.

현재 배포 구조를 담은 새 회귀를 먼저 추가했을 때 사이드바 검사는 종료 코드 1, 31개 중 26개 통과·5개 실패였어요. 수정 후 같은 검사는 종료 코드 0, 31개 모두 통과했어요. 하나·여러 보충 행, 원본 고정/일반 파티의 동일 DOM·클릭, 템플릿 파티 인원 변경·제거·추가, href 재사용·행/루트 교체·OFF/ON·펼침 복원과 정상 정보 보존을 확인했어요.

첫 수정 후 검사에서는 href 재사용 시 원본에서 빠진 `channel-a`가 비고정 보충 행으로 추가되는 기존 동작을 검사 기대가 놓쳐 30개 통과·1개 실패였어요. 현재 채널 ID와 보충 대상 수의 3개→2개 복원, 비고정 보충 행의 핀 0을 명시해 기대를 바로잡았어요. 런타임 수정 범위를 확대하거나 기존 검사를 약하게 만들지 않았어요.

최종 인접 검사는 다음 명령으로 종료 코드 0, 195개 통과·실패/취소/건너뜀 0개였어요.

```text
node --test --test-concurrency=2 tests/sidebar-customization.test.js tests/following-preview-tooltip.test.js tests/following-list-state.test.js tests/extension-pages.test.js tests/release-safety.test.js
```

변경한 JavaScript의 ESLint, 변경 파일의 Prettier와 `git diff --check`도 순차 실행해 모두 종료 코드 0을 확인했어요. ESLint 대상은 `features/sidebarCustomization.js`, `tests/sidebar-customization.test.js`이며 포맷 검사는 이 두 파일과 이번 측정·유지보수 메모·상태·남은 확인 문서를 포함해요. 단일 기능의 보충 DOM 생성만 바꾸고 영향받는 팔로잉 소비자·확장 안전 검사를 확인했으므로 이번에 전체 검사를 반복하지 않았어요. 별도 서버를 실행하는 제품이 아니므로 서버 시작 확인은 해당하지 않아요.

기존 테스트의 공용 조건 대기 변경과 다른 진행 중인 작업은 보존했어요. branch·HEAD·버전·커밋·배포는 변경하지 않았어요.

## 실제 화면 확인

현재 치지직의 로그인된 팔로잉 목록에서 원본 DOM·확장 주입·오표시 재현·수정 후 화면은 확인하지 않았어요. 사용자의 명시적 재요청 전 컴퓨터 사용 도구를 쓰지 않는 경계를 지켰어요.

수동 확인은 확장을 다시 로드하고 치지직을 새로고침한 뒤, 접힌 목록 밖의 고정 채널과 첫 일반 파티 채널을 함께 표시해요. 일반 채널의 정상 `+n`·파티 아이콘·파티 링크는 유지되고 보충 고정 채널에는 다른 채널의 표시와 링크가 없어야 해요. 고정 채널이 원본 목록에 보이는 경우의 정상 파티 표시, 고정 ON/OFF·접힘/펼침·여러 고정 채널·새로고침과 라이트·다크도 확인해요.
