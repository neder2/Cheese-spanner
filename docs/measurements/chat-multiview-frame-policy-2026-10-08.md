# 채팅 멀티뷰 프레임 정책 근거 — 2026-10-08

## 확인한 것

인증정보·쿠키 없이 `curl -sS -o /dev/null -D -`로 응답 헤더만 읽었어요. 본문 실행·로그인·채팅 연결은 하지 않았어요.

| 측정 시각                                                                                       | URL                                                                  | 상태         | 관련 헤더                                                                                                                                  |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 2026-10-08 23:1x KST(최초), 2026-10-09 00:05:56 KST(서버 `date: Thu, 08 Oct 2026 15:05:56 GMT`) | `https://chzzk.naver.com/live/feb20a676694b1163fed010da0848303/chat` | `HTTP/2 200` | `content-type: text/html`, `content-security-policy: frame-ancestors 'self' https://naver.com https://*.naver.com`, `X-Frame-Options` 없음 |
| 2026-10-08 23:21 KST, 2026-10-09 00:05:56 KST                                                   | `https://chzzk.naver.com/live/feb20a676694b1163fed010da0848303`      | `HTTP/2 200` | 위와 같은 `content-security-policy`, `X-Frame-Options` 없음                                                                                |

`Cross-Origin-Opener-Policy`·`Cross-Origin-Embedder-Policy`·`Cross-Origin-Resource-Policy` 헤더는 응답에 없었어요.

## 해석과 한계

- `frame-ancestors 'self'`는 같은 출처(`https://chzzk.naver.com`) 문서가 이 경로를 프레임으로 넣는 것을 사이트가 허용한다는 뜻이에요. 채팅 멀티뷰는 치지직 페이지 안에서 이 네이티브 채팅 팝업 경로만 같은 출처 프레임으로 표시해요.
- 채팅 팝업 경로 `/live/:channelId/chat`은 치지직 공개 번들의 `isPopupChat` 라우트로 기존 [남은 확인 사항](../tracking/findings.md)에서 관측했어요.
- 헤더 확인은 **정책상 허용**의 근거예요. 실제 Chrome에서 프레임이 그려지는지, 로그인 세션이 프레임에도 적용되는지, 입력이 표시한 채널로 전송되는지, 메모리·소켓 부하는 확인하지 않았어요. 이 항목은 Codex 실제 Chrome 검수 대상이에요.
- 응답 헤더는 치지직이 바꿀 수 있는 외부 계약이에요. 정책이 바뀌어 프레임이 막히면 해당 칸에만 실패를 표시하고 새 창·새 탭·원격 플레이어·다른 경로로 대체하지 않아요.

| ----------- | --------------------------------------------------------------- | ------------------------------------------------------ |
| 표시 대상   | 치지직이 제공하는 같은 출처 채팅 팝업 화면                      | 확장이 만든 플레이어·채팅 클라이언트, 다른 출처 페이지 |
