# 베타 피드백 수정 근거

- 작업 브랜치: `1.3.8`, 시작 HEAD: `659ad7ff5782bea66cf2ce1d395a80b41f1fd83b`
- 범위: 설정 카테고리 휠 스크롤, 시간 이동 간격 버튼의 깜빡임, 스트림 정보의 우클릭 메뉴 진입.
- 컴프레서와 멀티뷰 창 배치는 이번 변경 대상이 아니다.

## 실제 라이브 관측

- 날짜: 2026-09-15 (KST)
- 대상: https://chzzk.naver.com/live/7c4d5ea51cc36eff812e9c6059704f3f
- 브라우저 API로 현재 DOM과 computed style, 페이지 스타일시트를 읽었다.
- 플레이어는 `.pzp-pc`, 영상은 `video.webplayer-internal-video`, 왼쪽 컨트롤은 `.pzp-pc__bottom-buttons-left`였다. 기존 부분 문자열 선택자가 이 컨테이너를 처리하므로 새 호환 분기는 추가하지 않았다.
- `pzp-pc--controls`가 없는 재생 상태에서 네이티브 `.pzp-pc__playback-switch`의 opacity는 `0`, `#betterchzzk-skip-pill`의 opacity는 `1`이었다. 둘 다 같은 네이티브 버튼 클래스와 `opacity 0.2s ease-in` 전환을 갖고 있었다.
- 페이지 스타일시트에서 `.pzp-pc__playback-switch`의 기본 opacity `0`과 `.pzp-pc.pzp-pc--controls` 아래 opacity `1`을 확인했다.
- 수정 전 코드가 매 동기화마다 pill의 클래스를 비운 뒤 복원했고, 자신이 쓴 class/style 변경을 다시 관측해 동기화를 예약했다. 반복 전환으로 네이티브 페이드가 끝나지 않는 원인이 된다. 호버의 별도 opacity override도 제거했다.

## 변경과 회귀 검증

- 탭 위의 세로 휠을 가로 이동으로 변환한다. 픽셀·줄·페이지 단위를 처리하고, 가로 휠·Shift·확대 조합키와 더 이동할 수 없는 경계의 기본 동작을 보존한다. 탭 선택과 폼 저장값은 바꾸지 않는다.
- pill의 배치 모드가 바뀔 때만 배치 클래스를 초기화한다. 확장 소유 버튼 내부의 스타일·텍스트 변경은 재동기화 근거에서 제외하며, 네이티브 부모에서 버튼을 제거하는 mutation은 계속 처리한다.
- `tests/extension-pages.test.js`의 라이브·VOD 회귀 테스트를 수정 전 HEAD의 `skipControl.js`와 함께 실행하면 모두 실패한다. 초기 작업 이후 400ms 관측 구간에 라이브 28건, VOD 24건의 자체 mutation이 발생했다. 수정 후에는 모두 0건이며, 네이티브 클래스 유지와 컨트롤 교체 후 단일 재부착을 검증한다. 이 숫자는 해당 테스트 실행의 기록이다.
- 스트림 정보는 하단 아이콘을 제거하고 영상 우클릭 메뉴로 옮겼다. 메뉴를 여는 것만으로 통계 조회나 측정을 시작하지 않는다. 메뉴 항목을 선택했을 때 기존 패널을 열며 기존 지표 계산을 유지한다.
- 메뉴의 화면 경계, 키보드 메뉴 키·Shift+F10·방향키·Escape·Tab, 바깥 클릭, 리사이즈, 창 포커스 이탈, 탭 숨김, 옵션 비활성화, 소스 교체, SPA 이동과 플레이어 재마운트를 테스트한다. 플레이어 버튼·입력창·보조 플레이어의 우클릭은 가로채지 않는다.
- 기존 버튼의 가시성·아이콘 테스트는 변경된 진입 동작에 맞춰 우클릭 메뉴와 포커스 테스트로 대체했다. 통계 계산, 조회 실패, 취소된 응답, 탭 수명주기 검증은 유지했다. 하단 컨트롤만 교체될 때는 독립된 패널을 유지하도록 동작 계약을 변경했다.
- 관련 테스트 이후 `npm.cmd run test:all` 724개, `npm.cmd run lint`, `npm.cmd run format:check`가 모두 통과했다.

## 실제 확장 검증 한계와 수동 확인

브라우저 보안 정책이 `chrome://extensions` 접근을 차단했다. 다른 수단으로 우회하지 않았으며 수정 후 실제 확장 재로드·실행 context·주입 및 화면 검증은 완료하지 못했다. 라이트·다크 모드의 메뉴 동작은 JSDOM에서 확인했으며 실브라우저 외관은 미검증이다.

1. Chrome 확장 관리에서 치즈 스패너를 다시 로드하고 대상 치지직 탭을 새로고침한다.
2. 좁은 설정 팝업에서 카테고리 위의 일반 휠로 좌우 이동하고, 본문 세로 스크롤과 탭 키보드 선택도 확인한다.
3. 라이브·타임머신·VOD에서 마우스를 영상 밖으로 옮긴 뒤 `5s` 버튼이 기본 컨트롤과 함께 사라지고 깜빡이지 않는지 확인한다.
4. 영상 우클릭 → 스트림 정보로 패널을 열고 닫는다. 하단 정보 아이콘이 사라졌는지, 라이트·다크·전체화면·좁은 화면에서 메뉴가 영상 밖으로 넘치지 않는지 확인한다.
5. SPA 이동, 옵션 끄기·켜기와 플레이어 교체 뒤 메뉴·패널 중복 및 콘솔 오류를 확인한다.

스토어 등록용 로컬 설명 문구도 우클릭 조작에 맞춰 갱신했다. 실제 스토어 등록 정보의 수정·게시 작업은 수행하지 않았다.
