# 상단 버튼 숨기기 실측

- 날짜: 2026-09-14
- URL: https://chzzk.naver.com/
- 조건: 로그인한 Chrome의 데스크톱 홈, 라이트 테마. 브라우저 DOM 조회와 헤더 스크린샷으로 확인.
- 헤더: `header#header`. 스튜디오는 `https://studio.chzzk.naver.com/`으로 시작하는 링크.
- 치즈: `div > a[href="https://game.naver.com/profile#cash"]`.
- 알림: 치즈 다음, `div > a[href="https://game.naver.com/profile#cheat_key"]` 바로 앞의 `div > button`. 뒤에는 테마 버튼과 프로필 버튼이 있음.
- 알림 버튼에는 고유한 aria-label/title이 없고 CSS 클래스도 다른 버튼과 같음. 알림의 New 배지 대신 위의 링크·형제 구조를 함께 선택 조건으로 사용. 실제 선택 결과는 1개.
- 숨김은 CSS로 해당 항목에 적용하며 원본 DOM·배지·이벤트를 변경하지 않음. 치즈와 알림은 래퍼도 함께 숨겨 빈 자리를 남기지 않음.
- 자동 검증: 세 옵션의 모든 조합, 기본값, 원본 DOM 보존, 치트키·테마·프로필·사이드바 및 헤더 밖 요소 보존, SPA·재마운트·배지 제거·테마 속성 변경, 비활성화 복원.
- 한계: 브라우저 도구가 `chrome://extensions/` 접근을 차단하여 확장 다시 로드와 새 코드 주입 후의 수동 스모크는 수행하지 못함. 좁은 옵션 팝업과 라이트·다크의 실제 표시도 재검증 필요.
- 수동 확인: 확장 관리에서 다시 로드 → 치지직 새로고침 → 팝업·알림의 상단 버튼 옵션 각각 저장 → 해당 버튼만 숨겨지는지, 해제하면 복원되는지 확인. SPA 이동과 테마 전환 후에도 확인.
