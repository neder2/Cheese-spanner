# 1.3.7 화질 선택 방식 변경 구현·검증

## 작업 범위

작업 브랜치는 `1.3.7`, 시작 HEAD는 `b2f22a2b6e36ea3c1402c3b22580b3f644c3f4a2`예요. 기존에 진행 중이던 광고·설정 화면 등 변경은 유지했어요. 버전은 manifest, package, package-lock의 루트 메타데이터를 모두 `1.3.7`로 맞췄어요. 커밋·push·스토어 업로드·GitHub Release는 수행하지 않았어요.

## 구현

- `gridBypass.js`와 `gridBypassPage.js`를 패키지에서 제거하고 manifest 주입과 `gridBypassEnabled` 옵션을 제거했어요. worker가 이전 저장값을 정리하며, 정리가 실패해 값이 남아도 옵션 스키마가 읽지 않아요.
- `autoQualityPage.js`에 [실측한 플레이어 연결](grid-test-plan-2026-09-14.md)을 추가했어요. 현재 주 영상에 연결된 React 소유 컴포넌트만 최대 8단계, hook 목록은 각 48개까지 확인하고 후보가 하나일 때만 사용해요.
- 원래 화질 메뉴의 `$dispatch("change", { track })`와 `selectVideoTrack(id)`를 사용해요. 확인한 저지연 1920×1080 / encodingTrackId 1080p와 1280×720 / encodingTrackId 720p 트랙에 한해 원래 false 반환값을 true로 바꿔요. 수동 선택은 설정한 목표 화질과 일치할 때, 자동 선택은 목표 또는 가능한 하위 화질일 때 적용해요. 원래 함수와 안내 표시 등 부작용은 유지하고, 별도 옵션이 확인된 설치 안내를 닫아요. [후속 재생 시작·720p 조사](quality-startup-and-720p-2026-09-14.md)에 추가 근거를 기록했어요.
- 다른 트랙의 취소 결과는 바꾸지 않아요. 자동 적용이 취소·실패한 트랙은 ID와 목표 화질로 기억해 반복 팝업 요청을 방지하고, 명시적인 다음 선택·설정 변경이나 새 플레이어에서 다시 판단해요. 진행 중 선택을 공유하며 실패를 성공으로 표시하지 않아요.
- 옵션 끄기·라우트 변경·탐지된 주 영상/메뉴/provider 교체 때 연결을 정리해요. 늦게 끝난 선택은 다음 플레이어 상태를 갱신하지 않으며 다른 코드가 바꾼 메서드를 덮어쓰지 않아요. 기존 VOD와 다른 플레이어 경로는 유지했어요.
- 해당 라우트에서 현재의 네이티브 라이브 플레이어를 확인한 뒤에는 후보가 여러 개이거나 영상이 사라진 상태를 기존 트랙 탐색으로 대신하지 않아요. 남아 있던 추적 객체로 잘못 선택하던 경우를 수정 전 실패·수정 후 통과하는 회귀 테스트로 확인했어요.
- 새 방식은 JSON 파서·UA·미디어 주소·P2P 메타데이터를 수정하지 않아요. 그리드 프로그램이 설치된 환경에서 그 사용을 차단하는 기능은 제공하지 않아요.

## 업데이트 안내

1.3.7보다 낮은 버전에서 1.3.7로 업데이트한 경우, 치지직 페이지에 방식 변경을 한 번 안내해요. 새 설치·동일 버전 다시 로드·브라우저 업데이트에는 새 안내를 만들지 않아요. 원래의 범용 업데이트 알림 옵션·NEW 배지·튜토리얼은 재도입하지 않았어요.

여러 탭의 표시 요청은 worker 큐에서 순서대로 처리해 한 탭만 가져가도록 했어요. 표시할 수 없거나 탭이 숨겨지면 표시 요청을 반납하고, 숨김으로 반납한 탭은 다시 보일 때 재확인해요. 버전과 표시 상태는 확장 local 저장소에 남으며, 사용자 데이터 전송은 없어요. 페이지를 자동 이동하거나 새로고침하지 않아요.

## 검증 범위

새 자동 화질 검사는 원래 선택 이벤트 보존, 반복 적용, 미관측 트랙 취소, 동시 선택 공유, 선택 표시가 먼저 바뀐 뒤의 실패, ID가 같은 트랙 객체 교체, 옵션 끄기·SPA·DOM/provider 교체와 지연 응답 정리를 확인해요.

예전 그리드 기능의 활성 동작 검사는 기능 폐기에 맞춰 패키지·옵션에서의 부재, 저장값 무시, P2P 메타데이터 불변 검사로 교체했어요. 광고 기능과의 조합 검사도 P2P 정보를 보존하는 새로운 계약으로 바꿨고, 광고의 기존 검증은 유지했어요. 이전 ‘업데이트 UI 없음’ 검사는 범용 알림의 폐기를 유지하면서 이번 특정 버전 안내만 허용하도록 변경했어요.

브라우저 사용 도구로 실제 알림 코드에서 만든 로컬 미리보기를 렌더링했어요. 좁은 약 319px 화면에서 라이트·다크 모드, 가로 넘침 없음, 확인 버튼 노출, 키보드 포커스와 Esc/확인 닫기를 확인했어요. 최종 다크 모드 팝업은 폭 약 287px, 높이 약 436px였어요. 이 미리보기는 실제 확장의 worker·저장소·업데이트 설치 이벤트를 대신하지 않아요.

사용자 페이지의 `theme_dark`에서 현재 테마 변수를 확인했어요. 예전 `--Surface-Neutral-Base` 등은 비어 있고 `--sem-color-surface-neutral-base: #2e3033`, `--sem-color-content-neutral-cool-strong: #c9cedc`, `--sem-color-border-neutral-weak: #2e3033`가 있어서 새 변수명을 우선 사용하도록 맞췄어요. 이전 이름과 정적 라이트·다크 값은 미리보기·호환용 기본값으로 유지해요.

구현 직후 사용자 치지직 탭은 브라우저에서 읽을 수 있었지만, 확장 관리 탭은 도구가 접근을 차단했어요. 당시 DOM에는 Better Chzzk 주입 마커나 확장 리소스 링크가 없었고 영상은 이전 실험의 1080p 상태였어요. 사용자에게 1.3.7 개발본 다시 로드·활성화와 방송 새로고침을 요청했어요. 이후 통합된 확장의 첫 관측은 아래에 따로 기록해요.

## 통합 확장 첫 브라우저 관측

사용자가 ‘옵션에 있나? 그리드 팝업 뜨는데’라고 보고한 뒤 같은 한동숙 라이브를 브라우저 도구로 확인했어요. 확장 ID 마커는 `oijgeclpcafhkbaameifdomjononepol`, 자동 화질 상태는 `enabled: true, quality: 1080p`였어요. 그리드 설치 안내가 열려 있었고 문서에 video와 `.chzzk_player` 요소가 없어 자동 화질 결과는 `pending / player-missing`이었어요.

원래 ‘설치없이 일반 화질 시청’ 버튼을 눌러 닫자 플레이어가 생성됐고, `tracks-missing` 단계 후 1080p가 선택됐어요. 그 과정에서 설치 안내가 한 번 더 나타나 같은 버튼으로 닫았어요. 2026-09-14 09:58:28.476 UTC의 자동 화질 결과는 `already`, 선택 트랙은 `muxed.bw_8384000.avc1.size_1920x1080.fps_60.color_sdr.mp4a.lowlatency`, 트랙 수는 12개였어요. 실제 영상은 1920×1080, readyState 4, 오류 코드 null이었고, 확인 당시에는 일시정지 상태였어요. 이 단계에서 자동 시작이나 연속 프레임 진행까지 확인했다고 보지는 않아요.

실행한 것은 브라우저의 원래 안내 닫기 버튼뿐이며, Console 실험 코드를 다시 주입하지 않았어요. 이로써 통합 확장의 주입과 실제 1080p 적용을 처음 확인했어요. 실제 업데이트 안내 이벤트, 옵션 페이지의 토글 및 다른 방송·SPA 경로는 여전히 자동 검사와 미리보기 범위예요.

‘자동 화질 복구’에 새 선택 방식이 연결돼 있고 ‘고정할 화질’은 1080p로 설정돼 있었어요. 이 관측 시점에는 그리드 설치 안내 자동 닫기를 구현하지 않은 상태였어요. 초기 안내는 플레이어 생성을 막을 수 있고, 화질 선택 때 원래 안내가 재표시될 수 있다는 실측 사례예요.

## 커넥터 설치 안내 자동 닫기 추가

사용자가 ‘팝업도 안보이게 만들어봐’라고 요청해 `features/qualityInstallGuide.js`를 추가했어요. 처음 추가했을 때는 `자동 화질 복구` 아래에 `설치 안내 자동 닫기`를 두고 둘 다 켜졌을 때 동작했어요. 이후 옵션 통합 요청으로 변경한 현재 동작은 아래의 ‘팝업 옵션 통합’에 기록해요. 설정을 읽기 전에는 실행하지 않아요.

2026-09-14 같은 방송 URL(`https://chzzk.naver.com/live/75cbf189b3bb8f9f687d2aca0d0a382b`)을 새로고침해 원래 안내 DOM을 다시 확인했어요. `_player_jwedy_23 > _dimmed_10lql_28 > _layer_10lql_38` 구조이며, 안내의 p 문구는 ‘고화질 시청을 위해서는 네이버 라이브 스트리밍 커넥터가 필요합니다.’, 버튼 두 개는 ‘설치하고 고화질 시청’과 ‘설치없이 일반 화질 시청’이었어요. 클래스의 해시 대신 접두어·직접 부모 관계·고유한 안내 레이어·정확한 문구와 버튼 조합을 함께 확인해요.

표시된 안내에서 원래 일반 화질 시청 버튼을 한 번 클릭해요. CSS 숨김이나 DOM 삭제로 초기 플레이어 생성을 막지 않으며, 설치 버튼·재생 버튼·화질 트랙·재생정보는 이 모듈에서 다루지 않아요. 실패한 클릭은 성공으로 표시하지 않고 안내를 화면에 남겨요. 클릭 시도 횟수는 `data-betterchzzk-auto-quality-guide` DOM 속성으로만 확인할 수 있어요.

전역 childList 감시는 초기 진입을 제외하면 바뀐 하위 트리만 확인해요. 발견한 안내는 최대 4개까지 좁은 observer로 보고, 같은 표시 상태에 재클릭하지 않아요. 안내 재삽입·버튼 교체·숨김 후 재표시 때 현재 문구와 버튼을 다시 확인해요. 옵션 끄기·SPA 이동·분리된 안내의 observer를 정리해요. 채팅 변경으로 전체 문서를 반복 탐색하거나 재시도 타이머를 추가하지 않았어요.

새 회귀 검사는 초기 플레이어 생성과 두 번째 안내, 옵션 로드·저장·의존성, 표시·활성 상태, 다른 안내와 불완전한 구조, 콘텐츠 재사용, 클릭 실패와 반복 방지, 동일 DOM 재삽입·버튼 교체, SPA 및 document-start를 확인해요. 기존 튜토리얼 부재 검사는 이 네이티브 안내 처리 파일만 예외로 허용하며, 확장 튜토리얼·범용 업데이트 알림은 계속 금지해요.

## 팝업 옵션 통합과 배포 안내 문구

사용자가 릴리즈·옵션·다음 패치 안내 문구를 정리하고 기존 광고 팝업 옵션과 통합해 달라고 요청했어요. 공개 옵션 이름은 `시청 방해 팝업 제거`, 설명은 요청대로 `시청에 방해되는 팝업을 제거합니다.`만 표시해요. 위치는 `팝업·알림 → 시청 팝업`이에요.

`autoQualityDismissInstallGuide`는 스키마·화면에서 제거했어요. background가 예전 저장값을 정리하고, 정리가 실패해 값이 남아도 읽지 않아요. 기존 광고 팝업의 켜짐·꺼짐 값을 덮어쓰지 않아요. 통합 옵션이 꺼지면 두 모듈 모두 처리를 멈추고, 기존 광고 팝업의 숨김은 복원해요. 이미 원래 버튼으로 닫은 커넥터 안내를 임의로 다시 만들지는 않아요.

1.3.7 릴리즈 안내와 이번 버전 전용 팝업에 지원 종료 판단·화질 고정 강화·시청 방해 팝업 제거를 반영했어요. 법적 금지 확정이나 플랫폼 승인을 주장하는 문구는 추가하지 않았어요. 현재 화질 기능이 설치된 그리드 프로그램의 사용을 차단하지 않는다는 설명은 유지해요. README·스토어 등록 문구·개인정보 안내의 옵션 명칭도 맞췄어요. 실제 릴리즈 발행이나 스토어 업로드는 수행하지 않았어요.
