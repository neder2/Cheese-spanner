## 통합 집계 기준

- 월 스냅샷은 갱신 요청 시작 시점까지의 구매 내역만 포함한다. 요청 중 발생한 후원은 그 이후 실시간 기록으로 표시하거나 다음 갱신에서 가져온다.
- 조회한 월·시점까지는 API 기록을 기준으로 삼고, 그 이후의 실시간 후원 및 아직 조회하지 않은 기간의 실시간 기록을 함께 표시한다. 서로 다른 원본 ID를 같다고 추측하거나 금액·본문으로 동일 후원을 판정하지 않는다. API의 동일 시각·금액·본문인 별개 행은 모두 유지한다.
- 다른 계정임이 확인되는 실시간 행을 현재 API 계정의 중복으로 제거하지 않는다. 갱신 계정 변경 차단은 기존 동작을 유지한다.
- 미조회 기간과 경계 이후의 날짜는 기존 날짜별 누적 집계를 유지한다. 갱신 경계가 있는 날에 경계 이후의 상세 기록까지 보관 상한으로 정리되었으면 합계의 누락 가능성과 갱신 필요를 표시한다.
- 많이 본 채널의 후원 합계에도 같은 조회 기준을 사용한다. API에 방송 번호가 없으므로 특정 방송의 실시간 집계나 시청 시간을 임의로 변경하지 않는다. 후원 검색은 채널명 기준이다.
- 원본 실시간 기록은 보존한다. 관리 도구의 **후원 갱신 초기화**는 API 기록·완료 상태만 지우고 다음 갱신을 전체 조회로 되돌린다. 확인창에 실시간 기록을 유지한다고 명시한다.
