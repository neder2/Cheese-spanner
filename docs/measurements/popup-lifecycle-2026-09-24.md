# 시청 방해 팝업 표시 주기 보완

## 범위와 근거

- 기준: `1.4.0` 작업 브랜치, HEAD `c84233fa5007885b801244e6e8b8fc9992edde9d`. manifest/package 버전은 1.3.9이며 이번 작업에서 올리지 않았다.
- 사용자 제공 PRO 검토를 참고해 `adblockPopup.js`, `qualityInstallGuide.js`와 실제 옵션 로드 경로를 확인했다. 제공된 검토용 ZIP은 첨부되지 않아 실행하지 않았다.
- 2026-09-24 저장소 JSDOM fixture에서 회귀 테스트 17개를 먼저 추가했고, 수정 전 17개가 실패했다. 팝업 표시 주기·관찰 범위·버튼·초기 설정의 제어된 재현이며 리뷰 작성자의 환경이나 현재 치지직 팝업을 재현했다는 뜻은 아니다.
- 기존 실측 구조의 출처는 [광고 안내 조사](adblock-popup-close-2026-09-15.md), [커넥터 설치 안내 조사](quality-choice-implementation-1.3.7-2026-09-14.md)다. 이번에는 현재 치지직 DOM·문구·응답을 새로 측정하지 않았다.

## 수정한 동작

- 광고 안내는 저장 옵션을 받기 전 클릭·선행 숨김·준비 완료 발행을 하지 않는다. 저장된 OFF를 기본 ON보다 늦게 받던 경로를 차단했다.
- 두 기능에서 안내 또는 조상의 `hidden`, `aria-hidden`, inline `display`/`visibility`의 실제 숨김을 감지한다. `attributeOldValue`로 같은 mutation 배치 안의 숨김→재표시도 확인한다. 공용 판별은 두 소비자보다 먼저 로드되는 기존 `content.js`에 둔다.
- 확장 선행 숨김 속성과 무관한 class 변경은 새 표시 주기로 취급하지 않는다. 광고 안내의 선행 숨김을 복원한 뒤에는 해당 팝업만 확인해 네이티브 CSS 숨김 상태에서 클릭 이력을 정리한다. 새 전체 문서 스캔이나 재시도 타이머는 추가하지 않는다.
- 광고 안내의 닫기 버튼은 표시·크기·활성 여부를 먼저 확인한 뒤 유일성을 판단한다. 설치 안내의 일반 화질 버튼도 같은 가시성·크기·활성 조건을 확인한다. 설치·확인·계속 버튼으로 대체하지 않는다.
- 설치 안내는 후보 내부와 조상 체인의 표시 관련 속성을 같은 scoped observer로 관찰한다. 전역 observer는 기존 childList만 유지한다. 안내 구조가 먼저 만들어지고 직접 부모의 player class가 뒤늦게 생기는 경우도 재검사한다.
- 관찰 후보 4개 상한을 유지하면서, 완전한 설치 안내가 들어오면 잘못된 후보보다 우선 등록한다. 비활성 버튼도 안내 자체는 식별할 수 있어 활성화 변경을 놓치지 않는다. 라우트 이동·옵션 해제·재마운트 시 관찰을 정리한다.
- 기존 DOMContentLoaded 이전 닫기 검사는 옵션 전달을 직접 통제하도록 변경했다. 저장 응답 전에는 닫지 않고, 응답 후에는 DOMContentLoaded를 기다리지 않고 닫는 두 조건을 함께 검증한다.

## 유지한 제한과 후속 실측 항목

- 광고 안내의 넓은 단어 판별에 따른 오탐 가능성은 남아 있다. 현재 네이티브 안내 제목·본문·구조를 확보하지 못한 상태에서 임의의 새 판별 문구를 도입하지 않았다.
- 설치 안내의 정확한 문구, 부모·자식 관계와 버튼 2개 계약은 유지했다. 다른 래퍼·추가 버튼·문구 변형 지원은 실제 사례 확인이 필요하다.
- 같은 배치 안에서 class만 왕복한 경우는 과거 computed style을 복원할 수 없어 새 표시 주기로 추정하지 않는다. 별도 배치에서 관측한 실제 숨김과 명시적인 숨김 속성 왕복은 처리한다.
- 정상 후보가 이미 4개인 경우의 상한은 유지한다. 탈락한 불완전 후보의 모든 후속 속성 변화를 무제한 추적하지 않는다.
- 핸들러 준비 시점을 추측해 다시 클릭하거나 선행 숨김 시간을 늘리지 않는다. 한 표시 주기의 무효 클릭은 반복하지 않는다. ready는 준비 상태, attempts는 클릭 시도 수이며 제거 성공 수가 아니다.

## 검증

- 개별 회귀 테스트에서 최초 17개 실패→수정 후 통과를 확인했다. CSS 숨김, 조상 교체 후 관찰 정리, 크기 0 버튼 제외도 추가했다.
- 팝업 기능 테스트 40개와 전체 `npm.cmd run test:all` 913개가 통과했다. `npm.cmd run lint`, `npm.cmd run format:check`, `git diff --check`도 통과했다.
- 독립 브라우저 사용 도구가 제공되지 않아 확장 재로드, 실제 확장 주입, 현재 치지직 안내, 라이트·다크, 실제 React 상태와 M·F·T·포커스·스크롤·재생 복구는 미검증이다. 저장소 지침에 따라 컴퓨터 사용 도구는 사용하지 않았다.
- 수동 확인: 확장을 다시 로드하고 치지직 탭을 새로고침한다. 옵션 OFF에서 자동 닫기가 없는지 확인한 뒤 ON으로 바꾼다. 광고 안내와 커넥터 안내가 다시 나타날 때도 처리되는지, 방송 간 SPA 이동 후에도 동작하는지 확인한다. 닫힌 뒤 M·F·T, 포커스, 스크롤과 재생 상태를 확인한다.
