## 원인과 변경

- 기존 모델은 전체 길이와 병합된 방송을 시작 날짜의 `dailySeconds`, `startsByDate`에 저장했다. 화면은 이 두 값만 검사하여 날짜를 칠했으므로, 병합된 종료 시각이 다음 날이어도 이어진 날짜가 빠졌다.
- 병합이 끝난 방송 구간을 KST 날짜별로 나누어 `broadcastSecondsByDate`를 계산한다. 선택한 월과 조회 시점까지만 반영하고, 종료 시각이 정확히 자정이면 다음 날을 칠하지 않는다.
- 시작 날짜의 시간 합계·툴팁·다시보기 링크는 유지한다. 시작 기록이 없는 날짜는 확인된 구간으로 색만 채운다. 이전 달에 시작한 것으로 확인된 구간도 선택한 달에 걸친 부분을 반영한다.
- 방송일 수는 날짜별로 확인된 방송 시간이 기존 기준인 1분 이상인 날을 센다. 방송일당 평균의 분모도 이 일수이므로 함께 바뀐다. 월 총 시간과 달력 하단의 월평균 합산 방식은 유지한다.
- 기존 목록·상세 요청과 캐시를 재사용한다. 라이브 조회, 타이머, DOM 스캔은 추가하지 않았다.
- README의 분할 방송 설명을 갱신했다. 버전·커밋·릴리스는 변경하지 않았다.

## 실브라우저 검증 한계

브라우저 도구가 `chrome://extensions/` 탭 제어를 차단하여 확장을 다시 로드하지 못했다. 수정 후 실제 확장 ID·실행 컨텍스트·주입 성공, 실제 채널의 새로고침·SPA 이동·옵션 즉시 반영은 미검증이다. 원래 채널에서는 수정 전 증상만 확인했다.

최소 수동 확인: 이 작업 폴더를 사용하는 개발용 확장을 다시 로드한 다음 아리사 채널 탭을 새로고침한다. 캘린더에서 13일·14일 색 채움과 12일의 기존 전체 시간·다시보기 링크를 확인한다. 아직 다시보기로 공개되지 않은 라이브 시간은 집계 대상이 아니다.

## 추가 요청: 방송 시간 색상 세분화

같은 날 사용자가 11시간과 24시간의 색이 같다고 지적하여 기존 3단계를 9단계로 변경했다.

| 단계 | 방송 시간                |
| ---- | ------------------------ |
| 1    | 3시간 미만               |
| 2    | 3시간 이상, 6시간 미만   |
| 3    | 6시간 이상, 9시간 미만   |
| 4    | 9시간 이상, 12시간 미만  |
| 5    | 12시간 이상, 15시간 미만 |
| 6    | 15시간 이상, 18시간 미만 |
| 7    | 18시간 이상, 21시간 미만 |
| 8    | 21시간 이상, 24시간 미만 |
| 9    | 24시간 이상              |

- 기존 초록색의 OKLCH 색상각(약 158.31도)을 기준으로 밝기·채도를 조절했다. 개발 환경의 `@asamuzakjp/css-color`로 변환한 sRGB hex만 런타임에 넣었다. 색 변환 의존성은 추가하지 않았다.
- 색은 `--bcmb-duration-*-bg/fg` 변수에 정의하고, 라이트·다크 테마에서 각 배경과 글자색을 함께 바꾼다. 작은 날짜 글자와 시청 점, 오늘 테두리가 배경과 구분되도록 시청 점·오늘 테두리는 날짜 글자색을 따른다.
- 실제 치지직 탭의 루트에 `class="theme_dark"`, `data-theme="theme_dark"`가 있는 것을 브라우저로 확인했다. 기존 테마 전환 규칙을 유지하며 같은 루트 상태를 로컬 화면 검증에도 사용했다.
- 캘린더 아래에 9단계 범례와 `3시간 단위`, `24시간+` 문구를 표시한다. 범례에는 접근성 설명을 제공한다. 이어진 날짜에는 해당 날짜의 시간을 native title과 접근성 문구로 표시한다.
- 시간 합계·날짜별 배분은 앞선 수정 그대로이며, 기존 아리사 회귀 테스트의 24시간 날짜는 최상위 단계인 9를 기대하도록 변경했다.

## 추가 요청: 시청 기록이 있을 때만 내 시청 표시

- 개별 방송에 매칭된 시청 시간이 0이면 툴팁의 `내 시청` 행과 접근성 문구를 생략한다. 채널의 시청 합계가 0이면 달력 하단 합계도 생성하지 않는다. 기존 시청 점 표시·기록 매칭·저장 방식은 유지한다.
- 기존 모델과 렌더러를 실행하는 로컬 검증에서 기록 없음, 다른 채널 기록만 있음, 일부 방송만 시청함, 기록 삭제 후 재렌더링, 0초 기록, 표시 옵션 해제를 확인했다. 일부 방송만 시청한 경우 해당 방송의 행·점·접근성 문구가 각각 1개이고 하단에는 `내 시청 시간 10분`이 나타났다. 나머지 경우에는 모두 숨겨졌다.
- Chrome의 라이트 화면에서 기록 없는 방송의 툴팁·하단에 내 시청 문구가 없는 것을, 다크 화면에서 기록 있는 방송에만 `10분 (17%)`와 채널 합계가 표시되는 것을 확인했다. 임의 테스트 기록을 사용했으며 사용자 기록은 변경하지 않았다.
- 관련 테스트 22개, 전체 테스트 762개, lint·포맷 검사가 통과했다. 실제 확장 재로드와 치지직 탭에서의 동작은 앞서 기록한 도구 제한으로 미검증이다.
