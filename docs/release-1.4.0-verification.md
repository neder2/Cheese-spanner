## 실브라우저와 스토어

- 입장 광고는 9월 23일 수정 과정에서 새 문서 진입과 방송 간 SPA 이동을 확인한 기록이 있다. 이번 최종 ZIP을 새로 설치해 다시 검증한 결과로 간주하지 않는다.
- 팝업 수정은 제어된 DOM fixture 검증이다. 현재 제공된 도구로 독립 브라우저 조작을 할 수 없어 확장 재로드·주입과 실제 치지직 팝업·React 상태·라이트/다크·단축키·포커스·스크롤·재생 복구는 이번 릴리스 작업에서 직접 확인하지 못했다.
- 최소 수동 확인: ZIP을 풀어 확장을 다시 로드하고 치지직 탭을 새로고침한다. 라이브 입장·방송 간 이동 후 재생, 팝업 옵션 ON/OFF와 동일 안내 재등장, 안내가 닫힌 뒤 M·F·T·포커스·스크롤·재생 상태를 확인한다.
- Chrome 웹 스토어 업로드·심사 제출은 이 작업에서 수행하지 않는다. 제출용 파일은 위 ZIP이며, 새 권한·새 조작법 추가가 없어 기존 스토어 설명·권한 사유를 변경할 필요는 없다.
