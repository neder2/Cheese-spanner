# 오프라인 팔로잉 행 깜빡임 보완

- 확인일: 2026-09-12
- 실제 확인 URL: https://chzzk.naver.com/live/b68af124ae2f1743a1dcbf5e2ab41e0b
- 현재 DOM은 `#sidebar nav[aria-label="팔로우"]` 안의 `ul > li` 구조다. 라이브는 `/live/{channelId}`, 오프라인은 `/{channelId}` 링크를 사용하며, 확인 시 오프라인 행은 숨김 상태로 안정적이었다. 사용자에게 발생한 빠른 깜빡임 자체는 실브라우저에서 재현하지 못했다.
- 코드에서 숨김 속성은 관찰 대상이 아니므로 그 속성 자체의 재감지 루프는 확인되지 않았다. 확인한 결함은 네이티브 행 교체 후 숨김 적용이 다음 RAF까지 지연되는 것이다.
- 회귀 테스트에서 다음 RAF를 보류하고 여러 오프라인 행을 반복 교체했다. 수정 전 교체 행의 display가 `list-item`으로 남아 실패했고 수정 후 mutation 전달 단계에서 `none`이 되어 통과했다.
- 목록을 처음 발견하거나 교체했을 때 전체 숨김 상태를 동기화한다. 기존 목록에서는 변경된 행만 즉시 판별하며, 핀 UI 동기화는 기존 RAF 경로를 유지한다. 숨김 marker는 값이 달라질 때만 변경하며 observer의 attributeFilter에 추가하지 않는다.
- 회귀 범위: 반복 행 교체, 목록 전체 교체, href를 통한 라이브 전환과 오프라인 복귀, 숨김 marker를 복제한 라이브 행. 기존 검사는 옵션 해제·재활성화, SPA와 사이드바 교체, 고정 기능과의 조합을 포함한다.
- 확장 관리 페이지는 브라우저 도구의 접근 제한이 있어 수정본을 다시 로드하거나 실제 화면에서 적용을 확인하지 못했다. 확장을 다시 로드하고 치지직을 새로고침한 후 오프라인 숨기기를 켠 상태에서 목록 새로고침·접기·펼치기 때 깜빡임이 재발하는지 확인해야 한다.
- 검증: 팔로잉 관련 31개, 전체 재실행 610개, lint·format:check 통과. 첫 전체 실행에서는 범위 밖 카테고리 검색 테스트 하나가 대기 시간 초과로 실패했으나 단독 재실행과 전체 재실행은 통과했다. 해당 테스트와 카테고리 구현은 변경하지 않았다.
