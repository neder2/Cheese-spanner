## 검증 결과

- 최종 `npm.cmd run test:all`: 719개 통과, 실패·취소·건너뛰기 0개.
- `npm.cmd run lint`, `npm.cmd run format:check`, `git diff --check` 통과.
- 첫 전체 검사에서는 방송 목록 검색의 상태 대기가 시간 초과로 실패했다. 조사 중 대기 도우미가 콜백 지연 후 이미 완료된 조건을 재확인하지 않고 실패하는 경우를 결정적으로 재현했다.
- 대기 도우미가 조건부터 확인하도록 수정했다. 완료 상태의 늦은 확인은 통과하고, 미완료 상태는 기존 제한 시간으로 실패하는 두 회귀 검사를 추가했다. 완료 상태 검사는 수정 전에 실패하고 수정 후 통과했다. 검색 결과 개수·스크롤별 추가 상한·캐시 요청 횟수 검사는 그대로 유지했다.
- 신규 클립·PIP 버튼 숨기기 안내를 README와 릴리즈 내역에 반영했다. 스토어 설명도 멀티뷰 닉네임 검색·재시도, 스트림 정보, 단축키·버튼 옵션, 미리보기 카테고리 링크와 시청 기록 삭제 주의에 맞췄다.
- 필수 권한·호스트 권한·선택 호스트 권한은 1.3.6과 같다. Pretendard 파일은 치지직에 한정된 공개 리소스로 포함하며 폰트 라이선스와 서드파티 고지를 확인했다.

## 실브라우저와 스토어

현재 브라우저 도구로는 로컬 확장 페이지와 확장 관리 화면을 조작하지 못하므로, 이번 ZIP의 실제 확장 재로드·주입과 실시간 재생·권한 승인·라이트/다크 화면은 미검증이다. 개별 기능의 이전 실측이나 JSDOM 결과를 이번 ZIP의 실브라우저 검증으로 간주하지 않는다.

1. 확장을 다시 로드하고 열린 치지직 탭을 새로고침해 버전 1.3.7과 새 이름·아이콘을 확인한다.
2. 라이브 화질 선택, 멀티뷰 닉네임 검색·딜레이 재시도, 미리보기 카테고리 이동·진행 시간, 스트림 정보와 버튼 숨기기를 확인한다.
3. 좁은 설정창과 시청 기록에서 라이트·다크 모드, 기록 삭제 주의의 접기·펼치기, 옵션 저장과 비활성화 복원을 확인한다.

Chrome 웹 스토어 제출은 이 GitHub 릴리즈에 포함하지 않는다. 제출 시 ZIP과 `store-assets/chrome-web-store-description.txt`의 설명, 새 아이콘·이미지를 반영해야 한다.
