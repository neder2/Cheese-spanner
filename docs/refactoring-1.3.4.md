# 1.3.4 리팩터링

대상은 `codex/1.3.4-refactor`의 1.3.4 코드다. 기능·옵션·권한·저장 형식과 기존 비동기/DOM 수명주기를 유지하며, 아래 다섯 기능의 책임 분리를 완료한다. 커밋·릴리스·버전 증가는 이 작업에 포함하지 않는다.

## 완료 기준

- [x] 채팅: DOM 파싱, 메시지 정체성·수집 상태, 패널 UI, 런타임 연결을 분리한다.
- [x] 카테고리: 필터 모델에 더해 데이터 조회·캐시·페이지 탐색의 상태를 화면 반영에서 분리한다.
- [x] 멀티뷰: 플레이어 수명주기, 설정 패널, 드래그·크기 조절을 런타임 연결에서 분리한다.
- [x] 방송 통계: 날짜·방송 집계 모델과 API 조회·캐시·집계를 위젯 렌더링에서 분리한다.
- [x] 영상 검색: 영상·댓글 정규화와 인덱스 조회·캐시·댓글 검색을 DOM 렌더링에서 분리한다.
- [x] 새 모듈의 manifest 로드 순서, 모든 소비자/테스트 로더, 관련 구조 설명을 갱신한다.
- [x] 기존 동작 테스트와 보안·성능 가드의 보호 범위를 유지하고, 새 경계의 취소·캐시·재마운트 계약을 검증한다.
- [x] 관련 테스트 및 전체 `npm.cmd test`, `npm.cmd run lint`, `npm.cmd run format:check`를 통과한다.

이미 반영한 1차 작업은 카테고리 필터 모델, 미리보기 공용 유틸 재사용, 옵션 테스트와 공통 fixture 분리다. 팔로잉 자동 새로고침이 필터를 닫지 않도록 수정한 사용자 입력 구분도 유지한다.

## 검증 결과 — 2026-09-09

- 전체 테스트 549개 통과. ESLint, 전체 Prettier 검사, `git diff --check` 통과.
- 분리한 방송 통계 모델 32개 함수와 영상 검색 모델 13개 함수의 본문을 이전 HEAD와 AST로 비교해 계산 로직 동일성을 확인했다.
- 기존 단위·DOM 통합·보안·성능 가드를 유지했다. 새 모듈 로드 순서를 별도로 검사하고, 이동한 코드에도 기존 금지 패턴 검사를 적용한다.
- 새 회귀 범위: 채팅 메시지 스냅샷·원본 행 재사용·정리 후 callback, 카테고리 동일 라우트 reset·후속 batch 취소·카드 재사용, 멀티뷰 세션 정리·재배치 중 방송 추가·Escape 처리, 통계 공유 요청의 소비자별 취소, 영상 검색 인덱스 취소·댓글 초기화 후 늦은 응답.
- 실제로 재현된 취소 이후 댓글 재저장, 멀티뷰 제스처 취소 순서 문제도 원인 모듈에서 수정했다.
- 시간에 따라 간헐적으로 실패하던 화질·미리보기 테스트는 assertion을 보존하고 실제 상태 전이 또는 명시적인 미디어 이벤트를 기다리도록 바꿨다.
- manifest/package 버전은 모두 1.3.4이며 권한·저장 형식·서드파티 소스는 변경하지 않았다.
