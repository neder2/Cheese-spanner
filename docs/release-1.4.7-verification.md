## 최초 판정과 범위

**사전 점검은 진행했지만 릴리스 준비 완료는 아니에요.** 전체 테스트·lint, 실제 업데이트, 새 기능 안내의 주요 동작, 실제 다시보기 녹화와 후보 ZIP은 확인했어요. 아래 필수 화면 확인과 최종 버전·배포 파일 확정이 남아 있어요. 확인된 범위에서 새 런타임 결함은 발견하지 못했으며, 미검증을 성공으로 처리하지 않아요.

- 요청: 버전을 올리고 릴리스할 만한 상태인지 점검해요. 실제 버전 변경·커밋·push·태그·Release·스토어 제출은 하지 않았어요.
- 기준: branch `1.4.7`, HEAD `4bef5e0a22a70461a945df4eb4140bb24379cc07`와 점검 시작 시의 미커밋 변경 45개 파일, 미추적 런타임 파일 `recording-download.txt`예요. 기존 변경과 개인 설정을 보존했어요.

## 릴리스 전에 남은 항목

1. **새 기능 안내의 필수 실제 화면 조건:** 이번 1.4.7 업데이트에서 숨김 탭·전체화면·입력 중의 새 자동 안내 보류, 재생 화면에서 영상 중앙·조작부·채팅 입력을 가리지 않는 배치와 재생·음량·스크롤·입력 초점 보존, SPA·BFCache 복원을 마저 확인해야 해요. 브라우저 도구에서 비활성 탭의 실제 초점 변경은 확인했지만 `visibilityState`는 계속 `visible`로 관측돼 숨김 검증으로 세지 않았어요. 기본 실행의 BFCache 비활성화도 일반 뒤로 가기를 BFCache 결과로 인정하지 않은 이유예요.
2. **녹화 저장 경로:** 실제 권한 승인·거절에서 저장 상태가 맞는지, 선택한 하위 폴더와 같은 이름의 충돌 처리, Chrome의 저장 위치 확인 설정에서 저장·취소를 확인해야 해요. 자동 회귀는 통과했지만 브라우저 권한창·저장창 결과는 아직 근거가 없어요. 컴퓨터 사용 도구를 새로 사용하거나 승인 결과를 가정하지 않았어요.
3. **최종 릴리스 기준 확정:** 실제 버전 증가 요청을 받으면 manifest·package·lockfile의 루트 버전, README·업데이트 내역의 배포 상태를 맞추고 최종 검사·ZIP을 다시 확인해요. 현재 후보와 검사 결과만으로 최종 배포본의 정합성을 대신하지 않아요. 기존 개인 파일의 전체 포맷 예외도 그대로 보고해요.

자연 발생한 운영자 블라인드와 로그인 팔로잉 장목록, 장시간 녹화·DRM·광고·음향 설정 조합의 남은 범위는 [기존 확인 사항](tracking/findings.md#2026-11-08-147-인수인계-반영-후-남은-화면-확인)에 있어요. 이번 점검에서 해당 조건이 새로 통과했다고 기록하지 않아요.
