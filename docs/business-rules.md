# 치즈 스패너 기능 기준

## 제품 범위

치지직 시청·탐색 경험을 개선하는 비공식 Chrome 확장으로 무료 배포를 유지해요. 현재 서비스에 없는 결과를 만들어 보여 주거나, 기능 실패를 성공한 것처럼 표시하지 않아요. 원래 페이지의 조작을 다른 창·다른 플레이어로 바꾸는 임의 우회는 기능 개선으로 취급하지 않아요.

## 재생과 화질

일반 VOD 이어보기의 영구 저장·다음 방문 복원은 치지직의 네이티브 시청 위치를 사용해요. 확장 시청 기록은 라이브용이며 VOD 위치 저장기로 확대하지 않아요. 사용자가 연 명시적 `currentTime` 링크는 그대로 유지하되 초기 적용 완료·사용자 탐색 뒤 화질 요청이나 페이지 복귀가 같은 시간을 다시 강제하지 않아요.

다시보기 채팅 제목 누락을 이유로 페이지를 자동 새로고침하거나 복구 전용 재생 위치를 저장·적용하지 않아요. 채팅 표시와 일반 이어보기는 치지직의 네이티브 동작을 사용해요.

자동 화질의 목적은 광고 차단 프로그램 사용 등으로 낮게 설정되는 입장 화질을 개선하는 것이에요. 적용 계기는 방송 입장과 사용자가 확장 설정에서 선호 화질을 바꿔 저장하는 때예요. 시청 중 저장하면 현재 영상에도 바로 적용해요. 시청 내내 사용자의 화질 선택을 되돌리는 요구로 확대하지 않아요.

입장 후 사용자가 화질을 바꾸면 치지직이 다시 낮추지 않는다는 내용은 사용자의 현재 관찰이에요. 모든 방송의 변하지 않는 플랫폼 보장으로 취급하지 않아요. 입장 시 적용을 완료하는 데 필요한 첫 재생·메뉴 준비 대기와 시청 중 반복 강제 적용도 구분해요.

자동 재생 위치 보존의 의도는 사용자가 일시정지한 뒤 다시 재생하는 경우에 한정돼요. 사용자가 직접 시간을 이동하거나 실시간으로 돌아가는 조작, 멀티뷰에서 목표 딜레이를 선택하는 조작은 각각 별도의 명시적 조작이에요. 지속적으로 되감기 위치를 지키는 일반 규칙으로 확대하지 않아요. 현재 구현에는 더 넓은 화질 재적용·위치 보정 경로가 남아 있어 이 목표가 모두 구현된 상태는 아니에요.

홀드 배속은 누르는 동안만 적용하고 해제·화면 이탈·영상 교체 때 이전 배속으로 돌려요. 일시정지한 영상을 홀드했다고 자동 재생하지 않아요. Space 홀드가 켜져 있으면 짧은 Space와 긴 Space 모두 해당 기능이 소유하며 기본 단축키 복구와 중복 실행하지 않아요. 고정 배속 단축키는 홀드 기능과 별도 선택이에요.

메인 재생 조작은 미리보기·멀티뷰 보조 영상을 대상으로 삼지 않아요. 확대·배치 조작은 원본 영상의 재생 위치를 변경하는 기능이 아니며, 버튼 숨김으로 이미 실행 중인 PIP를 종료하지 않아요.

독립적인 저지연 우선 설정과 전환 동작은 제공하지 않아요. 기존 자동 화질 선택과 스트림 정보의 실제 재생 방식·지연·안정성 관측은 유지해요. 과거 저지연 설정값이 남아 있어도 제어를 다시 활성화하지 않아요.

컴프레서의 마지막 켜짐·꺼짐과 출력 볼륨은 새 탭의 기본 선택으로 함께 기억해요. 새 탭이 홈·방송 목록을 먼저 열면 선택을 미리 고정하지 않고 라이브·다시보기에 처음 들어갈 때 이어받아요. 이미 선택을 복원한 탭은 각자의 선택을 유지하고, 상속받은 탭도 새로고침·페이지 이동 뒤 다른 탭의 이후 조작을 따라 바뀌지 않아요. 마지막으로 조작한 탭을 닫거나 브라우저를 다시 켜도 기본 선택은 남아요.

처음 이 방식을 적용할 때는 남아 있는 탭 기록의 마지막 유효 선택을 이어받고, 아무 선택도 없으면 꺼짐·100%로 시작해요. 이미 닫힌 탭의 선택은 복구할 수 없어요. 버튼 표시 옵션 OFF와 외부 컴프레서 충돌 회피는 적용만 일시 해제하며 저장 선택을 바꾸지 않아요. 네이티브 볼륨·음소거와 컴프레서 출력은 별개예요.

## 채팅과 댓글

방송자·운영자 모아보기는 확인된 역할과 현재 메시지 정체성을 기준으로 수집해요. 본문에 운영자라는 단어가 들어 있다는 이유로 수집하지 않아요. 같은 작성자가 같은 내용을 실제로 다시 보낸 경우는 별개 메시지이고, 같은 행을 다시 렌더링한 경우는 새 메시지가 아니에요.

블라인드 원문은 실제로 확인한 원문 또는 정체성이 일치하는 기존 원문이 있을 때만 표시해요. 원문이 없으면 안내를 유지해요. 닉네임·배지·본문이 순서대로 바뀌는 중간 상태를 확정된 새 메시지로 취급하지 않아요.

미확인 채팅은 패널을 열었다는 이유만으로 읽음 처리하지 않아요. 선택된 필터 안에서 실제 노출된 항목을 읽음 처리하며, 닫힌 패널·숨겨진 탭·화면 밖 항목은 미확인 상태를 유지해요. 원본으로 이동할 때 이미 다른 메시지로 재사용된 행에는 이동하지 않아요.

라이브·VOD 타임스탬프는 서버 작성 시각이 확인된 행에만 표시해요. 현재 시각을 대신 넣지 않아요. 표시 시각은 브라우저 현지 시간이고, 방송 달력·기록 집계의 날짜 기준인 한국 시간과 구분해요.

VOD 댓글은 채팅 다시보기 유무와 별개로 표시할 수 있어요. 댓글 없음·댓글 비활성·조회 오류·추가 페이지 오류를 구분해요. 원본 댓글의 동작을 대신 눌러야 할 때는 같은 댓글·같은 조작인지 확인하며 다른 댓글의 버튼에 위임하지 않아요. 한도에 도달한 목록을 전체 댓글을 모두 읽은 결과로 표현하지 않아요.

## 채팅·사이드바 너비·위치·높이

채팅창과 사이드바의 너비 조절은 각각 기본 켜짐이고 다른 채팅·팔로잉 기능과 독립적이에요. 저장된 명시적 꺼짐은 유지해요. 저장된 사용자 지정 너비가 없을 때는 원래 너비에 조절 경계만 제공하며, 활성화만으로 임의의 고정 너비를 만들지 않아요. 저장된 너비가 있으면 새 문서에서 현재 가용 공간에 맞춰 복원해요.

왼쪽은 사이트 전반의 펼친 사이드바 오른쪽 경계, 오른쪽은 일반 라이브·다시보기에서 영상 옆에 표시된 채팅·댓글 왼쪽 경계를 조절해요. 라이브 채팅·다시보기 채팅·댓글·기존 댓글 전용 영역은 하나의 오른쪽 너비를 공유해요. 별도 채팅 팝업·임베드·클립·같이보기 오른쪽 배치는 대상이 아니며, 없는 채팅·댓글을 만들거나 숨긴 영역을 강제로 펼치지 않아요. 아래 위치·높이 규칙은 2026-10-08 사용자 위임에 따라 Claude가 정한 설계이며 개별 항목을 사용자가 확인한 결정은 아니에요([설계 기록](planned-features-design-2026-10-08.md)).

너비는 마우스로만 조절해요. 주 버튼 드래그는 놓을 때 확정하고, 포인터 취소·캡처 소실·창 포커스 이탈·화면 이탈은 시작 전 확정 상태로 되돌려요. 더블클릭하면 해당 영역만 현재 사이트 기본 너비로 돌아가며, 이미 기본 상태여도 이 선택을 저장해요. 방향키·Shift 미세 조절·Enter 복원·Escape 취소는 제공하지 않고 경계는 키보드 초점을 가져가지 않아요. 마우스를 올리거나 드래그하는 동안 경계선 하나만 강조해요. 조절 경계 밖의 채팅 입력·스크롤·영상 조작은 유지해요.

마지막으로 확정한 두 너비는 같은 Chrome 프로필에 각각 계속 저장하며 채널·영상별로 나누지 않아요. 새로고침·새 문서·브라우저 재시작 후 복원하고, 이미 열린 다른 문서의 너비는 바꾸지 않아요. 같은 문서의 페이지 내부 이동·뒤로 가기 캐시 복귀·OFF/ON은 현재 선택을 유지해요. 기능을 끄면 조작과 너비 적용을 정리하되 선택값은 남고, 다시 켜면 현재 공간에 맞춰 복원해요. 미배포 기능의 이전 탭 저장값은 자동 이전하지 않아요. 저장소를 사용할 수 없으면 현재 문서에서만 유지하고 실패한 과거 선택을 자동으로 다시 저장하지 않아요.

채팅 위치(`채팅창 위치`)는 오른쪽(기본)·왼쪽이고, 사이드바 위치(`사이드바 위치`)는 왼쪽(기본)·오른쪽이에요. 둘 다 sync 옵션이며 기본값은 원래 배치예요. 원래 노드를 옮기지 않고 확장 marker로 순서(CSS order)와 좌우 고정 기준·본문 여백 방향만 바꿔요. 채팅 위치는 너비 조절과 같은 가로 배치 조건에서만 적용하고 세로 쌓임·접힘·전체화면에서는 원래 순서예요. 다시보기에서는 채팅·댓글 영역이 영상 아래 정보 줄의 오른쪽 예약 열 위로 약 85px 내려오도록 설계돼 있어, 왼쪽 배치일 때 그 예약 열(폭을 채팅 폭에 맞춤)과 오른쪽 위 배너도 함께 왼쪽으로 옮겨 제목·태그를 가리지 않아요. 같은 쪽에 두면 사이드바가 바깥, 채팅이 안쪽이에요. 오른쪽 사이드바는 원래 본문 여백 크기를 그대로 오른쪽에 두고, 창이 원래 최소 폭(950px)보다 좁아 가로로 넘치면 잠시 왼쪽으로 돌아가요. 1199px 이하 펼침 오버레이의 딤과 접힌 사이드바의 항목 툴팁 영역도 오른쪽 기준으로 미러링해요. 위치를 바꿔도 너비 선택값은 그대로 따라가며, 경계는 영상·본문 쪽 가장자리로 옮기고 그 반대 방향 드래그가 넓히는 방향이에요.

채팅 높이는 채팅·댓글 영역 아래 가장자리를 마우스로 끌어 줄이며 너비 조절 옵션에 포함돼요. 전체화면에서는 좌우 위치와 높이를 원래대로 보여 주고(너비 조절은 기존처럼 유지) 일반 화면으로 돌아오면 선택을 다시 적용해요. 기본은 원래 높이이고 범위는 240px부터 확장이 높이를 지정하지 않았을 때의 원래 표시 높이까지예요. 메시지 목록만 줄고 입력 영역은 유지돼요. 더블클릭하면 기본 높이로 돌아가고, 프로필 local에 너비와 같은 수명 규칙으로 저장해요. 원래 높이보다 크게 저장된 값은 원래 높이로 보여요. 높이 경계도 마우스 전용이며, 키보드 사용자는 옵션의 `저장한 채팅·사이드바 크기 초기화` 버튼으로 너비·높이 선택을 함께 기본으로 되돌려요. 모아보기 상자의 최대 높이(240~720px, 기본 420px)는 별도 옵션이에요.

사용자 선택과 현재 표시 너비는 구분해요. 조절 범위는 사이드바 180~420px, 채팅·댓글 240~640px이고 중앙 콘텐츠에 최소 320px을 남겨요. 한쪽 조절은 다른 쪽의 실제 표시 공간을 유지하며 그 선택값을 바꾸지 않아요. 창이 줄어 두 사용자 지정 영역이 함께 줄어야 하면 각 최소 너비를 초과한 부분을 같은 비율로 줄여요. 최소 공간도 부족하거나 원래 배치가 겹침·세로 쌓임·숨김 상태이면 너비 지정을 일시 해제하고, 넓어졌을 때 저장한 선택을 다시 적용해요. 이 임시 표시 변경을 사용자 선택으로 저장하지 않아요.

## 탐색·방송 정보

영상 검색, 방송 목록 필터와 방송 달력은 조회한 자료 범위만 보여 줘요. 조회 한도나 부분 조회를 전체 자료의 부재로 바꾸지 않아요. 진행률·썸네일·방송 제목·채널 정보는 확인된 값만 사용해요. API 실패와 검색 결과 없음은 다른 상태예요.

방송 목록 검색은 띄어쓰기로 나눈 단어를 모두 포함한 방송만 남기고, `-`로 시작하는 두 글자 이상 단어가 들어간 방송은 빼요. 단어마다 제목·채널명·카테고리 이름·태그·카드 글자 조각 중 한 칸 안에서 대소문자 없이 찾고, 칸 경계를 넘는 일치는 인정하지 않아요. 전체 방송은 Enter로, 카테고리 목록은 입력 뒤 바로 적용하며 검색어는 최대 100자예요.

숫자 조건(팔로워 수, 시청자 수·조회수, 진행 시간)은 종류마다 전체·이상·이하·범위 중 하나예요. 이상·이하의 빠른 값은 옵션 기준값 6개이고, 범위는 양끝을 포함하며 입력 순서와 무관해요. 모드만 고르고 값이 없으면 조건으로 세지 않아요.

검색어나 숫자 조건이 있으면 툴바 줄 아래 적용 조건 줄에 조건 칩·`모두 해제`·`확인한 N개 중 M개`를 보여 줘요. 칩의 `×`와 검색 단어 칩 해제는 Enter 없이 바로 적용하고, `모두 해제`는 검색어와 숫자 조건만 지우며 카테고리·태그 제외와 집계 설정은 그대로 둬요.

2026-10-17 사용자 결정으로 검색어와 숫자 조건은 탭 동안 목록 주소마다 따로 유지해요(사이트 sessionStorage). 방송을 보고 돌아오기·새로고침·기능 OFF→ON에서 같은 주소의 조건을 되살리고, 되살린 뒤 첫 조작 전까지 줄 이름을 `이어서 적용 중`으로 보여요. 경로 이동·도구 해제·기능 OFF 같은 자동 초기화는 기록을 지우지 않고 사용자가 조건을 바꿀 때만 고쳐 써요. 다른 목록 주소와 다른 탭에는 따라가지 않으며 탭을 닫으면 사라져요. Chrome의 탭 복제·닫은 탭 다시 열기는 조건도 함께 되살릴 수 있어요.

카테고리 제외는 방송 목록 검색·필터와 옵션 방송 목록 탭의 `카테고리·태그 제외`(기본 켜짐)가 모두 켜진 전체 방송(`/lives`)의 인기·최신·추천 정렬 버튼과 같은 줄의 오른쪽 제외 박스와 `+ 제외 추가` 팝오버에서 제공해요. 정렬 줄을 찾지 못하면 검색 바 아래 줄에 표시해요. 목록이 비어 있어도 라벨과 추가 버튼은 표시하고, 각 박스의 `×`로 해제해요. 박스에는 이름만 표시하고 유형은 title로 제공해요. 제외 줄은 검색·숫자 필터와 독립된 UI이며 숫자 필터 메뉴·배지와 적용 조건 줄(결과 수 포함)에는 제외 항목만으로 표시를 더하지 않아요. 인기·최신·추천 목록의 원본 카드와 확보한 추가 결과에 함께 적용하며, 목록 검색·숫자 조건을 통과한 방송도 제외 대상이면 표시하지 않아요. 카테고리 라이브·영상·클립, 팔로잉과 재생 화면에는 적용하지 않아요. 전체 방송 집계는 제외 목록과 독립적으로 계산해요.

실제 게임·카테고리를 이름으로 검색하고 결과에서 명시적으로 선택해요. 현재 방송이 없는 게임도 미리 선택할 수 있으며 최대 100개를 보관하고 항목마다 해제해요. 검색어 입력만으로 카테고리를 제외하거나 방송 제목·태그·이름의 부분 일치로 다른 카테고리를 숨기지 않아요. 카테고리 판정은 유형과 ID의 정확한 쌍을 사용하고 ID의 대소문자를 구분해요. 카테고리 정체성을 확인하지 못하면 이름을 대체 근거로 쓰지 않아요.

태그 제외는 스트리머가 방송에 붙인 태그 단어를 직접 입력하고 Enter를 눌러 추가해요. 카테고리 검색 결과가 없어도 추가되며, 앞의 `#`·연속 공백·대소문자만 무시하고 태그 전체가 같은 방송만 숨겨요. 단어가 포함된 더 긴 태그나 제목·카테고리 이름은 숨기지 않아요. 한글 조합을 확정하는 Enter·누르고 있는 Enter는 추가하지 않아요. 태그도 카테고리와 같은 100개 한도·개별 해제·프로필 보관을 따라요.

선택 목록은 같은 Chrome 프로필의 이 기기에 계속 보관하고 다른 열린 전체 방송 탭에도 바로 반영해요. 추가 패널 닫기·검색어 변경·페이지 내부 이동·OFF/ON·탭 종료·새로고침·브라우저 재시작으로 선택을 지우지 않아요. `필터 초기화`는 팔로워 수·시청자 수/조회수·진행 시간의 숫자 조건만 해제하고 제외 목록은 남겨요. 숫자 조건이 없으면 초기화 버튼은 비활성화하고, 초기화 뒤 키보드 초점은 메뉴의 첫 조건 버튼에 남겨요.

검색 중·검색 결과 없음·검색 실패와 제외 목록 읽기·저장 실패를 구분해요. 읽기 실패나 손상 자료를 빈 목록으로 저장하지 않고, 저장 성공 전에 제외·해제 완료로 표시하지 않아요. 한도에 도달하면 기존 선택은 유지하며 새 항목 추가만 거절해요. 검색어·검색 결과는 영구 저장하지 않고 선택 목록 전체를 서버로 보내지 않아요.

방송 통계의 최근 일평균은 조회한 다시보기 중 기간과 겹치는 방송 시간의 합을 선택한 기간의 일수로 나눠요. 방송한 날만을 분모로 삼는 평균과 구분해요. 다시보기가 없는 방송까지 완전하게 파악한 총 방송시간으로 약속하지 않아요.

여러 날에 걸친 방송은 한국 날짜별로 겹치는 구간을 달력에 반영해요. 종료가 정확히 자정이면 다음 날 방송으로 세지 않아요. 여러 VOD로 분할된 같은 방송의 연결 정보와 시간축을 검증하고 합치며, 제목이 같다는 이유만으로 다른 방송을 합치지 않아요.

전체 방송 집계 표시는 검색·필터와 독립적으로 켜고 꺼요. 새 설치에서는 꺼져 있고, 기존 버전에서 업데이트할 때는 이전 표시 여부를 한 번 이어받아요. 이후 검색·필터를 바꿔도 집계 설정은 바뀌지 않아요. 집계만 켜면 검색창·필터·카드 배지 없이 전체 방송 목록 상단에 방송 수와 시청자 합계만 표시해요.

전체 라이브 목록의 집계는 시청자 10명 이상인 방송 범위를 표시해요. 이 숫자를 플랫폼 전체 방송·시청자의 완전한 총계라고 부르지 않아요. 팔로워 정보가 아직 도착하지 않았거나 조회에 실패한 상태도 실제 0명과 구분해요.

팔로잉 고정·오프라인 숨김·목록 접기 기억·폴더는 서로 독립적이에요. 고정은 표시 순서를 조절하며 실제 팔로우 관계를 변경하지 않아요. 제목 이력은 채널만이 아니라 현재 방송 정체성까지 확인하고, 새 방송에는 이전 방송의 제목을 이어 붙이지 않아요. 2026-10-12 사용자 결정으로 팔로잉 라이브 제목 이력의 목적은 팔로우한 채널의 방제를 놓치지 않는 것이에요. 팔로잉 화면을 열었을 때만 모으지 않고, 브라우저가 켜져 있는 동안 팔로잉 라이브 목록 한 번(채널 수와 무관)을 1분마다 조회해 공백만 정리한 원문 제목으로 비교해요. 한 글자·이모지·기호 변경도 새 방제이고, 같은 방송에서 예전 제목으로 돌아가도 순서대로 남겨요. 시청 기록용 제목 정리(치지직 접미사·채널명 접두사 제거)는 실제 변경을 지울 수 있어 쓰지 않아요. 보기는 다시보기의 이전 방제와 같은 버튼·패널로 제목 오른쪽에서 펼치며 현재 제목과 같은 줄은 빼요. 사용자가 처음 원한 자리는 방송을 볼 때의 방송 제목 오른쪽이었는데 1.4.4에는 팔로잉 본문 카드에만 들어갔어요. 2026-10-20 사용자 확인으로 라이브 시청 화면의 방송 제목 오른쪽을 주 위치로 더했고, 팔로잉 본문 카드의 버튼은 함께 유지해요(제거 여부는 사용자가 정하지 않아 기존 동작을 남겼어요). 1분 안에 두 번 바뀐 중간 제목, 브라우저가 꺼져 있거나 로그아웃된 동안은 기록되지 않는다는 한계를 사용자에게 알렸어요(채널별 30초 조회는 요청이 채널 수만큼 늘어 택하지 않았어요).

스트림 정보의 비트레이트는 API가 제공한 현재 해상도의 설정값이며 실제 전송 속도가 아니에요. WebGL 렌더러로 추정한 가속 상태도 영상 디코더의 사용 여부를 확정하지 않아요. 확인할 수 없는 측정값은 측정 불가로 표시해요.

일반 라이브의 스트림 정보는 현재 선택된 재생 방식, 라이브 지연 추정·버퍼의 최근 60초 변화, 관측한 끊김·프레임 누락을 함께 보여 줘요. 저지연 설정값이나 과거 적용 성공을 현재 재생 방식으로 대신하지 않아요. 지연은 플레이어의 라이브 끝을 기준으로 한 추정이며 촬영부터 화면까지의 전체 지연이 아니에요. 낮은 지연만으로 안정성이 좋아졌다는 점수·판정을 만들지 않아요.

측정은 패널이 열려 있고 탭이 보이는 동안만 하며 실제 관측 시간도 표시해요. 일시정지·탐색·광고·영상 전환·숨김은 끊김으로 세지 않고, 자료가 없으면 실제 0과 구분해요. 같은 방송으로 확인된 재생 전환은 패널과 최근 자료를 유지하되 그래프를 끊어요. 방송이 다르거나 교체한 영상의 방송을 확인하지 못하면 새 기록을 시작해요. 닫으면 메모리의 측정 자료를 폐기하고 시청 기록이나 저장소에 남기지 않아요. 측정을 위해 재생·화질·배속·시청 위치를 바꾸지 않아요.

## 시청 기록과 내 활동

시청 시간은 실제 미디어 시간이 전진하는 동안의 경과 시간을 기록해요. 탭을 열어 둔 시간, 일시정지·버퍼링 시간이나 탐색으로 건너뛴 영상 길이를 시청 시간으로 더하지 않아요. 재생 배속만큼 벽시계 시간을 곱하지 않아요.

각 방송의 세션은 누적 스냅샷으로 갱신하고 같은 스냅샷을 다시 받았다고 시간을 더하지 않아요. 전체·월별·일별 합계는 해당 범위에 들어오는 유효한 시청 시간대를 합쳐 동시 시청 구간을 중복 계산하지 않아요. 시간대가 없는 과거 기록의 누적값은 보존하며 정밀한 동시 시청 복원이 가능하다고 주장하지 않아요.

방송 정보가 늦게 오면 임시 기록을 실제 방송 기록으로 연결하되 이중 집계하지 않아요. 이전 화면에 남은 제목은 검증된 제목 이력으로 저장하지 않아요. 같은 채널에서 새 방송이 시작되면 별개 방송으로 나눠요. 삭제 이후 도착한 옛 저장 요청은 삭제 기록을 되살리지 않으며, 삭제 후 새로 시작한 시청·활동은 기록할 수 있어요.

내 채팅과 일반 후원 기록은 라이브 시청 기록과 별도로 각각 켜야 해요. 확인된 새 본인 활동은 최소 시청 시간에 미달하거나 영상이 일시정지돼 있어도 저장할 수 있어요. 다른 사람·과거 활동·익명 후원·미션·구독 결제를 실시간 일반 후원으로 추정해 저장하지 않아요.

활동 본문은 보관 상한 때문에 지워질 수 있고 집계는 남을 수 있어요. 집계가 남았는데 본문이 없다는 이유로 활동이 없었다고 표시하지 않아요.

과거 일반 후원 갱신은 사용자가 실행할 때만 이뤄져요. 처음에는 지원하는 전체 기간, 이후에는 마지막 조회 당시 진행 중이던 달·새 달·미조회 달을 조회해요. 완결된 과거 달은 반복 조회하지 않아요. 계정 변경·취소·불완전한 페이지·보관 한도 초과는 완료된 갱신으로 저장하지 않아요.

갱신한 월의 조회 시작 시점까지는 사용 내역을 기준으로, 그 이후는 실시간 후원을 더해 표시해요. 원본 실시간 기록을 삭제해 중복을 숨기지 않아요. 같은 금액·내용의 별개 후원은 유지하고, 가져온 내역에서 시청 세션을 만들어 내지 않아요. 이 기능은 후원·결제·환불을 실행하지 않아요.

## 시청 기록 파일 백업

전체 기간의 시청 기록과 내 채팅을 기록 페이지에서 JSON 파일로 저장하고 불러와요. 현재 화면의 검색·월·선택 상태는 범위를 제한하지 않아요. 실시간 후원과 치지직에서 조회한 후원은 모두 제외해요. 후원은 별도로 다시 조회할 수 있고, 백업의 목적은 확장이 따로 보관한 시청·채팅을 보존하는 것이에요. 옵션 페이지는 실제 조작이 가능한 기록 페이지를 안내해요.

파일을 선택하면 적용 결과를 먼저 보여주고 확인 후 현재 기록에 합쳐요. 전체 교체는 제공하지 않아요. 같은 백업을 반복 적용해도 중복 누적하지 않으며 파일에 없는 현재 기록과 모든 현재 후원은 보존해요. 상세가 정리돼 중복을 증명할 수 없는 기존 방송은 추정 합산하지 않고 건너뛴 이유를 보여줘요. 현재에 없는 정상 과거 합계는 그대로 추가할 수 있어요.

삭제했던 자료는 파일에 실제 들어 있는 시청·채팅만 안내 후 복원해요. 이 예외가 일반 늦은 저장 요청이나 파일 밖의 세션·후원으로 넓어지면 안 돼요. 미리보기 후 삭제·충돌 등 확인할 의미가 바뀌면 다시 확인하고, 불완전 파일·보관 한도·저장 실패에서는 부분 반영하지 않아요. 자동 백업은 하지 않으며 기기에 저장된 파일은 사용자가 보관·삭제해요.

## 방송 알림·자동 입장

처음 켜거나 브라우저를 시작할 때 이미 진행 중인 방송은 기준 상태로 기억하며 알림·자동 입장을 실행하지 않아요. 이후 새 방송을 확인하면 채널별로 선택한 동작을 수행해요. 데스크톱 알림과 자동 입장은 각각 켜고 끌 수 있고, 헤더 등록 버튼을 숨겨도 등록한 동작은 유지돼요.

이미 열린 동일 채널의 방송·대기 탭이 있으면 자동 입장은 새 탭을 만들거나 기존 탭을 앞으로 가져오지 않아요. 알림을 직접 클릭하면 해당 탭을 활성화하거나 새 탭으로 이동해요.

동작 전에 방송별 처리 상태를 저장해 중복 방지를 우선해요. 저장 실패 시 동작을 실행하지 않고, 저장 후 알림·탭 열기가 실패하더라도 같은 방송을 자동 재시도하는 보장은 하지 않아요. 상태 보관에는 상한이 있으므로 무기한 정확히 한 번의 전달을 보장한다고 표현하지 않아요.

## 광고·팝업·보상

동영상 광고 차단은 현재 기본 켜짐인 공개 실험 기능이에요. 확인된 광고 응답·소스·스케줄만 처리하고 알 수 없는 형식은 통과시켜요. 본영상에 포함된 광고 제거 또는 모든 광고 차단을 보장하지 않아요. 켜고 저장한 뒤 초기 주입을 적용하려면 새로고침이 필요하며 자동으로 새로고침하지 않아요.

본영상 재생을 우선해요. 필수 광고 계약·현재 소유 관계가 유지되는 새 ID와 부가 필드는 처리하지만, 계정의 `adFree`·구독 상태와 일반 재생 정보는 바꾸지 않아요. 명시적 표시 응답은 프리롤·미드롤 boolean만 끄고 나머지는 보존해요. 직접 소스는 최초 네이티브 초기화 전에만 판단하며, 이미 원본 초기화를 시작한 소스를 재연결·반복 설정으로 다시 끊지 않아요.

본방송 상태를 연결하는 라이브 바깥 객체와 별도 광고 요청을 구분해요. 독립 입장·중간 일정은 현재 광고 컴포넌트의 소유를 확인하고 각 항목의 광고 소스 목록만 비워요. 일정 항목·순서·시간·원본을 유지하고 완료는 네이티브에 맡겨요. 별도 광고용 `contentVideo`를 본영상 슬롯으로 간주하지 않아요. JSON 판단 경로를 지나지 않아도 지원 SDK 경계에 도달하면 그곳에서 처리하고, 어떤 지원 경계에도 도달하지 않으면 현재는 원본 통과예요. 자동 완료 모델을 실제 Chrome의 본영상 진행 성공으로 보고하지 않아요.

치지직 안의 라이브 PiP로 같은 방송을 계속 시청할 때는 홈·목록으로 이동해도 확인된 중간 광고 일정 처리를 이어가요. 현재 라이브 본영상과 광고 영역이 연결된 경우로 한정하고 목록 미리보기나 다른 보조 영상까지 확대하지 않아요. PiP 종료·영상 교체·등록 해제 뒤에는 과거의 소유 관계를 허용 근거로 쓰지 않아요.

광고 차단 안내와 고화질 설치 안내는 저장된 팝업 옵션을 읽은 뒤, 확인된 화면의 표시된 활성 버튼으로 처리해요. 고화질 설치 안내는 실측한 두 대상(네이버 라이브 스트리밍 커넥터, 크롬·엣지의 브라우저 확장 프로그램)과 현재 공개 코드의 일반/기본 화질 분기를 구분해, 문단·설치·미설치 선택이 같은 조합일 때만 미설치 시청을 선택해요. 2026-10-17 사용자 요청에 따라 제한된 문구·중립 래퍼 변경도 지원하지만 다른 서비스·모달·추가 동작·숨은 근거는 허용하지 않아요. 닫을 수 없는 안내를 계속 숨기거나 같은 표시 상태에서 반복 클릭하지 않아요. 광고 차단과 화질 설정은 독립적인 선택이에요.

2026-10-11 사용자 결정: 일부 환경에서 방송에 들어갈 때 뜨는 확인 버튼 하나짜리 안내도 같은 `시청 방해 팝업 제거` 옵션으로 닫아요. 확인 버튼에 연결된 치지직의 확인 동작이 실측한 형태일 때만 한 번 실행해 안내 표시만 꺼요. 재생·화질 상태와 다른 모달은 바꾸지 않으며, 닫혔다고 재생 문제가 해결됐다고 보지 않아요. 확인할 수 없는 구조나 같은 경로에서 반복해 다시 뜨는 안내는 직접 확인할 수 있게 남겨요. 같은 날 사용자 보고에 따라 입장 시 깜빡임을 줄이려고, 이 안내는 표시 여부가 아니라 정확한 안내와 현재 확인 동작의 존재로 판단하고 치지직이 실제로 제거할 때까지 잠시 가려요. 1초 안에 제거되지 않거나 실행할 수 없으면 다시 보여 직접 확인하게 해요.

2026-10-17 보강은 확인형 안내의 식별자·도움말·현재 React 연결을 유지하며, 같은 신뢰 조건 뒤 단일 false 호출의 제한된 표현 차이만 허용해요. 영상 광고도 현재 소유가 검증된 인접 ref 쌍의 제한된 위치 변경만 처리해요. 본영상 재생을 우선하며 확인 불가한 변화를 추측해 승인하지 않아요. 근거·합성 변형·검증 범위는 [보강 기록](measurements/ad-popup-resilience-2026-10-17.md)에 구분해요.

통나무 자동 받기는 확인된 수령 버튼·서버 claim만 처리해요. 1시간 시청 보상은 페이지의 버튼 흐름을 사용하고, 구독·팔로우·로그인·결제 행동을 수령 동작으로 대신 실행하지 않아요.

## 멀티뷰와 미리보기

미리보기와 보조 영상은 실제 제공된 재생 소스를 사용해요. 실패 시 새 창·iframe·원격 플레이어 실행으로 바꾸지 않아요. 사용자가 누른 채널 홈 링크의 새 탭 이동은 재생 실패 대체 경로와 구분해요.

## 앰비언트 효과

2026-10-08 사용자 결정: 라이브·다시보기의 메인 영상 색을 플레이어 바깥으로 번지게 해 채팅창과 사이드바 가장자리까지 약간 침투하는 경계 없는 느낌을 만들어요. 기본 꺼짐이고 켜기·끄기와 강도 슬라이더(10~100%, 기본 60%)를 제공해요. 강도는 밝기만 바꾸며 번지는 범위는 고정이에요. 라이트·다크 두 테마 모두 적용하고, 다크는 배경을 밝히는 합성, 라이트는 흰 배경을 영상 색으로 물들이는 합성을 사용해요.

효과는 영상 화면·플레이어 조작부를 덮지 않고 입력을 가로채지 않아요. 상단 헤더에도 채팅·사이드바와 같은 방식으로 번져요(2026-10-08 사용자 요청). 스크롤로 플레이어가 헤더 밑에 들어가도 플레이어 영역은 비워 두고 바깥 번짐만 헤더에 남겨요. 원본 헤더·채팅·사이드바 노드의 스타일을 바꾸지 않고 확장 소유 레이어만 그 위에 겹쳐요. 영상 픽셀 값을 읽거나 저장·전송하지 않으며 화면에 그린 축소 이미지만 사용해요. 전체 화면·숨긴 탭·화면 밖 플레이어에서는 표시와 갱신을 멈추고, 방송 이동·영상 소스 교체 때 이전 방송의 색을 남기지 않아요. 라이트 테마의 어두운 장면에서 효과가 회색 그림자처럼 보이는 표현은 2026-10-08 사용자가 확인하고 그대로 두기로 했어요. 번짐 폭은 첫 실측(100% 기준 사이드바 약 70~90px, 채팅 약 60px)의 두 배를 목표로 같은 날 넓혔어요. 설정이 켜져 있으면 플레이어 톱니바퀴 기본 메뉴에 켜기·끄기 스위치와 세기 슬라이더를 제공해요(2026-10-08 사용자 결정). 한 줄의 오른쪽 스위치가 켜기·끄기를 맡고, 세기 슬라이더는 기본으로 접혀 있다가 `앰비언트` 글자를 누르면 그 아래에 펼쳐져요. 펼침 상태는 현재 문서에서만 유지해요. 설정의 앰비언트 효과는 이 조절 메뉴를 포함한 기능 전체의 스위치이고, 플레이어 스위치는 효과 표시만 끄며 그 선택을 Chrome 프로필 local에 계속 기억해 다른 탭에도 반영해요. 플레이어 세기는 설정의 효과 강도와 같은 sync 값을 바꾸고 조절이 멈춘 뒤 저장해요. 라이브 멀티뷰를 켠 동안에는 효과를 표시하지 않아요(2026-10-08 사용자 결정). 화면이 여러 영상으로 나뉘어 번질 하나의 경계가 없고, 번짐이 보조 영상을 덮지 않게 하기 위해서예요. 2026-10-08 실제 Chrome 관찰과 남은 미검증 범위는 [앰비언트 실측](measurements/ambient-glow-2026-10-08.md)에 있어요.

폴더로`(그 채널로 새 폴더)에 놓아요. 사이드바를 벗어나면 기존 링크 드래그(영상 멀티뷰 추가 등)로 동작하며 확장은 그 링크 데이터를 바꾸지 않아요. 접기는 화살표가 바로, 이름 한 번 클릭은 더블클릭과 구분하려고 약 0.25초 기다린 뒤 해요(사용자 선택 (가)). 2026-10-13 사용자 요청으로 이름 옆 빈 공간(머리 행 여백)을 눌러도 화살표처럼 바로 접고 펼쳐요. 이름 입력 중에는 접지 않아요. 폴더 이름을 끌어 순서를 바꾸고, 머리의 ⋯ 메뉴(이름 변경·채널 선택·위·아래 이동·새 폴더 만들기·두 번 눌러 삭제)와 채널 선택 창(체크로 넣기·빼기)이 키보드 경로예요. 변경 직후 5초 동안 되돌리기를 제공하되(안내는 열린 메뉴·채널 선택 창과 실제로 겹칠 때만 옆으로 비켜요), 그사이 다른 곳에서 바뀌었으면 덮어쓰지 않아요. 같은 날 사용자 요청으로 끄는 동안의 체감을 높였어요. 아바타·이름 카드가 브라우저 드래그 그림으로 따라오고(링크 데이터는 그대로), 대상 폴더에 채널이 실제로 들어갈 자리(자동 정렬 기준)를 미리 보여 주며 다른 행·폴더 묶음이 미끄러지듯 비켜나요(원본 행 속성을 쓰지 않는 Web Animations, 동작 줄이기 설정이면 생략). 접힌 폴더 위에 약 0.5초 머물면 저장하지 않고 펼쳐 보이고, 거기에 놓으면 펼친 상태도 저장해요. 놓은 변경은 저장 응답을 기다리지 않고 먼저 보이며 실패하면 확인한 상태로 되돌리고 알려요. 쓰기 기대값은 언제나 확인한 원본이에요. 미리보기는 새 대상 위에 약 0.12초 머물러야 바뀌고, 바뀐 직후 행이 비켜나는 동안이나 커서가 거의 움직이지 않은 동안에는 다음 대상으로 넘어가지 않아요(같은 날 사용자 보고: 빠르게 지나갈 때 번쩍임, 가만히 있는 커서 밑 대상이 바뀌며 흔들림). 치지직 행 사이 3px 틈이나 채널이 아닌 행 위는 대상을 바꾸지 않아요(2026-10-12 사용자 보고: 다른 폴더 안에서 움직이면 미리보기가 깜빡임). 놓을 때는 화면에 보이는 대상을 우선해요. 폰 홈 화면처럼 행 자체가 손에 붙어 움직이는 직접 그리기 방식은 사이드바 밖 링크 드래그와 함께 쓸 수 없어 택하지 않았어요. 팔로잉 링크를 끄는 동안에는 사이드바 행의 치지직 방송 제목 툴팁을 감춰요(끄는 동안 행을 떠났다는 신호가 오지 않아 남던 문제). 아이콘만 보이는 접힌 사이드바에서는 폴더 놓기 대상을 두지 않아요. 폴더 안에서는 고정 규칙을 따르고 폴더 밖 채널은 마지막에 남아요. 폴더 삭제는 지정만 지우며 실제 팔로우를 바꾸지 않아요. 원본 목록이 접혀 렌더링되지 않은 채널은 보이는 채널만 묶어요. 2026-10-13 사용자 보고(목록을 접은 상태에서 폴더를 펼쳐도 채널이 안 보임)와 선택에 따라, 펼친 폴더(새로고침 뒤 이미 펼쳐진 폴더 포함)의 채널이 원본 목록에 없으면 원본 `더보기`를 대신 눌러요. 원본 목록은 접힌 5개에서 `더보기`마다 50개씩 늘고 최대 505개라, 같은 날 사용자 요청으로 그 채널이 나올 때까지 치지직 상한까지 눌러요. 원본 목록 새로고침(팔로잉 자동 새로고침 포함)은 첫 `더보기` 때의 55개로 다시 자르므로 줄면 바로 다시 펼쳐요(사용자가 맡긴 Claude 추천). 이 다시 펼침은 행 변화 알림 안에서 이어 눌러 줄어든 목록이 그려지기 전에 끝내요. 끝까지 펼쳐도 없는 채널(팔로우 해제·505개 밖)은 다시 펼칠 이유로 삼지 않아요. 끄는 중·이름 입력 중에는 누르지 않아요. 사용자가 원본 `접기`를 직접 누르면 다음에 폴더를 펼칠 때까지 다시 누르지 않아요. 팔로잉 목록 상태 기억이 켜져 있으면 끝까지 펼친 상태도 직접 누른 선택처럼 기억돼요. 저장은 Chrome sync이며 다른 탭이 먼저 바꾼 상태는 덮지 않고 최신 상태로 다시 계산해요. 팔로잉 목록 최대 줄 수(0=제한 없음, 최대 30)는 원본 행을 숨기지 않고 목록 안 스크롤로만 제한해요. 세부 구현 경계는 폴더 담당 파일과 [설계 기록](planned-features-design-2026-10-08.md)을 따라요.

## 채팅 멀티뷰

기본 꺼짐이에요. 켜면 치지직 상단의 `채팅 멀티뷰` 버튼으로 다른 채널의 채팅을 최대 4개까지 한 패널에서 봐요. 2026-10-12 사용자 요청으로 칸에는 채널 이름과 채팅만 보이고 패널 안쪽·칸 사이 여백을 4px로 줄였어요. 조작(채팅 크기, 채널 추가, 설정, 닫기, 칸 순서·제거·다시 시도, 크기 조절 손잡이)은 마우스를 패널·칸에 올리거나 키보드 초점이 들어왔을 때만 보여요. 조작 막대는 패널 바로 위에 떠서 채팅을 가리지 않으며, 그 자리를 위해 패널 높이 상한에서 40px를 비워 둬요. 칸의 네이티브 머리(제목·채팅 크기·메뉴)·배너·주간 랭킹·후원 버튼은 숨겨요. 채팅 입력창은 멀티뷰 설정의 `채팅 입력창`(기본 꺼짐)으로 켜고, 켜도 후원 버튼은 숨겨요. 채팅 크기(70~150%, 10% 단위)는 조작 막대에서 바꾸며 모든 칸에 같게 적용되고 구성과 함께 저장돼요. 치지직 칸의 채팅 크기 버튼은 확장이 대신 누르지 않으므로 프레임 바깥 배율로만 키우거나 줄여요. 같은 날 후속 요청(프리셋의 칸이 너무 넓음, 잡아서 옮기기)으로 크기는 채팅 한 칸의 크기가 됐어요. 설정의 `채팅 칸 크기`는 작게 280×480·보통 340×600·크게 420×760px이고, 패널은 칸 수만큼만 커져서 채널이 적어도 칸이 넓게 늘어나지 않아요. 한 줄에 다 들어가지 않으면 줄마다 칸 수를 고르게 나눠 여러 줄로 놓고, 화면보다 크면 화면에 맞춘 뒤 최소 크기 아래로는 칸을 줄이지 않고 패널 안에서 스크롤해요. 각 칸의 최소 크기는 입력창을 켜면 340×320px(네이티브 입력이 잘리지 않는 크기), 끄면 240×180px이고 채팅 크기 비율만큼 키워요. 칸 머리(채널 이름 줄)를 잡고 끌면 패널 전체가 따라오고, 놓은 곳에서 가장 가까운 화면 모서리와 그 거리를 저장해 창 크기가 바뀌어도 그 모서리에 붙어 있어요. 크기 조절 손잡이는 붙인 모서리의 반대쪽 모서리에 있고 끄는 만큼 칸 크기를 바꿔 저장해요. 설정의 `패널 위치` 버튼은 왼쪽·오른쪽 아래로 되돌려요. 배치 변경은 CSS 그리드 값만 바꾸며 채팅 프레임을 옮기거나 다시 불러오지 않아요(2026-10-09 Codex 실측의 약 225px 칸 잘림 보완). 채널 추가는 영상 멀티뷰와 같은 방식이에요(2026-10-11 사용자 요청으로 통일). 조작 막대의 `채널 추가`가 여는 시트에서 채널명 검색 결과 행 전체가 추가 버튼이고 방송 중 여부·팔로워 수와 추가·추가됨·가득 참 상태를 보여 주며, 채널 주소·ID 입력이나 팔로잉 채널 링크를 패널에 끌어 놓아도 같은 채널 조회로 확인해 추가해요. 채팅이 하나도 없으면 추가 시트를 펼쳐 둬요. 칸이 패널을 넘치면 그리드 스크롤바를 항상 보이고, 조작 막대에 이전·다음 버튼과 채널 이름 버튼(지금 보이는 칸 강조, 누르면 그 칸으로 이동)을 더해요. 이동은 그리드 스크롤만 바꿔요. 각 칸은 치지직이 제공하는 같은 출처 채팅 팝업 화면(`/live/{채널}/chat`)이고 칸 머리의 채널 이름이 입력 대상이에요. 로그인·작성 권한·입력은 각 칸의 치지직 화면이 소유해요. 사이트 응답의 `frame-ancestors 'self'` 정책을 근거로 하며([근거](measurements/chat-multiview-frame-policy-2026-10-08.md)), 불러오지 못하면 그 칸에만 실패를 보여 주고 새 창·새 탭·원격 플레이어로 대체하지 않아요. 확장 기능은 칸 안에서 실행되지 않으므로 칸에서 보낸 채팅은 내 채팅 기록에 들어가지 않아요. 구성·크기·위치·입력창 표시·채팅 크기는 기기 local에 남지만 열림 상태는 저장하지 않아 새로고침이 칸을 자동으로 다시 열지 않아요. 영상 멀티뷰와 독립이며, 채널 페이지의 `채팅` 링크는 현재 탭을 그 채널 라이브 화면으로 옮기는 별개 기능이에요.

## 설정 파일 저장·불러오기

옵션 헤더 더보기의 `설정 파일 저장`·`설정 파일 불러오기`로 설정을 JSON 파일로 옮기거나 복원해요. 포함 범위는 sync 옵션 전체, 팔로잉 고정·폴더, 채팅·사이드바 크기, 방송 알림·자동 입장 대상, 멀티뷰 채널별 딜레이·보조 화질, 채팅 멀티뷰 구성이에요. 시청·채팅·후원 기록, 방송 처리 상태, 새 기능 안내 상태, 컴프레서 선택, 앰비언트 플레이어 끔 선택, 옵션 화면 상태, 사이트 sessionStorage, 권한 승인 상태, 로그인 정보와 카테고리·태그 제외는 넣지 않아요.

파일을 고르면 바뀌는 구역을 먼저 보여 주고 확인해야 적용해요. 미리보기와 파일 읽기는 아무것도 저장하지 않아요. 저장하지 않은 옵션 변경이 있으면 시작하지 않고, 불러오는 동안 옵션 폼 편집은 잠겨요. 파일에 없는 구역은 현재 값을 유지하고 멀티뷰 값은 파일에 있는 채널만 바꿔요. 같은 파일을 다시 적용해도 바뀌는 것이 없어요. 미리보기 뒤 다른 곳에서 대상 값이 바뀌면 다시 확인을 요구해요. 저장은 다른 탭·옵션 페이지와 같은 설정 저장 잠금 안에서 한 번에 진행하며, 중간 실패 시 앞 단계를 되돌리고 되돌리지 못한 구역과 다른 곳에서 바뀐 구역을 나눠 알려요. 알림·자동 입장·기록 같은 효과 옵션은 끄는 쪽을 먼저, 켜는 쪽을 마지막에 적용하고, 복원한 방송 대상의 진행 중 방송은 알림·자동 입장 없이 기준으로만 기억해요. 알림·영상 호스트 권한은 파일이 꺼짐→켜짐으로 바꾸는 기능에만 적용 버튼에서 요청하고, 거부하면 아무것도 바꾸지 않으며 `(기능 이름) 기능은 켜지 않고 불러오기`를 따로 고를 수 있어요. 이때 파일이 켜려던 그 기능만 켜지 않고 현재 켜진 기능은 그대로 둬요. 멀티뷰 딜레이·화질은 각각 설정을 저장한 채널 4000개까지 내보내고 다시 읽으며, 넘는 구역은 일부만 넣지 않고 통째로 빼서 알려요.

## 화면 디자인

확장 화면은 치지직과 한 몸처럼 보이게 해요(2026-10-17 사용자 결정). 설정 화면·시청 기록·다시보기 대기 화면은 치지직 실측 색·모서리·그림자 값을 정적 토큰으로 쓰고, 치지직 안 확장 UI는 `shared/uiTheme.js`의 `--bct-*` 변수로 치지직 `--sem-*` 토큰을 따라가요. 확장 고유 브랜드 색이나 예전 중립 회색 팔레트로 되돌리지 않아요. 헤더에는 확장 자체 로고·이름을 두고 치지직 로고·이름은 쓰지 않아요.

설정 화면과 시청 기록은 사용자가 고른 시안 A 구조를 유지해요. 설정은 위쪽 분류 칩, 접히는 묶음 카드, 하단 저장 막대예요. 기록은 왼쪽 달력·요약, 오른쪽 목록, 아래 백업·관리예요. 치지직 안 패널은 배치를 바꾸지 않고 모양만 맞추며, 예전에 사용자가 정한 세부(채팅 멀티뷰 4px 여백·마우스 올림 조작, 폴더 조작, 기록 순위 막대, 미리보기 진행 시간)를 유지해요.

글꼴은 두 분류예요. 확장 소유 패널·툴팁은 번들 Pretendard를 써요. 치지직 글꼴을 따르도록 만든 화면(월간 방송 달력, 방송 목록 필터 배지·바, 플레이어 버튼 툴팁, 다시보기 댓글·탭, 멀티뷰 안내·조작, 지연 표시)과 원본 사이에 끼워 넣는 요소는 원본 글꼴을 유지해요. 썸네일·영상 위 표시는 테마와 무관한 고정 색을 유지해요.

화면 문구는 해요체로 써요. 다시보기 댓글 본문 자리의 치지직 원본 흉내 문구(`삭제된 댓글입니다.`, `내용을 표시할 수 없는 댓글입니다.`, `클린봇이 부적절한 표현을 감지한 댓글입니다.`)는 원래 말투를 유지해요. 문서(README·PRIVACY·스토어·업데이트 내역)의 문체는 별도예요.

시청 기록 목록은 채널 줄 앞에 치지직 공개 프로필 사진을 보여 줘요. 조회 실패·주소 없음이면 대체 그림 없이 글자만 보이고, 기록에 없는 '방송 중' 같은 상태는 표시하지 않아요.

## 계획된 범위

2026-10-08에 채팅·사이드바 위치·높이, 팔로잉 폴더, 채팅 멀티뷰, 설정 파일 저장·불러오기를 구현했어요(실제 Chrome 확인 전). 사용자 글꼴 선택은 계획에서 제외해요. 현재 확장 UI에 포함된 글꼴은 사용자 글꼴 선택 기능과 별개예요.

## 버전별 새 기능 안내

업데이트한 사용자가 새 기능을 발견하도록 버전마다 작은 안내를 한 번 표시해요. 새 설치·동일 버전 재로드·브라우저 업데이트·다운그레이드는 새 안내를 만들지 않아요. 이미 대기 중인 동일 버전 안내는 재로드만으로 삭제하지 않아요. 건너뛴 버전은 누적하지 않고 현재 설치 버전과 일치하는 안내만 제공해요.

자동 안내와 수동 다시보기는 같은 한 창에 두 기능을 동시에 표시해요. 1.4.1 헤더는 “치즈 스패너 1.4.1 새 기능”이며 채팅창·사이드바 크기 조절과 시청기록 백업·불러오기만 소개해요. 크기 조절은 제목과 조작 문장 하나로 구성하고, 시청기록은 제목만 표시해요. 스트림 정보 소개는 넣지 않아요. 페이지 넘김·별도 상세 열기·설정 이동 버튼·위치 강조를 제공하지 않고 닫기 버튼 하나만 표시해요.

기본 켜짐이며 화면 정리의 새 기능 안내에서 끌 수 있어요. OFF로 지나간 안내를 ON 전환으로 소급하지 않아요. 안내 상태는 Chrome 프로필의 기기 local에 보관하고 탭 전체에서 한 번만 표시해요. 표시 직전 저장에 성공한 경우만 허용하며, 저장 직후 문서가 종료돼 못 보여준 극단적 구간은 재알림 대신 수동 다시보기를 남겨요. 반복 팝업으로 시청을 방해하지 않는 것을 우선한 선택이에요.

자동 안내는 활성 최상위 치지직 문서에서 준비 후 표시해요. 숨김·전체화면·편집 입력 중이나 영상 중앙·컨트롤·입력창을 피할 공간이 없으면 소비 전에 기다려요. 자동 안내와 수동 다시보기 모두 상단의 2px 민트색 게이지가 20초의 남은 표시 시간에 맞춰 줄어들고, 호버·내부 키보드 초점 동안 타이머와 함께 멈춰요. 이미 표시한 안내는 다른 창이나 탭으로 옮겨도 유지하고, 남은 시간과 게이지는 치지직 문서가 다시 보이고 초점을 얻을 때 이어가요. 동작 줄이기를 사용하면 게이지는 1초 단위로 줄어들어요. 다시 열면 새 20초로 시작하고 게이지 생성 실패가 자동 닫힘을 막지 않아요. 시청 페이지 이동·전체화면 등으로 닫힌 뒤에는 같은 버전을 다시 자동 표시하지 않아요.

1.4.1의 크기 조절 설명은 “경계 드래그로 조절, 더블클릭으로 초기화.”이고 백업은 “시청기록 백업 및 불러오기” 제목만 표시하며 설명용 빈 줄도 만들지 않아요. 설명을 과하게 줄바꿈시키는 좁은 세로 배치를 피하고 두 항목을 같은 정렬선에 놓아요. 라이트·다크 테마에 맞는 배경과 제목·설명 색을 구분하고 민트색 상단 경계로 강조해요. 안내는 페이지를 어둡게 가리거나 재생·스크롤·설정·백업을 자동 조작하지 않아요. 다시보기를 열 때 제목에 초점을 강제로 옮기지 않으며, 안내 내부에 사용자가 초점을 옮겼을 때만 Escape를 처리해요. 닫기 버튼으로는 언제든 닫을 수 있어요.

수동 다시보기는 자동 안내 OFF와 독립적이에요. 치지직에서 연 액션 팝업의 다시보기는 현재 치지직 페이지에만 안내를 열어요. 옵션 문서 안에 안내를 만들지 않고, 연결 실패·전체화면 등으로 열지 못하면 실패를 표시해요. 별도 옵션 탭에서는 치지직 화면의 확장 아이콘에서 열도록 안내하며 다른 치지직 탭을 고르거나 새 시청 탭을 만들지 않아요. 페이지의 표시 확인 뒤 미저장 변경이 없는 팝업만 자동으로 닫고, 미저장 변경이 있으면 옵션 팝업과 선택한 설정 탭을 유지해요. 옵션 팝업을 닫아도 페이지의 안내는 남아요. 기능 추가가 없는 수정 버전은 작성된 짧은 요약만 제공해요.
