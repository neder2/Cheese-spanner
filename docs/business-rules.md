# 치즈 스패너 기능 기준

## 제품 범위

치지직 시청·탐색 경험을 개선하는 비공식 Chrome 확장으로 무료 배포를 유지해요. 현재 서비스에 없는 결과를 만들어 보여 주거나, 기능 실패를 성공한 것처럼 표시하지 않아요. 원래 페이지의 조작을 다른 창·다른 플레이어로 바꾸는 임의 우회는 기능 개선으로 취급하지 않아요.

## 재생과 화질

일반 VOD 이어보기의 영구 저장·다음 방문 복원은 치지직의 네이티브 시청 위치를 사용해요. 확장 시청 기록은 라이브용이며 VOD 위치 저장기로 확대하지 않아요. 사용자가 연 명시적 `currentTime` 링크는 그대로 유지하되 초기 적용 완료·사용자 탐색 뒤 화질 요청이나 페이지 복귀가 같은 시간을 다시 강제하지 않아요.

다시보기 채팅 복구는 SPA 진입 뒤 실제 네이티브 채팅 패널이 열려 있고 제목만 없으며 본영상이 준비된 경우에만 한 번 시도해요. 닫힌/없는 패널과 미준비 영상을 장애로 보지 않아요. 복구를 위한 위치는 URL에 추가하지 않고 60초 이내의 탭 일회용 상태로 전달하며, 첫 재생 뒤 복원 확인·사용자 탐색·이탈·만료 시 지워요. 이것은 다음 방문을 위한 영구 이어보기 기능이 아니에요.

자동 화질의 목적은 광고 차단 프로그램 사용 또는 그리드 미설치 상황에서 낮게 설정되는 입장 화질을 개선하는 것이에요. 적용 계기는 방송 입장과 사용자가 확장 설정에서 선호 화질을 바꿔 저장하는 때예요. 시청 중 저장하면 현재 영상에도 바로 적용해요. 시청 내내 사용자의 화질 선택을 되돌리는 요구로 확대하지 않아요.

입장 후 사용자가 화질을 바꾸면 치지직이 다시 낮추지 않는다는 내용은 사용자의 현재 관찰이에요. 모든 방송의 변하지 않는 플랫폼 보장으로 취급하지 않아요. 입장 시 적용을 완료하는 데 필요한 첫 재생·메뉴 준비 대기와 시청 중 반복 강제 적용도 구분해요.

자동 재생 위치 보존의 의도는 사용자가 일시정지한 뒤 다시 재생하는 경우에 한정돼요. 사용자가 직접 시간을 이동하거나 실시간으로 돌아가는 조작, 멀티뷰에서 목표 딜레이를 선택하는 조작은 각각 별도의 명시적 조작이에요. 지속적으로 되감기 위치를 지키는 일반 규칙으로 확대하지 않아요. 현재 구현에는 더 넓은 화질 재적용·위치 보정 경로가 남아 있어 이 목표가 모두 구현된 상태는 아니에요.

홀드 배속은 누르는 동안만 적용하고 해제·화면 이탈·영상 교체 때 이전 배속으로 돌려요. 일시정지한 영상을 홀드했다고 자동 재생하지 않아요. Space 홀드가 켜져 있으면 짧은 Space와 긴 Space 모두 해당 기능이 소유하며 기본 단축키 복구와 중복 실행하지 않아요. 고정 배속 단축키는 홀드 기능과 별도 선택이에요.

메인 재생 조작은 미리보기·멀티뷰 보조 영상을 대상으로 삼지 않아요. 확대·배치 조작은 원본 영상의 재생 위치를 변경하는 기능이 아니며, 버튼 숨김으로 이미 실행 중인 PIP를 종료하지 않아요.

독립적인 저지연 우선 설정과 전환 동작은 제공하지 않아요. 기존 자동 화질 선택과 스트림 정보의 실제 재생 방식·지연·안정성 관측은 유지해요. 과거 저지연 설정값이 남아 있어도 제어를 다시 활성화하지 않아요.

컴프레서의 마지막 켜짐·꺼짐과 출력 볼륨은 새 탭의 기본 선택으로 함께 기억해요. 새 탭이 홈·방송 목록을 먼저 열면 선택을 미리 고정하지 않고 라이브·다시보기에 처음 들어갈 때 이어받아요. 이미 선택을 복원한 탭은 각자의 선택을 유지하고, 상속받은 탭도 새로고침·페이지 이동 뒤 다른 탭의 이후 조작을 따라 바뀌지 않아요. 마지막으로 조작한 탭을 닫거나 브라우저를 다시 켜도 기본 선택은 남아요.

처음 이 방식을 적용할 때는 남아 있는 탭 기록의 마지막 유효 선택을 이어받고, 아무 선택도 없으면 꺼짐·100%로 시작해요. 이미 닫힌 탭의 선택은 복구할 수 없어요. 버튼 표시 옵션 OFF와 외부 컴프레서 충돌 회피는 적용만 일시 해제하며 저장 선택을 바꾸지 않아요. 네이티브 볼륨·음소거와 컴프레서 출력은 별개예요.

## 채팅과 댓글

방송자·운영자 모아보기는 확인된 역할과 현재 메시지 정체성을 기준으로 수집해요. 본문에 운영자라는 단어가 들어 있다는 이유로 수집하지 않아요. 같은 작성자가 같은 내용을 실제로 다시 보낸 경우는 별개 메시지이고, 같은 행을 다시 렌더링한 경우는 새 메시지가 아니에요.

블라인드 원문은 실제로 확인한 원문 또는 정체성이 일치하는 기존 원문이 있을 때만 표시해요. 원문이 없으면 안내를 유지해요. 닉네임·배지·본문이 순서대로 바뀌는 중간 상태를 확정된 새 메시지로 취급하지 않아요.

미확인 채팅은 패널을 열었다는 이유만으로 읽음 처리하지 않아요. 선택된 필터 안에서 실제 노출된 항목을 읽음 처리하며, 닫힌 패널·숨겨진 탭·화면 밖 항목은 미확인 상태를 유지해요. 원본으로 이동할 때 이미 다른 메시지로 재사용된 행에는 이동하지 않아요.

라이브·VOD 타임스탬프는 서버 작성 시각이 확인된 행에만 표시해요. 현재 시각을 대신 넣지 않아요. 표시 시각은 브라우저 현지 시간이고, 방송 달력·기록 집계의 날짜 기준인 한국 시간과 구분해요.

VOD 댓글은 채팅 다시보기 유무와 별개로 표시할 수 있어요. 댓글 없음·댓글 비활성·조회 오류·추가 페이지 오류를 구분해요. 원본 댓글의 동작을 대신 눌러야 할 때는 같은 댓글·같은 조작인지 확인하며 다른 댓글의 버튼에 위임하지 않아요. 한도에 도달한 목록을 전체 댓글을 모두 읽은 결과로 표현하지 않아요.

## 채팅·사이드바 너비

채팅창과 사이드바의 너비 조절은 각각 기본 켜짐이고 다른 채팅·팔로잉 기능과 독립적이에요. 저장된 명시적 꺼짐은 유지해요. 저장된 사용자 지정 너비가 없을 때는 원래 너비에 조절 경계만 제공하며, 활성화만으로 임의의 고정 너비를 만들지 않아요. 저장된 너비가 있으면 새 문서에서 현재 가용 공간에 맞춰 복원해요.

왼쪽은 사이트 전반의 펼친 사이드바 오른쪽 경계, 오른쪽은 일반 라이브·다시보기에서 영상 옆에 표시된 채팅·댓글 왼쪽 경계를 조절해요. 라이브 채팅·다시보기 채팅·댓글·기존 댓글 전용 영역은 하나의 오른쪽 너비를 공유해요. 별도 채팅 팝업·임베드·클립·같이보기 오른쪽 배치는 대상이 아니며, 없는 채팅·댓글을 만들거나 숨긴 영역을 강제로 펼치지 않아요. 현재 구현은 가로 너비만 바꾸고 높이·좌우 위치는 바꾸지 않아요.

너비는 마우스로만 조절해요. 주 버튼 드래그는 놓을 때 확정하고, 포인터 취소·캡처 소실·창 포커스 이탈·화면 이탈은 시작 전 확정 상태로 되돌려요. 더블클릭하면 해당 영역만 현재 사이트 기본 너비로 돌아가며, 이미 기본 상태여도 이 선택을 저장해요. 방향키·Shift 미세 조절·Enter 복원·Escape 취소는 제공하지 않고 경계는 키보드 초점을 가져가지 않아요. 마우스를 올리거나 드래그하는 동안 경계선 하나만 강조해요. 조절 경계 밖의 채팅 입력·스크롤·영상 조작은 유지해요.

마지막으로 확정한 두 너비는 같은 Chrome 프로필에 각각 계속 저장하며 채널·영상별로 나누지 않아요. 새로고침·새 문서·브라우저 재시작 후 복원하고, 이미 열린 다른 문서의 너비는 바꾸지 않아요. 같은 문서의 페이지 내부 이동·뒤로 가기 캐시 복귀·OFF/ON은 현재 선택을 유지해요. 기능을 끄면 조작과 너비 적용을 정리하되 선택값은 남고, 다시 켜면 현재 공간에 맞춰 복원해요. 미배포 기능의 이전 탭 저장값은 자동 이전하지 않아요. 저장소를 사용할 수 없으면 현재 문서에서만 유지하고 실패한 과거 선택을 자동으로 다시 저장하지 않아요.

사용자 선택과 현재 표시 너비는 구분해요. 조절 범위는 사이드바 180~420px, 채팅·댓글 240~640px이고 중앙 콘텐츠에 최소 320px을 남겨요. 한쪽 조절은 다른 쪽의 실제 표시 공간을 유지하며 그 선택값을 바꾸지 않아요. 창이 줄어 두 사용자 지정 영역이 함께 줄어야 하면 각 최소 너비를 초과한 부분을 같은 비율로 줄여요. 최소 공간도 부족하거나 원래 배치가 겹침·세로 쌓임·숨김 상태이면 너비 지정을 일시 해제하고, 넓어졌을 때 저장한 선택을 다시 적용해요. 이 임시 표시 변경을 사용자 선택으로 저장하지 않아요.

## 탐색·방송 정보

영상 검색, 방송 목록 필터와 방송 달력은 조회한 자료 범위만 보여 줘요. 조회 한도나 부분 조회를 전체 자료의 부재로 바꾸지 않아요. 진행률·썸네일·방송 제목·채널 정보는 확인된 값만 사용해요. API 실패와 검색 결과 없음은 다른 상태예요.

카테고리 제외는 방송 목록 검색·필터가 켜진 전체 방송(`/lives`)의 기존 필터 메뉴에서 제공해요. 인기·최신·추천 목록의 원본 카드와 확보한 추가 결과에 함께 적용하며, 목록 검색·숫자 조건을 통과한 방송도 제외 대상이면 표시하지 않아요. 카테고리 라이브·영상·클립, 팔로잉과 재생 화면에는 적용하지 않아요. 전체 방송 집계는 제외 목록과 독립적으로 계산해요.

실제 게임·카테고리를 이름으로 검색하고 결과에서 명시적으로 선택해요. 현재 방송이 없는 게임도 미리 선택할 수 있으며 최대 100개를 보관하고 항목마다 해제해요. 검색어 입력만으로 제외하거나 방송 제목·태그·이름의 부분 일치로 다른 카테고리를 숨기지 않아요. 판정은 유형과 ID의 정확한 쌍을 사용하고 ID의 대소문자를 구분해요. 카테고리 정체성을 확인하지 못하면 이름을 대체 근거로 쓰지 않아요.

선택 목록은 같은 Chrome 프로필의 이 기기에 계속 보관하고 다른 열린 전체 방송 탭에도 바로 반영해요. 메뉴 닫기·검색어 변경·페이지 내부 이동·OFF/ON·탭 종료·새로고침·브라우저 재시작으로 선택을 지우지 않아요. `필터 초기화`는 팔로워 수·시청자 수/조회수·진행 시간의 숫자 조건만 해제하고 제외 목록은 남겨요. 숫자 조건이 없으면 초기화 버튼은 비활성화해요.

검색 중·검색 결과 없음·검색 실패와 제외 목록 읽기·저장 실패를 구분해요. 읽기 실패나 손상 자료를 빈 목록으로 저장하지 않고, 저장 성공 전에 제외·해제 완료로 표시하지 않아요. 한도에 도달하면 기존 선택은 유지하며 새 항목 추가만 거절해요. 검색어·검색 결과는 영구 저장하지 않고 선택 목록 전체를 서버로 보내지 않아요.

방송 통계의 최근 일평균은 조회한 다시보기 중 기간과 겹치는 방송 시간의 합을 선택한 기간의 일수로 나눠요. 방송한 날만을 분모로 삼는 평균과 구분해요. 다시보기가 없는 방송까지 완전하게 파악한 총 방송시간으로 약속하지 않아요.

여러 날에 걸친 방송은 한국 날짜별로 겹치는 구간을 달력에 반영해요. 종료가 정확히 자정이면 다음 날 방송으로 세지 않아요. 여러 VOD로 분할된 같은 방송의 연결 정보와 시간축을 검증하고 합치며, 제목이 같다는 이유만으로 다른 방송을 합치지 않아요.

전체 방송 집계 표시는 검색·필터와 독립적으로 켜고 꺼요. 새 설치에서는 꺼져 있고, 기존 버전에서 업데이트할 때는 이전 표시 여부를 한 번 이어받아요. 이후 검색·필터를 바꿔도 집계 설정은 바뀌지 않아요. 집계만 켜면 검색창·필터·카드 배지 없이 전체 방송 목록 상단에 방송 수와 시청자 합계만 표시해요.

전체 라이브 목록의 집계는 시청자 10명 이상인 방송 범위를 표시해요. 이 숫자를 플랫폼 전체 방송·시청자의 완전한 총계라고 부르지 않아요. 팔로워 정보가 아직 도착하지 않았거나 조회에 실패한 상태도 실제 0명과 구분해요.

팔로잉 고정·오프라인 숨김·목록 접기 기억은 서로 독립적이에요. 고정은 표시 순서를 조절하며 실제 팔로우 관계를 변경하지 않아요. 제목 이력은 채널만이 아니라 현재 방송 정체성까지 확인하고, 새 방송에는 이전 방송의 제목을 이어 붙이지 않아요.

스트림 정보의 비트레이트는 API가 제공한 현재 해상도의 설정값이며 실제 전송 속도가 아니에요. WebGL 렌더러로 추정한 가속 상태도 영상 디코더의 사용 여부를 확정하지 않아요. 확인할 수 없는 측정값은 측정 불가로 표시해요.

일반 라이브의 스트림 정보는 현재 선택된 재생 방식, 라이브 지연 추정·버퍼의 최근 60초 변화, 관측한 끊김·프레임 누락을 함께 보여 줘요. 저지연 설정값이나 과거 적용 성공을 현재 재생 방식으로 대신하지 않아요. 지연은 플레이어의 라이브 끝을 기준으로 한 추정이며 촬영부터 화면까지의 전체 지연이 아니에요. 낮은 지연만으로 안정성이 좋아졌다는 점수·판정을 만들지 않아요.

측정은 패널이 열려 있고 탭이 보이는 동안만 하며 실제 관측 시간도 표시해요. 일시정지·탐색·광고·영상 전환·숨김은 끊김으로 세지 않고, 자료가 없으면 실제 0과 구분해요. 같은 방송으로 확인된 재생 전환은 패널과 최근 자료를 유지하되 그래프를 끊어요. 방송이 다르거나 교체한 영상의 방송을 확인하지 못하면 새 기록을 시작해요. 닫으면 메모리의 측정 자료를 폐기하고 시청 기록이나 저장소에 남기지 않아요. 측정을 위해 재생·화질·배속·시청 위치를 바꾸지 않아요.

## 시청 기록과 내 활동

시청 시간은 실제 미디어 시간이 전진하는 동안의 경과 시간을 기록해요. 탭을 열어 둔 시간, 일시정지·버퍼링 시간이나 탐색으로 건너뛴 영상 길이를 시청 시간으로 더하지 않아요. 재생 배속만큼 벽시계 시간을 곱하지 않아요.

각 방송의 세션은 누적 스냅샷으로 갱신하고 같은 스냅샷을 다시 받았다고 시간을 더하지 않아요. 전체·월별·일별 합계는 해당 범위에 들어오는 유효한 시청 시간대를 합쳐 동시 시청 구간을 중복 계산하지 않아요. 시간대가 없는 과거 기록의 누적값은 보존하며 정밀한 동시 시청 복원이 가능하다고 주장하지 않아요.

방송 정보가 늦게 오면 임시 기록을 실제 방송 기록으로 연결하되 이중 집계하지 않아요. 이전 화면에 남은 제목은 검증된 제목 이력으로 저장하지 않아요. 같은 채널에서 새 방송이 시작되면 별개 방송으로 나눠요. 삭제 이후 도착한 옛 저장 요청은 삭제 기록을 되살리지 않으며, 삭제 후 새로 시작한 시청·활동은 기록할 수 있어요.

내 채팅과 일반 후원 기록은 라이브 시청 기록과 별도로 각각 켜야 해요. 확인된 새 본인 활동은 최소 시청 시간에 미달하거나 영상이 일시정지돼 있어도 저장할 수 있어요. 다른 사람·과거 활동·익명 후원·미션·구독 결제를 실시간 일반 후원으로 추정해 저장하지 않아요.

활동 본문은 보관 상한 때문에 지워질 수 있고 집계는 남을 수 있어요. 집계가 남았는데 본문이 없다는 이유로 활동이 없었다고 표시하지 않아요.

과거 일반 후원 갱신은 사용자가 실행할 때만 이뤄져요. 처음에는 지원하는 전체 기간, 이후에는 마지막 조회 당시 진행 중이던 달·새 달·미조회 달을 조회해요. 완결된 과거 달은 반복 조회하지 않아요. 계정 변경·취소·불완전한 페이지·보관 한도 초과는 완료된 갱신으로 저장하지 않아요.

갱신한 월의 조회 시작 시점까지는 사용 내역을 기준으로, 그 이후는 실시간 후원을 더해 표시해요. 원본 실시간 기록을 삭제해 중복을 숨기지 않아요. 같은 금액·내용의 별개 후원은 유지하고, 가져온 내역에서 시청 세션을 만들어 내지 않아요. 이 기능은 후원·결제·환불을 실행하지 않아요.

## 시청 기록 파일 백업

전체 기간의 시청 기록과 내 채팅을 기록 페이지에서 JSON 파일로 저장하고 불러와요. 현재 화면의 검색·월·선택 상태는 범위를 제한하지 않아요. 실시간 후원과 치지직에서 조회한 후원은 모두 제외해요. 후원은 별도로 다시 조회할 수 있고, 백업의 목적은 확장이 따로 보관한 시청·채팅을 보존하는 것이에요. 옵션 페이지는 실제 조작이 가능한 기록 페이지를 안내해요.

파일을 선택하면 적용 결과를 먼저 보여주고 확인 후 현재 기록에 합쳐요. 전체 교체는 제공하지 않아요. 같은 백업을 반복 적용해도 중복 누적하지 않으며 파일에 없는 현재 기록과 모든 현재 후원은 보존해요. 상세가 정리돼 중복을 증명할 수 없는 기존 방송은 추정 합산하지 않고 건너뛴 이유를 보여줘요. 현재에 없는 정상 과거 합계는 그대로 추가할 수 있어요.

삭제했던 자료는 파일에 실제 들어 있는 시청·채팅만 안내 후 복원해요. 이 예외가 일반 늦은 저장 요청이나 파일 밖의 세션·후원으로 넓어지면 안 돼요. 미리보기 후 삭제·충돌 등 확인할 의미가 바뀌면 다시 확인하고, 불완전 파일·보관 한도·저장 실패에서는 부분 반영하지 않아요. 자동 백업은 하지 않으며 기기에 저장된 파일은 사용자가 보관·삭제해요.

## 방송 알림·자동 입장

처음 켜거나 브라우저를 시작할 때 이미 진행 중인 방송은 기준 상태로 기억하며 알림·자동 입장을 실행하지 않아요. 이후 새 방송을 확인하면 채널별로 선택한 동작을 수행해요. 데스크톱 알림과 자동 입장은 각각 켜고 끌 수 있고, 헤더 등록 버튼을 숨겨도 등록한 동작은 유지돼요.

이미 열린 동일 채널의 방송·대기 탭이 있으면 자동 입장은 새 탭을 만들거나 기존 탭을 앞으로 가져오지 않아요. 알림을 직접 클릭하면 해당 탭을 활성화하거나 새 탭으로 이동해요.

동작 전에 방송별 처리 상태를 저장해 중복 방지를 우선해요. 저장 실패 시 동작을 실행하지 않고, 저장 후 알림·탭 열기가 실패하더라도 같은 방송을 자동 재시도하는 보장은 하지 않아요. 상태 보관에는 상한이 있으므로 무기한 정확히 한 번의 전달을 보장한다고 표현하지 않아요.

## 광고·팝업·보상

동영상 광고 차단은 현재 기본 켜짐인 공개 실험 기능이에요. 확인된 광고 응답·소스·스케줄만 처리하고 알 수 없는 형식은 통과시켜요. 본영상에 포함된 광고 제거 또는 모든 광고 차단을 보장하지 않아요. 켜고 저장한 뒤 초기 주입을 적용하려면 새로고침이 필요하며 자동으로 새로고침하지 않아요.

본영상 재생을 우선해요. 필수 광고 계약·현재 소유 관계가 유지되는 새 ID와 부가 필드는 처리하지만, 계정의 `adFree`·구독 상태와 일반 재생 정보는 바꾸지 않아요. 명시적 표시 응답은 프리롤·미드롤 boolean만 끄고 나머지는 보존해요. 직접 소스는 최초 네이티브 초기화 전에만 판단하며, 이미 원본 초기화를 시작한 소스를 재연결·반복 설정으로 다시 끊지 않아요.

본방송 상태를 연결하는 라이브 바깥 객체와 별도 광고 요청을 구분해요. 독립 입장·중간 일정은 현재 광고 컴포넌트의 소유를 확인하고 각 항목의 광고 소스 목록만 비워요. 일정 항목·순서·시간·원본을 유지하고 완료는 네이티브에 맡겨요. 별도 광고용 `contentVideo`를 본영상 슬롯으로 간주하지 않아요. JSON 판단 경로를 지나지 않아도 지원 SDK 경계에 도달하면 그곳에서 처리하고, 어떤 지원 경계에도 도달하지 않으면 현재는 원본 통과예요. 자동 완료 모델을 실제 Chrome의 본영상 진행 성공으로 보고하지 않아요.

치지직 안의 라이브 PiP로 같은 방송을 계속 시청할 때는 홈·목록으로 이동해도 확인된 중간 광고 일정 처리를 이어가요. 현재 라이브 본영상과 광고 영역이 연결된 경우로 한정하고 목록 미리보기나 다른 보조 영상까지 확대하지 않아요. PiP 종료·영상 교체·등록 해제 뒤에는 과거의 소유 관계를 허용 근거로 쓰지 않아요.

광고 차단 안내와 커넥터 설치 안내는 저장된 팝업 옵션을 읽은 뒤, 확인된 화면의 표시된 활성 버튼으로 처리해요. 닫을 수 없는 안내를 계속 숨기거나 같은 표시 상태에서 반복 클릭하지 않아요. 광고 차단과 화질 설정은 독립적인 선택이에요.

통나무 자동 받기는 확인된 수령 버튼·서버 claim만 처리해요. 1시간 시청 보상은 페이지의 버튼 흐름을 사용하고, 구독·팔로우·로그인·결제 행동을 수령 동작으로 대신 실행하지 않아요.

## 멀티뷰와 미리보기

미리보기와 보조 영상은 실제 제공된 재생 소스를 사용해요. 실패 시 새 창·iframe·원격 플레이어 실행으로 바꾸지 않아요. 사용자가 누른 채널 홈 링크의 새 탭 이동은 재생 실패 대체 경로와 구분해요.

멀티뷰는 현재 메인 포함 최대 6개 방송을 지원해요. 메인 변경은 영상뿐 아니라 URL·제목·채팅의 대상도 일치해야 해요. 관측 딜레이, 저장한 목표 딜레이, 실제 적용 상태는 구분하며 버퍼 범위 밖의 목표나 아직 측정하지 못한 값을 적용 성공·0초로 표시하지 않아요.

## 계획된 범위

앰비언트 효과, 채팅·사이드바 위치 이동과 높이 조절, 팔로잉 폴더, 채팅 멀티뷰, 설정 파일 저장·불러오기는 계획된 기능이에요. 이 남은 범위의 세부 조작·기본값·우선순위는 아직 확정하지 않았어요. 가로 너비 조절은 위의 확정한 동작을 제공해요. 사용자 글꼴 선택은 계획에서 제외해요. 현재 확장 UI에 포함된 글꼴은 사용자 글꼴 선택 기능과 별개예요.

## 버전별 새 기능 안내

업데이트한 사용자가 새 기능을 발견하도록 버전마다 작은 안내를 한 번 표시해요. 새 설치·동일 버전 재로드·브라우저 업데이트·다운그레이드는 새 안내를 만들지 않아요. 이미 대기 중인 동일 버전 안내는 재로드만으로 삭제하지 않아요. 건너뛴 버전은 누적하지 않고 현재 설치 버전과 일치하는 안내만 제공해요.

자동 안내와 수동 다시보기는 같은 한 창에 두 기능을 동시에 표시해요. 1.4.1 헤더는 “치즈 스패너 1.4.1 새 기능”이며 채팅창·사이드바 크기 조절과 시청기록 백업·불러오기만 소개해요. 크기 조절은 제목과 조작 문장 하나로 구성하고, 시청기록은 제목만 표시해요. 스트림 정보 소개는 넣지 않아요. 페이지 넘김·별도 상세 열기·설정 이동 버튼·위치 강조를 제공하지 않고 닫기 버튼 하나만 표시해요.

기본 켜짐이며 화면 정리의 새 기능 안내에서 끌 수 있어요. OFF로 지나간 안내를 ON 전환으로 소급하지 않아요. 안내 상태는 Chrome 프로필의 기기 local에 보관하고 탭 전체에서 한 번만 표시해요. 표시 직전 저장에 성공한 경우만 허용하며, 저장 직후 문서가 종료돼 못 보여준 극단적 구간은 재알림 대신 수동 다시보기를 남겨요. 반복 팝업으로 시청을 방해하지 않는 것을 우선한 선택이에요.

자동 안내는 활성 최상위 치지직 문서에서 준비 후 표시해요. 숨김·전체화면·편집 입력 중이나 영상 중앙·컨트롤·입력창을 피할 공간이 없으면 소비 전에 기다려요. 자동 안내와 수동 다시보기 모두 상단의 2px 민트색 게이지가 20초의 남은 표시 시간에 맞춰 줄어들고, 호버·내부 키보드 초점 동안 타이머와 함께 멈춰요. 이미 표시한 안내는 다른 창이나 탭으로 옮겨도 유지하고, 남은 시간과 게이지는 치지직 문서가 다시 보이고 초점을 얻을 때 이어가요. 동작 줄이기를 사용하면 게이지는 1초 단위로 줄어들어요. 다시 열면 새 20초로 시작하고 게이지 생성 실패가 자동 닫힘을 막지 않아요. 시청 페이지 이동·전체화면 등으로 닫힌 뒤에는 같은 버전을 다시 자동 표시하지 않아요.

1.4.1의 크기 조절 설명은 “경계 드래그로 조절, 더블클릭으로 초기화.”이고 백업은 “시청기록 백업 및 불러오기” 제목만 표시하며 설명용 빈 줄도 만들지 않아요. 설명을 과하게 줄바꿈시키는 좁은 세로 배치를 피하고 두 항목을 같은 정렬선에 놓아요. 라이트·다크 테마에 맞는 배경과 제목·설명 색을 구분하고 민트색 상단 경계로 강조해요. 안내는 페이지를 어둡게 가리거나 재생·스크롤·설정·백업을 자동 조작하지 않아요. 다시보기를 열 때 제목에 초점을 강제로 옮기지 않으며, 안내 내부에 사용자가 초점을 옮겼을 때만 Escape를 처리해요. 닫기 버튼으로는 언제든 닫을 수 있어요.

수동 다시보기는 자동 안내 OFF와 독립적이에요. 치지직에서 연 액션 팝업의 다시보기는 현재 치지직 페이지에만 안내를 열어요. 옵션 문서 안에 안내를 만들지 않고, 연결 실패·전체화면 등으로 열지 못하면 실패를 표시해요. 별도 옵션 탭에서는 치지직 화면의 확장 아이콘에서 열도록 안내하며 다른 치지직 탭을 고르거나 새 시청 탭을 만들지 않아요. 페이지의 표시 확인 뒤 미저장 변경이 없는 팝업만 자동으로 닫고, 미저장 변경이 있으면 옵션 팝업과 선택한 설정 탭을 유지해요. 옵션 팝업을 닫아도 페이지의 안내는 남아요. 기능 추가가 없는 수정 버전은 작성된 짧은 요약만 제공해요.
