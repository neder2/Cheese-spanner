## 로컬 확인 화면 점검 (실제 치지직 아님)

내장 브라우저는 `chzzk.naver.com`을 안전 제한으로 열지 못해요. 그래서 치지직 공개 CSS(2026-10-11 `index-B5SHICxp.css`·`vendor-DVDNLy6N.css`)에서 읽은 라이트·다크 토큰과 비슷한 헤더·사이드바·채팅 구조를 만든 세션 임시 페이지에 실제 `features/followingFolders.js`·`features/chatMultiview.js`를 가짜 chrome 저장소와 함께 올려 확인했어요. **실제 확장·실제 치지직 화면 확인이 아니에요.**

- 폴더: 실제 마우스 드래그로 채널을 다른 폴더 머리에 놓아 이동, 되돌리기 안내와 진행 막대, ⋯ 메뉴(위로·아래로 비활성 표시 포함), 채널 선택 창(이니셜 아바타·방송 중 점·다른 폴더 표시), 체크로 넣은 뒤 되돌리기, 더블클릭 이름 입력칸과 같은 이름 오류 표시를 확인했어요. 드래그 도구가 끝점 이벤트를 보내지 않은 시도가 있어 끌어 놓기는 자동 회귀로도 확인했어요.
- 채팅 멀티뷰: 다크·라이트에서 헤더 도구(크기·위치·닫기 아이콘), 검색 칸과 검색 버튼, 결과 행(방송 중·팔로워·추가 상태)과 끌어 놓기 안내, 칸 머리(이니셜·입력 대상·이동·제거 아이콘)를 확인했어요. 칸 안 채팅은 이 페이지에서 프레임이 막혀 확인하지 못했어요.

## 기능별 실측 참조

다섯 기능의 실제 Chrome 결과는 2026-10-09 Codex가 사용자 Chrome에서 확인해 전달한 보고예요([현재 상태](tracking/status.md)의 `2026-10-08~09 미구현 계획 5개 구현`과 `계획된 기능` 표). 실측 결함 6건은 고쳐 재로드 뒤 통과했어요. 확인하지 않은 범위는 [남은 확인 사항](tracking/findings.md)의 `2026-10-09 미구현 계획 5개 — 실제 Chrome에서 확인하지 않은 범위`에 있어요. 2026-10-10 코드 리뷰 반영분(자동 화질 MAIN 스크립트, 시청 기록 최상위 프레임 조건)은 실제 Chrome에서 확인하지 않았어요. 2026-10-11 폴더 사이드바 조작과 채팅 멀티뷰 추가 방식·디자인 변경은 위 로컬 확인 화면까지만 봤고 실제 Chrome에서 확인하지 않았어요. 2026-10-12~13의 제목 이력 워커 수집(로그인 상태의 실제 응답 포함), 기록 페이지 정리, 버그 수정, 폴더 조작 보완도 실제 Chrome·치지직에서 확인하지 않았어요. 2026-10-13 사용자가 본 "사이드바 팔로잉 목록이 `접기` 앞에서 끝까지 스크롤되지 않음"은 사용자 결정으로 알려진 문제로 두었고 릴리스를 막지 않아요([남은 확인 사항](tracking/findings.md)).
