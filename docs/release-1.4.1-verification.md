## 옵션 팝업 내부 표시 제거

사용자가 치지직에서 확장 아이콘으로 연 작은 옵션 팝업 안에 안내가 나타나고, 그 팝업을 닫으면 안내도 사라진다고 확인했어요. 기존 `optionsUpdateGuide.js`는 페이지 전달 실패를 옵션 내부의 안내로 대신 처리했어요. 앞선 창 초점 이탈 수정은 이 옵션 팝업의 종료를 해결하지 못했어요.

- 옵션 문서에 안내를 만드는 코드를 제거했어요. 현재 치지직 페이지의 표시 응답이 성공일 때만 열린 것으로 처리하고, 실패·연결 불가·다른 사이트는 상태 문구로 알려요. 별도 옵션 탭은 치지직의 확장 아이콘에서 열도록 안내해요.
- 성공 후 저장된 상태의 팝업만 닫고, 미저장 변경이 있으면 선택 탭·편집값을 보존해요. 다른 탭 선택·새 탭 생성·페이지 새로고침·설정 저장을 자동 실행하지 않아요.
- 저장한 수정 전 소스에 새 실패 경로 검사 4개를 실행해 모두 실패하는 것을 확인했고 수정 후 통과했어요. 자동 검사에서 옵션 문서와 치지직 문서를 분리하고 실제 안내 수신 코드를 연결해, 안내의 소유 문서가 치지직이며 옵션 팝업 종료 뒤에도 남는지 확인했어요.
- 안내·옵션·컨트롤러·설정·확장 진입점·배포 안전 관련 검사 230개가 통과했고 실패·취소·건너뜀 0개, 종료 코드 0이에요. 전체 테스트를 다시 실행한 결과는 아니에요.
- 사용자의 기존 페이지가 전달에 실패한 구체적 원인과 수정본의 실제 Chrome 동작은 아직 미검증이에요. 사용자가 후속 확인 범위를 코드 수정까지만으로 지정해 Chrome을 조작하지 않았어요. 자동 검사는 현재 실행 중인 확장의 버전·주입·메시지 연결 실측을 대체하지 않아요.

## 자동 안내의 남은 시간 게이지 — 다시보기 타이머 연결 전

20초 뒤 닫히는 자동 안내 상단에 2px 민트색 게이지를 추가했어요. 기존 상단 선 자리를 사용해 콘텐츠 높이를 늘리지 않고, 남은 시간이 줄어들수록 왼쪽을 기준으로 짧아져요. 표시 승인 후 시작하며 기존 닫힘 타이머의 남은 시간으로 호버·키보드 초점·창/탭 이탈과 복귀를 함께 정지·재개해요. 별도의 반복 타이머나 RAF 루프는 추가하지 않았어요.

- 동작 줄이기 설정에서는 1초 단위로 줄어들고, 시간 제한 없는 수동 다시보기에는 게이지를 표시하지 않아요. 닫기·수동 안내 전환·페이지 정리 시 애니메이션도 취소해요.

## 다시보기 타이머 연결

타이머가 작동하지 않는다는 후속 요청에서 다시보기 경로에는 타이머와 게이지가 연결되지 않은 것을 코드로 확인했어요. 자동 안내와 다시보기 모두 같은 20초 타이머를 쓰도록 연결했어요. 다시보기를 열 때 제목에 초점을 강제로 옮기지 않아 시작과 동시에 내부 초점 조건으로 멈추지 않아요. 옵션 팝업이 닫혀 치지직에 초점이 돌아오면 시작하고, 호버·내부 키보드 초점·창/탭 이탈 때는 남은 시간을 보존해요.
