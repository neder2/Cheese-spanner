# 치즈 스패너 보안·개인정보 기준

## 보호 대상과 보관 경계

보호 대상은 사용자 설정, 방송 시청 시간대·제목 이력, 본인 채팅·후원 내용, 작성자 해시 ID, 후원 갱신 계정 정보와 동작 대상 채널이에요. 기록은 Chrome 프로필 단위로 보관해요. 같은 프로필에 접근하는 사람은 기록 페이지에서 볼 수 있으며, 치지직 로그아웃·계정 전환으로 기존 기록을 자동으로 숨기거나 지우지 않아요. 계정별 열람 분리는 현재 제품 요구사항이 아니에요.

설정·고정 채널은 Chrome sync에 저장하므로 Chrome 자체 동기화 대상이 될 수 있어요. 시청·활동·후원 기록, 방송 알림 대상과 처리 상태, 댓글 기기 식별자, 채널별 멀티뷰 딜레이·화질, 사이드바·채팅·댓글의 마지막 너비와 카테고리 제외 목록은 확장 local 저장소에 보관해요. 멀티뷰 구성·배치·볼륨은 사이트의 탭 sessionStorage에 있으므로 페이지 스크립트가 읽을 수 있어요. 이들을 모두 ‘페이지에서 읽을 수 없는 로컬 데이터’라고 설명하지 않아요.

너비 저장에는 비민감한 숫자 또는 기본 선택 null만 넣고 채팅 내용·계정·시청 정보를 섞지 않아요. 읽을 때 타입과 범위를 검증하며 특권 명령으로 해석하지 않아요. 두 너비는 프로필 local의 독립 키로 보관하고 다른 기기로 동기화하지 않아요. 새 너비를 페이지 저장소에 쓰지 않으며 이전 개발용 탭 값은 읽거나 갱신하거나 자동 이전하지 않아요. 너비 조절은 새 권한·네트워크 요청·시청 기록 쓰기를 사용하지 않고, 저장 실패 시 현재 문서의 메모리만 유지해요.

별도 개발자 서버, 분석 수집, 외부 계정 연동이나 기록 외부 전송을 추가하지 않아요. 추가 요구가 생기면 사용자 결정과 개인정보 고지 변경이 먼저 필요해요. 현재 데이터를 외부 동기화할 권한을 무료 배포 정책에서 추론하지 않아요.

사용자가 기록 페이지에서 시작한 백업은 시청·내 채팅만 평문 JSON 파일로 기기에 저장해요. 실시간·조회 후원, 설정, 인증 정보는 내보내지 않아요. 파일 생성·검사·복원에 로그인·외부 조회·새 권한이 필요하지 않아요. 파일에는 시청 이력·채팅 본문·작성자 식별 정보가 들어가며 확장 안의 삭제가 이미 내려받은 파일까지 지우지는 않아요.

## 로그인과 권한

자체 계정·비밀번호·API 토큰 발급은 없어요. 인증이 필요한 요청은 브라우저의 기존 치지직 로그인 세션을 사용하고 쿠키·토큰 값을 읽어 저장하지 않아요. 로그인·만료·로그아웃·계정 잠금·자격 증명 교체는 네이버가 관리해요. 확장이 로그인 성공이나 잠금 해제를 대신 만들어 내지 않아요.

실시간 본인 활동 수집은 옵션 활성화 → 현재 계정 확인 → 표시된 메시지의 작성자·형식·시각 확인 → 새 본인 활동 수집 순서예요. 로그인 조회 실패·미로그인·잘못된 해시는 수집을 시작하지 않는 조건이에요. 계정 변경 신호·탭 복귀 시 다시 확인하고, 취소된 조회가 수집을 다시 켜지 못하게 해요.

과거 후원 갱신은 기록 페이지에서 사용자가 시작하고, 열려 있는 일반 치지직 탭으로 시작·완료 시 계정을 확인해요. 일반 탭이 없거나 인증이 만료됐으면 저장하지 않고 실패를 알려요. 조회 중 계정이 바뀌거나 기존 가져온 내역의 소유자가 다르면 병합하지 않아요. 다른 계정의 과거 내역을 가져오려면 기존 가져온 내역을 사용자가 초기화해야 해요. 이는 전체 시청 기록의 계정별 열람 통제가 아니에요.

상시 권한은 storage·scripting·alarms와 manifest에 선언된 치지직·네이버 호스트 범위예요. notifications와 `https://*.pstatic.net/*`는 선택 권한이에요. 필요한 기능을 켜고 저장하는 사용자 동작 안에서 요청하고, 거부한 권한을 승인된 것처럼 처리하지 않아요. 알림 권한이 없어도 자동 입장은 독립적으로 동작할 수 있어요.

새 기능도 최소 권한을 원칙으로 해요. 상시 필요하지 않은 host 접근은 가능한 경우 `optional_host_permissions`로 두고 실제 사용하는 사용자 동작에서 승인받아요. 새 권한·match pattern을 추가하기 전에 필요성·대안·사용 시점, 설치·업데이트 경고와 심사 범위에 미치는 영향을 검토해요. 현재 특정 호스트를 허용했다는 사실을 더 넓은 호스트·상시 권한의 승인으로 해석하지 않아요.

| 일반 치지직 페이지 스크립트        | 공유 DOM·사이트 sessionStorage를 읽을 수 있어요                       | DOM 이벤트만으로 확장 저장소·탭·권한 API를 직접 사용하지 못해요             |
| MAIN 기능 스크립트                 | 확인된 페이지 객체와 제한된 DOM 브리지를 사용해요                     | 확장 특권 API·직접 네트워크 호출·원격 실행 코드를 추가하지 않아요           |

| 헤더의 방송 등록 UI                | 같은 확장, 치지직 최상위 탭에서 채널별 선택·해제를 요청해요           | 하위 프레임·다른 출처의 요청을 승인하지 않아요                              |
| 컴프레서 상태 요청                 | 같은 확장의 치지직 탭에서 유효한 활성·볼륨값을 요청해요               | 요청 본문이 지정한 다른 탭으로 저장 대상을 바꾸지 않아요                    |

DOM 속성과 이벤트는 페이지가 읽고 변경할 수 있어요. 출처가 서버로부터 암호학적으로 증명된 자료로 간주하지 않으며, 저장·탭 생성 같은 특권 동작의 최종 경계는 확장 메시지의 발신자와 데이터 검증이에요. `externally_connectable`로 외부 확장·사이트에 제공하는 공개 API는 현재 없어요.

헤더 방송 등록의 알림·자동 입장 선택과 등록 해제는 `isTrusted` 클릭에서만 요청해요. 대상 채널과 동작은 isolated 처리 함수에 보관한 값을 사용하며, 페이지의 합성 클릭이나 DOM 속성 변경으로 저장 명령을 만들지 않아요.

## 입력·실행 경계

실행 코드는 확장 패키지에 포함해요. 원격 JavaScript·WASM, 동적 원격 import, 문자열 코드 실행과 임의 iframe 플레이어 대체를 추가하지 않아요. 외부 응답은 JSON·미디어 데이터로 처리해요. 기존 광고 훅이 확인된 광고 데이터를 다룬다고 해서 본영상 재생 메타데이터나 암호화 바이트를 변경할 권한이 생기지 않아요.

탐색 URL·이미지·미디어 URL은 용도별로 검증해요. 네이버처럼 보이는 접미사 위장 호스트, 자격 증명을 포함한 URL, 실행 스킴을 신뢰하지 않아요. 브라우저가 어떤 주소를 재생할 수 있는지와 확장이 어느 주소를 요청하도록 허용하는지는 다른 조건이에요.

저장 요청의 식별자·시각·유한 숫자·문자열·배열 크기를 검증해요. 과거 저장값도 읽을 때 정규화하며 미래 시각·세션 밖 시청 구간·지나치게 긴 구간을 그대로 합산하지 않아요. 삭제 후 늦은 요청이 데이터를 복원하지 못하도록 삭제 시점과 세션 정체성을 보존해요.

## 카테고리 제외의 저장 권한

카테고리 제외는 같은 확장 ID의 정상 탭·최상위 프레임·치지직 출처 문서에서 Chrome이 제공한 현재 탭 URL이 정확한 `https://chzzk.naver.com/lives`인 경우만 읽기·추가·개별 해제를 요청할 수 있어요. 옵션·기록 페이지, 하위 프레임과 다른 경로는 이 권한을 갖지 않아요. 콘텐츠가 전체 선택 배열을 덮어쓰는 명령은 제공하지 않으며, 워커의 전용 큐가 최신 local 값을 읽고 개별 변경만 저장해요. 시청 기록·안내·알림 큐와 합치지 않아요.

저장은 확장이 소유한 현재 버튼의 신뢰된 사용자 조작에서만 시작해요. 유형·ID는 isolated의 버튼 처리 함수에 보관한 자료에서 가져오며 페이지가 바꿀 수 있는 DOM 속성을 저장 명령으로 읽지 않아요. MAIN의 합성 클릭·키 이벤트와 복제한 버튼은 선택을 저장할 권한이 없어요. 화면에 표시한 이름·선택 상태는 페이지에서도 읽을 수 있으므로 비밀 자료로 취급하지 않아요.

제외 목록에는 최대 100개의 검증한 유형·ID·이름과 변경 순서만 보관해요. 사용자가 Enter로 추가한 태그 단어도 같은 항목 형식·한도·발신자 검증을 따르며 치지직 API로 보내지 않아요. 읽기 실패·손상 값을 빈 목록으로 덮어쓰거나 상한을 넘긴 목록을 잘라서 저장하지 않아요. 저장 성공 전에는 선택 완료로 응답하지 않고 기존 선택을 보존해요. 기능 OFF·숫자 필터 초기화·탭 종료·브라우저 재시작은 목록 삭제가 아니며, 개별 해제나 확장 데이터 삭제·제거가 삭제 경로예요.

이름 검색은 기존 치지직 API 호스트에 검색어와 결과 개수 제한만 보내요. 선택 목록 전체를 서버에 전달하거나 검색어·검색 결과를 영구 저장하지 않아요. 기존 로그인 세션을 사용하는 일반 조회 경로이며 별도 토큰·계정·호스트 권한·개발자 서버·분석 수집을 추가하지 않아요. HTTP 응답과 CORS 헤더 확인은 실제 Chrome의 인증 포함 검색 요청 성공을 증명하지 않아요.

## 백업 입력과 복원 권한

백업 조회·미리보기·복원은 같은 확장 ID의 정확한 `history.html` protocol·hostname·pathname과 최상위 문서 정체성이 확인된 요청만 받아요. Chrome이 제공한 `documentId`를 사용하며, 옵션 페이지나 콘텐츠가 요청 본문으로 출처를 주장해 이 권한을 얻을 수 없어요. 일반 mutation 메시지로 임의의 전체 기록을 교체하는 경로는 추가하지 않아요.

파일 종류·버전·허용 필드·식별자·시각·구간·합계·URL·크기를 페이지와 워커에서 검사해요. 확인 토큰은 문서·파일 해시·미리보기 의미에 결합해 메모리에 최대 8개, 5분 동안만 보관해요. 미리보기 이후 삭제·충돌·복원 범위가 달라지면 다시 확인하며, 기존 단일 쓰기 큐에서 최신 자료로 계산해 한 번 저장해요. 읽기·검사·한도·저장 실패에서 일부 기록만 적용하지 않아요.

파일에는 후원이 없고 기존 후원 원본·집계·조회 상태는 유지해요. 삭제 복원은 파일에 실제 포함된 시청·채팅으로 한정하며 삭제 장벽을 낮추지 않아요. `backupRestore`는 이 예외를 유지할 범위만 기록하고 채팅 본문은 복제하지 않아요. 일반 늦은 요청은 삭제된 기록을 되살리지 못하며, 복원 뒤 새 명시 삭제는 다시 적용돼요. `chatCutoffAt`은 후원 정리 시점을 바꾸지 않고 채팅의 재집계를 막아요.

## 기록·보존·삭제

원격 감사 로그·텔레메트리는 없어요. 광고·팝업·화질의 상태·시도 횟수·확장 ID 등 진단값은 현재 DOM에 표시될 수 있고 페이지에서 읽을 수 있어요. 횟수를 성공 보장으로 해석하지 않아요. 방송 알림의 마지막 확인 시각·오류와 최근 처리 방송은 기기의 local 상태로 남아요. 이를 모든 보안 행위를 기록하는 감사 시스템으로 설명하지 않아요.

실시간 활동 본문은 방송별 500개·전체 3,000개, 개별 본문은 400자로 제한돼요. 과거 후원 조회는 총 3,000건 범위이며 한도를 초과한 조회를 일부만 성공한 것처럼 저장하지 않아요. 오래된 실시간 본문이 정리돼도 집계는 남을 수 있어요. 로그인 쿠키·토큰, 원본 광고 응답 본문, 검색어·검색 결과의 영구 저장을 새로 추가하지 않아요.

기능을 끄는 것은 수집·동작 중지이며 기존 기록 삭제와 같지 않아요. 기록 페이지의 개별·전체 삭제, 후원 갱신 초기화, 확장 데이터 삭제·확장 제거가 각각 해당 데이터의 삭제 경로예요. 컴프레서의 탭별 상태는 탭 종료·브라우저 시작 시 정리하지만 새 탭이 이어받을 마지막 기본 선택은 기기 local에 보존해요. 기본 선택도 확장 데이터 삭제·제거로 지워요. Chrome sync 설정 삭제와 기기 local 기록 삭제의 범위를 혼동하지 않아요.

사이드바·채팅·댓글 너비는 기능을 꺼도 프로필 local에 보관하고 해당 경계의 마우스 더블클릭으로 선택을 초기화해요. 탭 종료·브라우저 재시작으로 지우지 않으며 확장 데이터 삭제 또는 확장 제거로 보관값을 지울 수 있어요.

## 새 기능 안내의 권한

안내 자료와 실행 코드는 패키지에 들어 있고 새 권한·원격 콘텐츠·분석 전송은 없어요. 자동 안내 선택은 sync 설정, 최신 안내 버전과 pending/seen/suppressed 한 건은 기기 local 상태예요. 임시 표시 토큰과 탭·문서 정체성은 워커 메모리에서만 관리해요. 네이버 계정·시청 기록·채팅·후원과 연결하지 않아요.

표시 요청은 같은 확장 ID, 최상위 탭, 정확한 치지직 출처와 현재 자료 버전을 검증해요. 소비 저장이 실패하면 표시를 승인하지 않아요. DOM에서 합성한 클릭으로 설정 탭을 여는 명령을 보내지 않아요. 명시적 설정 이동도 크기 조절·시청 기록·스트림 정보·방송 목록의 네 목적지만 허용하고 임의 URL을 받지 않아요. 옵션의 다시보기는 신뢰한 확장 옵션 문서에서만 시작하며 MAIN 브리지를 거치지 않아요.
