## 자동 검증

- 직전 블라인드 수정 완료 시 실행한 `npm.cmd run test:all`의 최종 결과는 620개 통과, 실패·건너뛰기 0개예요. 첫 실행의 카테고리 대기시간 초과와 추가 테스트 종료 정리 오류 이후, 종료 처리를 수정하고 다시 실행한 결과예요.
- 업데이트 알림 제거 후 `npm.cmd run test:all`을 다시 실행해 최종 608개 통과, 실패·건너뛰기 0개를 확인했어요. 제거된 알림 표시 동작 테스트를 제거 보장 테스트로 대체해 테스트 개수가 달라졌어요.
- 같은 최종 상태에서 `npm.cmd run lint`와 `npm.cmd run format:check`도 통과했어요.
- 후속 요청으로 업데이트 새로고침 알림·NEW 배지·알림 설정과 연결 스크립트를 제거했어요. 기존 알림 표시 테스트는 설치·업데이트 후 알림 재생성 방지, 배지/저장값 정리, 정리 실패 시 오류 확인, 설정 UI·주입 경로 제거 검사로 대체했어요. 튜토리얼 다시보기는 이미 제거된 상태이며 다시 노출되지 않는지 확인했어요.
- 새 블라인드 회귀 테스트는 역할 단어가 포함된 원문, 원문 속성 추가·수정·제거, 같은 ID의 행 교체, 다른 ID·작성자·재사용 표식과 ID 없는 행의 복원 방지, 캐시 상한·목록 교체·초기화를 다뤄요.
