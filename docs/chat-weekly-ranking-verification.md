# 주간 후원 랭킹 숨기기

- 실측일: 2026-09-12
- 대상 URL: https://chzzk.naver.com/live/b68af124ae2f1743a1dcbf5e2ab41e0b
- `aside#aside-chatting` 직계 자식인 랭킹 컨테이너를 확인했다. 접힌 상태는 직계 `_ranking_button_` 버튼, 펼친 상태는 `div > strong > button._refresh_button_` 헤더와 `_icon_ranking_` 항목을 가진다. 확인 후 원래 접힌 상태로 복원했다.
- CSS는 배포 해시를 고정하지 않고 이 구조에만 적용한다. 별도 관찰자·타이머·클릭을 추가하지 않으며 DOM 교체와 SPA 이동에도 적용된다. 설정 해제 시 스타일을 제거해 네이티브 상태를 복원한다.
- `chatWeeklyRankingHidden`은 기본 꺼짐이다. 옵션 위치는 채팅 → 댓글·표시이며 같은 영역의 통나무 파워 랭킹도 숨긴다고 안내한다.
- 자동 검사는 라이트·다크 테마에서 기본 표시, 숨김, 펼친 구조, SPA·재마운트, 옵션 해제·재활성화, 스타일 중복 방지를 확인한다. 채팅·보상·채팅 밖의 랭킹 유사 요소가 유지되는지도 검사한다.
- 실제 확장 다시 로드는 브라우저 도구의 확장 관리 페이지 접근 제한으로 수행하지 못했다. 수정본 주입과 좁은 실제 확장 팝업의 수동 검증은 남아 있다. 확장을 다시 로드하고 치지직을 새로고침한 뒤 옵션을 켜고 끌 때 랭킹 영역만 사라지고 복원되는지 확인한다.
