# Chrome 프로필 단위 기록 보관

## 배경

치지직 로그인 계정은 바뀔 수 있지만 확장 local 저장소와 기록 페이지는 Chrome 프로필에 속해요. 본인 후원 조회에는 계정 혼합 방지가 있지만, 저장된 전체 기록을 계정별로 숨기는 접근 통제는 없어요.

## 선택

Chrome 프로필 단위 보관을 유지해요. 로그아웃·계정 변경만으로 기존 시청·채팅·후원 기록을 숨기거나 삭제하지 않아요. 같은 프로필에 접근하는 사람은 기존 기록을 볼 수 있어요. 과거 후원 조회에서는 시작·완료 계정과 저장된 소유자를 검사해 다른 계정 내역을 합치지 않아요.

## 다른 선택과 차이

치지직 계정별 열람 분리는 기록 귀속·기존 데이터 처리·로그아웃 상태의 조회 정책까지 바꿔야 하는 별도 제품 범위예요. 이번에 그 요구를 추가하지 않고 기존 프로필 보관 방식을 유지하기로 했어요. 계정 전환 시 자동 삭제도 기존 기록 보존 방침과 다르므로 선택하지 않아요.

## 결과

프로필 안의 다른 치지직 계정 사용자로부터 기록을 격리한다고 약속하지 않아요. 개인정보 설명에서 ‘로컬 보관’과 ‘계정별 비공개’를 같은 의미로 쓰지 않아요. 기록 삭제는 명시적인 사용자 삭제 경로로 처리해요. 외부 백업·동기화가 필요하면 파일 처리·개인정보 범위를 따로 정해야 해요.
