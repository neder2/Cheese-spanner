# 입장 화질 개선과 네이티브 재생 경로

## 배경

광고 차단 프로그램을 사용하거나 그리드가 설치되지 않은 상황에서 치지직이 입장 화질을 낮게 두거나 고정하는 점을 개선하려고 자동 화질 기능을 사용해요. 사용자의 현재 관찰은 입장 후 직접 화질을 바꾸면 다시 낮아지지는 않는다는 것이에요. 이 관찰을 모든 방송 형식에 대한 확정 사실로 넓히지 않아요.

## 선택

자동 화질은 입장 시와 선호 화질 저장 시 현재 플레이어에 적용하는 목적을 가져요. 초기 플레이어 준비·첫 재생을 기다리는 것과 시청 내내 사용자 선택을 강제 복구하는 것을 구분해요. 자동 위치 보존 의도는 일시정지 후 재생에 한정하고, 사용자 seek·멀티뷰 목표 딜레이는 별도 명시적 조작으로 다뤄요.

현재의 네이티브 화질 선택 경로를 사용하고 폐기한 P2P 재생정보 변조를 되살리지 않아요. 확인할 수 없는 형식에서 별도 창·iframe·원격 실행 플레이어로 바꾸지 않아요.

## 다른 선택과 차이

항상 선호 화질로 복구하는 방식은 일시적인 화질 강등에 대응할 수 있지만 입장 개선이라는 요구보다 넓고 시청 중 선택과 충돌할 수 있어요. 현재 구현에 이런 재적용 계기가 남아 있으므로 문서상의 목적과 구현 완료를 구분해요.

재생정보를 수정하거나 별도 플레이어로 재생하면 네이티브 제약을 피할 수 있어도 기존 재생·채팅·라우터와 다른 흐름이 돼요. 기존 그리드 방식의 폐기와 임의 우회 금지 범위를 유지해요.

## 결과

독립 저지연 우선은 같은 해상도의 네이티브 트랙 선택으로 구현했지만, 2026-09-28 사용자 요청으로 옵션과 제어를 제거했어요. 기존 자동 화질 경로와 스트림 정보의 읽기 전용 관측은 유지해요. 폐기된 저장값으로 선택을 실행하거나 제거를 일반 트랙 강제로 바꾸지 않아요.

초기 재생·선택 완료·설정 변경과 늦은 응답의 경계를 검증해야 해요. 실제 응답·플레이어가 지원하지 않는 경로를 만들어 지원한다고 약속할 수 없어요. 현재의 넓은 재적용·위치 보정 경로를 이 결정에 맞춰 검토하는 후속 작업은 남아 있어요.
