# 시청·내 채팅의 선택적 백업과 보존 우선 병합

## 배경

시청 기록 저장소에는 시청 시간·본인 채팅과 실시간 후원·치지직에서 조회한 후원이 함께 있어요. 저장소 전체를 파일로 복사하면 사용자가 원하지 않는 후원 자료와 실행 상태까지 따라가요. 오래된 기록은 상세 내역이 정리되고 합계만 남아 서로 다른 파일 사이의 중복을 정확히 판별하지 못할 수 있어요.

## 선택

사용자가 확장에서 별도로 보관하는 시청·내 채팅만 전체 기간 JSON으로 내보내요. 실시간·조회 후원 모두 제외하고, 불러올 때 현재 후원과 파일에 없는 기록을 보존해요. 사용자가 적용 결과를 확인한 뒤 기존 기록에 합치기만 제공해요. 정확히 비교할 수 없는 기존 방송은 추정 합산하지 않고 건너뛴 이유를 보여줘요.

삭제했던 시청·채팅은 파일에 실제 들어 있는 자료만 의도적으로 복원해요. 기존 삭제 장벽을 낮추지 않고 그 복원 범위만 예외로 유지해 일반 늦은 요청과 구분해요. 이후 사용자의 새 삭제는 복원한 기록에도 적용돼요.

## 다른 선택과 제약

전체 저장소 복사는 구현이 단순하지만 후원을 모두 제외하려는 선택을 충족하지 못해요. 전체 교체는 백업에 없는 최신 기록을 잃을 수 있어 제공하지 않아요. 과거 합계의 덧셈이나 큰 값 선택은 중복과 누락을 증명할 수 없어 사용하지 않아요.

이 방식은 안전한 병합을 증명할 수 없는 항목을 자동 복원하지 못하는 제약이 있어요. 사용자는 건너뛴 항목을 확인할 수 있고, 원본 파일은 그대로 보관해요. 새 복원 정책을 추가하려면 현재 기록 보존·후원 제외·삭제 범위와의 관계를 다시 결정해야 해요.
