# 치지직 맞춤 디자인과 공통 테마 모듈

## 배경

치지직 안 확장 UI는 기능마다 자기 색 묶음과 대체값·모서리·그림자·글꼴을 따로 정해 화면마다 느낌이 달랐어요. 설정·기록 페이지는 별도의 회색·초록 팔레트였어요. 사용자는 2026-10-17에 세 화면을 '치지직과 한 몸처럼' 맞추기로 했어요.

## 선택

- 치지직 안 확장 UI의 공통 기준을 `shared/uiTheme.js` 하나에 둬요. 이 모듈은 첫 요청 때 `:root`에 `--bct-*` 변수와 단일 `"BetterChzzk Pretendard"` @font-face만 넣어요. 변수는 치지직 `--sem-*`를 그대로 따르고, 토큰이 없을 때 쓰는 대체값 표는 이 모듈에만 있어요. 기능은 `ensureUiTheme?.()`를 부르고 대체값 없이 `var(--bct-…)`를 써요.
- 확장 페이지는 `styles.css`의 기존 변수 이름을 유지하고 값만 치지직 실측값으로 바꿔요.
- 글꼴은 확장 소유 패널은 번들 Pretendard, 치지직 글꼴을 따르는 화면과 원본 끼움 요소는 원본 글꼴로 나눠요.

## 다른 선택과 제약

기능별 값만 표로 맞추는 방식은 manifest를 바꾸지 않아 작지만, 같은 값이 여러 파일에 반복돼 기능이 늘면 다시 어긋나요. 그래서 로드 순서 변경과 전체 검증을 감수하고 공통 모듈을 골랐어요. 확장 고유 브랜드 색은 치지직 안에서 '확장 화면'임을 드러내지만 '한 몸처럼' 목표와 맞지 않아 쓰지 않아요.

치지직 라이트 토큰은 일부 조합에서 작은 글자 4.5:1을 못 맞춰요. 그래서 선택 상태 표현이 제한되고, 확장 페이지의 위험색·경고색은 치지직 값 대신 대비가 맞는 기존 값을 써요. 치지직이 토큰 이름이나 테마 표식을 바꾸면 모듈의 대응표와 판별을 다시 실측해야 해요. 대체값은 토큰이 없을 때만 쓰여요.
