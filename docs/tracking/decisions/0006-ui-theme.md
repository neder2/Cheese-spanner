# 치지직 맞춤 디자인과 공통 테마 모듈

## 배경

치지직 안 확장 UI는 기능마다 자기 색 묶음과 대체값·모서리·그림자·글꼴을 따로 정해 화면마다 느낌이 달랐어요. 설정·기록 페이지는 별도의 회색·초록 팔레트였어요. 사용자는 2026-10-17에 세 화면을 '치지직과 한 몸처럼' 맞추기로 했어요.

## 선택

- 치지직 안 확장 UI의 공통 기준을 `shared/uiTheme.js` 하나에 둬요. 이 모듈은 첫 요청 때 `:root`에 `--bct-*` 변수와 단일 `"CheeseSpanner Pretendard"` @font-face만 넣어요. 변수는 치지직 `--sem-*`를 그대로 따르고, 토큰이 없을 때 쓰는 대체값 표는 이 모듈에만 있어요. 기능은 `ensureUiTheme?.()`를 부르고 대체값 없이 `var(--bct-…)`를 써요.
- 확장 페이지는 `styles.css`의 기존 변수 이름을 유지하고 값만 치지직 실측값으로 바꿔요.
- 설정·시청 기록·다시보기 대기 페이지는 저장한 화면 테마와 번들 Pretendard를 공유해요. 설정 편집 중인 색상은 설정 페이지에서 미리 보고 저장 시 열린 다른 페이지에도 적용해요.
- 헤더 진입 버튼·채널 동영상 검색·방송 목록 도구 모음·프로필 방송 시간처럼 원본에 끼우는 요소는 인접 원본의 글꼴을 상속하거나 복사해요. 방송 목록의 팔로워 수 배지는 라이트·다크 모두 짙은 남색 바탕에 밝은 글자와 Sandoll Nemony2를 써요. 카테고리 제외 선택 줄은 사용자 지정 글꼴 예외예요.
- 라이브·다시보기 멀티뷰 설정, 방송 목록 필터, 제외 추가 등 독립 패널과 팝오버는 번들 글꼴을 써요. 월간 방송 달력은 치지직의 Sandoll Nemony2 글꼴을 써요. 패널 제목은 15px·700, 닫기 버튼은 28px와 작은 모서리, 접근 가능한 이름과 초점 고리를 써요. 새 기능 안내는 작은 원형 닫기를 사용하는 알림이에요.
- 영상 위 조작·가이드는 플레이어의 글꼴과 영상에서 보이는 대비를 사용해요. 영상 내부 쌓임 순서와 문서의 팝오버·독립 대화상자·토스트 순서는 각각의 컨테이너에서 정해요. 2026-11-24 Chrome의 헤더(10000)·사이드바(9999)·네이티브 공유 카드(20010)와 기존 PiP(20000)에 맞춰 일반 팝오버는 10020, PiP 위에 열어야 하는 대화상자는 20001을 써요.
- 다시보기 댓글의 BEST 배지는 두 테마 모두 치지직 원본과 같은 녹색 바탕과 흰 글자의 39×18px 도형을 본문 맨 앞에 표시해요.
- 다시보기 댓글의 정렬 버튼은 원본처럼 13px Sandoll Nemony2와 구분점을 쓰고 선택한 정렬은 글자색으로 표시해요. 스티커는 너비 103px, 단일 사진은 너비 215px와 최대 높이 440px로 표시하고 좁은 패널에서는 본문 폭에 맞춰 줄여요.

입력은 약한 면색과 구분선, 기본 버튼은 호버 면색과 초점 고리를 써요. 제출 버튼은 브랜드 채움과 그 위 글자색을, 선택·펼침은 주 글자와 옅은 브랜드 면·테두리를 써요. 삭제는 동작 이름과 위험색을 함께 써요. 비활성 상태를 제외한 작은 보조문구와 입력 힌트에는 보조 글자색을 사용해요.

## 다른 선택과 제약

기능별 값만 표로 맞추는 방식은 manifest를 바꾸지 않아 작지만, 같은 값이 여러 파일에 반복돼 기능이 늘면 다시 어긋나요. 그래서 로드 순서 변경과 전체 검증을 감수하고 공통 모듈을 골랐어요. 확장 고유 브랜드 색은 치지직 안에서 '확장 화면'임을 드러내지만 '한 몸처럼' 목표와 맞지 않아 쓰지 않아요.

치지직 라이트 토큰은 일부 조합에서 작은 글자 4.5:1을 못 맞춰요. 그래서 선택 상태 표현이 제한되고, 확장 페이지의 라이트 위험색과 경고색은 치지직 값 대신 대비가 맞는 기존 값을 써요. 치지직이 토큰 이름이나 테마 표식을 바꾸면 모듈의 대응표와 판별을 다시 실측해야 해요. 대체값은 토큰이 없을 때만 쓰여요.
