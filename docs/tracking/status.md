상시 화면 확대에서 처음부터 실제 배율이 100%일 때는 아래 휠을 페이지 기본 스크롤에 넘겨요. 휠로 축소해 100%에 도달한 직후에는 이어지는 아래 휠을 막고 마지막으로 막힌 아래 휠부터 1초가 지나야 페이지에 전달해요. 대기 중 위 휠 확대는 즉시 가능하며 버튼 모드·볼륨과 컨트롤 조작은 유지해요. 옵션·라우트·영상 변경과 기존 초기화 경로는 대기 상태도 정리해요. 지연 동작의 수정 전 실패와 수정 후 확대·컨트롤 관련 26개 통과를 확인했어요. 실제 Chrome에서 100% 직후 페이지가 움직여 불편하다는 사용자 보고를 반영한 보완이며, 보완 후 실제 페이지 이동·확장 재주입은 아직 확인하지 않았어요.

화면 확대 대기를 1초로 변경한 뒤 전체 검사는 `npm.cmd run test:all` 1,041개 통과, 실패·취소·건너뜀 0개예요. 확대 관련 26개 검사와 전체 lint, 변경 파일 포맷, `git diff --check`도 통과했어요. 전체 포맷 검사는 별도 스트림 정보 작업의 `features/streamInfoModel.js`, `shared/liveTiming.js`, `tests/stream-info-model.test.js` 세 파일에서 실패했어요. 해당 파일은 이 변경에서 포맷하지 않았어요.

시청 기록 백업의 최종 보완 후 `npm.cmd run test:all`은 1,000개 통과, 실패·취소·건너뜀 0개예요. 다른 작업의 임시 보관 테스트 사본 두 개를 제외한 프로젝트 소스 전체 lint, `npm.cmd run format:check`, `git diff --check`도 종료 코드 0으로 통과했어요. 기본 lint는 그 사본에서 `require` 전역 선언 오류 8개로 실패해 별도로 기록했어요. 실제 Chrome 재로드·파일 대화상자·다운로드·복원과 라이트/다크 화면 검증은 수행하지 않았어요. 아래 자동 회귀 결과는 실제 브라우저 검증을 대신하지 않아요.

시청 기록 페이지에서 전체 기간의 시청·내 채팅을 JSON으로 백업하고 미리보기 확인 후 현재 기록에 합치는 기능을 구현했어요. 실시간·조회 후원은 모두 제외하고 현재 후원은 보존해요. 삭제했던 파일 내 자료만 명시적으로 복원하며, 중복 판단이 불가능한 기존 방송은 보존하고 건너뛴 이유를 안내해요. 옵션 페이지 안내와 사용법·개인정보·스토어 설명 원문도 갱신했어요. 새 권한·설정·버전 변경·배포는 없어요. 파일 검증, 병합, 워커 요청, UI의 네 테스트 묶음이 관련 경계를 보호해요.

## 구현과 의도의 차이

자동 화질은 입장 저화질 개선과 선호 화질 저장 시 즉시 반영이 목표예요. 독립 저지연 설정을 제거한 뒤에도 기존 자동 화질 경로에는 트랙 변경·플레이어 DOM 변화·옵션 갱신 뒤 재적용 경로가 남아 있어 전체 적용 계기의 후속 검토가 필요해요.

자동 위치 보존은 일시정지 후 재생에 한정한다는 의도가 확정됐어요. 현재 skipControl에는 별도 타임시프트 위치 가드가, 화질 코드에는 VOD 전환 후 위치 복원 경로가 있어 구분·검토가 필요해요. 멀티뷰의 명시적 딜레이 조작과 사용자 시간 이동은 별도 기능이에요.

같이보기 고정 제목 여백 보정은 미커밋 상태로 구현·회귀 검사돼 있어요. 새로고침 후 실제 확장 주입과 라이트·다크 배치 검증은 남아 있어요.

## 공개·개발·중단 상태

- 동영상 광고 차단은 공개된 실험 기능이고 기본 켜짐이에요. 확인된 형식만 처리하며 보장 범위를 확대하지 않아요.
- 광고 SKIP 버튼 자동 누르기 `adAutoSkip.js`는 개발 전용 코드예요. 옵션·자동 주입·배포 대상에서 제외되고 과거 저장값도 비활성으로 남아요. 출시 결정은 없어요.
- 클립 화질 선택은 관측한 복수 화질 소스는 있지만 안전한 플레이어 제어 경로가 없어 중단됐어요. 기능 코드·옵션·권한을 추가한 상태가 아니며, 제어 경로 실측이 재개 조건이에요.
- 그리드 재생정보 변조와 자동 단축키 실패 감지는 폐기 상태예요. 선택형 기본 단축키는 별개로 구현돼 있어요.
- 이전 화질 공지는 자동 표시가 중단됐고 템플릿 코드만 보관돼 있어요. 새 공지 일정은 확정하지 않았어요.
