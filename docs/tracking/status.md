## 구현과 의도의 차이

자동 화질은 입장 저화질 개선과 선호 화질 저장 시 즉시 반영이 목표예요. 독립 저지연 설정을 제거한 뒤에도 기존 자동 화질 경로에는 트랙 변경·플레이어 DOM 변화·옵션 갱신 뒤 재적용 경로가 남아 있어 전체 적용 계기의 후속 검토가 필요해요.

자동 위치 보존은 일시정지 후 재생에 한정한다는 의도가 확정됐어요. 현재 skipControl에는 별도 타임시프트 위치 가드가, 화질 코드에는 VOD 전환 후 위치 복원 경로가 있어 구분·검토가 필요해요. 멀티뷰의 명시적 딜레이 조작과 사용자 시간 이동은 별도 기능이에요.

같이보기 고정 제목 여백 보정은 미커밋 상태로 구현·회귀 검사돼 있어요. 새로고침 후 실제 확장 주입과 라이트·다크 배치 검증은 남아 있어요.

## 공개·개발·중단 상태

- 동영상 광고 차단은 공개된 실험 기능이고 기본 켜짐이에요. 확인된 형식만 처리하며 보장 범위를 확대하지 않아요.
- 광고 SKIP 버튼 자동 누르기 `adAutoSkip.js`는 개발 전용 코드예요. 옵션·자동 주입·배포 대상에서 제외되고 과거 저장값도 비활성으로 남아요. 출시 결정은 없어요.
- 클립 화질 선택은 관측한 복수 화질 소스는 있지만 안전한 플레이어 제어 경로가 없어 중단됐어요. 기능 코드·옵션·권한을 추가한 상태가 아니며, 제어 경로 실측이 재개 조건이에요.
- 그리드 재생정보 변조와 자동 단축키 실패 감지는 폐기 상태예요. 선택형 기본 단축키는 별개로 구현돼 있어요.
- 이전 화질 공지는 자동 표시가 중단됐고 템플릿 코드만 보관돼 있어요. 새 공지 일정은 확정하지 않았어요.

## 2026-10-03 카테고리 제외 후속 확인

필터 최상단 배치와 시청자 내림차순·확인된 0명 후보 제외·오른쪽 한 줄 표시를 보완했어요. 최종 전체 1,444개, lint·포맷 검사가 통과했고 실제 Mac Chrome에서 검색·추가·중복 방지·해제·새로고침 복원·숫자 필터 조합·두 테마를 확인했어요. 테스트 설정은 원복했어요. [상세 결과와 실제 UI 미실행 범위](../measurements/category-exclusions-mac-2026-10-03.md)를 구분해요. 커밋·push·릴리스는 하지 않았어요.

### 전체 방송 검색 적용 후속

전체 방송 우측 상단 `현재 목록 검색`에 적용 버튼·Enter 제출을 추가했어요. 입력 초안은 적용 검색어와 분리하며 카테고리 이름 검색·숫자 필터 조작은 유지해요. 실제 Chrome에서 타이핑 중 결과 유지·적용 클릭·Enter·새로고침 초기화를 확인했고 사용자 GTA V 제외 항목을 보존했어요. 세부 검증은 위 Mac 기록의 후속 절에 있어요.

### VOD 검색 원본 쪽수 버튼

2026-10-03 실제 Chrome에서 검색 결과 0개와 원본 1·2 페이지 버튼이 함께 표시되는 현상을 재현했어요. 숫자만 있는 현재 페이지 DOM을 식별하고 검색 종료·DOM 교체 때 복원하도록 보완했어요. 검색·원본 페이지 이동·뒤로/앞으로·Escape의 실제 결과와 자동 회귀는 [VOD 검색 페이지 버튼 기록](../measurements/vod-search-pagination-2026-10-03.md)에 구분했어요.
