## 소스와 확인 범위

2026-10-01 최종 자동 검증이며 작업 branch `1.4.1`, 기준 HEAD `01e9358e7b81b695dbd779af2b2745daea901b99`의 카테고리 제외 작업 트리를 대상으로 해요. 작업·HTTP 확인은 2026-09-30에 시작했어요. manifest·package 버전은 1.4.1을 유지했어요. 버전·branch 변경, 커밋·push·병합·태그·Release·스토어 제출은 수행하지 않았어요. 앞선 릴리스의 실제 화면 확인은 이번 변경의 확인 결과가 아니에요.

구현은 기존 방송 목록 검색·필터가 켜진 전체 방송(`/lives`)의 필터 메뉴에만 연결돼요. 실제 카테고리 이름 검색·최대 100개의 선택·개별 해제, 정확한 유형·ID 판정, 인기·최신·추천과 원본·추가 카드의 제외를 제공해요. 숫자 필터 초기화는 제외 목록을 유지하고 전체 방송 집계도 독립이에요. 선택은 프로필 local에 지속 보관하며 전용 워커 큐의 개별 변경과 저장소 구독으로 열린 탭에 반영해요. 검색어·검색 결과는 메모리에서만 유지해요.

## HTTP와 공식 공개 코드 확인

2026-09-30 인증정보 없는 GET `https://api.chzzk.naver.com/manage/v1/auto-complete/categories?keyword=%EB%A7%88%EB%A6%AC%EB%AA%A8&size=50`은 HTTP 200·code 200과 `content.results`를 반환했어요. 관측한 항목은 `categoryType:GAME`, `categoryId:Marimo_League`, `categoryValue:마리모 리그`예요. GET `https://api.chzzk.naver.com/service/v1/categories/GAME/Marimo_League/info`에서 `openLiveCount:0`을 확인해 그 시점에 방송이 없는 게임도 검색 결과에 포함됨을 확인했어요. 현재 방송 수의 영구 보장은 아니에요.

이름 검색 endpoint는 [공식 스튜디오 공개 코드](https://ssl.pstatic.net/static/nng/glive-center/resource/p/static/js/index-DgDGwqgY.js)에서 확인했어요. 전체 라이브 HTTP 항목의 카테고리 필드는 categoryType·liveCategory·liveCategoryValue이며, [공식 일반 페이지 공개 코드](https://ssl.pstatic.net/static/nng/glive/resource/p/static/js/index-BBIPHoDO.js)에는 `/category/${n.categoryType}/${n.liveCategory}/lives` 링크 구성이 있어요. 유형·ID를 그대로 사용하는 근거이며 실제 Chrome의 현재 원본 카드 href를 읽은 결과는 아니에요.

Origin `https://chzzk.naver.com`을 보낸 HTTP 확인에서는 `Access-Control-Allow-Origin:https://chzzk.naver.com`, `Access-Control-Allow-Credentials:true`를 관측했어요. 이는 실제 Chrome isolated 요청의 CORS·기존 로그인 세션 전달·검색 성공을 증명하지 않아요. 확장 요청에는 별도 토큰이나 새로운 host 권한을 추가하지 않았어요.

## 실제 Chrome 미검증과 최소 수동 절차

실제 Chrome 확인은 아래 모든 항목이 미검증이에요. 명시적 재요청 전에는 컴퓨터 사용을 하지 않는 제한을 유지했고 다른 브라우저 제어로 우회하지 않았어요. 현재 소스를 로드한 확장과 같은 Chrome 프로필에서 확인하며, 확인한 날짜·소스·URL·조건·결과를 따로 남겨요.

먼저 기존 제외 항목과 검색·필터/집계 설정·테마를 기록해요. 종료할 때 이번 확인에서 추가한 항목만 `제외 해제`로 정리하고 원래 설정·테마로 돌려요. 기존 선택 전체 초기화와 사용자 저장소의 임의 삭제는 하지 않아요.
